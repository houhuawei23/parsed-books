# 第3章 复杂度 - 详细学习材料

## 一、本章概述

### 1.1 为什么研究复杂度？

从第2章的PAC学习理论可以看出，**假设空间 $\mathcal{H}$ 的复杂度**直接影响：

1. **可学性**：复杂度过高可能导致不可学
2. **样本复杂度**：复杂度越高，需要的样本越多
3. **泛化能力**：复杂度过高容易过拟合

**核心问题**：对于**无限假设空间**，如何刻画其复杂度？

### 1.2 本章知识架构

```

```

## 二、3.1 分布无关复杂度 - 深度解析

### 2.1 增长函数（Growth Function）

#### 限制（Restriction）

**定义**：假设空间 $\mathcal{H}$ 在数据集 $D = \{\boldsymbol{x}_1, \ldots, \boldsymbol{x}_m\}$ 上的限制为：

$$\mathcal{H}_{|D} = \{(h(\boldsymbol{x}_1), \ldots, h(\boldsymbol{x}_m)) \mid  h \in \mathcal{H}\}$$

**含义**：

- 将无限假设空间在有限数据集上"投影"
- 结果是一个有限的向量集合
- 每个向量代表一种对样本的标记方式

**等价关系**：
若两个假设 $h_1, h_2$ 在 $D$ 上取值相同，则称 $h_1 \sim_D h_2$（在 $D$ 上等价）。
$\mathcal{H}_{|D}$ 是 $\mathcal{H}$ 关于 $\sim_D$ 的**等价类集合**。

#### 增长函数定义

**定义**：假设空间 $\mathcal{H}$ 的增长函数为：

$$\Pi_{\mathcal{H}}(m) = \max_{\{\boldsymbol{x}_1, \ldots, \boldsymbol{x}_m\} \subset \mathcal{X}} |\mathcal{H}_{|D}|$$

**含义**：

- 对 $m$ 个样本，假设空间能赋予的**最大不同标记数**
- 度量假设空间的"表达能力"
- 反映假设空间的复杂程度

**例子**：二分类问题中，$\Pi_{\mathcal{H}}(m) \leqslant 2^m$

---

### 2.2 VC维（Vapnik-Chervonenkis Dimension）

#### 对分（Dichotomy）与打散（Shattering）

**对分**：假设 $h$ 对 $D$ 中样本的标记结果称为一种对分（将 $D$ 分为正、负两类）。

**打散**：若假设空间 $\mathcal{H}$ 能实现样本集 $D$ 上的**所有对分**，即 $|\mathcal{H}_{|D}| = 2^m$，则称 $D$ 能被 $\mathcal{H}$ **打散**。

**直观理解**：

- "打散"意味着假设空间足够"强大"，可以对样本进行任意标记
- 若 $m$ 个样本被打散，则 $\Pi_{\mathcal{H}}(m) = 2^m$

#### VC维定义

**定义 3.1**：假设空间 $\mathcal{H}$ 的VC维是能被 $\mathcal{H}$ 打散的最大样本集的大小：

$$VC(\mathcal{H}) = \max\{m : \Pi_{\mathcal{H}}(m) = 2^m\}$$

**关键性质**：

- $VC(\mathcal{H}) = d$ 表示**存在**大小为 $d$ 的样本集能被 $\mathcal{H}$ 打散
- 但**不意味着**所有大小为 $d$ 的样本集都能被打散
- VC维与数据分布**无关**，只与假设空间结构有关

#### VC维计算：两步法

要证明 $VC(\mathcal{H}) = d$，需要证明两点：

1. **存在性**：找到大小为 $d$ 的样本集能被 $\mathcal{H}$ 打散
2. **最大性**：任意大小为 $d+1$ 的样本集**不能**被 $\mathcal{H}$ 打散

---

### 2.3 VC维计算实例

#### 阈值函数的VC维

**假设空间**：$\mathcal{H} = \{h_a : a \in \mathbb{R}\}$，$h_a(x) = \text{sign}(\mathbb{I}(x < a) - 1/2)$

**分析**：

- **$m=1$**：能打散。对单点 $\{x_1\}$，取 $a = x_1 + 1$ 得+1，取 $a = x_1 - 1$ 得-1。
- **$m=2$**：不能打散。对 $x_1 < x_2$，无法实现 $(+1, -1)$ 的标记。

**结论**：$VC(\mathcal{H}) = 1$

#### 区间函数的VC维

**假设空间**：$\mathcal{H} = \{h_{a,b} : a, b \in \mathbb{R}, a < b\}$，$h_{a,b}(x) = \text{sign}(\mathbb{I}(x \in (a,b)) - 1/2)$

**分析**：

- **$m=2$**：能打散。对 $\{1, 2\}$，所有4种标记都能实现。
- **$m=3$**：不能打散。对 $x_1 < x_2 < x_3$，无法实现 $(+1, -1, +1)$。

**结论**：$VC(\mathcal{H}) = 2$

#### 齐次线性超平面的VC维

**定理 3.5**：$\mathbb{R}^d$ 中齐次线性超平面构成的假设空间 $\mathcal{H}$ 的VC维为 $d$。

**证明**：

1. **$VC(\mathcal{H}) \geqslant d$**：
   - 取 $D = \{\boldsymbol{e}_1, \ldots, \boldsymbol{e}_d\}$（标准基向量）
   - 对任意标记 $(y_1, \ldots, y_d) \in \{-1,+1\}^d$
   - 取 $\boldsymbol{w} = (y_1; \ldots; y_d)$，则 $\boldsymbol{w}^T \boldsymbol{e}_i = y_i$
   - 因此 $D$ 被打散

2. **$VC(\mathcal{H}) \leqslant d$**：
   - 对任意 $d+1$ 个向量 $\{\boldsymbol{x}_1, \ldots, \boldsymbol{x}_{d+1}\}$
   - 必存在不全为零的 $a_1, \ldots, a_{d+1}$ 使得 $\sum a_i \boldsymbol{x}_i = \boldsymbol{0}$
   - 取 $I = \{i : a_i > 0\}$，$J = \{j : a_j < 0\}$
   - 无法实现标记：$y_i = +1$（$i \in I$），$y_j = -1$（$j \in J$）

#### 非齐次线性超平面的VC维

**定理 3.6**：$\mathbb{R}^d$ 中非齐次线性超平面的VC维为 $d+1$。

**证明思路**：

- 转化为 $d+1$ 维的齐次问题
- 令 $\boldsymbol{w}' = (\boldsymbol{w}; b)$，$\boldsymbol{x}' = (\boldsymbol{x}; 1)$
- 则 $\boldsymbol{w}^T \boldsymbol{x} + b = \boldsymbol{w}'^T \boldsymbol{x}'$

### 2.4 Sauer引理与增长函数上界

#### Sauer引理（引理 3.1）

若假设空间 $\mathcal{H}$ 的VC维为 $d$，则对任意 $m \in \mathbb{N}$：

$$\Pi_{\mathcal{H}}(m) \leqslant \sum_{i=0}^d \binom{m}{i}$$

**证明思路**（数学归纳法）：

1. 基础情形：$m=1$ 或 $d=0$ 显然成立
2. 归纳步骤：考虑 $D = \{\boldsymbol{x}_1, \ldots, \boldsymbol{x}_m\}$ 和 $D' = \{\boldsymbol{x}_1, \ldots, \boldsymbol{x}_{m-1}\}$
3. 关键观察：$\mathcal{H}_{|D}$ 中的串可以按最后一个分量分为"出现一次"和"出现两次"
4. 利用组合恒等式 $\binom{m}{i} = \binom{m-1}{i} + \binom{m-1}{i-1}$

#### 增长函数的指数上界

**定理 3.1**：若 $VC(\mathcal{H}) = d$，则对 $m \geqslant d$：

$$\Pi_{\mathcal{H}}(m) \leqslant \left(\frac{e \cdot m}{d}\right)^d$$

**证明要点**：

```
Π_ℋ(m) ≤ Σᵢ₌₀ᵈ C(m,i)
        ≤ Σᵢ₌₀ᵈ C(m,i)(m/d)^(d-i)    [因为 m/d ≥ 1]
        = (m/d)^d Σᵢ₌₀ᵈ C(m,i)(d/m)^i
        ≤ (m/d)^d Σᵢ₌₀^m C(m,i)(d/m)^i
        = (m/d)^d (1 + d/m)^m
        ≤ (m/d)^d e^d
        = (em/d)^d
```

**关键洞察**：

- 当 $m \leqslant d$ 时：$\Pi_{\mathcal{H}}(m) = 2^m$（指数增长）
- 当 $m > d$ 时：$\Pi_{\mathcal{H}}(m) \leqslant (em/d)^d$（多项式增长）

VC维是增长函数从**指数增长**转变为**多项式增长**的临界点！

---

### 2.5 有限假设空间与VC维

**关系**：对有限假设空间 $\mathcal{H}$，有 $VC(\mathcal{H}) \leqslant \log_2 |\mathcal{H}|$。

**证明**：若 $m > \log_2 |\mathcal{H}|$，则 $|\mathcal{H}| < 2^m$，无法打散 $m$ 个样本。

**注意**：$VC(\mathcal{H})$ 通常远小于 $\log_2 |\mathcal{H}|$。因此VC维是更精确的复杂度度量。

---

### 2.6 Natarajan维（多分类扩展）

#### 多分类问题的挑战

VC维是针对二分类定义的。对于多分类问题（$\mathcal{Y} = \{0, \ldots, K-1\}$），需要扩展。

#### 打散的定义（多分类）

对集合 $D \subset \mathcal{X}$，若存在两个假设 $f_0, f_1: D \to \mathcal{Y}$ 满足：

1. 对所有 $\boldsymbol{x} \in D$，$f_0(\boldsymbol{x}) \neq f_1(\boldsymbol{x})$
2. 对任意 $B \subset D$，存在 $h \in \mathcal{H}$ 使得：
   - $\forall \boldsymbol{x} \in B: h(\boldsymbol{x}) = f_0(\boldsymbol{x})$
   - $\forall \boldsymbol{x} \in D \setminus B: h(\boldsymbol{x}) = f_1(\boldsymbol{x})$

则称 $D$ 能被 $\mathcal{H}$ 打散。

#### Natarajan维定义

**定义 3.2**：多分类假设空间 $\mathcal{H}$ 的Natarajan维为：

$$\text{Natarajan}(\mathcal{H}) = \max\{|D| : D \text{ 能被 } \mathcal{H} \text{ 打散}\}$$

**定理 3.2**：当类别数 $K=2$ 时，$VC(\mathcal{H}) = \text{Natarajan}(\mathcal{H})$。

**定理 3.3**：若Natarajan维为 $d$，类别数为 $K$，则：

$$\Pi_{\mathcal{H}}(m) \leqslant m^d K^{2d}$$

## 三、3.2 分布相关复杂度 - 深度解析

### 3.1 VC维的局限性

**问题**：VC维是**分布无关**的。

**后果**：

- 优点：对任意数据分布都成立，普适性强
- 缺点：未考虑数据特点，分析结果可能"过松"
- 对"坏"分布给出的界可能很悲观

**解决方案**：引入**数据分布相关**的复杂度度量

---

### 3.2 Rademacher复杂度

#### 基本思想

考虑假设空间拟合**随机噪声**的能力：

- 若假设空间能完美拟合随机噪声，则复杂度高
- 若假设空间难以拟合随机噪声，则复杂度低

#### Rademacher随机变量

**定义**：随机变量 $\sigma_i$ 以0.5概率取值+1，以0.5概率取值-1。

**作用**：模拟随机标记（噪声）。

#### 经验Rademacher复杂度

**定义 3.3**：函数空间 $\mathcal{F}$ 关于 $Z = \{z_1, \ldots, z_m\}$ 的经验Rademacher复杂度为：

$$\widehat{\mathfrak{R}}_Z(\mathcal{F}) = \mathbb{E}_{\boldsymbol{\sigma}}\left[\sup_{f \in \mathcal{F}} \frac{1}{m} \sum_{i=1}^m \sigma_i f(z_i)\right]$$

**含义**：

- 内层 $\sup$：假设空间中最能拟合噪声 $\sigma$ 的假设
- 外层期望：对随机噪声取平均
- 结果 $\in [0, 1]$：值越接近1，复杂度越高

**与增长函数的联系**：

- 当 $\widehat{\mathfrak{R}}_Z(\mathcal{H}) = 1$ 时，对任意 $\sigma$，存在 $h$ 使 $h(\boldsymbol{x}_i) = \sigma_i$
- 即 $\Pi_{\mathcal{H}}(m) = 2^m$，$\mathcal{H}$ 能打散 $Z$

#### Rademacher复杂度

**定义 3.4**：函数空间 $\mathcal{F}$ 关于 $\mathcal{Z}$ 在分布 $\mathcal{D}$ 上的Rademacher复杂度为：

$$\mathfrak{R}_m(\mathcal{F}) = \mathbb{E}_{Z \subset \mathcal{Z}: |Z|=m}[\widehat{\mathfrak{R}}_Z(\mathcal{F})]$$

**特点**：

- 考虑了数据分布 $\mathcal{D}$
- 为具体学习问题"量身定制"
- 通常给出比VC维更紧的界

---

### 3.3 Rademacher复杂度与增长函数的关系

**定理 3.4**（Massart引理）：令 $A \subset \mathbb{R}^m$ 为有限集合，$r = \max_{\boldsymbol{x} \in A} \|\boldsymbol{x}\|$，则：

$$\mathbb{E}_{\boldsymbol{\sigma}}\left[\frac{1}{m} \sup_{\boldsymbol{x} \in A} \sum_{i=1}^m \sigma_i x_i\right] \leqslant \frac{r\sqrt{2\ln|A|}}{m}$$

**推论 3.1**：

$$\mathfrak{R}_m(\mathcal{H}) \leqslant \sqrt{\frac{2 \ln \Pi_{\mathcal{H}}(m)}{m}}$$

**证明要点**：

- 对 $D = \{\boldsymbol{x}_1, \ldots, \boldsymbol{x}_m\}$，$\mathcal{H}_{|D}$ 是有限集合
- 元素为模长 $\sqrt{m}$ 的向量（因 $h(\boldsymbol{x}) \in \{-1, +1\}$）
- 应用定理3.4

---

### 3.4 Gaussian复杂度

**定义 3.5-3.6**：将Rademacher随机变量 $\sigma_i$ 替换为标准正态随机变量 $g_i \sim \mathcal{N}(0,1)$，得到Gaussian复杂度 $\widehat{\mathfrak{G}}_Z(\mathcal{F})$ 和 $\mathfrak{G}_m(\mathcal{F})$。

**与Rademacher复杂度的关系**：

- 两者在刻画复杂度上等价（相差常数倍）
- Rademacher更常用（取值有界，分析更方便）
- Gaussian在某些场景下分析更便利

## 四、3.3 分析实例 - 深度解析

### 4.1 线性超平面的Rademacher复杂度

**定理 3.7**：若 $\|\boldsymbol{x}\| \leqslant r$，$D$ 为大小为 $m$ 的数据集，则超平面族 $\mathcal{H} = \{\boldsymbol{x} \mapsto \boldsymbol{w}^T \boldsymbol{x} : \|\boldsymbol{w}\| \leqslant \Lambda\}$ 的经验Rademacher复杂度满足：

$$\widehat{\mathfrak{R}}_D(\mathcal{H}) \leqslant \sqrt{\frac{r^2 \Lambda^2}{m}}$$

**证明要点**：

```
ℜ̂_D(ℋ) = (1/m) 𝔼_σ[sup_{‖w‖≤Λ} Σ σᵢ w^T xᵢ]
        = (1/m) 𝔼_σ[sup_{‖w‖≤Λ} w^T (Σ σᵢ xᵢ)]
        ≤ (Λ/m) 𝔼_σ[‖Σ σᵢ xᵢ‖]                 [Cauchy-Schwarz]
        ≤ (Λ/m) [𝔼_σ[‖Σ σᵢ xᵢ‖²]]^(1/2)         [Jensen]
        = (Λ/m) [Σ ‖xᵢ‖²]^(1/2)                [σᵢ独立，𝔼[σᵢσⱼ]=0]
        ≤ (Λ/m) √(mr²)
        = √(r²Λ²/m)
```

**关键洞察**：

- Rademacher复杂度随 $\Lambda$ 增大而增大（模型越复杂）
- 随 $m$ 增大而减小（数据越多，估计越准）
- 与数据范数 $r$ 成正比

### 4.2 支持向量机的VC维

**问题**：SVM使用核函数映射到高维空间，VC维可能很大甚至无穷。

**解决方案**：限制超平面的范数。

**定理 3.8**：若 $\|\boldsymbol{x}\| \leqslant r$，考虑超平面族 $\{\boldsymbol{x} \mapsto \text{sign}(\boldsymbol{w}^T \boldsymbol{x}) : \min_{\boldsymbol{x}} |\boldsymbol{w}^T \boldsymbol{x}| = 1, \|\boldsymbol{w}\| \leqslant \Lambda\}$，则VC维 $d$ 满足：

$$d \leqslant r^2 \Lambda^2$$

**证明要点**：

1. 设 $\{\boldsymbol{x}_1, \ldots, \boldsymbol{x}_d\}$ 被打散，则对任意 $(y_1, \ldots, y_d) \in \{-1,+1\}^d$，存在 $\boldsymbol{w}$ 使 $y_i (\boldsymbol{w}^T \boldsymbol{x}_i) \geqslant 1$
2. 求和得：$d \leqslant \boldsymbol{w}^T \sum y_i \boldsymbol{x}_i \leqslant \|\boldsymbol{w}\| \|\sum y_i \boldsymbol{x}_i\|$
3. 对随机 $y_i$ 取期望，利用 $\mathbb{E}[y_i y_j] = \delta_{ij}$
4. 最终得到 $\sqrt{d} \leqslant \Lambda r$

**意义**：

- 通过控制 $\|\boldsymbol{w}\| \leqslant \Lambda$，可以限制SVM的有效VC维
- 解释了SVM正则化 $\frac{\lambda}{2}\|\boldsymbol{w}\|^2$ 的作用

### 4.3 多层神经网络的VC维

**网络结构**：$l$ 层网络，$d_i$ 个神经元在第 $i$ 层，符号激活函数 $\varphi(t) = \text{sign}(t)$。

**函数族表示**：
$$\mathcal{F} = \mathcal{F}^{(l)} \circ \cdots \circ \mathcal{F}^{(2)} \circ \mathcal{F}^{(1)}$$

**增长函数上界**（引理3.2、3.3）：

$$\Pi_{\mathcal{F}}(m) \leqslant (e \cdot m)^N$$

其中 $N = \sum_{i=1}^l \sum_{j=1}^{d_i} (d_{i-1} + 1)$ 是总参数数目。

**定理 3.9**：多层神经网络的VC维为 $O(N \log N)$。

**证明**：设VC维为 $d$，则 $\Pi_{\mathcal{F}}(d) = 2^d \leqslant (ed)^N$，解得 $d = O(N \log N)$。

## 五、复杂度度量对比总结

### 5.1 三种复杂度度量对比

| 特性     | 增长函数 | VC维     | Rademacher复杂度 |
| -------- | -------- | -------- | ---------------- |
| 分布相关 | 否       | 否       | 是               |
| 计算难度 | 困难     | 中等     | 困难             |
| 紧致性   | 基准     | 较松     | 较紧             |
| 适用范围 | 二分类   | 二分类   | 一般函数类       |
| 主要用途 | 理论分析 | 快速估计 | 精细分析         |

### 5.2 VC维与Rademacher复杂度的选择

- **快速估算**：使用VC维
- **精细分析**：使用Rademacher复杂度
- **理论推导**：两者结合

### 5.3 不同假设空间的复杂度

| 假设空间                           | VC维         | Rademacher复杂度           |
| ---------------------------------- | ------------ | -------------------------- |
| 阈值函数                           | 1            | $O(1/\sqrt{m})$            |
| 区间                               | 2            | $O(1/\sqrt{m})$            |
| 齐次线性超平面（$\mathbb{R}^d$）   | $d$          | $O(\sqrt{r^2\Lambda^2/m})$ |
| 非齐次线性超平面（$\mathbb{R}^d$） | $d+1$        | $O(\sqrt{r^2\Lambda^2/m})$ |
| 轴平行矩形                         | $2d$         | —                          |
| 神经网络                           | $O(N\log N)$ | —                          |
