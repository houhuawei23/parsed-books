## 章节概述

### 7.1 什么是收敛率？

**收敛率 (Convergence Rate)** 是优化理论中的核心概念，它描述了优化算法逼近最优解的速度。在机器学习中，训练模型通常需要求解一个优化问题，收敛率告诉我们"算法需要多少轮迭代才能达到满意的解"。

#### 直观理解

想象你在爬山寻找最高点：

- **梯度下降**：每次都朝着最陡的方向走一步
- **收敛率**：告诉你需要走多少步才能到达山顶附近
- **不同地形**：平缓的山坡和陡峭的悬崖需要不同的策略

### 7.2 优化问题的一般形式

**标准形式**：
$$\min_{\boldsymbol{w} \in \mathcal{W}} f(\boldsymbol{w})$$

其中：

- $f(\cdot)$：目标函数（如损失函数）
- $\boldsymbol{w}$：优化变量（如模型参数）
- $\mathcal{W}$：可行域（如参数约束集合）

**本章关注**：凸优化问题

- 目标函数 $f(\cdot)$ 是**凸函数**
- 可行域 $\mathcal{W}$ 是**凸集合**

## 核心概念详解

### 概念1：收敛率与迭代复杂度

**收敛率**：描述优化误差 $f(\boldsymbol{w}_T) - f(\boldsymbol{w}^*)$ 与迭代轮数 $T$ 之间的关系。

**常见的收敛率**：

| 收敛率          | 名称       | 速度 |
| --------------- | ---------- | ---- |
| $O(1/\sqrt{T})$ | 次线性收敛 | 慢   |
| $O(1/T)$        | 次线性收敛 | 中等 |
| $O(1/T^2)$      | 次线性收敛 | 快   |
| $O(1/\beta^T)$  | 线性收敛   | 很快 |

**迭代复杂度**：为了达到 $\epsilon$-最优解（即 $f(\boldsymbol{w}_T) - f(\boldsymbol{w}^*) \leqslant \epsilon$），需要的迭代轮数 $T$。

**收敛率与迭代复杂度的对应关系**：

| 收敛率          | 迭代复杂度                  |
| --------------- | --------------------------- |
| $O(1/\sqrt{T})$ | $\Omega(1/\epsilon^2)$      |
| $O(1/T)$        | $\Omega(1/\epsilon)$        |
| $O(1/T^2)$      | $\Omega(1/\sqrt{\epsilon})$ |
| $O(1/\beta^T)$  | $\Omega(\log(1/\epsilon))$  |

**直观理解**：

- 收敛率越快，达到相同精度需要的迭代次数越少
- 线性收敛意味着误差以几何级数下降
- 实际应用中，线性收敛通常比多项式收敛快得多

### 概念2：优化算法的分类

根据使用的函数信息，优化算法分为三类：

#### 零阶算法 (Zero-order Methods)

- **信息**：仅使用函数值 $f(\boldsymbol{w})$
- **特点**：不需要梯度信息
- **代表算法**：
  - 遗传算法 (Genetic Algorithm)
  - 粒子群算法 (Particle Swarm Optimization)
  - 模拟退火 (Simulated Annealing)
- **适用场景**：梯度难以计算或不存在

#### 一阶算法 (First-order Methods)

- **信息**：使用函数值和梯度 $\nabla f(\boldsymbol{w})$
- **特点**：计算代价相对较低
- **代表算法**：
  - 梯度下降 (Gradient Descent, GD)
  - 随机梯度下降 (Stochastic Gradient Descent, SGD)
  - 加速梯度法 (Accelerated Gradient Methods)
- **适用场景**：大规模机器学习问题

#### 二阶算法 (Second-order Methods)

- **信息**：使用函数值、梯度和Hessian矩阵 $\nabla^2 f(\boldsymbol{w})$
- **特点**：收敛快但计算代价高
- **代表算法**：
  - 牛顿法 (Newton's Method)
  - 拟牛顿法 (Quasi-Newton Methods, 如L-BFGS)
- **适用场景**：中小规模问题，需要快速收敛

### 概念3：关键数学概念

#### Lipschitz连续性

**定义**：函数 $f$ 满足 $l$-Lipschitz连续，如果对任意 $\boldsymbol{u}, \boldsymbol{v} \in \mathcal{W}$：
$$\|\nabla f(\boldsymbol{u})\| \leqslant l$$

或等价地：
$$|f(\boldsymbol{u}) - f(\boldsymbol{v})| \leqslant l\|\boldsymbol{u} - \boldsymbol{v}\|$$

**意义**：

- 梯度有界，函数变化不会太快
- 保证梯度下降的稳定性
- 大多数机器学习损失函数都满足Lipschitz连续

#### 强凸性 (Strong Convexity)

**定义**：函数 $f$ 是 $\lambda$-强凸的，如果对任意 $\boldsymbol{u}, \boldsymbol{v} \in \mathcal{W}$：
$$f(\boldsymbol{u}) \geqslant f(\boldsymbol{v}) + \langle \nabla f(\boldsymbol{v}), \boldsymbol{u} - \boldsymbol{v} \rangle + \frac{\lambda}{2}\|\boldsymbol{u} - \boldsymbol{v}\|^2$$

**直观理解**：

- 函数在任何点的曲率至少为 $\lambda$
- 强凸函数有唯一全局最小值
- 比普通凸函数"更凸"，优化更容易

**性质**（定理 7.2）：

若 $f$ 为 $\lambda$-强凸函数，$\boldsymbol{w}^*$ 为其最优解，则对任意 $\boldsymbol{w} \in \mathcal{W}$：

1. **函数值下界**：
   $$f(\boldsymbol{w}) - f(\boldsymbol{w}^*) \geqslant \frac{\lambda}{2}\|\boldsymbol{w} - \boldsymbol{w}^*\|^2$$

2. **距离上界**（若梯度有界 $l$）：
   $$\|\boldsymbol{w} - \boldsymbol{w}^*\| \leqslant \frac{2l}{\lambda}$$

3. **函数值上界**（若梯度有界 $l$）：
   $$f(\boldsymbol{w}) - f(\boldsymbol{w}^*) \leqslant \frac{2l^2}{\lambda}$$

#### 光滑性 (Smoothness)

**定义**：函数 $f$ 是 $\gamma$-光滑的，如果对任意 $\boldsymbol{w}, \boldsymbol{w}' \in \mathcal{W}$：
$$f(\boldsymbol{w}') \leqslant f(\boldsymbol{w}) + \langle \nabla f(\boldsymbol{w}), \boldsymbol{w}' - \boldsymbol{w} \rangle + \frac{\gamma}{2}\|\boldsymbol{w}' - \boldsymbol{w}\|^2$$

**直观理解**：

- 函数在任何点的曲率至多为 $\gamma$
- 可以用二次函数作为上界
- 光滑函数的梯度变化不会太剧烈

**与强凸性的关系**：

- 强凸性提供下界，光滑性提供上界
- 若函数既强凸又光滑，则 $\lambda \leqslant \gamma$
- 条件数：$\kappa = \gamma/\lambda$，影响收敛速度

## 确定优化

### 7.2.1 凸函数的梯度下降

**算法流程**：

```
输入: 初始点 w_1 ∈ W, 步长 η, 迭代轮数 T
for t = 1, ..., T do:
    计算梯度: g_t = ∇f(w_t)
    梯度下降: w_{t+1}' = w_t - η * g_t
    投影: w_{t+1} = Π_W(w_{t+1}')
end for
返回: w̄_T = (1/T) * Σ_{t=1}^T w_t
```

**投影操作**：
$$\Pi_{\mathcal{W}}(\boldsymbol{z}) = \arg\min_{\boldsymbol{x} \in \mathcal{W}}\|\boldsymbol{x} - \boldsymbol{z}\|$$

投影保证迭代点始终在可行域内。

**投影的非扩展性**（重要性质）：
$$\|\Pi_{\mathcal{W}}(\boldsymbol{x}) - \Pi_{\mathcal{W}}(\boldsymbol{z})\| \leqslant \|\boldsymbol{x} - \boldsymbol{z}\|, \quad \forall \boldsymbol{x}, \boldsymbol{z}$$

**定理 7.1 (梯度下降收敛率)**：

若目标函数是 $l$-Lipschitz连续函数，且可行域有界（直径为 $\Gamma$），采用固定步长 $\eta = \Gamma/(l\sqrt{T})$ 的梯度下降，收敛率为 $O(1/\sqrt{T})$。

**详细证明**：

**步骤1**：建立单步不等式

对任意 $\boldsymbol{w} \in \mathcal{W}$，利用凸性：
$$f(\boldsymbol{w}_t) - f(\boldsymbol{w}) \leqslant \langle \nabla f(\boldsymbol{w}_t), \boldsymbol{w}_t - \boldsymbol{w} \rangle$$

**步骤2**：代入梯度下降更新

$$= \frac{1}{\eta}\langle \boldsymbol{w}_t - \boldsymbol{w}_{t+1}', \boldsymbol{w}_t - \boldsymbol{w} \rangle$$

**步骤3**：应用恒等式

利用恒等式 $2\langle \boldsymbol{a}, \boldsymbol{b} \rangle = \|\boldsymbol{a}\|^2 + \|\boldsymbol{b}\|^2 - \|\boldsymbol{a} - \boldsymbol{b}\|^2$：

$$= \frac{1}{2\eta}\left(\|\boldsymbol{w}_t - \boldsymbol{w}\|^2 - \|\boldsymbol{w}_{t+1}' - \boldsymbol{w}\|^2 + \|\boldsymbol{w}_t - \boldsymbol{w}_{t+1}'\|^2\right)$$

$$= \frac{1}{2\eta}\left(\|\boldsymbol{w}_t - \boldsymbol{w}\|^2 - \|\boldsymbol{w}_{t+1}' - \boldsymbol{w}\|^2\right) + \frac{\eta}{2}\|\nabla f(\boldsymbol{w}_t)\|^2$$

**步骤4**：利用投影的非扩展性

$$\|\boldsymbol{w}_{t+1}' - \boldsymbol{w}\|^2 \geqslant \|\boldsymbol{w}_{t+1} - \boldsymbol{w}\|^2$$

因此：
$$f(\boldsymbol{w}_t) - f(\boldsymbol{w}) \leqslant \frac{1}{2\eta}\left(\|\boldsymbol{w}_t - \boldsymbol{w}\|^2 - \|\boldsymbol{w}_{t+1} - \boldsymbol{w}\|^2\right) + \frac{\eta}{2}l^2$$

**步骤5**：对 $t = 1$ 到 $T$ 求和

$$\sum_{t=1}^{T}f(\boldsymbol{w}_t) - Tf(\boldsymbol{w}) \leqslant \frac{1}{2\eta}\|\boldsymbol{w}_1 - \boldsymbol{w}\|^2 + \frac{\eta T}{2}l^2$$

利用 $\|\boldsymbol{w}_1 - \boldsymbol{w}\| \leqslant \Gamma$：
$$\leqslant \frac{\Gamma^2}{2\eta} + \frac{\eta Tl^2}{2}$$

**步骤6**：应用Jensen不等式

令 $\bar{\boldsymbol{w}}_T = \frac{1}{T}\sum_{t=1}^{T}\boldsymbol{w}_t$，由凸性：
$$f(\bar{\boldsymbol{w}}_T) \leqslant \frac{1}{T}\sum_{t=1}^{T}f(\boldsymbol{w}_t)$$

因此：
$$f(\bar{\boldsymbol{w}}_T) - f(\boldsymbol{w}) \leqslant \frac{\Gamma^2}{2\eta T} + \frac{\eta l^2}{2}$$

**步骤7**：选择最优步长

令 $\eta = \Gamma/(l\sqrt{T})$：
$$f(\bar{\boldsymbol{w}}_T) - f(\boldsymbol{w}^*) \leqslant \frac{l\Gamma}{\sqrt{T}} = O\left(\frac{1}{\sqrt{T}}\right)$$

### 7.2.2 强凸函数的梯度下降

对于强凸且光滑的函数，梯度下降可以达到**线性收敛**。

**算法流程**：

```
输入: 初始点 w_1 ∈ W, 光滑参数 γ, 迭代轮数 T
for t = 1, ..., T do:
    计算梯度: g_t = ∇f(w_t)
    更新: w_{t+1} = argmin_{w∈W} {f(w_t) + <g_t, w-w_t> + (γ/2)||w-w_t||^2}
end for
返回: w_T
```

**闭式解**：
$$\boldsymbol{w}_{t+1} = \Pi_{\mathcal{W}}\left(\boldsymbol{w}_t - \frac{1}{\gamma}\nabla f(\boldsymbol{w}_t)\right)$$

**定理 7.3 (强凸函数的线性收敛)**：

若目标函数满足 $\lambda$-强凸且 $\gamma$-光滑，梯度下降取得线性收敛率 $O(1/\beta^T)$，其中 $\beta > 1$。

**详细证明**：

**步骤1**：利用光滑性

$$f(\boldsymbol{w}_{t+1}) \leqslant f(\boldsymbol{w}_t) + \langle \nabla f(\boldsymbol{w}_t), \boldsymbol{w}_{t+1} - \boldsymbol{w}_t \rangle + \frac{\gamma}{2}\|\boldsymbol{w}_{t+1} - \boldsymbol{w}_t\|^2$$

由更新规则：
$$= \min_{\boldsymbol{w} \in \mathcal{W}}\left(f(\boldsymbol{w}_t) + \langle \nabla f(\boldsymbol{w}_t), \boldsymbol{w} - \boldsymbol{w}_t \rangle + \frac{\gamma}{2}\|\boldsymbol{w} - \boldsymbol{w}_t\|^2\right)$$

**步骤2**：利用强凸性

$$\leqslant \min_{\boldsymbol{w} \in \mathcal{W}}\left(f(\boldsymbol{w}) - \frac{\lambda}{2}\|\boldsymbol{w} - \boldsymbol{w}_t\|^2 + \frac{\gamma}{2}\|\boldsymbol{w} - \boldsymbol{w}_t\|^2\right)$$

$$= \min_{\boldsymbol{w} \in \mathcal{W}}\left(f(\boldsymbol{w}) + \frac{\gamma - \lambda}{2}\|\boldsymbol{w} - \boldsymbol{w}_t\|^2\right)$$

**步骤3**：限制在凸组合上

考虑 $\boldsymbol{w} = \alpha\boldsymbol{w}^* + (1-\alpha)\boldsymbol{w}_t$，$\alpha \in [0, 1]$：

$$\leqslant \min_{\alpha \in [0,1]}\left(f(\alpha\boldsymbol{w}^* + (1-\alpha)\boldsymbol{w}_t) + \frac{\gamma - \lambda}{2}\alpha^2\|\boldsymbol{w}^* - \boldsymbol{w}_t\|^2\right)$$

**步骤4**：利用凸性

$$f(\alpha\boldsymbol{w}^* + (1-\alpha)\boldsymbol{w}_t) \leqslant \alpha f(\boldsymbol{w}^*) + (1-\alpha)f(\boldsymbol{w}_t)$$

因此：
$$\leqslant \min_{\alpha \in [0,1]}\left(\alpha f(\boldsymbol{w}^*) + (1-\alpha)f(\boldsymbol{w}_t) + \frac{\gamma - \lambda}{2}\alpha^2\|\boldsymbol{w}^* - \boldsymbol{w}_t\|^2\right)$$

**步骤5**：利用强凸性性质

由定理 7.2：$\|\boldsymbol{w}_t - \boldsymbol{w}^*\|^2 \leqslant \frac{2}{\lambda}(f(\boldsymbol{w}_t) - f(\boldsymbol{w}^*))$

代入得：
$$f(\boldsymbol{w}_{t+1}) - f(\boldsymbol{w}^*) \leqslant \min_{\alpha \in [0,1]}\left((1-\alpha) + \frac{\gamma - \lambda}{\lambda}\alpha^2\right)(f(\boldsymbol{w}_t) - f(\boldsymbol{w}^*))$$

**步骤6**：选择最优 $\alpha$

若 $\frac{\lambda}{2(\gamma - \lambda)} \geqslant 1$，取 $\alpha = 1$：
$$f(\boldsymbol{w}_{t+1}) - f(\boldsymbol{w}^*) \leqslant \frac{\gamma - \lambda}{\lambda}(f(\boldsymbol{w}_t) - f(\boldsymbol{w}^*))$$

若 $\frac{\lambda}{2(\gamma - \lambda)} < 1$，取 $\alpha = \frac{\lambda}{2(\gamma - \lambda)}$：
$$f(\boldsymbol{w}_{t+1}) - f(\boldsymbol{w}^*) \leqslant \left(1 - \frac{\lambda}{4(\gamma - \lambda)}\right)(f(\boldsymbol{w}_t) - f(\boldsymbol{w}^*))$$

**步骤7**：定义收敛率参数

令：
$$\beta = \begin{cases} \frac{\lambda}{\gamma - \lambda} & \text{if } \frac{\lambda}{2(\gamma - \lambda)} \geqslant 1 \\ \frac{4(\gamma - \lambda)}{4\gamma - 5\lambda} & \text{if } \frac{\lambda}{2(\gamma - \lambda)} < 1 \end{cases}$$

则：
$$f(\boldsymbol{w}_{t+1}) - f(\boldsymbol{w}^*) \leqslant \frac{1}{\beta}(f(\boldsymbol{w}_t) - f(\boldsymbol{w}^*))$$

递推得：
$$f(\boldsymbol{w}_T) - f(\boldsymbol{w}^*) \leqslant \frac{1}{\beta^{T-1}}(f(\boldsymbol{w}_1) - f(\boldsymbol{w}^*)) = O\left(\frac{1}{\beta^T}\right)$$

## 随机优化

### 7.3.1 凸函数的随机梯度下降

**随机梯度下降 (SGD)** 与梯度下降的主要区别：使用**随机梯度**代替真实梯度。

**算法流程**：

```
输入: 初始点 w_1 ∈ W, 步长 η_t, 迭代轮数 T
for t = 1, ..., T do:
    计算随机梯度: g_t (满足 E[g_t] = ∇f(w_t))
    梯度下降: w_{t+1}' = w_t - η_t * g_t
    投影: w_{t+1} = Π_W(w_{t+1}')
end for
返回: w̄_T = (1/T) * Σ_{t=1}^T w_t
```

**随机梯度的无偏性**：
$$\mathbb{E}[\mathbf{g}_t] = \nabla f(\boldsymbol{w}_t)$$

**机器学习中的应用**：

对于经验风险最小化：
$$f(\boldsymbol{w}) = \frac{1}{m}\sum_{i=1}^{m}\ell(\boldsymbol{w}, \boldsymbol{z}_i)$$

随机梯度可以通过随机采样一个样本计算：
$$\mathbf{g}_t = \nabla \ell(\boldsymbol{w}_t, \boldsymbol{z}_{i_t})$$

其中 $i_t$ 从 $\{1, \ldots, m\}$ 中均匀随机采样。

**定理 7.4 (SGD的收敛率)**：

假设目标函数的随机梯度有上界 $l$，可行域直径为 $\Gamma$，采用固定步长 $\eta = \Gamma/(l\sqrt{T})$ 的SGD，收敛率为 $O(1/\sqrt{T})$。

**详细证明**：

**步骤1**：建立单步不等式

对任意 $\boldsymbol{w} \in \mathcal{W}$：
$$f(\boldsymbol{w}_t) - f(\boldsymbol{w}) \leqslant \langle \nabla f(\boldsymbol{w}_t), \boldsymbol{w}_t - \boldsymbol{w} \rangle$$

$$= \langle \mathbf{g}_t, \boldsymbol{w}_t - \boldsymbol{w} \rangle + \langle \nabla f(\boldsymbol{w}_t) - \mathbf{g}_t, \boldsymbol{w}_t - \boldsymbol{w} \rangle$$

**步骤2**：处理随机梯度项

$$\langle \mathbf{g}_t, \boldsymbol{w}_t - \boldsymbol{w} \rangle = \frac{1}{\eta}\langle \boldsymbol{w}_t - \boldsymbol{w}_{t+1}', \boldsymbol{w}_t - \boldsymbol{w} \rangle$$

$$= \frac{1}{2\eta}\left(\|\boldsymbol{w}_t - \boldsymbol{w}\|^2 - \|\boldsymbol{w}_{t+1}' - \boldsymbol{w}\|^2 + \|\boldsymbol{w}_t - \boldsymbol{w}_{t+1}'\|^2\right)$$

$$\leqslant \frac{1}{2\eta}\left(\|\boldsymbol{w}_t - \boldsymbol{w}\|^2 - \|\boldsymbol{w}_{t+1} - \boldsymbol{w}\|^2\right) + \frac{\eta}{2}\|\mathbf{g}_t\|^2$$

**步骤3**：综合不等式

$$f(\boldsymbol{w}_t) - f(\boldsymbol{w}) \leqslant \frac{1}{2\eta}\left(\|\boldsymbol{w}_t - \boldsymbol{w}\|^2 - \|\boldsymbol{w}_{t+1} - \boldsymbol{w}\|^2\right) + \frac{\eta}{2}l^2 + \langle \nabla f(\boldsymbol{w}_t) - \mathbf{g}_t, \boldsymbol{w}_t - \boldsymbol{w} \rangle$$

**步骤4**：对 $t = 1$ 到 $T$ 求和

$$\sum_{t=1}^{T}f(\boldsymbol{w}_t) - Tf(\boldsymbol{w}) \leqslant \frac{\Gamma^2}{2\eta} + \frac{\eta Tl^2}{2} + \sum_{t=1}^{T}\langle \nabla f(\boldsymbol{w}_t) - \mathbf{g}_t, \boldsymbol{w}_t - \boldsymbol{w} \rangle$$

**步骤5**：取期望

由于 $\mathbb{E}[\langle \nabla f(\boldsymbol{w}_t) - \mathbf{g}_t, \boldsymbol{w}_t - \boldsymbol{w} \rangle] = 0$：

$$\mathbb{E}[f(\bar{\boldsymbol{w}}_T)] - f(\boldsymbol{w}) \leqslant \frac{\Gamma^2}{2\eta T} + \frac{\eta l^2}{2}$$

**步骤6**：选择步长

令 $\eta = \Gamma/(l\sqrt{T})$：
$$\mathbb{E}[f(\bar{\boldsymbol{w}}_T)] - f(\boldsymbol{w}^*) \leqslant \frac{l\Gamma}{\sqrt{T}} = O\left(\frac{1}{\sqrt{T}}\right)$$

**高概率界**：

利用Azuma不等式（针对鞅差序列），可以证明以至少 $1-\delta$ 的概率：
$$f(\bar{\boldsymbol{w}}_T) - f(\boldsymbol{w}^*) \leqslant O\left(\frac{1}{\sqrt{T}}\left(1 + \sqrt{\log\frac{1}{\delta}}\right)\right)$$

### 7.3.2 强凸函数的Epoch-GD算法

对于强凸函数，普通的SGD只能达到 $O(\log T/T)$ 的收敛率。**Epoch-GD** 算法可以达到最优的 $O(1/T)$ 收敛率。

**算法流程**：

```
输入: 初始点 w_1^1 ∈ W, 参数 T_1, η_1, 总迭代次数 T
k = 1
while Σ_{i=1}^k T_i ≤ T do:
    for t = 1, ..., T_k do:
        计算随机梯度: g_t^k
        更新: w_{t+1}^k = Π_W(w_t^k - η_k * g_t^k)
    end for
    w_1^{k+1} = (1/T_k) * Σ_{t=1}^{T_k} w_t^k
    T_{k+1} = 2 * T_k
    η_{k+1} = η_k / 2
    k = k + 1
end while
返回: w_1^k
```

**算法特点**：

- 外层循环（epoch）：迭代轮数加倍，步长减半
- 内层循环：固定步长的SGD
- 每轮结束取平均作为下轮初始值

**定理 7.5 (Epoch-GD的收敛率)**：

当目标函数 $f(\cdot)$ 为 $\lambda$-强凸时，Epoch-GD期望意义上的收敛率为 $O(1/(\lambda T))$。

**关键引理**：

**引理 7.1**：设 $T_1 = 4$，$\eta_1 = 1/\lambda$，$\Delta_k = f(\boldsymbol{w}_1^k) - f(\boldsymbol{w}^*)$，$V_k = l^2/(\lambda 2^{k-2})$，则对任意 $k$：
$$\mathbb{E}[\Delta_k] \leqslant V_k$$

**证明思路（数学归纳法）**：

**基例** ($k=1$)：
由定理 7.2：$\mathbb{E}[\Delta_1] \leqslant 2l^2/\lambda = V_1$

**归纳步骤**：
假设 $\mathbb{E}[\Delta_k] \leqslant V_k$，则：
$$\mathbb{E}[\Delta_{k+1}] \leqslant \frac{\eta_k l^2}{2} + \frac{\mathbb{E}[\Delta_k]}{\eta_k T_k \lambda}$$

代入 $T_k = 8l^2/(\lambda V_k) = 2^{k+1}$ 和 $\eta_k = V_k/(2l^2) = 1/(\lambda 2^{k-1})$：
$$\mathbb{E}[\Delta_{k+1}] \leqslant \frac{l^2}{\lambda 2^k} = V_{k+1}$$

**主定理证明**：

设最后一轮为 $k^\dagger = \lfloor\log_2(T/T_1 + 1)\rfloor$，则：
$$\mathbb{E}[f(\boldsymbol{w}_1^{k^\dagger+1})] - f(\boldsymbol{w}^*) \leqslant V_{k^\dagger+1} = \frac{l^2}{\lambda 2^{k^\dagger-1}} \leqslant \frac{16l^2}{\lambda T} = O\left(\frac{1}{\lambda T}\right)$$

**高概率界**（定理 7.7）：

Epoch-GD以大概率取得 $O(\log\log T/(\lambda T))$ 的收敛率。

## 分析实例

### 7.4.1 支持向量机 (SVM)

**优化问题**：

$$\min_{\|\boldsymbol{w}\| \leqslant \Lambda} f(\boldsymbol{w}) = \sum_{i=1}^{m}\max(0, 1 - y_i\boldsymbol{w}^T\boldsymbol{x}_i)$$

**次梯度计算**：

由于hinge损失不光滑，使用次梯度：
$$\nabla f(\boldsymbol{w}) = \sum_{i=1}^{m}\mathbf{g}_i$$

其中：
$$\mathbf{g}_i = \begin{cases} -y_i\boldsymbol{x}_i & \text{if } 1 - y_i\boldsymbol{w}^T\boldsymbol{x}_i \geqslant 0 \\ 0 & \text{if } 1 - y_i\boldsymbol{w}^T\boldsymbol{x}_i < 0 \end{cases}$$

**算法流程**：

```
输入: 初始点 w_1, 步长 η, 迭代轮数 T
for t = 1, ..., T do:
    计算次梯度: ∇f(w_t)
    梯度下降: w_{t+1}' = w_t - η * ∇f(w_t)
    投影: w_{t+1} = (Λ / max(||w_{t+1}'||, Λ)) * w_{t+1}'
end for
返回: w̄_T = (1/T) * Σ_{t=1}^T w_t
```

**定理 7.8 (SVM的收敛率)**：

梯度下降求解SVM的收敛率为 $O(1/\sqrt{T})$。

**证明**：

假设 $\|\boldsymbol{x}_i\| \leqslant r$，则：
$$\|\nabla f(\boldsymbol{w})\| \leqslant \sum_{i=1}^{m}\|y_i\boldsymbol{x}_i\| \leqslant mr$$

可行域直径 $\Gamma = 2\Lambda$。

由定理 7.1，取 $\eta = 2\Lambda/(mr\sqrt{T})$：
$$f(\bar{\boldsymbol{w}}_T) - \min_{\|\boldsymbol{w}\| \leqslant \Lambda}f(\boldsymbol{w}) \leqslant \frac{2mr\Lambda}{\sqrt{T}} = O\left(\frac{1}{\sqrt{T}}\right)$$

### 7.4.2 对率回归 (Logistic Regression)

**优化问题**：

$$\min_{\|\boldsymbol{w}\| \leqslant \Lambda} f(\boldsymbol{w}) = \frac{1}{m}\sum_{i=1}^{m}\ln(1 + \exp(-y_i\boldsymbol{w}^T\boldsymbol{x}_i))$$

**随机梯度计算**：

在第 $t$ 轮，随机采样样本 $(\boldsymbol{x}_t, y_t)$：
$$\mathbf{g}_t = \frac{y_t\exp(-y_t\boldsymbol{w}_t^T\boldsymbol{x}_t)}{1 + \exp(-y_t\boldsymbol{w}_t^T\boldsymbol{x}_t)}\boldsymbol{x}_t$$

**算法流程**：

```
输入: 初始点 w_1, 步长 η, 迭代轮数 T
for t = 1, ..., T do:
    随机采样: (x_t, y_t)
    计算随机梯度: g_t
    梯度下降: w_{t+1}' = w_t - η * g_t
    投影: w_{t+1} = (Λ / max(||w_{t+1}'||, Λ)) * w_{t+1}'
end for
返回: w̄_T = (1/T) * Σ_{t=1}^T w_t
```

**定理 7.9 (对率回归的收敛率)**：

随机梯度下降求解对率回归的收敛率为 $O(1/\sqrt{T})$。

**证明**：

假设 $\|\boldsymbol{x}_i\| \leqslant r$，则：
$$\|\mathbf{g}_t\| = \left\|\frac{\exp(-y_t\boldsymbol{w}_t^T\boldsymbol{x}_t)}{1 + \exp(-y_t\boldsymbol{w}_t^T\boldsymbol{x}_t)}y_t\boldsymbol{x}_t\right\| \leqslant \|\boldsymbol{x}_t\| \leqslant r$$

可行域直径 $\Gamma = 2\Lambda$。

由定理 7.4，取 $\eta = 2\Lambda/(r\sqrt{T})$，以至少 $1-\delta$ 的概率：
$$f(\bar{\boldsymbol{w}}_T) - \min_{\|\boldsymbol{w}\| \leqslant \Lambda}f(\boldsymbol{w}) \leqslant \frac{2\Lambda r}{\sqrt{T}}\left(1 + 2\sqrt{2\log\frac{1}{\delta}}\right) = O\left(\frac{1}{\sqrt{T}}\right)$$

## 章节小结

### 核心要点回顾

1. **收敛率的类型**：
   | 函数类型 | 确定优化 | 随机优化 |
   |----------|----------|----------|
   | 凸函数 | $O(1/\sqrt{T})$ | $O(1/\sqrt{T})$ |
   | 强凸函数 | $O(1/\beta^T)$（线性） | $O(1/T)$ |

2. **关键算法**：
   - **梯度下降 (GD)**：适用于确定优化，需要计算全梯度
   - **随机梯度下降 (SGD)**：适用于大规模数据，每步计算随机梯度
   - **Epoch-GD**：针对强凸函数的改进SGD，达到最优 $O(1/T)$

3. **收敛率 vs 迭代复杂度**：
   - 收敛率：误差随迭代的变化
   - 迭代复杂度：达到指定精度需要的迭代次数
   - 两者是等价的描述方式

4. **影响收敛率的因素**：
   - 函数性质：凸性、强凸性、光滑性
   - 算法选择：确定 vs 随机
   - 步长设置：固定 vs 衰减

### 关键公式总结

| 概念                 | 公式                                                                                                                                                                               |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Lipschitz连续        | $\|\nabla f(\boldsymbol{u})\| \leqslant l$                                                                                                                                         |
| 强凸性               | $f(\boldsymbol{u}) \geqslant f(\boldsymbol{v}) + \langle \nabla f(\boldsymbol{v}), \boldsymbol{u}-\boldsymbol{v} \rangle + \frac{\lambda}{2}\|\boldsymbol{u}-\boldsymbol{v}\|^2$   |
| 光滑性               | $f(\boldsymbol{w}') \leqslant f(\boldsymbol{w}) + \langle \nabla f(\boldsymbol{w}), \boldsymbol{w}'-\boldsymbol{w} \rangle + \frac{\gamma}{2}\|\boldsymbol{w}'-\boldsymbol{w}\|^2$ |
| GD收敛（凸）         | $O(1/\sqrt{T})$                                                                                                                                                                    |
| GD收敛（强凸光滑）   | $O(1/\beta^T)$                                                                                                                                                                     |
| SGD收敛（凸）        | $O(1/\sqrt{T})$                                                                                                                                                                    |
| Epoch-GD收敛（强凸） | $O(1/(\lambda T))$                                                                                                                                                                 |
