# 第5章 稳定性 - 详细学习材料

## 一、本章概述

### 1.1 为什么需要稳定性？

第3-4章介绍的泛化误差界基于**假设空间复杂度**（VC维、Rademacher复杂度）。但这些方法有局限性：

**局限性**：

- 不适用于**无限VC维**的学习方法（如最近邻）
- 与**具体学习算法无关**，只考虑假设空间
- 对于某些算法给出的界过于悲观

**解决方案**：从**算法稳定性**角度分析泛化性。

### 1.2 核心思想

**稳定性（Stability）**：刻画训练集的**扰动**对算法结果的影响。

**直观理解**：

- **稳定算法**：改变一个训练样本，输出变化不大
- **不稳定算法**：改变一个训练样本，输出剧烈变化
- 稳定算法通常具有更好的泛化性能

### 1.3 本章结构

```
稳定性分析
├── 基本概念
│   ├── 训练集扰动（移除/替换）
│   ├── 均匀稳定性
│   └── 假设稳定性
├── 稳定性与泛化性
│   ├── 泛化误差界
│   └── 过拟合分析
├── 稳定性与可学性
│   └── ERM算法的稳定性
└── 分析实例
    ├── 支持向量机
    ├── 支持向量回归
    ├── 岭回归
    └── k-近邻
```

## 二、5.1 基本概念 - 深度解析

### 2.1 训练集的扰动

**定义**：考虑两种训练集扰动方式：

#### 移除样本（Leave-one-out）

$$D^{\setminus i} = \{z_1, \ldots, z_{i-1}, z_{i+1}, \ldots, z_m\}$$

#### 替换样本

$$D^{i,z_i'} = \{z_1, \ldots, z_{i-1}, z_i', z_{i+1}, \ldots, z_m\}$$

**为什么研究扰动？**

- 模拟训练数据的随机性
- 评估算法对数据变化的敏感度
- 连接经验风险与泛化风险

---

### 2.2 三种风险

#### 经验风险（Empirical Risk）

$$\widehat{R}(\mathfrak{L}_D) = \frac{1}{m} \sum_{i=1}^m \ell(\mathfrak{L}_D, z_i)$$

#### 泛化风险（Generalization Risk）

$$R(\mathfrak{L}_D) = \mathbb{E}_{z \sim \mathcal{D}}[\ell(\mathfrak{L}_D, z)]$$

#### 留一风险（Leave-one-out Risk）

$$R_{loo}(\mathfrak{L}_D) = \frac{1}{m} \sum_{i=1}^m \ell(\mathfrak{L}_{D^{\setminus i}}, z_i)$$

**留一风险的重要性**：

- 是泛化风险的**无偏估计**（引理5.1）
- 与交叉验证密切相关

---

### 2.3 均匀稳定性（Uniform Stability）

#### 替换样本均匀稳定性

**定义 5.1**：对任意数据集 $D$ 和样本 $z, z' \in \mathcal{X} \times \mathcal{Y}$，若学习算法 $\mathfrak{L}$ 满足：

$$|\ell(\mathfrak{L}_D, z) - \ell(\mathfrak{L}_{D^{i,z'}}, z)| \leqslant \beta \quad (i \in [m])$$

则称算法 $\mathfrak{L}$ 具有**替换样本$\beta$-均匀稳定性**。

#### 移除样本均匀稳定性

**定义 5.2**：对任意数据集 $D$ 和样本 $z \in \mathcal{X} \times \mathcal{Y}$，若：

$$|\ell(\mathfrak{L}_D, z) - \ell(\mathfrak{L}_{D^{\setminus i}}, z)| \leqslant \gamma \quad (i \in [m])$$

则称算法 $\mathfrak{L}$ 具有**移除样本$\gamma$-均匀稳定性**。

#### 两种稳定性的关系

若算法具有移除样本$\gamma$-均匀稳定性，则具有替换样本$2\gamma$-均匀稳定性。

**证明**：

```
|ℓ(𝔏_D, z) - ℓ(𝔏_{D^{i,z'}}, z)|
≤ |ℓ(𝔏_D, z) - ℓ(𝔏_{D^{\i}}, z)| + |ℓ(𝔏_{D^{i,z'}}, z) - ℓ(𝔏_{D^{\i}}, z)|
≤ γ + γ = 2γ
```

#### 稳定性的极限定义

若 $\lim_{m \to \infty} \beta(m) = 0$，则称算法 $\mathfrak{L}$ 是**稳定的**。

**直观**：训练数据足够多时，替换一个样本对学习结果影响很小。

---

### 2.4 假设稳定性（Hypothesis Stability）

**定义 5.3**：若学习算法 $\mathfrak{L}$ 满足：

$$\mathbb{E}_{D, z_i' \sim \mathcal{D}^{m+1}}[|\ell(\mathfrak{L}_D, z_i) - \ell(\mathfrak{L}_{D^{i,z_i'}}, z_i)|] \leqslant \beta \quad (i \in [m])$$

则称算法 $\mathfrak{L}$ 具有**替换样本$\beta$-假设稳定性**。

**与均匀稳定性的区别**：

| 特性 | 均匀稳定性     | 假设稳定性   |
| ---- | -------------- | ------------ |
| 条件 | 对所有D和z成立 | 对D和z取期望 |
| 强度 | 强             | 弱           |
| 结果 | 高概率界       | 期望界       |
| 适用 | 分析要求严格   | 分析要求宽松 |

## 三、5.2 稳定性与泛化性 - 深度解析

### 3.1 均匀稳定性的泛化界

**定理 5.1**（Bousquet & Elisseeff, 2002）：

给定学习算法 $\mathfrak{L}$ 和数据集 $D = \{z_1, \ldots, z_m\}$，假设损失函数 $\ell(\cdot, \cdot) \in [0, M]$。

**替换样本稳定性**：若 $\mathfrak{L}$ 具有替换样本$\beta$-均匀稳定性，则对任意 $\delta \in (0,1)$，以至少 $1-\delta$ 的概率：

$$R(\mathfrak{L}_D) \leqslant \widehat{R}(\mathfrak{L}_D) + \beta + (2m\beta + M)\sqrt{\frac{\ln(1/\delta)}{2m}}$$

**移除样本稳定性**：若 $\mathfrak{L}$ 具有移除样本$\gamma$-均匀稳定性，则：

$$R(\mathfrak{L}_D) \leqslant R_{loo}(\mathfrak{L}_D) + \gamma + (4m\gamma + M)\sqrt{\frac{\ln(1/\delta)}{2m}}$$

#### 证明思路

1. 定义 $\Phi(D) = R(\mathfrak{L}_D) - \widehat{R}(\mathfrak{L}_D)$
2. 利用稳定性证明 $\Phi(D)$ 满足**有界差分条件**
3. 应用McDiarmid不等式

**关键推导**：

```
|Φ(D) - Φ(D^{i,z_i'})| ≤ |R(𝔏_D) - R(𝔏_{D^{i,z_i'}})| + |R̂(𝔏_{D^{i,z_i'}}) - R̂(𝔏_D)|

第一项 ≤ β                      [稳定性]
第二项 ≤ β + M/m                [稳定性+损失有界]

总差分 ≤ 2β + M/m
```

#### 三种情况分析

根据 $\lim_{m \to \infty} m\beta$ 的值：

1. **$m\beta \to c \in (0, \infty)$**：$R \leqslant \widehat{R} + O(1/\sqrt{m})$（与VC维界一致）
2. **$m\beta \to 0$**：$R \leqslant \widehat{R}$（泛化风险不超过经验风险）
3. **$m\beta \to \infty$**：无法保证泛化性能

---

### 3.2 假设稳定性的泛化界

**定理 5.2**（Bousquet & Elisseeff, 2002）：

若学习算法 $\mathfrak{L}$ 具有替换样本$\beta$-假设稳定性，则：

$$\mathbb{E}_{D \sim \mathcal{D}^m}[(R(\mathfrak{L}_D) - \widehat{R}(\mathfrak{L}_D))^2] \leqslant 4M\beta + \frac{M^2}{m}$$

**意义**：

- 给出泛化误差**方差**的上界
- 说明稳定的算法泛化误差波动小

---

### 3.3 稳定性与过拟合

**过拟合定义**：经验风险较小但泛化风险较大，即 $R - \widehat{R}$ 较大。

**定理 5.3**（Shalev-Shwartz & Ben-David, 2014）：

对任何学习算法 $\mathfrak{L}$：

$$\mathbb{E}_{D \sim \mathcal{D}^m}[R(\mathfrak{L}_D) - \widehat{R}(\mathfrak{L}_D)] = \mathbb{E}_{D, z' \sim \mathcal{D}^{m+1}, i \sim \mathcal{U}(m)}[\ell(\mathfrak{L}_{D^{i,z'}}, z_i) - \ell(\mathfrak{L}_D, z_i)]$$

**核心洞察**：

- 不过拟合 $\Leftrightarrow$ 算法具有（期望意义下的）稳定性
- 稳定算法：替换样本不会显著改变输出
- 因此不会过拟合

## 四、5.2.2 稳定性与可学性 - 深度解析

### 4.1 ERM算法

**定义 5.4**：经验风险最小化（ERM）算法输出满足：

$$\mathfrak{L}_D \in \arg\min_{h \in \mathcal{H}} \widehat{R}_D(h)$$

**稳定性与可学性的关系**：

**定理 5.4**：若ERM算法 $\mathfrak{L}$ 具有替换样本$\beta$-均匀稳定性（其中 $\beta = 1/m$），则函数空间 $\mathcal{H}$ 是不可知PAC可学的。

**证明要点**：

1. 令 $h^* = \arg\min_{h \in \mathcal{H}} R(h)$ 为 $\mathcal{H}$ 中最优假设
2. 分解：
   ```
   R(𝔏_D) - R(h*) = [R(𝔏_D) - R̂(𝔏_D)] + [R̂(𝔏_D) - R̂(h*)] + [R̂(h*) - R(h*)]
   ```
3. 分别控制三项：
   - 第一项：由稳定性定理5.1控制
   - 第二项：由ERM性质 $\widehat{R}(\mathfrak{L}_D) \leqslant \widehat{R}(h^*)$ 知非正
   - 第三项：由Hoeffding不等式控制
4. 最终得到样本复杂度 $m = O(\frac{1}{\epsilon^2} \ln \frac{1}{\delta})$

## 五、5.3 分析实例 - 深度解析

### 5.1 支持向量机的稳定性

**优化目标**：
$$F_D(\boldsymbol{w}) = \frac{1}{m} \sum_{i=1}^m \max(0, 1 - y_i \boldsymbol{w}^T \boldsymbol{x}_i) + \lambda \|\boldsymbol{w}\|^2$$

**定理 5.5**：SVM具有替换样本$\beta$-均匀稳定性，其中 $\beta = \frac{r^2}{\lambda m}$。

**证明要点**：

1. 令 $\boldsymbol{w}_D$ 和 $\boldsymbol{w}_{D'}$ 分别为 $F_D$ 和 $F_{D'}$ 的最优解
2. $F_D$ 是 $2\lambda$-强凸函数
3. 利用强凸性：
   ```
   λ‖w_D - w_{D'}‖² ≤ (F_D(w_{D'}) - F_D(w_D)) + (F_{D'}(w_D) - F_{D'}(w_{D'}))
   ```
4. 右式可控制为 $\frac{r}{m} \|\boldsymbol{w}_D - \boldsymbol{w}_{D'}\|$
5. 解得：$\|\boldsymbol{w}_D - \boldsymbol{w}_{D'}\| \leqslant \frac{r}{\lambda m}$
6. 由Lipschitz性质：$|\ell_{hinge}(\boldsymbol{w}_D, z) - \ell_{hinge}(\boldsymbol{w}_{D'}, z)| \leqslant r \|\boldsymbol{w}_D - \boldsymbol{w}_{D'}\| \leqslant \frac{r^2}{\lambda m}$

**关键洞察**：

- **正则化**将凸函数变为强凸函数，保证稳定性
- 正则化参数 $\lambda$ 越大，稳定性越好（$\beta$ 越小）
- 但 $\lambda$ 过大可能导致欠拟合

**推论 5.1**（SVM泛化界）：

对任意 $\delta \in (0,1)$，以至少 $1-\delta$ 的概率：

$$R(\boldsymbol{w}_D) \leqslant \widehat{R}(\boldsymbol{w}_D) + \frac{r^2}{m\lambda} + \left(\frac{2r^2}{\lambda} + M\right)\sqrt{\frac{\ln(1/\delta)}{2m}}$$

---

### 5.2 支持向量回归的稳定性

**$\epsilon$-不敏感损失**：
$$\ell_\epsilon(\boldsymbol{w}, (\boldsymbol{x}, y)) = \begin{cases} 0 & \text{if } |\boldsymbol{w}^T \boldsymbol{x} - y| \leqslant \epsilon \\ |\boldsymbol{w}^T \boldsymbol{x} - y| - \epsilon & \text{otherwise} \end{cases}$$

**定理 5.6**：SVR具有替换样本$\beta$-均匀稳定性，其中 $\beta = \frac{2r^2}{\lambda m}$。

**推论 5.2**（SVR泛化界）：

$$R(\boldsymbol{w}_D) \leqslant \widehat{R}(\boldsymbol{w}_D) + \frac{2r^2}{m\lambda} + \left(\frac{4r^2}{\lambda} + M\right)\sqrt{\frac{\ln(1/\delta)}{2m}}$$

---

### 5.3 岭回归的稳定性

**优化目标**：
$$F_D(\boldsymbol{w}) = \frac{1}{m} \sum_{i=1}^m (\boldsymbol{w}^T \boldsymbol{x}_i - y_i)^2 + \lambda \|\boldsymbol{w}\|^2$$

**定理 5.7**：岭回归具有替换样本$\beta$-均匀稳定性，其中 $\beta = \frac{4r^2 M}{m\lambda}$。

**推论 5.3**（岭回归泛化界）：

$$R(\boldsymbol{w}_D) \leqslant \widehat{R}(\boldsymbol{w}_D) + \frac{4Mr^2}{\lambda m} + \left(\frac{8Mr^2}{\lambda} + M\right)\sqrt{\frac{\ln(1/\delta)}{2m}}$$

---

### 5.4 k-近邻的稳定性

**挑战**：k-近邻的VC维是**无限的**，无法使用复杂度-based分析。

**定理 5.8**：k-近邻算法具有替换样本$\beta$-假设稳定性，其中 $\beta = \frac{2\sqrt{2k/\pi}}{m}$。

**关键观察**：

- k-近邻**不具有**均匀稳定性
- 但具有假设稳定性（期望意义下）

**证明要点**：

1. 替换一个样本改变预测的条件：
   - 被替换的样本是测试点的k个近邻之一（概率 $k/m$）
   - k个近邻中正反例个数相差不超过1

2. 利用引理5.2（二项分布集中性）：
   $$P(|N_+ - k/2| \leqslant 1/2) \leqslant \frac{2\sqrt{2k}}{\sqrt{\pi k}} = \frac{2\sqrt{2}}{\sqrt{\pi}}$$

3. 综合得：
   $$P(\mathfrak{L}_D(\boldsymbol{x}) \neq \mathfrak{L}_{D^{i,z_i'}}(\boldsymbol{x})) \leqslant \frac{k}{m} \cdot \frac{2}{\sqrt{\pi k}} = \frac{2\sqrt{2k}}{m\sqrt{\pi}}$$

**推论 5.4**（k-近邻泛化界）：

$$\mathbb{E}_{D \sim \mathcal{D}^m}[(R(\mathfrak{L}_D) - \widehat{R}(\mathfrak{L}_D))^2] \leqslant \frac{8M\sqrt{2k}}{m\sqrt{\pi}} + \frac{M^2}{m}$$

## 六、本章核心要点总结

### 6.1 稳定性类型对比

| 稳定性类型         | 条件          | 结果         | 典型应用    |
| ------------------ | ------------- | ------------ | ----------- |
| 替换样本均匀稳定性 | 对所有D,z成立 | 高概率泛化界 | SVM、岭回归 |
| 移除样本均匀稳定性 | 对所有D,z成立 | 留一风险界   | 各种算法    |
| 假设稳定性         | 期望意义下    | 期望界       | k-近邻      |

### 6.2 算法稳定性总结

| 算法   | 稳定性类型 | 稳定性参数                 | 关键条件 |
| ------ | ---------- | -------------------------- | -------- |
| SVM    | 均匀稳定性 | $\beta = r^2/(\lambda m)$  | 正则化   |
| SVR    | 均匀稳定性 | $\beta = 2r^2/(\lambda m)$ | 正则化   |
| 岭回归 | 均匀稳定性 | $\beta = 4r^2M/(m\lambda)$ | 正则化   |
| k-近邻 | 假设稳定性 | $\beta = O(\sqrt{k}/m)$    | —        |

### 6.3 稳定性 vs 复杂度

| 特性       | 复杂度-based分析 | 稳定性-based分析     |
| ---------- | ---------------- | -------------------- |
| 适用范围   | 有限VC维         | 无限VC维也适用       |
| 与算法关系 | 无关             | 紧密相关             |
| 紧致性     | 通常较松         | 通常较紧             |
| 计算难度   | 计算VC维困难     | 证明稳定性可能更容易 |
| 典型应用   | 通用分析         | 特定算法分析         |

### 6.4 一句话总结

- **稳定性**：训练集扰动对算法输出的影响程度
- **均匀稳定性**：最坏情况下的稳定性保证
- **假设稳定性**：平均情况下的稳定性
- **正则化**：将凸问题变为强凸，保证稳定性
- **稳定性→泛化性**：稳定算法不会过拟合
- **稳定性→可学性**：ERM+稳定性⇒PAC可学
