## 章节概述

### 8.1 什么是在线学习？

**在线学习 (Online Learning)** 是一种学习范式，其中数据以序列形式陆续到达，学习器需要在每一轮做出决策并立即获得反馈。这与**批量学习 (Batch Learning)** 形成对比，后者假设所有训练数据提前获得。

#### 直观对比

| 特性       | 批量学习               | 在线学习           |
| ---------- | ---------------------- | ------------------ |
| 数据使用   | 一次性使用所有数据     | 逐轮使用新数据     |
| 模型更新   | 训练完成后固定         | 每轮持续更新       |
| 评价指标   | 超额风险 (Excess Risk) | 遗憾 (Regret)      |
| 空间复杂度 | 高（存储所有数据）     | 低（只需当前样本） |
| 实时性     | 差                     | 好                 |

#### 在线学习的应用场景

1. **实时推荐系统**：用户行为持续产生，需要实时更新推荐模型
2. **广告投放**：根据用户实时反馈调整投放策略
3. **股票交易**：根据市场变化实时调整投资组合
4. **网络路由**：根据网络状况动态调整路由策略

### 8.2 遗憾 (Regret) 的概念

**批量学习中的超额风险**：
$$\mathbb{E}_{(\boldsymbol{x}, y) \sim \mathcal{D}}[\ell(\boldsymbol{w}_{T+1}, (\boldsymbol{x}, y))] - \min_{\boldsymbol{w} \in \mathcal{W}}\mathbb{E}_{(\boldsymbol{x}, y) \sim \mathcal{D}}[\ell(\boldsymbol{w}, (\boldsymbol{x}, y))]$$

**在线学习中的遗憾**：
$$\sum_{t=1}^{T}\ell(\boldsymbol{w}_t, (\boldsymbol{x}_t, y_t)) - \min_{\boldsymbol{w} \in \mathcal{W}}\sum_{t=1}^{T}\ell(\boldsymbol{w}, (\boldsymbol{x}_t, y_t))$$

**关键区别**：

- 超额风险：关注最终模型的性能
- 遗憾：关注整个学习过程中累积的性能差距

## 核心概念详解

### 概念1：在线学习框架

**基本流程**：

在每一轮 $t = 1, 2, \ldots, T$：

1. **学习器选择决策**：$\boldsymbol{w}_t \in \mathcal{W}$
2. **对手选择损失函数**：$f_t: \mathcal{W} \mapsto \mathbb{R}$
3. **学习器遭受损失**：$f_t(\boldsymbol{w}_t)$
4. **学习器获得反馈**（取决于具体设置）

**两种反馈模型**：

1. **完全信息 (Full Information)**：
   - 学习器观察到整个损失函数 $f_t(\cdot)$
   - 可以计算任意 $\boldsymbol{w}$ 处的 $f_t(\boldsymbol{w})$
   - 例如：在线凸优化

2. **赌博机反馈 (Bandit Feedback)**：
   - 学习器只观察到 $f_t(\boldsymbol{w}_t)$
   - 无法知道其他决策的损失
   - 例如：多臂赌博机

### 概念2：遗憾的定义

**标准遗憾 (Standard Regret)**：

$$\text{regret} = \sum_{t=1}^{T}f_t(\boldsymbol{w}_t) - \min_{\boldsymbol{w} \in \mathcal{W}}\sum_{t=1}^{T}f_t(\boldsymbol{w})$$

**解释**：

- 第一项：学习器在实际运行中累积的损失
- 第二项：事后最优固定决策的累积损失
- 遗憾衡量：学习器与最优固定策略的差距

**关键观察**：

- 比较基准是**固定的**最优决策
- 不是与自适应的最优序列比较（那是动态遗憾）
- 遗憾随 $T$ 增长，我们希望增长速度尽可能慢

### 概念3：次线性遗憾 (Sublinear Regret)

**定义**：若遗憾满足 $\text{regret} = o(T)$，即：
$$\lim_{T \to \infty}\frac{\text{regret}}{T} = 0$$

则称算法具有**次线性遗憾**。

**意义**：

- 平均每轮遗憾趋于0：$\frac{\text{regret}}{T} \to 0$
- 学习器长期来看与最优策略表现相当
- 这是在线学习算法的基本要求

**常见的遗憾界**：

| 问题类型   | 遗憾界                       | 平均每轮遗憾          |
| ---------- | ---------------------------- | --------------------- |
| 一般凸函数 | $O(\sqrt{T})$                | $O(1/\sqrt{T}) \to 0$ |
| 强凸函数   | $O(\log T)$                  | $O(\log T/T) \to 0$   |
| 多臂赌博机 | $O(\sqrt{T})$ 或 $O(\log T)$ | 趋于0                 |

## 在线凸优化

### 8.2.1 在线梯度下降 (Online Gradient Descent, OGD)

**算法流程**：

```
输入: 初始点 w_1 ∈ W, 步长 η_t
for t = 1, ..., T do:
    学习器选择决策: w_t
    观测到损失函数: f_t(·)
    遭受损失: f_t(w_t)
    计算梯度: ∇f_t(w_t)
    更新: w_{t+1} = Π_W(w_t - η_t * ∇f_t(w_t))
end for
```

**与批量梯度下降的区别**：

- 每轮使用新的损失函数 $f_t$
- 不假设所有 $f_t$ 相同
- 目标是控制累积遗憾而非找到单一点

### 8.2.2 凸函数的遗憾界

**定理 8.1 (OGD的遗憾界)**：

假设：

- 可行域 $\mathcal{W}$ 直径为 $\Gamma$：$\|\boldsymbol{u} - \boldsymbol{v}\| \leqslant \Gamma$，$\forall \boldsymbol{u}, \boldsymbol{v} \in \mathcal{W}$
- 梯度有界：$\|\nabla f_t(\boldsymbol{w})\| \leqslant l$，$\forall t, \boldsymbol{w} \in \mathcal{W}$

采用步长 $\eta_t = \Gamma/(l\sqrt{t})$ 的OGD，遗憾界为：
$$\sum_{t=1}^{T}f_t(\boldsymbol{w}_t) - \sum_{t=1}^{T}f_t(\boldsymbol{w}) \leqslant \frac{3\Gamma l}{2}\sqrt{T} = O(\sqrt{T})$$

**详细证明**：

**步骤1**：建立单步不等式

对任意 $\boldsymbol{w} \in \mathcal{W}$，由凸性：
$$f_t(\boldsymbol{w}_t) - f_t(\boldsymbol{w}) \leqslant \langle \nabla f_t(\boldsymbol{w}_t), \boldsymbol{w}_t - \boldsymbol{w} \rangle$$

**步骤2**：代入梯度下降更新

令 $\boldsymbol{g}_t = \nabla f_t(\boldsymbol{w}_t)$：
$$= \frac{1}{\eta_t}\langle \boldsymbol{w}_t - \boldsymbol{w}_{t+1}', \boldsymbol{w}_t - \boldsymbol{w} \rangle$$

$$= \frac{1}{2\eta_t}\left(\|\boldsymbol{w}_t - \boldsymbol{w}\|^2 - \|\boldsymbol{w}_{t+1}' - \boldsymbol{w}\|^2 + \|\boldsymbol{w}_t - \boldsymbol{w}_{t+1}'\|^2\right)$$

**步骤3**：利用投影性质

$$\leqslant \frac{1}{2\eta_t}\left(\|\boldsymbol{w}_t - \boldsymbol{w}\|^2 - \|\boldsymbol{w}_{t+1} - \boldsymbol{w}\|^2\right) + \frac{\eta_t}{2}\|\boldsymbol{g}_t\|^2$$

**步骤4**：对 $t = 1$ 到 $T$ 求和

$$\sum_{t=1}^{T}(f_t(\boldsymbol{w}_t) - f_t(\boldsymbol{w})) \leqslant \sum_{t=1}^{T}\frac{1}{2\eta_t}\left(\|\boldsymbol{w}_t - \boldsymbol{w}\|^2 - \|\boldsymbol{w}_{t+1} - \boldsymbol{w}\|^2\right) + \sum_{t=1}^{T}\frac{\eta_t l^2}{2}$$

**步骤5**：处理望远镜和

第一项：
$$\sum_{t=1}^{T}\frac{1}{2\eta_t}\left(\|\boldsymbol{w}_t - \boldsymbol{w}\|^2 - \|\boldsymbol{w}_{t+1} - \boldsymbol{w}\|^2\right)$$

$$= \frac{\|\boldsymbol{w}_1 - \boldsymbol{w}\|^2}{2\eta_1} - \frac{\|\boldsymbol{w}_{T+1} - \boldsymbol{w}\|^2}{2\eta_T} + \sum_{t=2}^{T}\|\boldsymbol{w}_t - \boldsymbol{w}\|^2\left(\frac{1}{2\eta_t} - \frac{1}{2\eta_{t-1}}\right)$$

$$\leqslant \frac{\Gamma^2}{2\eta_1} + \Gamma^2\sum_{t=2}^{T}\left(\frac{1}{2\eta_t} - \frac{1}{2\eta_{t-1}}\right) = \frac{\Gamma^2}{2\eta_T}$$

**步骤6**：计算步长项

取 $\eta_t = \Gamma/(l\sqrt{t})$：
$$\sum_{t=1}^{T}\frac{\eta_t l^2}{2} = \frac{\Gamma l}{2}\sum_{t=1}^{T}\frac{1}{\sqrt{t}} \leqslant \Gamma l\sqrt{T}$$

**步骤7**：综合

$$\sum_{t=1}^{T}(f_t(\boldsymbol{w}_t) - f_t(\boldsymbol{w})) \leqslant \frac{\Gamma l\sqrt{T}}{2} + \Gamma l\sqrt{T} = \frac{3\Gamma l}{2}\sqrt{T}$$

### 8.2.3 强凸函数的遗憾界

**定理 8.2 (强凸函数的遗憾界)**：

若损失函数 $f_t$ 是 $\lambda$-强凸的，采用步长 $\eta_t = 1/(\lambda t)$ 的OGD，遗憾界为：
$$\sum_{t=1}^{T}f_t(\boldsymbol{w}_t) - \sum_{t=1}^{T}f_t(\boldsymbol{w}) \leqslant \frac{l^2}{2\lambda}(\ln T + 1) = O(\log T)$$

**详细证明**：

**步骤1**：利用强凸性

$$f_t(\boldsymbol{w}_t) - f_t(\boldsymbol{w}) \leqslant \langle \nabla f_t(\boldsymbol{w}_t), \boldsymbol{w}_t - \boldsymbol{w} \rangle - \frac{\lambda}{2}\|\boldsymbol{w}_t - \boldsymbol{w}\|^2$$

**步骤2**：代入更新规则

$$= \frac{1}{\eta_t}\langle \boldsymbol{w}_t - \boldsymbol{w}_{t+1}, \boldsymbol{w}_t - \boldsymbol{w} \rangle - \frac{\lambda}{2}\|\boldsymbol{w}_t - \boldsymbol{w}\|^2$$

$$= \frac{1}{2\eta_t}\left(\|\boldsymbol{w}_t - \boldsymbol{w}\|^2 - \|\boldsymbol{w}_{t+1} - \boldsymbol{w}\|^2 + \|\boldsymbol{w}_t - \boldsymbol{w}_{t+1}\|^2\right) - \frac{\lambda}{2}\|\boldsymbol{w}_t - \boldsymbol{w}\|^2$$

**步骤3**：代入 $\eta_t = 1/(\lambda t)$

$$= \frac{\lambda t}{2}\left(\|\boldsymbol{w}_t - \boldsymbol{w}\|^2 - \|\boldsymbol{w}_{t+1} - \boldsymbol{w}\|^2\right) + \frac{1}{2\eta_t}\|\boldsymbol{w}_t - \boldsymbol{w}_{t+1}\|^2 - \frac{\lambda}{2}\|\boldsymbol{w}_t - \boldsymbol{w}\|^2$$

$$= \frac{\lambda(t-1)}{2}\|\boldsymbol{w}_t - \boldsymbol{w}\|^2 - \frac{\lambda t}{2}\|\boldsymbol{w}_{t+1} - \boldsymbol{w}\|^2 + \frac{\eta_t}{2}\|\nabla f_t(\boldsymbol{w}_t)\|^2$$

**步骤4**：对 $t = 1$ 到 $T$ 求和

望远镜求和：
$$\sum_{t=1}^{T}\left(\frac{\lambda(t-1)}{2}\|\boldsymbol{w}_t - \boldsymbol{w}\|^2 - \frac{\lambda t}{2}\|\boldsymbol{w}_{t+1} - \boldsymbol{w}\|^2\right) = -\frac{\lambda T}{2}\|\boldsymbol{w}_{T+1} - \boldsymbol{w}\|^2 \leqslant 0$$

梯度项：
$$\sum_{t=1}^{T}\frac{\eta_t}{2}\|\nabla f_t(\boldsymbol{w}_t)\|^2 \leqslant \frac{l^2}{2\lambda}\sum_{t=1}^{T}\frac{1}{t} \leqslant \frac{l^2}{2\lambda}(\ln T + 1)$$

**结论**：
$$\sum_{t=1}^{T}f_t(\boldsymbol{w}_t) - \sum_{t=1}^{T}f_t(\boldsymbol{w}) \leqslant \frac{l^2}{2\lambda}(\ln T + 1)$$

## 赌博机在线学习

### 8.3.1 随机多臂赌博机 (Stochastic Multi-Armed Bandit)

**问题设置**：

- 有 $K$ 个摇臂 (arms)
- 每个摇臂 $i$ 有未知的期望奖励 $\mu_i$
- 每轮选择一个摇臂 $i_t$，获得随机奖励 $r_t \sim \text{Distribution}(\mu_{i_t})$
- 目标：最大化累积奖励（或最小化遗憾）

**遗憾定义**：
$$\text{regret} = T\mu^* - \sum_{t=1}^{T}\mu_{i_t}$$

其中 $\mu^* = \max_i \mu_i$ 是最优摇臂的期望奖励。

**探索-利用困境 (Exploration-Exploitation Dilemma)**：

- **利用 (Exploitation)**：选择当前估计奖励最高的摇臂
- **探索 (Exploration)**：尝试其他摇臂以获取更多信息
- 困境：过多探索浪费机会，过少探索可能错过最优摇臂

### 8.3.2 置信上界 (Upper Confidence Bound, UCB) 算法

**核心思想**：乐观面对不确定性 (Optimism in the Face of Uncertainty)

对每个摇臂 $i$，维护：

- $n_i(t)$：到第 $t$ 轮为止选择摇臂 $i$ 的次数
- $\hat{\mu}_i(t)$：到第 $t$ 轮为止摇臂 $i$ 的平均奖励

**UCB1 算法**：

```
初始化: 对每个摇臂 i, 选择一次, 记录奖励
for t = K+1, ..., T do:
    计算每个摇臂的UCB值:
        UCB_i = μ̂_i + √(2ln(t)/n_i)
    选择: i_t = argmax_i UCB_i
    观测奖励并更新 μ̂_{i_t} 和 n_{i_t}
end for
```

**UCB公式的解释**：

- $\hat{\mu}_i$：利用项（当前估计）
- $\sqrt{2\ln(t)/n_i}$：探索项（不确定性）
- 选择次数少的摇臂有更高的探索项，鼓励探索

**定理 8.3 (UCB的遗憾界)**：

UCB算法的遗憾界为 $O(\sqrt{KT\ln T})$。

**证明的核心思想**：

**步骤1**：定义坏事件

摇臂 $i$ 被选择当：
$$\hat{\mu}_i + \sqrt{\frac{2\ln t}{n_i}} \geqslant \hat{\mu}^* + \sqrt{\frac{2\ln t}{n^*}}$$

若最优摇臂 $i^*$ 和次优摇臂 $i$ 都被充分采样，这种情况不太可能发生。

**步骤2**：分析次优摇臂的选择次数

可以证明，次优摇臂 $i$ 被选择的期望次数：
$$\mathbb{E}[n_i(T)] \leqslant \frac{8\ln T}{\Delta_i^2} + O(1)$$

其中 $\Delta_i = \mu^* - \mu_i$ 是奖励差距。

**步骤3**：计算遗憾

$$\text{regret} = \sum_{i: \mu_i < \mu^*}\Delta_i \cdot \mathbb{E}[n_i(T)] \leqslant \sum_{i: \mu_i < \mu^*}\frac{8\ln T}{\Delta_i} + O(1)$$

对于最坏情况，可以证明 $O(\sqrt{KT\ln T})$ 的界。

### 8.3.3 线性赌博机 (Linear Bandit)

**问题设置**：

- 决策空间 $\mathcal{X} \subseteq \mathbb{R}^d$（可能是无限的）
- 未知参数 $\boldsymbol{w}^* \in \mathbb{R}^d$
- 选择决策 $\boldsymbol{x}_t$ 获得奖励 $r_t = \boldsymbol{x}_t^T\boldsymbol{w}^* + \epsilon_t$（$\epsilon_t$ 是噪声）
- 目标：最小化遗憾

**遗憾定义**：
$$\text{regret} = T\max_{\boldsymbol{x} \in \mathcal{X}}\boldsymbol{x}^T\boldsymbol{w}^* - \sum_{t=1}^{T}\boldsymbol{x}_t^T\boldsymbol{w}^*$$

**线性UCB算法**：

**核心思想**：维护 $\boldsymbol{w}^*$ 的置信区域，选择乐观最优的决策。

**参数估计**：

使用岭回归估计 $\boldsymbol{w}^*$：
$$\boldsymbol{w}_t = \mathbf{Z}_t^{-1}\boldsymbol{b}_t$$

其中：
$$\mathbf{Z}_t = \lambda\mathbf{I} + \sum_{s=1}^{t-1}\boldsymbol{x}_s\boldsymbol{x}_s^T, \quad \boldsymbol{b}_t = \sum_{s=1}^{t-1}r_s\boldsymbol{x}_s$$

**置信区域**：

以高概率，$\boldsymbol{w}^*$ 落在椭圆置信区域内：
$$\mathcal{R}_t = \{\boldsymbol{w}: \|\boldsymbol{w} - \boldsymbol{w}_t\|_{\mathbf{Z}_t} \leqslant \sqrt{\gamma_t}\}$$

其中 $\|\boldsymbol{w}\|_{\mathbf{Z}} = \sqrt{\boldsymbol{w}^T\mathbf{Z}\boldsymbol{w}}$ 是Mahalanobis范数。

**决策选择**：
$$(\boldsymbol{x}_t, \tilde{\boldsymbol{w}}_t) = \arg\max_{\boldsymbol{x} \in \mathcal{X}, \boldsymbol{w} \in \mathcal{R}_t}\boldsymbol{x}^T\boldsymbol{w}$$

**定理 8.4 (线性赌博机的遗憾界)**：

线性UCB算法的遗憾界为 $\tilde{O}(d\sqrt{T})$。

**关键分析**：

**步骤1**：分解遗憾

$$\text{regret} = \sum_{t=1}^{T}(\boldsymbol{x}^* - \boldsymbol{x}_t)^T\boldsymbol{w}^* \leqslant \sum_{t=1}^{T}(\boldsymbol{x}_t^T\tilde{\boldsymbol{w}}_t - \boldsymbol{x}_t^T\boldsymbol{w}^*)$$

（由乐观选择性质）

**步骤2**：利用置信区域

在置信区域内：
$$\boldsymbol{x}_t^T\tilde{\boldsymbol{w}}_t - \boldsymbol{x}_t^T\boldsymbol{w}^* \leqslant \|\boldsymbol{x}_t\|_{\mathbf{Z}_t^{-1}} \cdot \|\tilde{\boldsymbol{w}}_t - \boldsymbol{w}^*\|_{\mathbf{Z}_t} \leqslant \sqrt{\gamma_t}\|\boldsymbol{x}_t\|_{\mathbf{Z}_t^{-1}}$$

**步骤3**：应用椭圆势引理

$$\sum_{t=1}^{T}\min(1, \|\boldsymbol{x}_t\|_{\mathbf{Z}_t^{-1}}^2) \leqslant 2d\ln\left(1 + \frac{T}{d\lambda}\right)$$

**结论**：
$$\text{regret} \leqslant \sqrt{\gamma_T T \cdot 2d\ln\left(1 + \frac{T}{d\lambda}\right)} = \tilde{O}(d\sqrt{T})$$

### 8.3.4 凸赌博机 (Convex Bandit)

**问题设置**：

- 可行域 $\mathcal{W} \subseteq \mathbb{R}^d$ 是凸集
- 每轮选择 $\boldsymbol{w}_t \in \mathcal{W}$
- 遭受损失 $f_t(\boldsymbol{w}_t)$（只观察到损失值，不观察到梯度）
- 损失函数 $f_t$ 是凸函数

**挑战**：

- 只有赌博机反馈（单点损失值）
- 无法直接计算梯度
- 需要梯度估计

**单点梯度估计** [Flaxman et al., 2005]：

对于单位球 $\mathcal{B}$ 上的均匀随机向量 $\boldsymbol{u}$：
$$\mathbb{E}[f(\boldsymbol{w} + \delta\boldsymbol{u})\boldsymbol{u}] = \frac{\delta}{d}\nabla \hat{f}(\boldsymbol{w})$$

其中 $\hat{f}$ 是 $f$ 的平滑版本。

**算法流程**：

```
输入: 初始点 w_1, 参数 δ, 步长 η_t
for t = 1, ..., T do:
    采样: u_t ~ Uniform({u: ||u|| = 1})
    选择决策: w_t' = w_t + δ*u_t
    观测损失: f_t(w_t')
    梯度估计: g_t = (d/δ) * f_t(w_t') * u_t
    更新: w_{t+1} = Π_W(w_t - η_t * g_t)
end for
```

**定理 8.5 (凸赌博机的遗憾界)**：

对于Lipschitz连续的凸函数，上述算法的遗憾界为 $O(T^{3/4})$。

**注**：通过更高级的梯度估计技术（如核方法），可以达到 $O(\text{poly}(\log T)\sqrt{T})$ 的遗憾界。

## 分析实例

### 8.4.1 在线支持向量机

**问题设置**：

每轮 $t$：

1. 学习器选择分类面 $\boldsymbol{w}_t$
2. 观测到样本 $(\boldsymbol{x}_t, y_t)$
3. 遭受hinge损失：
   $$f_t(\boldsymbol{w}_t) = \max(0, 1 - y_t\boldsymbol{w}_t^T\boldsymbol{x}_t) + \frac{\lambda}{2}\|\boldsymbol{w}_t\|^2$$

**算法**：在线梯度下降

**梯度计算**：
$$\nabla f_t(\boldsymbol{w}_t) = \begin{cases} -y_t\boldsymbol{x}_t + \lambda\boldsymbol{w}_t & \text{if } y_t\boldsymbol{w}_t^T\boldsymbol{x}_t \leqslant 1 \\ \lambda\boldsymbol{w}_t & \text{if } y_t\boldsymbol{w}_t^T\boldsymbol{x}_t > 1 \end{cases}$$

**更新规则**：
$$\boldsymbol{w}_{t+1} = \boldsymbol{w}_t - \eta_t\nabla f_t(\boldsymbol{w}_t) = \left(1 - \frac{1}{t}\right)\boldsymbol{w}_t + \frac{y_t}{\lambda t}\boldsymbol{x}_t\mathbb{I}(y_t\boldsymbol{w}_t^T\boldsymbol{x}_t \leqslant 1)$$

（取 $\eta_t = 1/(\lambda t)$）

**定理 8.6 (在线SVM的遗憾界)**：

在线梯度下降算法的遗憾界为 $O(\log T)$。

**证明的核心步骤**：

**步骤1**：证明梯度有界

通过归纳法证明 $\|\boldsymbol{w}_t\| \leqslant r/\lambda$（假设 $\|\boldsymbol{x}_t\| \leqslant r$）：

- 基例：$\|\boldsymbol{w}_1\| = 0 \leqslant r/\lambda$
- 归纳步骤：
  $$\|\boldsymbol{w}_{k+1}\| \leqslant \frac{k-1}{k}\|\boldsymbol{w}_k\| + \frac{1}{\lambda k}\|\boldsymbol{x}_k\| \leqslant \frac{k-1}{k}\frac{r}{\lambda} + \frac{r}{\lambda k} = \frac{r}{\lambda}$$

因此：$\|\nabla f_t(\boldsymbol{w}_t)\| \leqslant r + \lambda(r/\lambda) = 2r$

**步骤2**：应用强凸函数的遗憾界

由定理 8.2：
$$\sum_{t=1}^{T}f_t(\boldsymbol{w}_t) - \min_{\boldsymbol{w}}\sum_{t=1}^{T}f_t(\boldsymbol{w}) \leqslant \frac{(2r)^2}{2\lambda}(\ln T + 1) = O(\log T)$$

### 8.4.2 对率赌博机 (Logistic Bandit)

**问题设置**：

- 布尔反馈：$y_t \in \{-1, +1\}$
- 对率模型：$P(y_t = \pm 1 | \boldsymbol{x}_t) = \frac{1}{1 + \exp(-y_t\boldsymbol{x}_t^T\boldsymbol{w}^*)}$
- 期望奖励：$r_t = \frac{\exp(\boldsymbol{x}_t^T\boldsymbol{w}^*)}{1 + \exp(\boldsymbol{x}_t^T\boldsymbol{w}^*)}$

**遗憾定义**：
$$\text{regret} = T\max_{\boldsymbol{x} \in \mathcal{X}}\frac{\exp(\boldsymbol{x}^T\boldsymbol{w}^*)}{1 + \exp(\boldsymbol{x}^T\boldsymbol{w}^*)} - \sum_{t=1}^{T}\frac{\exp(\boldsymbol{x}_t^T\boldsymbol{w}^*)}{1 + \exp(\boldsymbol{x}_t^T\boldsymbol{w}^*)}$$

**算法**：

**步骤1**：维护参数估计

在第 $t$ 轮，$\boldsymbol{w}^*$ 以高概率落在置信区域：
$$\mathcal{R}_t = \{\boldsymbol{w}: \|\boldsymbol{w} - \boldsymbol{w}_t\|_{\mathbf{Z}_t} \leqslant \sqrt{\gamma_t}\}$$

**步骤2**：乐观选择决策

$$(\boldsymbol{x}_t, \tilde{\boldsymbol{w}}_t) = \arg\max_{\boldsymbol{x} \in \mathcal{X}, \boldsymbol{w} \in \mathcal{R}_t}\boldsymbol{x}^T\boldsymbol{w}$$

**步骤3**：更新参数

对率损失：
$$f_t(\boldsymbol{w}) = \ln(1 + \exp(-y_t\boldsymbol{x}_t^T\boldsymbol{w}))$$

利用指数凹性质，使用类似在线牛顿法的更新：
$$\boldsymbol{w}_{t+1} = \arg\min_{\|\boldsymbol{w}\| \leqslant \Lambda}\frac{\|\boldsymbol{w} - \boldsymbol{w}_t\|_{\mathbf{Z}_{t+1}}^2}{2} + (\boldsymbol{w} - \boldsymbol{w}_t)^T\nabla f_t(\boldsymbol{w}_t)$$

其中：
$$\mathbf{Z}_{t+1} = \mathbf{Z}_t + \frac{\beta}{2}\boldsymbol{x}_t\boldsymbol{x}_t^T, \quad \mathbf{Z}_1 = \lambda\mathbf{I}$$

**定理 8.7 (对率赌博机的遗憾界)**：

对率赌博机的遗憾界为 $\tilde{O}(d\sqrt{T})$。

## 章节小结

### 核心要点回顾

1. **在线学习 vs 批量学习**：
   - 在线学习：数据序列到达，逐轮更新
   - 批量学习：一次性使用所有数据
   - 评价指标：遗憾 vs 超额风险

2. **遗憾的定义**：
   $$\text{regret} = \sum_{t=1}^{T}f_t(\boldsymbol{w}_t) - \min_{\boldsymbol{w} \in \mathcal{W}}\sum_{t=1}^{T}f_t(\boldsymbol{w})$$
   - 累积损失与最优固定策略的差距
   - 次线性遗憾：$\text{regret} = o(T)$

3. **在线凸优化**：
   | 函数类型 | 遗憾界 | 算法 |
   |----------|--------|------|
   | 凸函数 | $O(\sqrt{T})$ | OGD |
   | 强凸函数 | $O(\log T)$ | OGD（衰减步长） |

4. **赌博机在线学习**：
   | 问题类型 | 遗憾界 | 算法 |
   |----------|--------|------|
   | 多臂赌博机 | $O(\sqrt{KT\ln T})$ | UCB |
   | 线性赌博机 | $\tilde{O}(d\sqrt{T})$ | 线性UCB |
   | 凸赌博机 | $O(T^{3/4})$ | 单点梯度估计 |

5. **探索-利用困境**：
   - 核心挑战：在探索新选项和利用已知好选项之间平衡
   - UCB策略：乐观面对不确定性

### 关键公式总结

| 概念        | 公式                                                                                                             |
| ----------- | ---------------------------------------------------------------------------------------------------------------- |
| 遗憾        | $\sum_{t=1}^{T}f_t(\boldsymbol{w}_t) - \min_{\boldsymbol{w}}\sum_{t=1}^{T}f_t(\boldsymbol{w})$                   |
| OGD（凸）   | $\eta_t = \Gamma/(l\sqrt{t})$，遗憾 $O(\sqrt{T})$                                                                |
| OGD（强凸） | $\eta_t = 1/(\lambda t)$，遗憾 $O(\log T)$                                                                       |
| UCB         | $\text{UCB}_i = \hat{\mu}_i + \sqrt{2\ln t/n_i}$                                                                 |
| 线性UCB     | 选择 $\arg\max_{\boldsymbol{x} \in \mathcal{X}, \boldsymbol{w} \in \mathcal{R}_t}\boldsymbol{x}^T\boldsymbol{w}$ |
