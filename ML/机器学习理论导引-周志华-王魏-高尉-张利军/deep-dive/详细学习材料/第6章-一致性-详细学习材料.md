## 章节概述

### 6.1 什么是一致性？

**一致性 (Consistency)** 是机器学习理论中研究学习算法在**无限数据极限**下性能的重要概念。它关注的是：随着训练数据的增多，甚至趋于无穷的极限过程中，学习算法通过训练数据学习得到的分类器是否趋于**贝叶斯最优分类器**。

#### 直观理解

想象一个学生在不断学习：

- **初期**：学生只看过几本教材，知识有限
- **中期**：学生阅读了大量书籍，知识逐渐完善
- **极限**：学生读完了世界上所有的书，掌握了所有知识

一致性问的是：当学生读的书趋于无穷时，他能否成为该领域的"最优专家"？

## 核心概念详解

### 概念1：问题设置

本章关注**二分类问题**，基本设置如下：

- **样本空间**：$\mathcal{X} \subseteq \mathbb{R}^d$
- **标记空间**：$\mathcal{Y} = \{-1, +1\}$
- **数据分布**：$\mathcal{D}$ 是 $\mathcal{X} \times \mathcal{Y}$ 上的联合分布

**边缘分布与条件概率**：

基于联合分布 $\mathcal{D}$，可以定义：

- **边缘分布**：$\mathcal{D}_{\mathcal{X}}$ 是样本空间 $\mathcal{X}$ 上的分布
- **条件概率**：

$$\eta(\boldsymbol{x}) = P(y = +1 | \boldsymbol{x})$$

**详细解释**：

- $\eta(\boldsymbol{x})$ 表示给定样本 $\boldsymbol{x}$ 时，其标记为正类 (+1) 的概率
- 由定义可知：$P(y = -1 | \boldsymbol{x}) = 1 - \eta(\boldsymbol{x})$
- 条件概率 $\eta(\boldsymbol{x})$ 完全刻画了数据生成的随机性

### 概念2：泛化风险 (Generalization Risk)

**定义**：对于分类器 $h: \mathcal{X} \mapsto \mathcal{Y}$，其泛化风险定义为：

$$R(h) = P_{(\boldsymbol{x}, y) \sim \mathcal{D}}(h(\boldsymbol{x}) \neq y) = \mathbb{E}_{(\boldsymbol{x}, y) \sim \mathcal{D}}[\mathbb{I}(h(\boldsymbol{x}) \neq y)]$$

**基于条件概率的展开**：

利用全期望公式，可以将泛化风险展开为：

$$R(h) = \mathbb{E}_{\boldsymbol{x} \sim \mathcal{D}_{\mathcal{X}}}[\eta(\boldsymbol{x})\mathbb{I}(h(\boldsymbol{x}) = -1) + (1-\eta(\boldsymbol{x}))\mathbb{I}(h(\boldsymbol{x}) = +1)]$$

**详细推导**：

$$
\begin{aligned}
R(h) &= \mathbb{E}_{(\boldsymbol{x}, y) \sim \mathcal{D}}[\mathbb{I}(h(\boldsymbol{x}) \neq y)] \\
&= \mathbb{E}_{\boldsymbol{x} \sim \mathcal{D}_{\mathcal{X}}}\left[\mathbb{E}_{y|\boldsymbol{x}}[\mathbb{I}(h(\boldsymbol{x}) \neq y)]\right] \\
&= \mathbb{E}_{\boldsymbol{x} \sim \mathcal{D}_{\mathcal{X}}}\left[P(y=+1|\boldsymbol{x})\mathbb{I}(h(\boldsymbol{x}) \neq +1) + P(y=-1|\boldsymbol{x})\mathbb{I}(h(\boldsymbol{x}) \neq -1)\right] \\
&= \mathbb{E}_{\boldsymbol{x} \sim \mathcal{D}_{\mathcal{X}}}[\eta(\boldsymbol{x})\mathbb{I}(h(\boldsymbol{x}) = -1) + (1-\eta(\boldsymbol{x}))\mathbb{I}(h(\boldsymbol{x}) = +1)]
\end{aligned}
$$

### 概念3：贝叶斯最优分类器 (Bayes Optimal Classifier)

**定义**：在分布 $\mathcal{D}$ 上取得最小泛化风险的分类器称为**贝叶斯最优分类器**，记为 $h^*$：

$$h^* \in \arg\min_h R(h)$$

**贝叶斯风险**：贝叶斯分类器的泛化风险称为**贝叶斯风险**：

$$R^* = R(h^*) = \min_h R(h)$$

**贝叶斯分类器的显式形式**：

**定理**：贝叶斯最优分类器可以显式表示为：

$$h^*(\boldsymbol{x}) = 2\mathbb{I}\left(\eta(\boldsymbol{x}) \geqslant \frac{1}{2}\right) - 1 = \begin{cases} +1 & \text{if } \eta(\boldsymbol{x}) \geqslant 1/2 \\ -1 & \text{if } \eta(\boldsymbol{x}) < 1/2 \end{cases}$$

**证明**：

对于固定的 $\boldsymbol{x}$，考虑两种决策的风险：

- 预测 $h(\boldsymbol{x}) = +1$ 的风险：$1 - \eta(\boldsymbol{x})$
- 预测 $h(\boldsymbol{x}) = -1$ 的风险：$\eta(\boldsymbol{x})$

最优决策是选择风险较小的标记：

- 若 $\eta(\boldsymbol{x}) \geqslant 1 - \eta(\boldsymbol{x})$（即 $\eta(\boldsymbol{x}) \geqslant 1/2$），预测 +1
- 若 $\eta(\boldsymbol{x}) < 1/2$，预测 -1

**贝叶斯风险的显式形式**：

$$R^* = \mathbb{E}_{\boldsymbol{x} \sim \mathcal{D}_{\mathcal{X}}}[\min\{\eta(\boldsymbol{x}), 1-\eta(\boldsymbol{x})\}]$$

**直观理解**：

- 当 $\eta(\boldsymbol{x}) = 1$ 或 $\eta(\boldsymbol{x}) = 0$ 时，数据是"确定性"的，贝叶斯风险为0
- 当 $\eta(\boldsymbol{x}) = 1/2$ 时，数据是"纯随机"的，该点贡献的风险为 $1/2$
- 贝叶斯风险反映了数据本身的"固有噪声"

### 概念4：一致性的定义

**定义 6.1 (一致性)**：当 $m \to \infty$ 时，若学习算法 $\mathfrak{L}$ 满足：

$$\mathbb{E}_{D_m \sim \mathcal{D}^m}[R(\mathfrak{L}_{D_m})] \to R(h^*)$$

则称学习算法 $\mathfrak{L}$ 具有**一致性**（弱一致性）。

**详细解释**：

- $D_m$：大小为 $m$ 的训练集
- $\mathfrak{L}_{D_m}$：算法 $\mathfrak{L}$ 基于训练集 $D_m$ 输出的分类器
- $R(\mathfrak{L}_{D_m})$：该分类器的泛化风险
- 期望 $\mathbb{E}_{D_m \sim \mathcal{D}^m}$ 是对训练集的随机性取期望

**直观理解**：

- 一致性反映了：在训练数据足够多的情形下，算法能否学习得到贝叶斯最优分类器
- 理论上，一致性刻画了学习算法在无限多数据情形下学习的性能极限
- 注意：一致性是**渐近**性质，不直接给出有限样本下的保证

**引理 6.1 (风险差公式)**：对任意分类器 $h$ 和贝叶斯分类器 $h^*$，有：

$$R(h) - R^* = \mathbb{E}_{\boldsymbol{x} \sim \mathcal{D}_{\mathcal{X}}}[|1 - 2\eta(\boldsymbol{x})|\mathbb{I}(h(\boldsymbol{x}) \neq h^*(\boldsymbol{x}))]$$

**证明详解**：

定义：
$$\Delta(\boldsymbol{x}) = \eta(\boldsymbol{x})\mathbb{I}(h(\boldsymbol{x}) = -1) + (1-\eta(\boldsymbol{x}))\mathbb{I}(h(\boldsymbol{x}) = +1) - \min\{\eta(\boldsymbol{x}), 1-\eta(\boldsymbol{x})\}$$

则：
$$R(h) - R^* = \mathbb{E}_{\boldsymbol{x} \sim \mathcal{D}_{\mathcal{X}}}[\Delta(\boldsymbol{x})]$$

分情况讨论：

**情况1**：$\eta(\boldsymbol{x}) > 1/2$

- 此时 $h^*(\boldsymbol{x}) = +1$
- 若 $h(\boldsymbol{x}) = +1$：$\Delta(\boldsymbol{x}) = 0$
- 若 $h(\boldsymbol{x}) = -1$：$\Delta(\boldsymbol{x}) = \eta(\boldsymbol{x}) - (1-\eta(\boldsymbol{x})) = 2\eta(\boldsymbol{x}) - 1 = |1 - 2\eta(\boldsymbol{x})|$

**情况2**：$\eta(\boldsymbol{x}) < 1/2$

- 此时 $h^*(\boldsymbol{x}) = -1$
- 若 $h(\boldsymbol{x}) = -1$：$\Delta(\boldsymbol{x}) = 0$
- 若 $h(\boldsymbol{x}) = +1$：$\Delta(\boldsymbol{x}) = (1-\eta(\boldsymbol{x})) - \eta(\boldsymbol{x}) = 1 - 2\eta(\boldsymbol{x}) = |1 - 2\eta(\boldsymbol{x})|$

**情况3**：$\eta(\boldsymbol{x}) = 1/2$

- 此时 $|1 - 2\eta(\boldsymbol{x})| = 0$，无论 $h(\boldsymbol{x})$ 取何值，$\Delta(\boldsymbol{x}) = 0$

综上：
$$\Delta(\boldsymbol{x}) = |1 - 2\eta(\boldsymbol{x})|\mathbb{I}(h(\boldsymbol{x}) \neq h^*(\boldsymbol{x}))$$

### 概念5：插入法 (Plug-in Method)

**基本思想**：

1. 通过训练集估计条件概率 $\hat{\eta}(\boldsymbol{x})$
2. 使用估计的条件概率构建分类器：

$$h(\boldsymbol{x}) = 2\mathbb{I}\left(\hat{\eta}(\boldsymbol{x}) \geqslant \frac{1}{2}\right) - 1$$

**引理 6.2 (插入法的性能保证)**：对插入法分类器 $h$，有：

$$R(h) - R^* \leqslant 2\mathbb{E}_{\boldsymbol{x} \sim \mathcal{D}_{\mathcal{X}}}[|\hat{\eta}(\boldsymbol{x}) - \eta(\boldsymbol{x})|] \leqslant 2\sqrt{\mathbb{E}_{\boldsymbol{x} \sim \mathcal{D}_{\mathcal{X}}}[(\hat{\eta}(\boldsymbol{x}) - \eta(\boldsymbol{x}))^2]}$$

**证明详解**：

**步骤1**：应用引理 6.1

$$R(h) - R^* = \mathbb{E}_{\boldsymbol{x} \sim \mathcal{D}_{\mathcal{X}}}[|1 - 2\eta(\boldsymbol{x})|\mathbb{I}(h(\boldsymbol{x}) \neq h^*(\boldsymbol{x}))]$$

**步骤2**：分析 $h(\boldsymbol{x}) \neq h^*(\boldsymbol{x})$ 的条件

当 $h(\boldsymbol{x}) \neq h^*(\boldsymbol{x})$ 时，有：
$$\mathbb{I}\left(\hat{\eta}(\boldsymbol{x}) \geqslant \frac{1}{2}\right) \neq \mathbb{I}\left(\eta(\boldsymbol{x}) \geqslant \frac{1}{2}\right)$$

这意味着 $\hat{\eta}(\boldsymbol{x})$ 和 $\eta(\boldsymbol{x})$ 位于 $1/2$ 的两侧（或一侧等于 $1/2$）。

**步骤3**：建立关键不等式

若 $\hat{\eta}(\boldsymbol{x}) \geqslant 1/2$ 且 $\eta(\boldsymbol{x}) < 1/2$：
$$|1 - 2\eta(\boldsymbol{x})| = 2|1/2 - \eta(\boldsymbol{x})| \leqslant 2|\hat{\eta}(\boldsymbol{x}) - \eta(\boldsymbol{x})|$$

同理，若 $\hat{\eta}(\boldsymbol{x}) < 1/2$ 且 $\eta(\boldsymbol{x}) \geqslant 1/2$：
$$|1 - 2\eta(\boldsymbol{x})| = 2|\eta(\boldsymbol{x}) - 1/2| \leqslant 2|\hat{\eta}(\boldsymbol{x}) - \eta(\boldsymbol{x})|$$

**步骤4**：综合推导

因此：
$$R(h) - R^* \leqslant 2\mathbb{E}_{\boldsymbol{x} \sim \mathcal{D}_{\mathcal{X}}}[|\hat{\eta}(\boldsymbol{x}) - \eta(\boldsymbol{x})|]$$

由Jensen不等式：
$$\mathbb{E}[|X|] \leqslant \sqrt{\mathbb{E}[X^2]}$$

得：
$$R(h) - R^* \leqslant 2\sqrt{\mathbb{E}_{\boldsymbol{x} \sim \mathcal{D}_{\mathcal{X}}}[(\hat{\eta}(\boldsymbol{x}) - \eta(\boldsymbol{x}))^2]}$$

**结论**：插入法的一致性等价于条件概率估计的 $L_1$ 或 $L_2$ 一致性。

## 替代函数与一致性

### 6.2.1 从0/1损失到替代函数

**0/1损失的问题**：

对于二分类问题，理想的优化目标是0/1损失：

$$R(h) = \mathbb{E}_{(\boldsymbol{x}, y) \sim \mathcal{D}}[\mathbb{I}(yh(\boldsymbol{x}) \leqslant 0)]$$

但0/1损失存在以下问题：

1. **非凸**：导致优化问题有多个局部最优
2. **不连续**：在 $yf(\boldsymbol{x}) = 0$ 处不连续
3. **难以优化**：直接优化是NP难问题

**替代函数的思想**：

用一个具有良好数学性质的**凸函数** $\phi: \mathbb{R} \mapsto \mathbb{R}$ 来替代0/1损失：

$$\ell(f(\boldsymbol{x}), y) = \phi(yf(\boldsymbol{x}))$$

其中 $f: \mathcal{X} \mapsto \mathbb{R}$ 是实值输出函数，最终分类器为：

$$h(\boldsymbol{x}) = \begin{cases} +1 & f(\boldsymbol{x}) \geqslant 0 \\ -1 & f(\boldsymbol{x}) < 0 \end{cases}$$

### 6.2.2 常见的替代函数

| 名称          | 函数形式                    | 应用                           |
| ------------- | --------------------------- | ------------------------------ |
| **平方损失**  | $\phi(t) = (1-t)^2$         | 最小二乘分类                   |
| **Hinge损失** | $\phi(t) = \max(0, 1-t)$    | 支持向量机 (SVM)               |
| **指数损失**  | $\phi(t) = e^{-t}$          | AdaBoost                       |
| **对率损失**  | $\phi(t) = \ln(1 + e^{-t})$ | 对率回归 (Logistic Regression) |

**各替代函数的特点**：

1. **平方损失**：
   - 处处光滑
   - 对异常值敏感
   - 最优解与贝叶斯分类器相关

2. **Hinge损失**：
   - 在 $t \geqslant 1$ 时为0，形成"间隔"
   - 不是处处可导（在 $t=1$ 处）
   - 支持向量机的核心

3. **指数损失**：
   - 对误分类样本惩罚指数增长
   - AdaBoost的理论基础
   - 对异常值非常敏感

4. **对率损失**：
   - 处处光滑
   - 概率解释清晰
   - 对异常值相对鲁棒

### 6.2.3 替代泛化风险

**定义**：给定替代函数 $\phi$，定义替代泛化风险：

$$R_{\phi}(f) = \mathbb{E}_{(\boldsymbol{x}, y) \sim \mathcal{D}}[\phi(yf(\boldsymbol{x}))]$$

**最优替代风险**：

$$R_{\phi}^* = \min_f R_{\phi}(f)$$

**基于条件概率的展开**：

$$R_{\phi}(f) = \mathbb{E}_{\boldsymbol{x} \sim \mathcal{D}_{\mathcal{X}}}[\eta(\boldsymbol{x})\phi(f(\boldsymbol{x})) + (1-\eta(\boldsymbol{x}))\phi(-f(\boldsymbol{x}))]$$

**点态最优解**：

对于固定的 $\boldsymbol{x}$，最优实值输出为：

$$f_{\phi}^*(\boldsymbol{x}) \in \arg\min_{f(\boldsymbol{x}) \in \mathbb{R}}(\eta(\boldsymbol{x})\phi(f(\boldsymbol{x})) + (1-\eta(\boldsymbol{x}))\phi(-f(\boldsymbol{x})))$$

### 6.2.4 替代一致性的定义

**定义 6.2 (替代函数一致性)**：随着训练数据规模 $m \to \infty$，通过优化替代经验风险得到一系列输出函数 $\hat{f}_1, \hat{f}_2, \ldots, \hat{f}_m, \ldots$，若 $R_{\phi}(\hat{f}_m) \to R_{\phi}^*$ 时有 $R(\hat{f}_m) \to R^*$ 成立，则称替代函数 $\phi$ 对原0/1目标函数具有**一致性**。

**直观理解**：

- 替代一致性关心的是：通过优化替代函数能否有效优化原0/1目标函数
- 即使替代风险收敛到最优，原风险是否也收敛到贝叶斯风险？
- 并非所有替代函数都具有一致性

### 6.2.5 替代一致性的充分条件

**定理 6.1 (替代一致性的充分条件)** [Zhang, 2004b]：

对替代函数 $\phi$，若：

1. 最优实值输出函数满足 $f_{\phi}^* \in \mathcal{F}^*$，其中：

$$\mathcal{F}^* = \{f: \text{当 } \eta(\boldsymbol{x}) = 1/2 \text{ 时 } f(\boldsymbol{x}) \text{ 任意}; \text{当 } \eta(\boldsymbol{x}) \neq 1/2 \text{ 时 } f(\boldsymbol{x})(\eta(\boldsymbol{x}) - 1/2) > 0\}$$

2. 存在常数 $c > 0$ 和 $s \geqslant 1$ 使：

$$|\eta(\boldsymbol{x}) - 1/2|^s \leqslant c^s(\phi(0) - \eta(\boldsymbol{x})\phi(f_{\phi}^*(\boldsymbol{x})) - (1-\eta(\boldsymbol{x}))\phi(-f_{\phi}^*(\boldsymbol{x})))$$

则替代函数 $\phi$ 具有一致性。

**详细解读**：

**条件1 ($f_{\phi}^* \in \mathcal{F}^*$)**：

- 确保替代函数的最优解对应正确的分类决策
- 当 $\eta(\boldsymbol{x}) > 1/2$ 时，要求 $f_{\phi}^*(\boldsymbol{x}) > 0$
- 当 $\eta(\boldsymbol{x}) < 1/2$ 时，要求 $f_{\phi}^*(\boldsymbol{x}) < 0$

**条件2 (不等式条件)**：

- 建立了替代风险与分类风险之间的联系
- 左边 $|\eta(\boldsymbol{x}) - 1/2|$ 衡量分类的"确定性"
- 右边是替代函数在最优解处的"冗余"

**证明的核心思想**：

**步骤1**：定义风险差

$$\Delta_1(\boldsymbol{x}) = \eta(\boldsymbol{x})\mathbb{I}(f(\boldsymbol{x}) \leqslant 0) + (1-\eta(\boldsymbol{x}))\mathbb{I}(f(\boldsymbol{x}) \geqslant 0) - \min\{\eta(\boldsymbol{x}), 1-\eta(\boldsymbol{x})\}$$

则：
$$R(f) - R^* = \mathbb{E}_{\boldsymbol{x} \sim \mathcal{D}_{\mathcal{X}}}[\Delta_1(\boldsymbol{x})]$$

**步骤2**：分析 $\Delta_1(\boldsymbol{x})$

可以证明：
$$\Delta_1(\boldsymbol{x}) = 2\mathbb{I}((\eta(\boldsymbol{x}) - 1/2)f(\boldsymbol{x}) \leqslant 0)|\eta(\boldsymbol{x}) - 1/2|$$

因此：
$$R(f) - R^* = 2\mathbb{E}_{(\eta(\boldsymbol{x}) - 1/2)f(\boldsymbol{x}) \leqslant 0}[|\eta(\boldsymbol{x}) - 1/2|]$$

**步骤3**：应用Jensen不等式

对 $s \geqslant 1$：
$$R(f) - R^* \leqslant 2\sqrt[s]{\mathbb{E}_{(\eta(\boldsymbol{x}) - 1/2)f(\boldsymbol{x}) \leqslant 0}[|\eta(\boldsymbol{x}) - 1/2|^s]}$$

**步骤4**：利用定理条件

根据条件2：
$$|\eta(\boldsymbol{x}) - 1/2|^s \leqslant c^s(\phi(0) - \Delta_3(\boldsymbol{x}))$$

其中 $\Delta_3(\boldsymbol{x}) = \eta(\boldsymbol{x})\phi(f_{\phi}^*(\boldsymbol{x})) + (1-\eta(\boldsymbol{x}))\phi(-f_{\phi}^*(\boldsymbol{x}))$。

**步骤5**：建立替代风险与分类风险的关系

定义：
$$\Delta_2(\boldsymbol{x}) = \eta(\boldsymbol{x})\phi(f(\boldsymbol{x})) + (1-\eta(\boldsymbol{x}))\phi(-f(\boldsymbol{x}))$$

利用凸函数的性质，可以证明：
$$\phi(0) \leqslant \Delta_2(\boldsymbol{x})$$

因此：
$$R(f) - R^* \leqslant 2c\sqrt[s]{R_{\phi}(f) - R_{\phi}^*}$$

**结论**：当 $R_{\phi}(\hat{f}_m) \to R_{\phi}^*$ 时，$R(\hat{f}_m) \to R^*$。

## 划分机制与一致性

### 6.3.1 划分机制的基本思想

**划分机制 (Partitioning Mechanism)** 是一类重要的机器学习方法，包括：

- 最近邻 (Nearest Neighbor)
- 决策树 (Decision Tree)
- 随机森林 (Random Forest)

**基本流程**：

1. 将样本空间 $\mathcal{X}$ 划分成多个互不相容的区域 $\Omega_1, \Omega_2, \ldots, \Omega_n$
2. 对每个区域中的正例和反例分别计数
3. 按"少数服从多数"原则确定区域中样本的标记

**形式化定义**：

给定训练集 $D_m = \{(\boldsymbol{x}_1, y_1), \ldots, (\boldsymbol{x}_m, y_m)\}$，划分机制输出的分类器为：

$$h_m(\boldsymbol{x}) = \begin{cases} +1 & \text{if } \sum_{\boldsymbol{x}_i \in \Omega(\boldsymbol{x})}\mathbb{I}(y_i = +1) \geqslant \sum_{\boldsymbol{x}_i \in \Omega(\boldsymbol{x})}\mathbb{I}(y_i = -1) \\ -1 & \text{otherwise} \end{cases}$$

其中 $\Omega(\boldsymbol{x})$ 表示样本 $\boldsymbol{x}$ 所在的区域。

### 6.3.2 划分机制一致性的条件

**直观理解**：

划分机制具有一致性需要满足两个看似矛盾的条件：

1. **区域足够小**：能够捕捉数据的局部信息
2. **区域包含足够多的样本**：确保"少数服从多数"的有效性

**关键定义**：

**区域直径**：
$$\text{Diam}(\Omega) = \sup_{\boldsymbol{x}, \boldsymbol{x}' \in \Omega}\|\boldsymbol{x} - \boldsymbol{x}'\|$$

**落入样本数**：
$$N(\boldsymbol{x}) = \sum_{i=1}^{m}\mathbb{I}(\boldsymbol{x}_i \in \Omega(\boldsymbol{x}))$$

**定理 6.2 (划分机制一致性的充分条件)** [Devroye et al., 1996]：

假设条件概率 $\eta(\boldsymbol{x})$ 在样本空间 $\mathcal{X}$ 上连续。若划分后的每个区域满足：

1. 当 $m \to \infty$ 时，$\text{Diam}(\Omega(\boldsymbol{x})) \to 0$ 依概率成立
2. 当 $m \to \infty$ 时，$N(\boldsymbol{x}) \to \infty$ 依概率成立

则该划分机制具有一致性。

**证明详解**：

**步骤1**：将划分机制表示为插入法

定义区域 $\Omega(\boldsymbol{x})$ 中条件概率的估计：
$$\hat{\eta}(\boldsymbol{x}) = \frac{\sum_{\boldsymbol{x}_i \in \Omega(\boldsymbol{x})}\mathbb{I}(y_i = +1)}{N(\boldsymbol{x})}$$

则划分机制等价于：
$$h_m(\boldsymbol{x}) = 2\mathbb{I}\left(\hat{\eta}(\boldsymbol{x}) \geqslant \frac{1}{2}\right) - 1$$

**步骤2**：应用引理 6.2

$$R(h_m) - R^* \leqslant 2\mathbb{E}[|\hat{\eta}(\boldsymbol{x}) - \eta(\boldsymbol{x})|]$$

**步骤3**：分解估计误差

定义区域平均条件概率：
$$\bar{\eta}(\boldsymbol{x}) = \mathbb{E}[\eta(\boldsymbol{x}') | \boldsymbol{x}' \in \Omega(\boldsymbol{x})]$$

利用三角不等式：
$$\mathbb{E}[|\hat{\eta}(\boldsymbol{x}) - \eta(\boldsymbol{x})|] \leqslant \mathbb{E}[|\hat{\eta}(\boldsymbol{x}) - \bar{\eta}(\boldsymbol{x})|] + \mathbb{E}[|\bar{\eta}(\boldsymbol{x}) - \eta(\boldsymbol{x})|]$$

**步骤4**：分析偏差项 $|\bar{\eta}(\boldsymbol{x}) - \eta(\boldsymbol{x})|$

由 $\eta(\boldsymbol{x})$ 的连续性和条件1（区域直径趋于0）：
$$\mathbb{E}[|\bar{\eta}(\boldsymbol{x}) - \eta(\boldsymbol{x})|] \to 0 \text{ as } m \to \infty$$

**步骤5**：分析方差项 $|\hat{\eta}(\boldsymbol{x}) - \bar{\eta}(\boldsymbol{x})|$

给定 $\boldsymbol{x}, \boldsymbol{x}_1, \ldots, \boldsymbol{x}_m$，有：
$$N(\boldsymbol{x})\hat{\eta}(\boldsymbol{x}) \sim \text{Binomial}(N(\boldsymbol{x}), \bar{\eta}(\boldsymbol{x}))$$

利用引理 6.3（Bernoulli变量的集中不等式）：
$$\mathbb{E}\left[\left|\frac{1}{m}\sum_{i=1}^{m}X_i - \mathbb{E}[X_i]\right|\right] \leqslant \sqrt{\frac{p(1-p)}{m}}$$

结合条件2（$N(\boldsymbol{x}) \to \infty$），可以证明：
$$\mathbb{E}[|\hat{\eta}(\boldsymbol{x}) - \bar{\eta}(\boldsymbol{x})|] \to 0 \text{ as } m \to \infty$$

**结论**：$R(h_m) \to R^*$，即划分机制具有一致性。

## 分析实例

### 6.4.1 支持向量机 (SVM)

**SVM的替代函数**：

SVM优化的是hinge损失：
$$\phi(t) = \max(0, 1-t)$$

**引理 6.4 (Hinge损失的最优解)**：

优化hinge损失得到的最优实值输出函数为：

$$f_{\phi}^*(\boldsymbol{x}) = \begin{cases} \text{sign}(2\eta(\boldsymbol{x}) - 1) & \eta(\boldsymbol{x}) \neq 1/2 \\ c & \eta(\boldsymbol{x}) = 1/2 \end{cases}$$

其中 $c \in [-1, 1]$ 是任意常数。

对应的贝叶斯风险为：
$$R_{\phi}^* = 2\mathbb{E}_{\boldsymbol{x} \sim \mathcal{D}_{\mathcal{X}}}[\min\{\eta(\boldsymbol{x}), 1-\eta(\boldsymbol{x})\}]$$

**证明详解**：

对于hinge损失，替代泛化风险为：
$$R_{\phi}(f) = \mathbb{E}_{\boldsymbol{x} \sim \mathcal{D}_{\mathcal{X}}}[\eta(\boldsymbol{x})\max(0, 1-f(\boldsymbol{x})) + (1-\eta(\boldsymbol{x}))\max(0, 1+f(\boldsymbol{x}))]$$

对于固定的 $\boldsymbol{x}$，令 $\alpha = f(\boldsymbol{x})$，定义：
$$g(\alpha) = \eta(\boldsymbol{x})\max(0, 1-\alpha) + (1-\eta(\boldsymbol{x}))\max(0, 1+\alpha)$$

分段讨论：

- 当 $\alpha \in [-1, 1]$：$g(\alpha) = 1 + \alpha(1 - 2\eta(\boldsymbol{x}))$
- 当 $\alpha \leqslant -1$：$g(\alpha) = \eta(\boldsymbol{x})(1-\alpha)$
- 当 $\alpha \geqslant 1$：$g(\alpha) = (1-\eta(\boldsymbol{x}))(1+\alpha)$

求最小值：

- 若 $\eta(\boldsymbol{x}) > 1/2$：$g(\alpha)$ 在 $\alpha = 1$ 处取最小值
- 若 $\eta(\boldsymbol{x}) < 1/2$：$g(\alpha)$ 在 $\alpha = -1$ 处取最小值
- 若 $\eta(\boldsymbol{x}) = 1/2$：$g(\alpha)$ 在 $[-1, 1]$ 上恒等于1

**定理 6.3 (Hinge损失的一致性)**：

Hinge损失 $\phi(t) = \max(0, 1-t)$ 针对原0/1目标函数具有替代一致性。

**证明**：

验证定理 6.1 的两个条件：

**条件1**：$f_{\phi}^* \in \mathcal{F}^*$

- 当 $\eta(\boldsymbol{x}) > 1/2$ 时，$f_{\phi}^*(\boldsymbol{x}) = 1 > 0$
- 当 $\eta(\boldsymbol{x}) < 1/2$ 时，$f_{\phi}^*(\boldsymbol{x}) = -1 < 0$
- 满足 $\mathcal{F}^*$ 的定义

**条件2**：不等式条件

分情况计算：

- 当 $\eta(\boldsymbol{x}) > 1/2$：$f_{\phi}^*(\boldsymbol{x}) = 1$
  $$\phi(0) - \eta(\boldsymbol{x})\phi(1) - (1-\eta(\boldsymbol{x}))\phi(-1) = 1 - 0 - 2(1-\eta(\boldsymbol{x})) = 2\eta(\boldsymbol{x}) - 1 = 2|\eta(\boldsymbol{x}) - 1/2|$$

- 当 $\eta(\boldsymbol{x}) < 1/2$：$f_{\phi}^*(\boldsymbol{x}) = -1$
  $$\phi(0) - \eta(\boldsymbol{x})\phi(-1) - (1-\eta(\boldsymbol{x}))\phi(1) = 1 - 2\eta(\boldsymbol{x}) - 0 = 1 - 2\eta(\boldsymbol{x}) = 2|\eta(\boldsymbol{x}) - 1/2|$$

- 当 $\eta(\boldsymbol{x}) = 1/2$：两边都为0

因此，取 $c = 1/2$，$s = 1$，条件2满足。

**平方Hinge损失**：

SVM的另一种形式使用平方hinge损失：
$$\phi(t) = (\max(0, 1-t))^2$$

**引理 6.5**：优化平方hinge损失得到的最优实值输出函数为：
$$f_{\phi}^*(\boldsymbol{x}) = 2\eta(\boldsymbol{x}) - 1$$

对应的最优替代风险为：
$$R_{\phi}^* = \mathbb{E}_{\boldsymbol{x} \sim \mathcal{D}_{\mathcal{X}}}[4\eta(\boldsymbol{x})(1-\eta(\boldsymbol{x}))]$$

**定理 6.4 (平方Hinge损失的一致性)**：

平方hinge损失针对原0/1目标函数具有替代一致性。

**证明**：

验证定理 6.1 的条件：

对于任意 $\boldsymbol{x}$：
$$\phi(0) - \eta(\boldsymbol{x})\phi(f_{\phi}^*(\boldsymbol{x})) - (1-\eta(\boldsymbol{x}))\phi(-f_{\phi}^*(\boldsymbol{x}))$$
$$= 1 - 4\eta(\boldsymbol{x})(1-\eta(\boldsymbol{x})) = (2\eta(\boldsymbol{x}) - 1)^2 = 4|\eta(\boldsymbol{x}) - 1/2|^2$$

取 $c = 1/2$，$s = 2$，条件满足。

### 6.4.2 随机森林 (Random Forest)

**随机森林的基本结构**：

随机森林是一种集成学习方法，通过以下步骤构建：

1. **Bootstrap采样**：从原始数据中有放回地采样生成多个训练集
2. **随机决策树**：对每个训练集构建随机决策树
   - 在每个结点随机选择划分属性
   - 在划分属性中随机选择划分点
3. **投票集成**：通过多数投票得到最终预测

**随机决策树的形式化**：

引入随机变量 $Z \in \mathcal{Z}$ 刻画决策树的随机性，用 $h_m(\boldsymbol{x}, Z)$ 表示随机决策树。

随机森林为：
$$\bar{h}_m(\boldsymbol{x}; Z_1, \ldots, Z_n) = \text{sign}\left(\sum_{i=1}^{n}h_m(\boldsymbol{x}, Z_i)\right)$$

**引理 6.6 (随机森林与单棵树的关系)**：

$$\mathbb{E}_{Z_1, \ldots, Z_n}[R(\bar{h}_m(\boldsymbol{x}; Z_1, \ldots, Z_n))] - R^* \leqslant 2(\mathbb{E}_Z[R(h_m(\boldsymbol{x}, Z))] - R^*)$$

**证明思路**：

利用Markov不等式和投票的性质，可以证明随机森林的期望风险与单棵树的期望风险之间存在上述关系。

**关键结论**：若随机决策树具有一致性，则随机森林也具有一致性。

**定理 6.5 (随机森林的一致性)** [Biau et al., 2008]：

当训练集规模 $m \to \infty$ 时，如果每棵随机决策树的迭代轮数 $k = k(m) \to \infty$ 且 $k/m \to 0$，则随机森林具有一致性。

**证明的核心步骤**：

**步骤1**：证明 $N(\boldsymbol{x}, Z) \to \infty$ 依概率成立

设 $\Omega_1, \ldots, \Omega_{k+1}$ 为 $k$ 轮迭代后得到的 $k+1$ 个区域，$N_1, \ldots, N_{k+1}$ 为落入各区域的样本数。

对任意 $t > 0$：
$$P(N(\boldsymbol{x}, Z) < t) = \mathbb{E}\left[\sum_{i: N_i < t}\frac{N_i}{m}\right] \leqslant \frac{(t-1)(k+1)}{m} \to 0$$

由 $k/m \to 0$。

**步骤2**：证明 $\text{Diam}(\Omega(\boldsymbol{x}, Z)) \to 0$ 依概率成立

设 $T_m$ 为区域 $\Omega(\boldsymbol{x}, Z)$ 被划分的次数，$T_m = \sum_{i=1}^{k}\xi_i$，其中 $\xi_i \sim \text{Bernoulli}(1/i)$。

计算期望和方差：
$$\mathbb{E}[T_m] = \sum_{i=1}^{k}\frac{1}{i} \geqslant \ln k$$
$$\mathbb{V}(T_m) = \sum_{i=2}^{k}\frac{1}{i}(1-\frac{1}{i}) \leqslant \ln k + 1$$

由Chebyshev不等式，当 $k \to \infty$ 时：
$$P\left(|T_m - \mathbb{E}[T_m]| \geqslant \frac{\mathbb{E}[T_m]}{2}\right) \leqslant 4\frac{\ln k + 1}{\ln^2 k} \to 0$$

因此 $P(T_m \geqslant \ln k / 2) \to 1$。

**步骤3**：分析区域边长

设 $L_j$ 为区域在第 $j$ 个属性上的边长。若该属性被划分 $K_j$ 次，每次划分位置 $U_i \sim \mathcal{U}(0,1)$，则：
$$\mathbb{E}[L_j] = \mathbb{E}\left[\left(\frac{3}{4}\right)^{K_j}\right]$$

其中 $K_j \sim \text{Binomial}(T_m, 1/d)$。

计算得：
$$\mathbb{E}[L_j] = \mathbb{E}\left[\left(1 - \frac{1}{4d}\right)^{T_m}\right] \to 0 \text{ as } k \to \infty$$

因此区域直径趋于0。

**结论**：随机决策树满足定理 6.2 的条件，具有一致性，从而随机森林也具有一致性。

## 章节小结

### 核心要点回顾

1. **一致性的本质**：
   - 研究学习算法在无限数据极限下的性能
   - 目标：算法输出的分类器趋于贝叶斯最优分类器
   - 贝叶斯风险是任何算法能达到的理论下界

2. **贝叶斯最优分类器**：
   $$h^*(\boldsymbol{x}) = 2\mathbb{I}(\eta(\boldsymbol{x}) \geqslant 1/2) - 1$$
   $$R^* = \mathbb{E}[\min\{\eta(\boldsymbol{x}), 1-\eta(\boldsymbol{x})\}]$$

3. **替代函数一致性**：
   - 凸替代函数使优化变得可行
   - 一致性的充分条件：
     - 最优解对应正确的分类决策
     - 替代风险与分类风险之间存在定量关系
   - 常见替代函数（hinge、平方、指数、对率）都具有一致性

4. **划分机制一致性**：
   - 需要同时满足：区域直径 $\to 0$ 且落入样本数 $\to \infty$
   - 最近邻、决策树、随机森林都满足一致性

### 关键公式总结

| 概念         | 公式                                                                        |
| ------------ | --------------------------------------------------------------------------- | ----------------------- | --------------------------------------------------------- |
| 贝叶斯分类器 | $h^*(\boldsymbol{x}) = 2\mathbb{I}(\eta(\boldsymbol{x}) \geqslant 1/2) - 1$ |
| 贝叶斯风险   | $R^* = \mathbb{E}[\min\{\eta(\boldsymbol{x}), 1-\eta(\boldsymbol{x})\}]$    |
| 风险差       | $R(h) - R^\* = \mathbb{E}[                                                  | 1-2\eta(\boldsymbol{x}) | \mathbb{I}(h(\boldsymbol{x}) \neq h^\*(\boldsymbol{x}))]$ |
| 替代风险     | $R_{\phi}(f) = \mathbb{E}[\phi(yf(\boldsymbol{x}))]$                        |
| 一致性条件   | $R_{\phi}(\hat{f}_m) \to R_{\phi}^* \Rightarrow R(\hat{f}_m) \to R^*$       |

### 与其他章节的联系

- **第2章 (PAC学习)**：一致性是PAC学习在 $m \to \infty$ 时的极限形式
- **第4章 (泛化界)**：泛化界给出有限样本下的保证，一致性给出渐近保证
- **第7章 (收敛率)**：一致性关注是否收敛，收敛率关注收敛速度
