$$
P \left(| \hat {E} (h) - E (h) | \geq \epsilon\right) \leq 2 \exp \left(- 2 m \epsilon^ {2}\right) \tag {3}

# 第四题

设 X × Y 为样本空间，D 为该空间上的未知真实分布。训练集 $D = \{ z _ { 1 } , z _ { 2 } , \ldots , z _ { m } \}$ 是 从分布 D 中独立同分布（i.i.d.）采样得到的包含 m 个样本的数据集。令 L 表示一个学习算法， $\mathfrak { L } _ { D }$ 为其在数据集 D 上训练得到的模型。用 $\ell ( \cdot , \cdot )$ 表示损失函数。

定义模型 $\mathfrak { L } _ { D }$ 的泛化风险为 $R ( \mathfrak { L } _ { D } ) = \mathbb { E } _ { z \sim D } [ \ell ( \mathfrak { L } _ { D } , z ) ]$ ，其经验风险为 $\begin{array} { r } { \hat { R } ( \mathfrak { L } _ { D } ) = \frac { 1 } { m } \sum _ { i = 1 } ^ { m } \ell ( \mathfrak { L } _ { D } , z _ { i } ) } \end{array}$

令 $D ^ { k , z } = \{ z _ { 1 } , \dots , z _ { k - 1 } , z , z _ { k + 1 } , \dots , z _ { m } \}$ 表示将数据集 D 中的第 k 个样本 $z _ { k }$ 替换为任意新样本 z 后得到的新数据集。

若对任意 $k \in [ m ]$ ，数据集 D 和样本 $z \in \mathcal { X } \times \mathcal { Y }$ ，算法 L 满足以下两个稳定性条件：

$$
\left| \hat {R} (\mathfrak {L} _ {D}) - \sum_ {z ^ {\prime} \in D ^ {k, z}} \frac {\ell \left(\mathfrak {L} _ {D ^ {k , z}} , z ^ {\prime}\right)}{m} \right| \leq \beta_ {1}
$$

$$
| R (\mathfrak {L} _ {D}) - \mathbb {E} _ {z \sim \mathcal {D}} [ \ell (\mathfrak {L} _ {D ^ {k, z}}, z) ] | \leq \beta_ {2}
$$

试证明：对任意 $\epsilon > 0$ ，有：

$$
P _ {D \sim \mathcal {D} ^ {m}} \left(\left| R (\mathfrak {L} _ {D}) - \hat {R} (\mathfrak {L} _ {D}) \right| \geq \epsilon + \beta_ {2}\right) \leq 2 \exp \left(\frac {- 2 \epsilon^ {2}}{m (\beta_ {1} + 2 \beta_ {2}) ^ {2}}\right)
$$

# 第六题

设 $f : \mathbb { R } ^ { d } \rightarrow \mathbb { R }$ 为一个可微的凸函数，且其梯度满足有界性条件，即存在常数 $G > 0$ ，使得对任意 $\boldsymbol { x } \in \mathbb { R } ^ { d }$ 均有 $\| \nabla f ( x ) \| _ { 2 } \leq G _ { \mathfrak { c } }$ 。

我们采用梯度下降算法来最小化 f(x)，其迭代规则为：

$$
x _ {t + 1} = x _ {t} - \eta_ {t} \nabla f (x _ {t})
$$

其中 $x _ { 1 }$ 为初始解。假设最优解 $x ^ { * } = \arg \operatorname* { m i n } _ { x } f ( x )$ 存在，且初始距离满足 $\| x _ { 1 } - x ^ { * } \| _ { 2 } \leq R { \mathrm { . } }$ 。

试分析当步长设置为衰减步长 $\begin{array} { r } { \eta _ { t } = \frac { \alpha } { \sqrt { t } } } \end{array}$ （其中 $\alpha > 0$ 为常数，即 $\eta _ { t } = O ( 1 / \sqrt { t } ) )$ ）时该算法的收敛率。证明在迭代 T 步后，其平均迭代点 $\begin{array} { r } { \bar { x } _ { T } = \frac { 1 } { T } \sum _ { t = 1 } ^ { T } x _ { t } } \end{array}$ 满足：

$$
f (\bar {x} _ {T}) - f (x ^ {*}) = O \left(\frac {1}{\sqrt {T}}\right)
$$
