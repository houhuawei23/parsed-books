# 第 22 章 目标试验模拟（TARGET TRIAL EMULATION）

正如第一部分所讨论的，基于观测数据进行因果推断可被视为试图模拟一个假设的随机试验，我们称之为 **目标试验（target trial）** 。然而，第一部分和第二部分仅涉及比较固定时间处理的简单目标试验。既然我们现在已拥有处理时变处理因果推断所需的所有工具，我们便可以讨论比较持续性治疗策略的现实目标试验了。

本章将目标试验的概念推广到持续性治疗策略，并概述了一个统一的因果推断框架，无论数据是来自随机实验还是观测性研究。

本章还描述了一个在模拟目标试验时可能感兴趣的因果效应分类，包括意向性治疗效应和符合方案效应的观测对应物。对这些因果效应的有效估计通常需要关于时变预后因素和治疗的数据，以及使用 g-方法对这些时变因素进行适当的调整。正是 g-方法的发展，使得此处讨论的概念不仅仅是一种形式上的练习：如果所有重要的固定和时变混杂因素的数据都可用，那么感兴趣的效应现在就可以被有效地估计。

### 22.1 意向性治疗效应与符合方案效应

考虑一项随机试验，其中面临某种危险病毒感染风险的个体被随机分配至联合治疗方案（立即接种疫苗，并在感染时接受一种实验性抗病毒治疗）( $Z = 1$ ) 或标准治疗方案（不接种疫苗且不接受抗病毒治疗）( $Z = 0$ )。图 22.1 展示了该试验，其中包含分配治疗 $Z$ 、接受治疗 $A$ 和结局（死亡） $Y$ 。

对于给定的个体， $Z$ 和 $A$ 的值可能因对分配治疗的依从性不足而不同：一些被分配到疫苗组的个体 ( $Z = 1$ ) 可能因为拒绝接种而实际上未接受疫苗 ( $A = 0$ )；一些被分配到无疫苗组的个体 ( $Z = 0$ ) 仍可能在研究之外获得疫苗 ( $A = 1$ )。变量 $U$ 代表影响个体接种决策的未测量风险因素。

如图 22.1 所示，分配治疗 $Z$ 可以通过两条不同的路径对结局 $Y$ 产生因果效应。首先，治疗分配 $Z$ 可能影响结局 $Y$ ，仅仅因为它影响了接受治疗 $A$ 。被分配到疫苗组的个体更可能接受疫苗，如从 $Z$ 到 $A$ 的箭头所示。如果接种疫苗对死亡率有因果效应，如从 $A$ 到 $Y$ 的箭头所示，那么分配到疫苗组通过路径 $Z \rightarrow A \rightarrow Y$ 对结局 $Y$ 产生因果效应。

其次，治疗分配 $Z$ 可能通过并非由接受治疗 $A$ 中介的路径影响结局 $Y$ 。例如，对分配治疗的知晓可能导致参与者行为发生改变：意识到自己被分配到疫苗接种联合一种有前景的抗病毒治疗的个体，可能会在预防感染方面变得不那么谨慎。这些行为改变由从 $Z$ 到 $Y$ 的直接箭头表示。

#### 要点 22.1（Fine Point 22.1）

**排除限制（再次讨论）。** 图 22.1 中箭头 $Z \to Y$ 的存在，代表了随机分组对结局的 **直接效应** ，该效应不通过治疗产生。当此箭头存在时，我们称 **排除限制不成立** 。关于排除限制的形式化讨论，请参见技术要点 16.1。

研究者通常试图通过消除箭头 $Z \to Y$ 来部分地“去污染” $Z$ 的效应，如图 22.2（与图 16.1 相同）所示，该图描绘了不存在从 $Z$ 到 $Y$ 的直接箭头这一排除限制。为此，他们对参与者及其医生隐瞒了所分配的 **治疗 $Z$ ** 的信息。例如，研究者会对随机分配到 $Z = 1$ 的个体接种疫苗，而对分配到 $Z = 0$ 的个体给予安慰剂（一种除不含疫苗外完全相同的注射剂）。

由于参与者及其医生不知道他们接受的注射是活性治疗还是安慰剂，因此称他们处于“盲态”，这类研究被称为 **双盲安慰剂对照随机试验（double-blind placebo-controlled randomized trial）** 。在第 16 章中，我们使用双盲安慰剂对照随机试验的概念来引入 **工具变量（instrumental variable）** 的概念。

双盲治疗分配通常是不可行的。许多研究无法有效实施盲法，原因包括：没有实际方法进行令人信服的安慰剂操作（例如，对于开胸手术），治疗的副作用会使受试者明显知道自己在接受何种治疗，等等。此外，当研究者旨在量化真实世界（不存在盲法或安慰剂）中的治疗效果时，也不建议采用盲法（和安慰剂对照）。

> 图 22.2

**符合方案效应（per-protocol effect）** 由对比 $\operatorname{Pr}[Y^{z=1, a=1}=1]$ 与 $\operatorname{Pr}[Y^{z=0, a=0}=1]$ 来定义，或者，在排除限制下，由对比 $\operatorname{Pr}[Y^{a=1}=1]$ 与 $\operatorname{Pr}[Y^{a=0}=1]$ 来定义。在正文中，为简化符号，我们使用后者。

因此， **分配治疗 $Z$ ** 的因果效应不仅取决于箭头 $A \longrightarrow Y$ 的强度（即 **接受治疗** 的效应），还取决于箭头 $Z \longrightarrow A$ 的强度（研究中 **对分配治疗的依从性** 程度）和箭头 $Z \longrightarrow Y$ 的强度（伴随的行为改变）。 $Z$ 的效应不是“用 $A$ 治疗的效应”，而是“将参与者分配至接受 $A$ 治疗的效应”或“具有用 $A$ 治疗意图的效应”，这就是为什么随机分配 $Z$ 的效应通常被称为 **意向治疗效应（intention-to-treat effect）** 。

由于 $Z$ 是随机分配的，因此预计分配治疗的效应不存在混杂。由于在图 22.1 中不存在从 $Z$ 到 $Y$ 的后门路径，因此预计分配治疗 $Z$ 满足可交换性 $Y^z \perp\!\!\!\perp Z$ 。 $Z$ 与 $Y$ 之间的关联意味着 $Z$ 对 $Y$ 存在因果效应，无论是否所有个体都依从了分配治疗。关联风险比 $\operatorname{Pr}[Y=1 \mid Z=1] / \operatorname{Pr}[Y=1 \mid Z=0]$ 等于因果意向治疗风险比 $\operatorname{Pr}[Y^{z=1}=1] / \operatorname{Pr}[Y^{z=0}=1]$ 。通过估计 $Z$ 和 $Y$ 之间未经调整的关联来估计意向治疗效应的分析，称为 **意向治疗分析（intention-to-treat analysis）** 。关于通常存在偏倚的意向治疗分析的常见变体，请参见要点 22.2。

现在考虑如果所有个体都按照实验方案规定依从了分配治疗时将会观察到的治疗的因果效应，我们称之为 **符合方案效应** 。在本书的大部分内容中，我们假设对分配治疗具有完美依从性，因此对所有参与者而言，分配治疗 $Z$ 和接受治疗 $A$ 的值是一致的。也就是说，我们假设 $U$ 不存在，因此接受治疗者（ $A=1$ ）和未接受治疗者（ $A=0$ ）是可交换的，即 $Y^a \perp\!\!\!\perp A$ 。

现在考虑这样一种情景： $U$ 表示感染的高风险（1：是，0：否），并且 $Z=0$ 组中感染高风险个体（ $U=1$ ）倾向于在研究之外寻求疫苗接种（ $A=1$ ）。如果发生这种情况，那么 $A=1$ 组中高风险个体的比例将高于 $A=0$ 组： $A=1$ 组和 $A=0$ 组将不可交换，因此关联风险比 $\operatorname{Pr}[Y=1 \mid A=1] / \operatorname{Pr}[Y=1 \mid A=0]$ 将不等于（因果）符合方案风险比 $\operatorname{Pr}[Y^{a=1}=1] / \operatorname{Pr}[Y^{a=0}=1]$ 。如后门路径 $A \leftarrow U \rightarrow Y$ 所示， $A$ 对 $Y$ 的效应存在混杂，估计符合方案效应需要进行调整。也就是说，估计符合方案效应需要将随机实验视为一项观察性研究。要点 22.3 描述了未能认识到这一点的、用于量化符合方案效应的传统方法。

无混杂这一事实在很大程度上解释了为什么在许多随机实验中意向治疗效应受到青睐：“具有用 $A$ 治疗意图的效应”可能不是我们想要的效应——“用 $A$ 治疗的效应”或符合方案效应——但它更容易计算。正如常发生的那样，当一个不那么令人感兴趣的量比一个更令人感兴趣的量更容易计算时，我们倾向于提出各种理由来证明使用这个不那么令人感兴趣的量的合理性。意向治疗效应也不例外。我们现在讨论为什么几个众所周知的、支持意向治疗效应的理由需要谨慎对待。

一个常见的支持意向治疗效应的理由是它 **能保留原假设（preserves the null）** 。也就是说，如果治疗 $A$ 对 $Y$ 有零效应，那么分配治疗 $Z$ 对 $Y$ 也将有零效应。保留原假设是一个关键性质，因为它确保当不存在效应时不会宣称存在效应。更形式化地说，在 **严格零因果假设（sharp causal null hypothesis）** 和排除限制下，可以证明 $\operatorname{Pr}[Y=1 \mid Z=1] / \operatorname{Pr}[Y=1 \mid Z=0] = \operatorname{Pr}[Y^{a=1}=1] / \operatorname{Pr}[Y^{a=0}=1] = 1$ 。然而，当排除限制不成立时，如图 22.1 所示，这个等式是不成立的。在这些情况下——即非双盲安慰剂对照的实验中—— $A$ 的效应可能为零，而 $Z$ 的效应可能非零。要理解这一点，请在脑海中擦除图 22.1 中的箭头 $A \longrightarrow Y$ ：仍然存在从 $Z$ 到 $Y$ 的箭头。

另一个相关的支持意向治疗效应的理由是，其值“比符合方案效应的值更接近于零”。直觉是，如果不完美的依从性导致效应衰减——而非夸大——那么意向治疗风险比 $\operatorname{Pr}[Y=1 \mid Z=1] / \operatorname{Pr}[Y=1 \mid Z=0]$ 的值将介于 1 和符合方案风险比 $\operatorname{Pr}[Y^{a=1}=1] / \operatorname{Pr}[Y^{a=0}=1]$ 之间。因此，意向治疗效应可以被解释为符合方案效应的一个下界，即意向治疗效应是符合方案效应的一个保守估计。不幸的是，意向-

#### 要点 22.2（Fine Point 22.2）

**伪意向治疗分析（Pseudo-intention-to-treat analysis）和修正意向治疗分析（Modified intention-to-treat analysis）。** 意向治疗分析对于意向治疗效应是无偏的，因为它包含了所有随机化的个体。因此，仅包含随机化个体子集的意向治疗分析变体可能存在偏倚。

当一些个体未完成随访时，他们的结局是未知的，因此分析需要限制在具有完整随访数据的个体中。因此，我们只能进行 **伪意向治疗分析** $\operatorname{Pr}[Y=1 \mid Z=1, C=0] / \operatorname{Pr}[Y=1 \mid Z=0, C=0]$ ，其中 $C=0$ 表示个体在测量 $Y$ 之前一直未被删失。如第 8 章所述，删失可能导致选择偏倚，因此伪意向治疗估计值可能是对意向治疗效应的有偏估计，偏倚方向不定。在存在失访或其他形式删失的情况下，随机实验的意向治疗分析需要对选择偏倚进行适当的调整。关于更多讨论，请参见第 21.5 节以及 Little 等人 (2012) 的文献。

对于持续治疗策略，一种常见方法是将意向治疗分析限制在至少开始了其分配策略的个体（例如，至少服用了一粒药丸）。这种方法被称为 **修正意向治疗分析** ，它仅包含随机化个体的一个子集，因此可能对意向治疗效应产生偏倚。修正意向治疗分析通常需要对影响依从性的风险因素进行调整。

从统计学角度来看，在双盲安慰剂对照随机实验中，意向治疗分析为检验无平均治疗效应的零假设提供了一个有效——尽管可能检验效能不足——的 $\alpha$ 水平检验。

#### 要点 22.3（Fine Point 22.3）

**朴素的符合方案分析（Naïve per-protocol analyses）。** 在随机试验中，试图估计治疗 $A$ 的符合方案效应的两种常见方法是“按实际治疗分析（as treated）”和所谓的“符合方案分析（per protocol）”。

传统的 **按实际治疗分析** 会比较那些接受了治疗（ $A = 1$ ）与未接受治疗（ $A = 0$ ）的个体中结局 $Y$ 的分布，而不考虑他们的治疗分配 $Z$ 。显然，如果促使参与者接受治疗的原因与未测量的预后因素 $U$ 相关（如图 22.1 和 22.2 所示），那么传统的按实际治疗比较将存在混杂。另一方面，考虑一种情景，其中 $A$ 和 $Y$ 之间的所有后门路径都可以通过以测量因素 $L$ 为条件来阻断，如图 22.3 所示。那么，按实际治疗分析需要调整因素 $L$ 。

传统的 **符合方案分析** ——有时被称为按方案治疗分析——只包括那些遵守研究方案的个体：即所谓的符合方案人群，其中 $A = Z$ 。然后，该分析仅在符合方案人群中，比较被分配至治疗组（ $Z = 1$ ）与被分配至对照组（ $Z = 0$ ）的个体中结局 $Y$ 的分布。也就是说，传统的符合方案分析只是将意向治疗分析限制在符合方案人群中。这种限制通常会导致对符合方案效应的有偏估计。

要理解原因，请考虑图 22.4 中的因果图，该图包含一个进入符合方案人群的选择指标 $S$ ：如果 $A = Z$ ，则 $S = 1$ ，否则 $S = 0$ 。除非符合方案分析恰当地测量并调整了因素 $L$ ，否则选择偏倚将会产生，因为以 $S = 1$ 为条件会打开非因果路径 $Z \to A \leftarrow L \to U \to Y$ 。

也就是说，按实际治疗分析和符合方案分析是对随机实验进行的观察性分析，并且与任何观察性分析一样，需要对混杂和选择偏倚进行适当的调整，才能获得对符合方案效应的有效估计。有关示例和更多讨论，请参见 Hernán 和 Hernández-Díaz (2012) 的文献。

反对保守的意向治疗分析的论点适用于非劣效性试验，其目标是证明一种治疗不劣于另一种治疗。

**意向治疗效应（Intention-to-treat effect）** 并不总是保守的，因为衰减效应并不能得到保证。参见 **精细要点 22.4（Fine Point 22.4）** 。

即使在意向治疗效应是保守的情况下，这也未必是一件好事。假设目标是评估一种治疗的安全性：人们可能会天真地得出结论，认为治疗 $A$ 是安全的，因为 $Z$ 对不良结局的意向治疗效应接近于零，即使治疗 $A$ 在相当一部分患者中导致了不良结局。其原因可能是，许多被分配到 $Z = 1$ 的患者在出现不良结局之前并未服用或停止了治疗。那么，意向治疗效应将是定义治疗效应的一种危险方式。

总之，对于存在大量不依从的随机试验以及那些评估危害而非获益的试验，仅依赖意向治疗效应估计是很难站得住脚的。 **符合方案效应（Per-protocol effect）** 对于研究人员和决策者（例如临床医生、患者）来说，往往是一个更自然的估计目标。估计符合方案效应需要在可交换性（exchangeability）假设下（以测量到的协变量为条件）调整混杂，或者是在替代假设下（例如工具变量估计所需的假设，参见第 16 章）。

上述讨论主要围绕 **固定时间治疗（time-fixed treatments）** 展开。当随机试验研究的是治疗可以随时间变化的持续策略时（这种情况经常发生），不依从的概率会大大增加。此时，与符合方案效应相比，意向治疗效应变得越来越缺乏信息。符合方案效应定义为：如果在整个随访期间每个人都坚持了他们被分配的治疗策略，那么将会观察到的效应。无论是在真实的随机试验中，还是在模拟该试验的观察性分析中，估计持续策略的符合方案效应通常都需要 **g-方法（g-methods）** 。

#### 精细要点 22.4（Fine Point 22.4）

**关于意向治疗效应的更多误解。**

一个常见的论点是，意向治疗效应衡量的是治疗在现实世界中的有效性（effectiveness），因为它纳入了人们不会完全依从所分配治疗这一事实。相比之下，符合方案效应衡量的是在完全依从治疗条件下的疗效（efficacy）。使用这一术语，人们常常认为“疗效”并不能反映治疗在现实条件下的效应，因此，报告意向治疗效应作为随机实验的主要结果是合理的，因为“有效性”是衡量治疗效应最现实的指标。

这种推理存在几个问题：

- 首先，意向治疗效应衡量的是在特定实验中观察到的依从条件下，所分配治疗的效应。现实生活中的实际依从性可能不同（例如，如果受到密切监测，研究参与者可能会更好地依从），并且实际上可能会受到该特定实验发现的影响（例如，人们在得知某种治疗有效后，会更可能依从）。
- 其次，如果目标是有效性，我们应该避免进行双盲安慰剂对照随机临床试验，因为在现实生活中，患者和医生都知道所接受的治疗，并且不使用安慰剂。真正的有效性衡量应该纳入因知晓分配而产生的效应（例如行为改变），而这些效应在双盲随机实验中被消除了。
- 第三，计划依从医生处方治疗的个人，对符合方案效应的兴趣将大于对意向治疗效应的兴趣。

另一个常见的论点是，意向治疗效应保证是保守的。这在所有情况下都不成立。如果治疗的符合方案效应不是单调的（即，并非对所有个体方向都相同；参见 **技术要点 5.2（Technical Point 5.2）** ），并且不依从程度很高，那么符合方案效应可能比意向治疗效应更接近零。即使对于单调效应，在个体被分配到两种活性治疗之一的头对头试验中，意向治疗效应也不一定是保守的。

假设患有疼痛疾病的个体被随机分配到昂贵的药物（ $Z = 1$ ）或布洛芬（ $Z = 0$ ）。目标是确定哪种药物在 1 年随访后导致严重疼痛 $Y$ 的风险更低。研究人员不知道的是，两种药物在减轻疼痛方面同样有效，即符合方案风险比为 1。然而，由于布洛芬有一种很容易缓解的轻微副作用，其对布洛芬的依从性恰好低于对昂贵药物的依从性。结果，意向治疗风险比大于 1，研究人员错误地得出结论，认为布洛芬在减轻严重疼痛方面不如昂贵药物有效。更多细节，请参见 Robins (1998b) 以及 Hernán 和 Hernández-Díaz (2012) 的讨论。

### 22.2 具有持续治疗策略的目标试验（A Target Trial with Sustained Treatment Strategies）

我们现在准备讨论比较持续治疗策略的目标试验。由于最终目标是使用真实世界的观察性数据来模拟这些试验，我们只考虑具有类似真实世界特征的实用性试验。特别是：

- 参与者及其治疗医生需要知道他们接受的治疗（即治疗分配不是盲法的）。
- 没有人接受安慰剂（即，两种策略 $g$ 和 $g'$ 都涉及活性治疗或不治疗）。
- 参与者的监测频率和强度与研究外的常规患者一样。

当目标是在现实条件下量化治疗策略的效应时，具有实用性特征的试验是更可取的。

为了具体说明，考虑一项随机试验，旨在估计抗逆转录病毒治疗对 HIV 感染者 5 年死亡风险的影响。符合条件的参与者——18 岁及以上、无艾滋病、既往未使用抗逆转录病毒治疗——在随访开始时间 $k = 0$ （基线）被随机分配到治疗策略 $g$ 或治疗策略 $g'$ 。他们的随访从分配时间开始，在死亡（感兴趣结局）、失访或基线后 60 个月时结束，以先发生者为准。

在前面的章节中，我们考虑了治疗对随访结束时测量的结局 $Y$ 的因果效应。在本试验中，结局是一个失效时间，即死亡时间（参见 **技术要点 21.10（Technical Point 21.10）** ）。

令 $A_k$ 在个体在时间 $k$ 接受治疗时取值为 1，否则为 0，其中 $k = 0, 1, 2, \dots, K$ ，且 $K = 59$ 。我们的试验将符合条件的个体分配到策略 $g_1$ （“在随访期间持续接受治疗 $A_k = 1$ ，除非出现禁忌症或毒性”）或策略 $g_0$ （“在随访期间持续接受治疗 $A_k = 0$ ”）。令分配指标 $Z$ 在个体被分配到 $g_1$ 时取值为 1，被分配到 $g_0$ 时取值为 0。令 $D_k$ 为截至第 $k$ 个月（ $k = 1, 2, \dots, K + 1$ ）的死亡指标（1：是，0：否）， $C_k$ 为删失指标（1：是，0：否）。

现在让我们在具有持续治疗策略的随机试验中定义意向治疗效应和符合方案效应。持续策略的其他对比——称为直接效应（direct effects）——在 **技术要点 22.1（Technical Point 22.1）** 中描述。

意向治疗效应是静态策略的对比：

- $z = 1, \bar{c}_K = 0$ ：在基线被分配到策略 $g_1$ ，并持续研究直至随访结束。
- $z = 0, \bar{c}_K = 0$ ：在基线被分配到策略 $g_0$ ，并持续研究直至随访结束。

那么，时间 $k$ 的意向治疗效应可以表示为反事实死亡风险的对比：

$$
\mathrm{Pr}\left[ D_k^{z = 1, \bar{c}_k = \bar{0}} = 1 \right] - \mathrm{Pr}\left[ D_k^{z = 0, \bar{c}_k = \bar{0}} = 1 \right]
$$

这是在分配到策略 $g_1$ 与 $g_0$ 的情况下，假设到时间 $k$ 为止没有人失访（ $\bar{c}_k = 0$ ）时的效应。

在一些随机试验中，治疗策略的分配和启动是同时发生的。也就是说，所有分配到策略 $g_1$ 的个体在时间 0 开始接受治疗，无论他们在基线后是否继续服用；而分配到策略 $g_0$ 的个体在时间 0 不接受治疗，无论他们在基线后是否开始服用。在这些情况下，意向治疗效应不仅是分配的效应，也是治疗启动的效应：

$$
\mathrm{Pr}\left[ D_k^{a_0 = 1, \bar{c}_k = \bar{0}} = 1 \right] - \mathrm{Pr}\left[ D_k^{a_0 = 0, \bar{c}_k = \bar{0}} = 1 \right]
$$

与任何随机试验一样，一些参与者会偏离方案，具体方式为

#### 技术要点 22.1（Technical Point 22.1）

- 从基线 $k = 0$ 到随访结束，持续接受治疗策略 $g_1$
- 从基线 $k = 0$ 到随访结束，持续接受治疗策略 $g_0$

那么，时间 $k$ 的符合方案效应可以表示为反事实死亡风险的对比

$$
\mathrm{Pr}\left[D_k^{g_1, \bar{c}_k = \bar{0}} = 1\right] - \mathrm{Pr}\left[D_k^{g_0, \bar{c}_k = \bar{0}} = 1\right]
$$

这是在完全

**受控直接效应（Controlled direct effects）。** 考虑当中介变量 $M$ 被设定为特定值时，治疗 $A$ 对结局 $Y$ 的平均因果效应。我们将此量称为 $A$ 对 $Y$ 不通过 $M$ 的直接效应。如果中介变量 $M$ 可以取两个值（0 或 1），那么我们可以定义当 $M$ 设为 1 时 $A$ 对 $Y$ 的直接效应，以及当 $M$ 设为 0 时 $A$ 对 $Y$ 的直接效应。在加性尺度上，这两个直接效应由反事实差异定义

$$
E\left[Y^{a=1, m=1}\right] - E\left[Y^{a=0, m=1}\right]
$$

和

$$
E\left[Y^{a=1, m=0}\right] - E\left[Y^{a=0, m=0}\right],
$$

分别表示。这些直接效应通常被称为 **平均受控直接效应（average controlled direct effects）** ，原则上可以通过对治疗 $A$ 和中介变量 $M$ 进行顺序随机化的实验来识别，或者通过使用观察性数据模拟此类目标实验来识别。

> **技术要点 22.2（Technical Point 22.2）** 描述了其他类型的直接效应，这些效应不存在对应的目标实验。

假设我们进行一项随机实验，参与者在基线时被随机分配到治疗 $A=1$ 或 $A=0$ ，并在基线后一个月被随机分配到治疗 $M=1$ 或 $M=0$ 。因此，所有个体将被分到四个组之一： $(A=1, M=1)$ 、 $(A=1, M=0)$ 、 $(A=0, M=1)$ 或 $(A=0, M=0)$ 。感兴趣的结局 $Y$ 在 3 个月时对所有个体进行测量（为简单起见，假设没有个体失访或死亡）。这种研究设计使我们能够一致地估计受控直接效应，因为 $A$ 和 $M$ 的随机化确保了反事实量

$$
E\left[Y^{a,m}\right] = Pr\left[Y^{a,m}=1\right]
$$

可以通过观察到的风险

$$
Pr\left[Y=1 \mid A=a, M=m\right]
$$

得到一致估计。

只要一致性（consistency）、阳性（positivity）和可交换性（exchangeability）的可识别性条件对 $A$ 和 $M$ 都成立，受控直接效应也可以在观察性研究中得到有效估计。这些可识别性条件的精确刻画实际上已在 _第 19 章_ 中提供，因为受控直接效应只是随时间持续的治疗策略对比的一个特例。要理解这一点，只需将上述表达式中的 $A$ 和 $M$ 替换为 $A_0$ 和 $A_1$ 。更一般地，治疗 $A$ 和中介变量 $M$ 本身都可以是随时间变化的。

理想情况下，为避免对在整个随访期间什么应被视为或不视为不依从产生混淆，方案将完全指定感兴趣的治疗策略。那么，符合方案效应将是良好定义的（Hernán and Robins, 2017）。

> 在分配到策略 $g_1$ 与 $g_0$ 的情况下，假设到时间 $k$ 为止没有人失访（ $\bar{c}_k = 0$ ）时的依从性。

明智的试验方案不会要求无论个体发生什么情况都继续治疗。例如，我们的持续治疗策略 $g_1$ 规定，当出现禁忌症或毒性时，必须停止治疗。也就是说，符合方案效应通常涉及 **动态策略（dynamic strategies）** （“这样做，如果 $X$ 发生，那么就做另一件事”）的比较，而不是 **静态策略（static strategies）** （“这样做，无论发生什么”）。

有时研究方案并未明确说明治疗策略的动态性质。例如，方案可能将策略 $g_1$ 简化为“在随访期间持续接受治疗 $A_k = 1$ ”，而没有明确说明“当出现禁忌症或毒性时”必须停止治疗。这种对策略 $g_1$ 的简化描述可能导致误解。具体来说，一个因毒性而停止治疗的被分配到 $g_1$ 的个体， **不应** 被标记为不依从策略 $g_1$ 的人。事实上，该个体完全依从了方案中（本应）陈述的策略 $g_1$ 。

当在现实世界中别无选择时，停止最初分配的治疗或开始其他医学上指示的治疗，绝不能被视为偏离方案。由于符合方案效应是通过现实策略的对比来定义的，因此它对于旨在为现实世界决策提供证据的因果推断研究尤其相关。

事实上，符合方案效应通常是推断的隐含目标。例如，研究人员常常质疑研究中实施的干预措施与方案中描述的干预措施之间的一致性，并说存在“偏倚”。这种语言表明研究人员实际上是在

#### 技术要点 22.2（Technical Point 22.2）

**纯直接效应和主层直接效应（Pure direct effects and principal stratum direct effects）。**  
除了技术要点 22.1 中描述的受控直接效应外，还存在其他关于当潜在中介变量 $M$ 被设定为特定值时，治疗 $A$ 对结局 $Y$ 的平均直接效应的定义。

$A$ 对 $Y$ 不通过 $M$ 的 **纯直接效应（pure direct effect）** （也称为*自然直接效应*）是如果 $M$ 的值被设定为 $A$ 被设为 0 时 $M$ 本应取的值，即如果 $M$ 被设定为值 $M^{a=0}$ （对某些个体为 1，对另一些个体为 0），则 $A$ 对 $Y$ 的平均因果效应。纯直接效应由对比定义

$$
\mathrm{E}\left[Y^{a=1, M^{a=0}}\right] - \mathrm{E}\left[Y^{a=0, M^{a=0}}\right],
$$

这是一个跨世界量（cross-world quantity），因为 $\mathrm{E}\left[Y^{a=1, M^{a=0}}\right]$ 包含了一个同时由 $a=1$ 和 $a=0$ 索引的反事实结局。因此， **纯直接效应（pure direct effect）** 无法通过对 $A$ 、 $M$ 或两者的随机实验来识别，也无法在 **有限时间完全随机因果图模型（Finite Time Fully Randomized Causal Graph Model, FFRCISTG）** 下从观测数据中识别（见技术要点 6.2）。

尽管如此，纯直接效应的估计通常是因果中介分析的目标，因为总处理效应可以分解为纯直接效应和总间接效应。纯直接效应由 Robins 和 Greenland (1992) 提出；Pearl (2001) 将其重新命名为*自然直接效应（natural direct effects）*，并指出，对于某些因果图，在其 **非参数结构方程模型与独立误差（Non-Parametric Structural Equation Model with Independent Errors, NPSEM-IE）** 下，纯直接效应可以从观测数据中识别，因为与 FFRCISTG 模型不同，NPSEM-IE 模型假设了无法通过关于 $A$ 、 $M$ 或两者的随机实验来反驳的、不可检验的跨世界独立性。相关综述可参见 VanderWeele (2015) 的著作。

如果将 $M$ 的值设为 $m$ ，则 $A$ 对 $Y$ 的 **主分层直接效应（principal stratum direct effect）** 是在人群中 $M$ 的值无论 $A$ 取何值都等于 $m$ 的子集（即满足 $M^{a=0} = M^{a=1} = m$ 的人群子集）中， $A$ 对 $Y$ 的平均因果效应。那么，主分层直接效应由以下对比定义：

$$
\mathrm{E}\left[Y^{a=1, m} \mid M^{a=0} = M^{a=1} = m\right] - \mathrm{E}\left[Y^{a=0, m} \mid M^{a=0} = M^{a=1} = m\right].
$$

有趣的是，这等于：

$$
\operatorname{E}\left[Y^{a=1} \mid M^{a=0} = M^{a=1} = m\right] - \operatorname{E}\left[Y^{a=0} \mid M^{a=0} = M^{a=1} = m\right].
$$

因此，主分层直接效应不涉及联合反事实 $Y^{a, m}$ ，只涉及该人群子集中的反事实 $Y^{a}$ ；所以，从这个意义上说，它们是该人群子集中处理的总效应（而非直接效应）。由此可知，与受控直接效应或纯直接效应不同，主分层直接效应不要求对 $M$ 的干预是良好定义的。

当 $A$ 对几乎所有的个体都影响 $M$ 时，主分层直接效应几乎没有政策相关性，因为此时它们只适用于满足 $M^{a=0} = M^{a=1}$ 的非常小的人群子集。在实践中， $M$ 通常被粗化（通常转化为一个二值指示变量）以增加主分层的大小，但粗化本身可能会使主分层直接效应的科学相关性降低 (Robins et al. 2007)。主分层直接效应由 Robins (1986) 提出，并由 Rubin (2004) 推广。Frangakis 和 Rubin (2002) 遵循 Robins (1986) 的思路，将主分层的概念用作处理竞争事件（competing events）的工具。

在第 23 章中，我们将考虑一种干预主义的中介理论（interventionist theory of mediation）(Robins and Richardson 2010)，该理论提供了另一种类型的直接效应。

---

我们感兴趣的是比较在随访期间按照方案实施的干预措施（即*符合方案效应（per-protocol effect）*），而非在基线时分配至干预措施的效果（即*意向治疗效应（intention-to-treat effect）*），因为基线后的不依从性不可能使基线分配的效果产生偏倚。

最后，让我们考虑接受除研究方案中规定的干预措施之外的其他干预措施的效果。假设，在我们的试验进行期间，开始形成一种共识，即策略 $g_0$ “在随访期间持续接受治疗 $A_k = 0$ ” 劣于策略 $g_1$ 。因此，一些医生开始建议在临床病程恶化、 **CD4 细胞计数（CD4 cell count）** （ $L_k$ ）首次降至 $200$ 个细胞/ $\mu\mathrm{L}$ 以下时启动治疗。结果，试验中被分配到策略 $g_0$ 的许多个体实际上遵循了修改后的策略 $g_0^\prime$ ：“在随访期间持续接受治疗 $A_k = 0$ ，但在 $L_k < 200$ 后，切换至治疗 $A_k = 1$ ”。

在以下干预措施下结局分布的对比：

- 在基线 $k=0$ 和随访结束之间持续接受治疗策略 $g_1$ ；
- 在基线 $k=0$ 和随访结束之间持续接受治疗策略 $g_0^\prime$ ；

既不对应于意向治疗效应，也不对应于原始的符合方案效应。相反，这是一个关于在假设目标试验中符合方案效应的问题，在该试验中，个体被随机分配至策略 $g_1$ 或 $g_0^\prime$ 。

这个例子说明了，如何将那些与原始符合方案效应不对应的、感兴趣因果效应概念化为可以使用随机试验数据进行模拟的目标试验中的符合方案效应。有趣的是，如果感兴趣的策略与实际试验中的策略不同，那么让实际试验中所有参与者都遵守方案中规定的策略实际上是不利的。完全依从意味着试验数据不能用于模拟具有不同方案的目标试验（因为没有个体在实际数据中遵循新目标试验的方案）。例如，一个完全依从的随机试验，其中 HIV 感染者被分配至不同的 CD4 细胞计数阈值以启动抗逆转录病毒治疗，对于模拟一个将个体分配至持续治疗或无治疗的试验几乎没有用处，反之亦然。正是这种不依从性使我们能够利用给定随机试验的数据来模拟其他回答不同、可能更相关的因果问题的随机试验。

关于随机试验中符合方案效应估计的更多细节，请参见 Hernán 和 Robins (2017)。

在采用持续治疗策略的随机试验中，估计符合方案效应会引发与在观察性研究中比较任何持续策略相同的问题。正如我们稍后讨论的，对符合方案效应的有效估计通常要求试验研究者收集关于策略依从性的随机化后数据，以及与依从性相关的时变预后因素（time-varying prognostic factors）的数据。

### 22.3 模拟具有持续策略的目标试验（Emulating a Target Trial with Sustained Strategies）

如果无法进行实用性随机试验，我们可以尝试通过分析现有的观测数据来模拟它。此时，我们将该试验称为我们观测分析的 **目标试验（target trial）** 。

明确目标试验的方案是一个有用的工具，可以澄清我们希望观测分析回答的感兴趣因果问题。至少，我们需要明确方案的以下关键组成部分：资格标准、随访开始和结束时间、治疗策略、感兴趣的结局、因果对比以及数据分析计划。

> 请注意，对目标试验方案的精确规定可能需要探索可用数据。例如，只有在确定数据包含 HIV 诊断信息后，我们才能合理地提议模拟一个针对 HIV 感染者的目标试验。

对于模拟目标试验的观测分析，可以提出与前面章节为随机试验描述的因果效应类似的分析。

在现有数据的观测分析中，很少能够模拟 **意向治疗** 效应，因为实际分配至治疗策略的情况是未知的。在我们的例子中，与意向治疗效应最接近的观测类比是比较不同治疗策略的*启动（initiation）*。对启动者的比较，类似于在目标试验中，无论个体在基线后是否继续遵循策略，分配和启动治疗策略总是在基线时同时发生的意向治疗分析。

如果我们有抗逆转录病毒治疗处方（而非配药）的数据，那么根据个体在基线时是否收到治疗处方来比较组别，会更类似于目标试验中的意向治疗分析。

> 比较启动者的观测分析等价于精细要点 22.2 中描述的修正意向治疗分析（modified intention-to-treat analysis）。

我们可以通过以下假设干预措施下结局分布的对比来定义这个意向治疗效应的观测类比：

- 在基线时启动治疗 $A_{0} = 1$ 并保持研究状态直至随访结束
- 在基线时启动治疗 $A_{0} = 0$ 并保持研究状态直至随访结束

这个在时间 $k$ 的意向治疗效应的观测类比，可以表示为反事实风险的对比：

$$
\mathrm {P r} \left[ D_{k}^{a_{0} = 1 , \bar {c}_{k} = \bar {0}} = 1 \right] - \mathrm {P r} \left[ D_{k}^{a_{0} = 0 , \bar {c}_{k} = \bar {0}} = 1 \right].
$$

与根据分配策略定义组的真实意向治疗效应不同，该对比根据每种策略的*启动*来定义组。如果我们在随机试验中使用这个对比，我们会将所有在基线时未服用任何剂量治疗的个体归入同一组，无论他们是被分配到策略 $g_{1}$ 还是 $g_{0}$ 。如果治疗的启动发生在分配后不久，我们的观测类比大致保留了意向治疗效应的一个关键特征：该对比由基线后不久发生的干预措施定义。

另一方面， **符合方案** 效应的观测类比起始定义与目标试验中的定义相同。在随机试验中，我们区分了原始符合方案效应和替代目标试验中的符合方案效应。在观测研究中这种区分是不必要的，因为在没有预先指定方案的情况下，每个符合方案效应都对应一个特定的目标试验。

一般来说，我们只能使用观测数据来模拟那些其预设干预措施至少被研究中一些个体实际遵循的目标试验。然而，在某些情况下，研究者可能愿意使用建模（例如，剂量反应结构模型）来推断数据中实际存在的干预措施之外的情况。

参考目标试验中的效应来定义观测研究中的因果效应，迫使我们明确所比较的策略。这种对治疗策略的明确规定可以防止偏倚，因为它使得某些数据分析涉及无法转化为假设干预措施之间对比的情况变得显而易见。正如我们在第 3.5 节和 3.6 节中讨论的，当分析的目标是帮助决策者在几个行动方案中进行选择时，应避免这些数据分析。

在观测分析中明确定义治疗策略的另一个优点是清晰性。正如精细要点 22.4 所讨论的，一些研究者坚持将因果效应分为“效力（efficacy）”（松散定义：在完美条件下观察到的治疗效应）或“效果（effectiveness）”（松散定义：在现实条件下观察到的治疗效应）。

有时，随机试验中的意向治疗效应被解释为治疗的*效果*，而同一试验中的符合方案效应被解释为治疗的*效力*。其他时候，随机试验中的意向治疗效应被解释为*效力*（即使是在不依从等不完美条件下），而模拟该试验的观测研究中的符合方案效应被解释为*效果*（即使在完全依从条件下）。也就是说，尤其是在具有长期持续策略的环境中，“效果”和“效力”的标签是模糊的：通常很难论证，在存在不依从情况下的意向治疗效应，或现实世界环境中的符合方案效应，能够衡量完美条件下的治疗因果效应。

与其坚持人为的效力-效果二分法，不如接受所有因果效应都位于效果连续谱上的某个位置，这可能更有帮助。此时，明确定义构成感兴趣因果效应的治疗策略将提供更多信息，因为决策者需要了解关于明确定义干预措施的效果的信息。

### 22.4 时间零点（Time Zero）

> **例子：** 观测研究与随机试验之间关于绝经后激素疗法对心脏病影响的估计存在高度公开的差异，部分原因是前者对时间零点（time zero）的处理不当 (Hernán et al. 2008)。

目标试验模拟的一个关键组成部分是在观测分析中确定随访开始时间，也称为 **基线（baseline）** 或 **时间零点（time zero）** 。资格标准需要在那个时间点满足，而非之后；研究结局在那个时间点之后开始计数，而非之前。

在随机实验中，每个个体的时间零点是他们满足资格标准的同时被分配至治疗策略的时间。例如，在我们关于抗逆转录病毒治疗的随机试验中，时间零点是分配治疗策略的时间（随机化时间），这通常发生在治疗启动前不久或同时。

我们不会在治疗分配前（例如 2 年）或分配后开始随访。在随机化之前开始随访是不合理的，因为治疗策略尚未分配，资格标准也尚未定义，更不用说满足了；在随机化之后开始随访则可能存在偏倚，因为试验前两年的死亡将被排除在分析之外，并且任何治疗的短期效应都会被遗漏。更成问题的是，如果治疗确实有短期效应，那么在接受积极治疗的组中，更多易感个体将在第 2 年死亡，而另一组则不会。两年后这种易感个体比例的差异破坏了随机化实现的基线可比性，并为选择偏倚打开了大门。

关于时间零点的相同规则适用于观测分析和随机试验，且原因相同。通常，观测分析中的随访应在目标试验中随访开始的时间点开始。否则，效应估计可能难以解释，并且由于受治疗影响的选择而存在偏倚。

尽管如此，在因果推断的观测研究中，模拟目标试验时间零点的错误非常常见。这些错误的发生源于两个常见问题：

1.  有时时间零点没有唯一的选择。
2.  有时治疗策略无法在时间零点唯一地分配。

我们现在描述针对这两个问题的解决方案。

#### 首先，非唯一时间零点的问题。

考虑两种情景，根据个体一生中可以满足资格标准的次数：

1.  **资格标准可以在单个时间点满足。**  
    这是最简单的情况。随访在满足资格标准的唯一时间点开始。  
    例如，考虑一项针对 HIV 感染者的研究，比较在 CD4 细胞计数首次降至 $500$ 个细胞/ $\mu$ L 以下时立即启动抗逆转录病毒治疗与在 CD4 细胞计数首次降至 $350$ 个细胞/ $\mu$ L 以下时延迟启动。合格个体的随访从他们的 CD4 细胞计数首次降至 $500$ 以下时开始。

2.  **资格标准可以在多个时间点满足。**  
    这是经常导致混淆的情况。  
    例如，考虑一项研究，比较在既往无慢性病史且过去两年内未使用激素疗法的绝经后女性中启动与不启动激素疗法。如果一名女性在 51 岁至 65 岁之间持续满足这些资格标准，她的随访应该何时开始？在 51 岁、52 岁、53 岁...？在目标试验中...

时间单位的无偏选择在不同研究中可能有所不同。例如，考虑一项研究，其中 **时变治疗（time-varying treatment）** 和 **时变混杂因素（time-varying confounders）** 对许多个体而言每周变化超过一次。那么选择一周或一个月作为时间单位会引入偏倚。这种偏倚可以通过选择一天作为时间单位来消除。如果无法获得治疗和混杂因素的日度数据，则偏倚无法完全校正。

从统计学角度来看， **序贯模拟策略（sequential emulation strategy）** (c) 可能比前几种策略更高效，因为它利用了更多可用数据。然而，由于个体可能被纳入多个 **目标试验（target trials）** ，需要对效应估计的方差进行适当调整。这可以通过对整个分析进行 **自助法（bootstrapping）** 来实现。

其次，让我们讨论如何解决无法为每个个体分配唯一治疗策略的问题。考虑一个目标试验，其中 **CD4 细胞计数（CD4 cell count）** 刚刚降至 500 cells/µL 以下的个体被分配到以下策略之一：

1. 立即开始治疗
2. 当 CD4 细胞计数降至 350 cells/ $\mu \mathrm{L}$ 以下时开始治疗
3. 当 CD4 细胞计数降至 200 cells/µL 以下时开始治疗

当使用观察性数据模拟此目标试验时，我们会发现有些个体在时间零（即他们的 CD4 细胞计数首次降至 500 cells/ $\mu \mathrm{L}$ 以下时）已开始治疗，因此我们将他们分配到策略 (1)。然而，其他个体在时间零并未开始治疗，这意味着他们的数据在基线时与同时遵循策略 (2) 和策略 (3) 兼容。我们应该将他们分配到哪种策略？

一种可能性是随机选择单一策略并分配给他们，但这在统计上效率低下。另一种可能性是在数据中为每个此类个体创建两个完全相同的副本—— **克隆体（clones）** ，并将两个克隆体分别分配到不同的策略。当克隆体的数据不再与其被分配到的组别一致时，对其进行删失。例如，如果个体在 CD4 降至 350 时未开始治疗，那么被分配到“当 CD4 细胞计数降至 350 时开始治疗”的克隆体将在此时被删失。这种可能具有信息性的删失所引入的潜在偏倚，需要通过 **逆概率加权（IP weighting）** 调整时变因素来校正。

重要的是，如果个体在任一克隆体被删失之前死亡，那么两个克隆体都会死亡，因此死亡事件将被分配到两种策略。这种事件的双重分配防止了如果等待期间发生的事件被系统性地仅分配到两种策略之一时可能产生的偏倚。

同样，由于个体可能通过其克隆体在分析中被多次纳入，需要通过自助法对效应估计的方差进行适当调整。当资格标准可以在多个时间点满足时， **克隆 $^+$ 删失 $^+$ 加权** 程序可以与序贯目标试验模拟相结合。

> **要点 22.5：宽限期（Grace periods）**
>
> 考虑一项比较在时间零立即启动抗逆转录病毒治疗与延迟启动的试验。在现实世界中，抗逆转录病毒治疗无法在分配的当天精确启动。根据医疗系统的不同，可能需要数周或数月才能完成必要的临床和行政程序，并使患者得到充分告知。因此，研究人员需要定义一个 **宽限期（grace period）** （例如 3 个月），在此期间启动仍被视为立即启动。否则，该研究将估计现实中不常发生或实践中无法成功实施的策略的效果。
>
> 使用宽限期的一个后果是，在宽限期内，个体的观察数据与多种策略一致。例如，在上述研究中，引入 3 个月的宽限期意味着干预措施被重新定义为“在时间零后 3 个月内启动治疗”与“从不启动治疗”。因此，在基线后第 3 个月开始治疗的个体，其在第 1 个月和第 2 个月的数据与两种策略一致。如果他们中的一些人在那 2 个月内死亡，我们应该将这些死亡分配到哪种策略？如文中所述，我们可以随机将这些个体分配到两种策略之一，或者更好的做法是为每个个体创建两个克隆体，并将两个克隆体分别分配到不同的策略。当克隆体的数据不再与其被分配的策略兼容时，对其进行删失。例如，如果个体在第 3 个月开始治疗，那么被分配到“3 个月后启动”的克隆体将在此时被删失。删失引入的潜在偏倚可以通过 IP 加权处理。
>
> 当使用带有克隆和删失的宽限期时， **意向治疗（intention-to-treat, ITT）** 效应无法被估计，因为几乎每个人都会为每种治疗策略贡献一个克隆体。由于每个个体在基线时被分配到所有策略，基于基线分配的对比（即“意向治疗分析”）将比较结果本质上相同的组别。因此，在基线带有宽限期的分析旨在估计某种形式的 **符合方案（per-protocol）** 效应，因此通常需要纳入适当的调整。
>
> 最后，请注意，带有宽限期的明确定义的启动策略应指定宽限期内的启动时间。详情请参见 Cain 等人 (2010) 的附录。
>
> 关于克隆 $^+$ 删失 $^+$ 加权程序的描述，请参见 Robins 等人 (2008) 和 Cain 等人 (2010)。相关研究请参见 van der Laan 和 Petersen (2007)。

## 22.5 用数据回答“如果”问题的统一方法（A Unified Approach to Answer "What If" Questions with Data）

本书描述并整合了两个 **因果推断（causal inference）** 框架： **反事实（counterfactuals）** 和 **因果图（causal diagrams）** 。明确的 **目标试验模拟（target trial emulation）** 概括了这两个框架，并将其奠定在可操作的因果推断基础上。通过将因果推断组织在一个非常熟悉的科学概念——实验——周围，目标试验框架帮助研究人员利用其专业知识提出明确定义的因果推断问题。一旦因果问题被明确陈述，研究设计和数据分析便自然展开。

目标试验框架适用于多个学科的广泛因果问题，无论各领域偏好的术语和方法论如何。例如，经济学家通常将混杂和条件可交换性分别称为 **遗漏变量偏倚（omitted variable bias）** 和 **基于可观测变量的选择（selection on observables）** ，而传统社会科学家不太可能使用 **g 方法（g-methods）** ，因为他们的因果问题通常不围绕时变治疗组织。但这些学科差异与所有对因果推断感兴趣的健康和社会科学家面临的基本任务相比是表面的：他们都需要将其因果问题表达为明确定义的反事实的对比。目标试验框架通过帮助定义导致明确定义反事实的明确定义的干预措施，促进了这一任务。

目标试验框架还提供了一种通用语言来统一随机研究和观察性研究的因果分析。除了基线随机化之外，模拟目标试验的观察性数据分析和真实随机试验分析之间没有其他必要差异（见要点 22.6）。也就是说，随机试验可被视为带有基线随机化的随访研究，而观察性纵向数据则被视为没有基线随机化的随访研究。

随着越来越多的随机实验试图在现实世界环境中估计长期持续治疗策略的效果，带有和不带有基线随机化的随访研究之间的相似性在健康和社会科学中日益明显。这些研究与 20 世纪中期将随机试验置于研究设计层级顶端的严格控制环境下的短期实验相去甚远。对于涉及长期持续治疗策略的因果问题，可能存在显著偏离方案的随机实验（例如，对被分配策略的依从性不完美、失访）会受到我们通常认为仅与观察性研究相关的混杂和选择偏倚的影响。

特别是，在估计 **符合方案效应（per-protocol effect）** 时，随机试验和观察性研究可能都需要调整预测退出（选择偏倚）和治疗（混杂）的时变预后因素。也就是说，本书描述的因果推断方法论同样适用于随机试验和观察性研究的符合方案分析。出于同样的原因，当从观察性数据估计因果效应时不能保证成功，随机试验的符合方案效应估计也可能存在偏倚。

鉴于这些相似性，可以预期随机实验和观察性研究将被类似地分析，除了在观察性分析中调整基线混杂因素以估计与意向治疗效应类似的效果。然而，在实践中，随机实验和观察性研究的典型分析截然不同，这既令人困惑，而且正如我们下文所述，也成问题。

一个自然的问题是，随机试验中常用的“意向治疗分析”和所谓的“符合方案分析”是否分别有效估计了意向治疗效应和符合方案效应。

典型的意向治疗分析比较随机组之间的结果分布，而不进行任何形式的混杂调整。

> **要点 22.6：观察性研究中的时变混杂（Time-varying confounding in observational studies）**
>
> 观察性研究中的时变混杂是一种偏倚，其结构与随机试验中的非随机不依从性相同。

随机实验和观察性研究的数据有何不同？只有三点区别随机实验和观察性研究的数据。在随机实验中：

- (i) 由于随机化，预期不存在基线混杂，
- (ii) 随机化概率已知，且
- (iii) 每个个体在基线时的治疗策略分配是已知的。

如果测量并适当调整了充分的协变量集，并且给定历史的治疗分配模型被正确设定，观察性分析可以模拟 (i) 和 (ii)。有趣的是，(iii) 对于在随机实验或观察性研究中估计符合方案效应并非必要，因为高效估计量（作为充分统计量的函数）不使用此信息。也就是说，分析者不需要知道正在比较的策略，更不需要知道谁被分配到哪个策略：在随机试验中，如果测量了充分的混杂因素集，你可以从数据集中删除随机化分配，仍然可以估计符合方案效应。在具有完美依从性的动态策略试验中，充分的集合是策略用于分配治疗的所有时间固定和时变协变量（Robins 1986）。

> **要点 22.2** 将甚至不尝试调整选择偏倚的意向治疗分析称为 **伪意向治疗分析（pseudointention-to-treat analysis）** 。

> **要点 22.3** 将甚至不尝试调整混杂的符合方案分析称为 **朴素符合方案分析（naïve per-protocol analysis）** 。

...或选择偏倚。不对基线混杂进行调整的理由是随机化：随机组预期是可交换的，因为如果两组被分配到相同的治疗策略，它们预期具有相同的结果风险。不需要对随机化后的混杂（例如，由于不依从性）进行调整，因为同样，对于基线分配的效果，不可能存在随机化后的混杂。

然而，基线随机化不能确保随机化后失访和未失访个体之间的可交换性。由于定义意向治疗效应的策略要求个体留在研究中直到其结果变量可以被确定，如果在那些未失访的个体中计算的意向治疗效应估计值受到预后因素影响或与差异性失访相关，则可能受到随机化后选择偏倚的影响。因此，有效估计意向治疗效应可能需要调整随机化后（时变）预后因素的“意向治疗分析”，以消除失访带来的选择偏倚。例如，在 HIV 患者抗逆转录病毒治疗的随机试验中，如果退出研究的概率受到症状发作或其他结果风险因素的影响，则需要使用 g 方法。

除了主要的意向治疗分析之外，许多随机试验还报告了所谓的符合方案分析的结果，该分析仅限于遵循研究方案中指定说明的个体，如要点 22.3 中对点干预的描述。对于持续治疗策略，个体在第一次偏离方案时被删失。也就是说，每个时间点剩余的符合方案人群是仍然遵循方案的一组个体。不进行任何形式的调整。这种未调整的分析由于三个原因而存在疑问。

**第一** ，与意向治疗分析一样，可能存在由于差异性失访导致的选择偏倚。如果是这样，则需要通过 g 方法调整基线后（时变）风险因素。

**第二** ，该分析部分忽略了随机组，因此一种策略下仍遵循方案的个体子集可能与另一种策略下遵循方案的子集不可交换。也就是说，这种“符合方案分析”类似于观察性分析，因此需要 g 方法来调整影响是否继续遵循方案决策的时变风险因素带来的偏倚。 **工具变量估计（Instrumental variable estimation）** （第 16 章）有时可用于在不显式调整任何变量的情况下有效估计符合方案效应，但这些方法的有效性取决于拥有有效的工具变量和强模型假设。某些形式的工具变量估计是 g 估计的一个特例（见技术要点 16.6）。

> 对于失效时间结局，当治疗对结果有因果效应时，总是需要 g 方法。原因是治疗 $A_{k}$ 通过其对时变指示变量 $D_{k + 1}$ 的影响影响时间 $k$ 之后的所有变量，如技术要点 21.10 所讨论。

**第三** ，这种传统的符合方案分析忽略了所比较的持续治疗策略是动态策略。一个常见的错误是删失停止治疗的个体，仿佛停止治疗本身就定义为偏离方案——这就是为什么这种分析也被称为 **按治疗分析（on-treatment analysis）** 。我们上面已经讨论过，因毒性或禁忌症而停止治疗的个体并未偏离方案，因此不应被删失。

以上所有考虑都适用于随机试验和观察性数据的分析，以模拟目标试验。当目标是估计符合方案效应或其观察性类似物时，随机试验和观察性研究的分析应该是相同的。如果我们觉得有必要在观察性研究的分析中调整时变混杂和选择偏倚，那么我们应该同样觉得有必要在随机试验的分析中调整随机化后的混杂和选择偏倚。对于随机试验和观察性研究的符合方案分析，通常需要使用 g 方法调整时变因素。目标试验框架和 g 方法使得对持续治疗策略实施 **统一方法（unified approach）** 进行因果推断成为可能。

从历史上看，为了进行因果推断和辅助决策，随机实验被认为远优于观察性研究。不幸的是，随机实验并不总是可用的，因为它们可能昂贵、不可行、不道德，或者只是不够及时以支持紧急决策。因此，尽管我们重视随机化的益处，但事实是许多决策需要在缺乏随机试验证据的情况下做出。当我们无法进行能够回答我们因果问题的随机实验时，我们求助于尝试使用观察性数据进行模拟。因此，使用合理的方法来设计和分析观察性研究非常重要。使目标试验明确是朝这个方向迈出的一步。当目标是辅助决策时，对现有观察性数据的分析需要明确模拟试验，并根据它们模拟目标试验的效果进行评估。

> 在某些极为罕见的情况下，基于高质量随机试验的决策可能不如基于严重混杂的观察性数据的决策，如要点 22.7 和 22.8 所述。

#### 要点 22.7（Fine Point 22.7）

随机试验和观察性研究的反直觉比较。某国许多肺癌患者使用了一种未经测试的非处方治疗 $A$ 。这引起了该国药品监管机构的担忧，作为回应，该机构资助了一项关于 $A$ 的双盲安慰剂对照随机试验，样本为下一年诊断出肺癌的 $20\%$ 的随机个体。所有试验参与者都遵守了其被分配的治疗。治疗组和安慰剂组的 60 个月死亡风险分别为 $55\%$ 和 $45\%$ ，如下表所示：

|         | $A = 0$ | $A = 1$ |
| :------ | :-----: | :-----: |
| $Y = 1$ |   450   |   550   |
| $Y = 0$ |   550   |   450   |
|         |  1000   |  1000   |

结果，监管机构禁止了该治疗。后来，对未被选入试验的 $80\%$ 的肺癌患者进行了一项观察性研究。该研究发现，在与试验相同的时期内，接受治疗和未接受治疗的患者死亡风险均为 $0\%$ 。如何协调观察性和随机试验的数据？

让我们首先回顾一下，个体可以根据反事实类型进行分类：

1. “注定死亡”（Doomed） $(Y^{a=0} = Y^{a=1} = 1)$ ，
2. “受伤”（Hurt） $(Y^{a=0} = 0, Y^{a=1} = 1)$ ，
3. “受益”（Helped） $(Y^{a=0} = 1, Y^{a=1} = 0)$ ，
4. “免疫”（Immune） $(Y^{a=0} = Y^{a=1} = 0)$ 。

通过随机抽样和随机化，以下三组具有相同的反事实类型分布：试验中接受治疗的 1000 名个体、试验中未接受治疗的 1000 名个体以及观察性研究中的 8000 名个体。关键的观察结果是，观察性研究中 $0\%$ 的死亡率意味着：

- (i) 不存在“注定死亡”的个体，
- (ii) 所有 $Y^{a=1} = 1$ 的个体必须是“受伤”类型并且接受了 $A = 0$ ，
- (iii) 所有 $Y^{a=0} = 1$ 的个体必须是“受益”类型并且接受了 $A = 1$ 。

接下来，我们利用这些观察结果按反事实类型重建试验数据。如上所述，550 名接受 $A = 1$ 后死亡（ $Y^{a=1} = 1$ ）的个体属于“受伤”类型。由于随机化，也必须有 550 名接受 $A = 0$ 的“受伤”个体，他们自然存活。类似地，我们可以填充“受益”类型的表格。

| “受伤”  | $A = 0$ | $A = 1$ | “受益”  | $A = 0$ | $A = 1$ |
| ------- | ------- | ------- | ------- | ------- | ------- |
| $Y = 1$ | 0       | 550     | $Y = 1$ | 450     | 0       |
| $Y = 0$ | 550     | 0       | $Y = 0$ | 0       | 450     |
|         | 550     | 550     |         | 450     | 450     |

合并这两个表格，我们恢复了完整的试验数据，这表明不存在“免疫”个体。

我们得出结论，监管机构应重新批准治疗 $A$ ，并建议继续当前实践，因为观察性研究证明，不知何故，每位肺癌患者都拥有试验者无法获得的私人知识，即关于治疗对个人是有害还是有益。

接下来，我们描述一个极端的场景，可以解释这种私人知识的来源。假设人群中存在 55/45 的种族划分，并且由于遗传原因，治疗对第一组中的肺癌患者普遍有害（即全部为“受伤”类型），但对第二组中的所有肺癌患者普遍有益（即全部为“受益”类型）。还假设，在试验之前的某个时间，第一组中的肺癌患者在看到该组几名成员服药后迅速死亡后，便避免接受治疗。相反，假设第二组中的所有肺癌患者在看到该组几名成员服药后存活下来后，都选择接受治疗。换句话说，假设存在 (i) 按种族划分的最大定性效应修饰（qualitative effect modification）和 (ii) 观察性数据中按种族划分的最大混杂（maximal confounding）。

上述描述的极端情景当然是不现实的，但它有助于解释一个重要观点：随机化试验比较了“治疗所有人”和“不治疗任何人”的策略，但最优策略是“仅治疗属于种族组 $2$ 的个体”。当未获取效应修饰因子（即种族组）的数据时，不可能在随机化试验中将个体分配到最优策略。相反，在观察性研究中，所有个体都遵循了最优策略，从而获得了无死亡的最优结果。因此，正是存在混杂的观察性研究，而非无混杂的随机化试验，揭示了正确的政策。

#### 细节点 22.8（Fine Point 22.8）

**将细节点 22.7 推广到现实场景**

上述讨论可以推广到更现实的场景，以表明如果随机化试验和观察性数据中的个体都是所有符合试验条件的个体的随机样本，那么将随机化试验和观察性数据结合的设计可能比仅使用随机化试验数据的设计提供更多信息。

假设我们在一个已经使用某种治疗的人群中，对二值治疗 $A$ 和结局 $Y$ （ $Y$ 值越小越优）进行了一项随机化试验。进一步假设，正如偶尔可能发生的那样，观察性研究中的平均结局 $\operatorname{E}[Y]$ 小于随机化试验两个臂中的平均结局，这意味着 $\operatorname{E}[Y]$ 同时小于 $\mathrm{E}[Y^{a=0}]$ 和 $\mathrm{E}[Y^{a=1}]$ 。那么，我们可能选择不改变当前关于该治疗的社区实践。

接下来我们证明，对于不同于试验中比较的“治疗所有人”（ $a = 1$ ）和“不治疗任何人”（ $a = 0$ ）策略的策略 $g$ ，有 $\operatorname{E}[Y] = \operatorname{E}[Y^{g}]$ 。具体来说，令 $U$ 是一组充分的、未测量的、可能未知的治疗前协变量，足以确保 $Y^{a} \amalg A \mid U$ ，并令 $\operatorname{Pr}[A = 1 \mid U]$ 是观察性数据中相应的倾向得分（propensity score）。那么，上述等式对于随机策略 $g$ 成立，在该策略中，治疗 $A = 1$ 以概率 $\operatorname{Pr}[A = 1 \mid U]$ 随机分配，因为这一选择给出了生成关于 $A, Y$ 和未知 $U$ 的观察性数据的随机策略 $g$ 。

尽管由于无法获得关于 $U$ 的数据，策略 $g$ 无法实施，但上述讨论可以激励研究者测量治疗前协变量 $V$ ，这些协变量可用于分析随机化试验数据，以找到并随后实施一个确定性动态策略 $g^{\ast}(x)$ ，使得根据无混杂的随机化试验数据估计的 $\operatorname{E}[Y^{g^{*}}]$ 小于观察性的 $\operatorname{E}[Y]$ 。
