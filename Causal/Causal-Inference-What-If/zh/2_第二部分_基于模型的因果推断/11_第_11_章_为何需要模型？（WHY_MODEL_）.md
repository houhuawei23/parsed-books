## 11.1 数据无法自我表达（Data Cannot Speak for Themselves）

> 关于一致估计量的严格定义，请参见第 10 章。

考虑一个由 16 名感染了 **人类免疫缺陷病毒（human immunodeficiency virus, HIV）** 的个体组成的研究人群。与本书第一部分不同，我们不会将这些个体视为与它们相同的 10 亿个体的代表。相反，这仅仅是随机抽样自一个大型的、可能是假设的 **超总体（super-population）** ——即 **目标总体（target population）** ——的 16 个个体。

在研究开始时，每个个体接受一定水平的治疗 $A$ （抗逆转录病毒疗法），并在研究期间维持该治疗水平。在研究结束时，对所有个体测量一个连续结局 $Y$ （CD4 细胞计数，单位：cells/mm³）。我们希望一致地估计在随机抽取这 16 个个体的总体中，治疗水平为 $A = a$ 的个体中 $Y$ 的均值。也就是说， **估计目标（estimand）** 是未知的总体参数 $\operatorname{E}[Y \mid A = a]$ 。

如第 10 章所定义， $\operatorname{E}[Y \mid A = a]$ 的估计量 $\widehat{\operatorname{E}}[Y \mid A = a]$ 是用于估计未知总体参数的某个数据函数。非正式地说，一个一致估计量 $\widehat{\operatorname{E}}[Y \mid A = a]$ 满足这样的要求：“样本量越大，估计值越接近总体值 $\operatorname{E}[Y \mid A = a]$ 。”可能的估计量 $\widehat{\operatorname{E}}[Y \mid A = a]$ 的两个例子是：(i) 接受 $A = a$ 的个体中 $Y$ 的样本均值，以及 (ii) 数据集中碰巧具有值 $A = a$ 的第一个观测值。接受 $A = a$ 的个体中 $Y$ 的样本均值是总体均值的一致估计量；而具有 $A = a$ 的第一个观测值则不是。在实践中，我们要求所有估计量都是一致的，因此我们使用样本均值来估计总体均值。

假设治疗 $A$ 是一个 **二分变量（dichotomous variable）** ，有两个可能的值：未治疗（ $A = 0$ ）和治疗（ $A = 1$ ）。一半的个体接受了治疗（ $A = 1$ ）。图 11.1 是一个散点图，将 16 个个体中的每一个显示为一个点。点的高度表示个体结局 $Y$ 的值。8 名接受治疗的个体沿着 $A = 1$ 列放置，8 名未接受治疗的个体沿着 $A = 0$ 列放置。

如第 10 章所定义，总体中水平为 $A = a$ 的个体中 $Y$ 均值的 **估计值（estimate）** 是将估计量——在我们的例子中是样本均值——应用于特定数据集所得的数值结果。我们对治疗组总体均值的估计值是 $A = 1$ 组样本均值 146.25，对未治疗组总体均值的估计值是 $A = 0$ 组样本均值 67.50。在治疗组和未治疗组 **可交换（exchangeability）** 的条件下，差值 $146.25 - 67.50$ 将被解释为治疗 $A$ 对目标总体中结局 $Y$ 的 **平均因果效应（average causal effect）** 的估计值。然而，本章并非关于进行因果推断。我们当前的目标仅仅是激发在试图估计诸如均值 $\operatorname{E}[Y \mid A = a]$ 等总体量时对模型的需求，无论这些估计值是否具有因果解释。

现在假设治疗 $A$ 是一个 **多分类变量（polytomous variable）** ，可以取 4 个可能的值：未治疗（ $A = 1$ ）、低剂量治疗（ $A = 2$ ）、中剂量治疗（ $A = 3$ ）和高剂量治疗（ $A = 4$ ）。每个治疗水平的个体各占总数的四分之一。图 11.2 显示了研究人群中 16 个个体的结局值。为了估计由治疗水平定义的 4 个组中的总体均值，我们计算相应的样本均值。对于 $A = 1$ 、 $A = 2$ 、 $A = 3$ 和 $A = 4$ ，估计值分别为 70.0、80.0、117.5 和 195.0。

图 11.1 和 11.2 分别描绘了具有 2 个和 4 个类别的 **离散（分类）变量（discrete (categorical) variables）** 的例子。由于研究个体数固定为 16，随着类别数量的增加，每个类别中的个体数减少。每个类别中的样本均值仍然是相应总体均值的精确无偏估计量，但随着每个类别中个体数的减少，样本均值接近相应总体均值的概率降低。对于图 11.2 中的数据，类别特异性均值的 $95\%$ **置信区间（confidence intervals）** （见第 10 章）的长度将大于图 11.1 中的数据。

最后，假设 $A$ 表示治疗剂量（mg/day），并且取从 0 到 100 mg 的整数值。图 11.3 显示了 16 个个体中每一个的结局值。由于治疗的可能值数量远大于研究中的个体数量，因此存在许多 $A$ 值没有个体接受。例如，研究人群中不存在治疗剂量 $A = 90$ 的个体。这产生了一个问题：我们如何估计目标总体中治疗水平为 $A = 90$ 的个体中结局 $Y$ 的均值？我们用于图 11.1 和 11.2 中数据的估计量——治疗特异性样本均值——对于图 11.3 中零个体的治疗水平是未定义的。如果治疗 $A$ 是一个真正的 **连续变量（continuous variable）** ，那么样本均值对于几乎所有的治疗水平都是未定义的。（连续变量 $A$ 可以被视为一个具有不可数无限多个类别的分类变量。）

以上描述表明，我们并不能总是让数据“自我表达”来获得有意义的估计值。相反，我们通常需要用一个模型来补充数据，正如我们在下一节中描述的那样。

## 11.2 条件均值的参数估计量（Parametric Estimators of the Conditional Mean）

我们希望根据图 11.3 中的数据估计治疗水平为 $A = 90$ 的个体中 $Y$ 的均值，即 $\operatorname{E}[Y \mid A = 90]$ 。假设我们预期治疗水平为 $A = 90$ 的个体中 $Y$ 的均值位于 $A = 80$ 的个体均值与 $A = 100$ 的个体均值之间。事实上，假设我们知道在整个 $A$ 范围内， $Y$ 的治疗特异性总体均值是治疗值 $A$ 的线性函数。更精确地说，我们知道 $Y$ 的均值 $\operatorname{E}[Y \mid A]$ 从 $A = 0$ 时的某个值 $\theta_0$ 开始，每单位 $A$ 增加（或减少） $\theta_1$ 个单位。或者，更简洁地：

这个方程是对条件均值函数 $\operatorname{E}[Y \mid A]$ 形状的一个限制。这个特定的限制被称为 **线性均值模型（linear mean model）** ，而量 $\theta_0$ 和 $\theta_1$ 被称为模型的 **参数（parameters）** 。用有限数量的参数来描述条件均值函数的模型被称为 **参数条件均值模型（parametric conditional mean models）** 。在我们的例子中，参数 $\theta_0$ 和 $\theta_1$ 定义了一条在 $\theta_0$ 处与纵轴相交（截距）且斜率为 $\theta_1$ 的直线。也就是说，该模型规定所有条件均值函数都是直线，尽管它们的截距和斜率可能不同。

我们现在准备将图 11.3 中的数据与我们的参数均值模型结合起来，以估计从 0 到 100 所有值 $a$ 的 $\operatorname{E}[Y \mid A = a]$ 。第一步是获得参数 $\theta_0$ 和 $\theta_1$ 的估计值 $\hat{\theta}_0$ 和 $\widehat{\theta}_1$ 。第二步是使用这些估计值来估计任何值 $A = a$ 时 $Y$ 的均值。例如，为了估计治疗水平为 $A = 90$ 的个体中 $Y$ 的均值，我们使用表达式 $\widehat{\operatorname{E}}[Y \mid A = 90] = \widehat{\theta}_0 + 90 \widehat{\theta}_1$ 。每个个体的估计值 $\widehat{\mathrm{E}}[Y \mid A]$ 被称为 **预测值（predicted value）** 。

$\theta_0$ 和 $\theta_1$ 的精确无偏估计量可以通过 **普通最小二乘法（method of ordinary least squares）** 获得。下面介绍该方法的一种非技术性动机。考虑图 11.3 中所有可能的候选直线，每条直线都有不同的截距 $\theta_0$ 和斜率 $\theta_1$ 值组合。对于每条候选直线，可以计算每个点到直线的垂直距离（ **残差（residual）** ），将这 16 个残差分别平方，然后求和这 16 个平方残差。使该和最小的那条线就是“最小二乘”线，而这条“最小二乘”线的参数值 $\widehat{\theta}_0$ 和 $\widehat{\theta}_1$ 就是“最小二乘”估计值。值 $\hat{\theta}_0$ 和 $\widehat{\theta}_1$ 可以使用线性代数轻松计算，如任何统计学教科书所述。

在我们的例子中，参数估计值为 $\hat{\theta}_0 = 24.55$ 和 $\hat{\theta}_1 = 2.14$ ，它们定义了图 11.4 中所示的直线。因此，治疗水平为 $A = 90$ 的个体中 $Y$ 的预测均值为 $\widehat{\operatorname{E}}[Y \mid A = 90] = 24.55 + 90 \times 2.14 = 216.9$ 。由于普通最小二乘估计使用所有数据点来寻找最佳直线，因此 $A = a$ 组中 $Y$ 的均值，即 $\operatorname{E}[Y \mid A = a]$ ，是通过借用治疗 $A$ 值不等于 $a$ 的个体的信息来估计的。

那么什么是模型？模型是由对数据联合分布的先验限制定义的。我们的线性条件均值模型规定条件均值函数 $\operatorname{E}[Y \mid A]$ 是一条直线，这限制了它的形状。例如，该模型将 $A = 90$ 时 $Y$ 的均值限制在 $A = 80$ 时 $Y$ 的均值和 $A = 100$ 时 $Y$ 的均值之间。这个限制由参数 $\theta_0$ 和 $\theta_1$ 编码。一个参数条件均值模型，通过其先验限制，增加了信息以补偿数据中信息的不足。

**参数估计量（Parametric estimators）** ——那些基于参数条件均值模型的估计量——使我们能够估计否则无法估计的量，例如，当研究人群中不存在治疗水平为 $A = 90$ 的个体时，目标总体中该水平个体的 $Y$ 均值。但这并非免费的午餐。当使用参数模型时，只有当模型中编码的限制是正确的，即模型被 **正确设定（correctly specified）** 时，推断才是正确的。因此，基于模型的因果推断——本书剩余部分的大部分内容都致力于此——依赖于（近似）无模型误设的条件。由于参数模型很少（如果有的话）被完美设定，因此几乎总是预期存在一定程度的 **模型误设（model misspecification）** 。这可以通过使用 **非参数估计量（nonparametric estimators）** 得到至少部分纠正，我们将在下一节中描述。

其中 $\operatorname{E}[Y \mid A = 0] = \theta_0 + 0 \times \theta_1 = \theta_0$ 且 $\operatorname{E}[Y \mid A = 1] = \theta_0 + 1 \times \theta_1 = \theta_0 + \theta_1$ 。我们使用最小二乘法来获得参数 $\theta_0$ 和 $\theta_1$ 的估计值。这些估计值为 $\hat{\theta}_0 = 67.5$ 和 $\hat{\theta}_1 = 78.75$ 。因此我们估计 $\widehat{\mathrm{E}}[Y \mid A = 0] = 67.5$ 和 $\widehat{\mathrm{E}}[Y \mid A = 1] = 146.25$ 。请注意，我们基于模型的 $Y$ 均值估计值与我们在第 11.1 节中计算的样本均值完全相同。这不是巧合，而是一个预期的发现。

让我们再次审视二分治疗 $A$ 的模型 $\operatorname{E}[Y \mid A] = \theta_0 + \theta_1 A$ 。如果我们将模型重写为 $\operatorname{E}[Y \mid A = 1] = \operatorname{E}[Y \mid A = 0] + \theta_1$ ，我们看到该模型仅仅说明治疗组均值 $\operatorname{E}[Y \mid A = 1]$ 等于未治疗组均值 $\operatorname{E}[Y \mid A = 0]$ 加上一个量 $\theta_1$ ，其中 $\theta_1$ 可以为负、正或零。但这当然是永远正确的陈述！该模型对 $\operatorname{E}[Y \mid A = 1]$ 和 $\mathrm{E}[Y \mid A = 0]$ 的值没有施加任何限制。因此，对于二分治疗 $A$ ， $\operatorname{E}[Y \mid A = a] = \theta_0 + \theta_1 A$ 不是一个模型，因为它让数据自我表达，就像样本均值一样。不对数据分布施加限制的“模型”是饱和模型。尽管它们形式上看起来像模型，即使它们不符合我们对模型的定义，饱和模型通常也被称为模型。

通常，当条件均值模型中的参数数量等于总体中未知条件均值的数量时，该模型是饱和的。例如，线性模型 $\operatorname{E}[Y \mid A] = \theta_0 + \theta_1 A$ 有两个参数，并且当 $A$ 是二分变量时，存在两个未知的条件均值：均值 $\operatorname{E}[Y \mid A = 1]$ 和 $\operatorname{E}[Y \mid A = 0]$ 。由于这两个参数的值不受模型限制，均值的值也不受限制。作为对比，考虑图 11.3 中的数据，其中 $A$ 可以取从 0 到 100 的值。线性模型 $\operatorname{E}[Y \mid A] = \theta_0 + \theta_1 A$ 有两个参数，但估计了 101 个量，即 $\operatorname{E}[Y \mid A = 0], \operatorname{E}[Y \mid A = 1], \dots, \operatorname{E}[Y \mid A = 100]$ 。

## 精细点 11.1（Fine Point 11.1）

**Fisher 一致性（Fisher consistency）。** 我们在正文中对非参数估计量的定义与统计学中已知的 **Fisher 一致估计量（Fisher consistent estimator）** （Fisher 1922）一致。也就是说，一个总体量的估计量，当使用整个总体而不是样本计算时，会产生总体参数的真实值。根据定义，Fisher 一致估计量缺乏任何模型限制，但正如正文中所讨论的，对于许多总体量，Fisher 一致估计量可能不存在。

从技术上讲，Fisher 一致估计量（当存在时）是在饱和模型下总体量的非参数最大似然估计量。

在统计学文献中，术语*非参数估计量*有时用于指代不是 Fisher 一致但施加了非常弱限制的估计量，例如 **核回归模型（kernel regression models）** 。详情见技术点 11.1（Technical Point 11.1）。

**可识别性假设（Identifiability assumptions）** 是我们即使拥有无限数据量也必须做出的假设，以计算参数。 **建模假设（Modeling assumptions）** 是我们由于没有无限数据量而必须做出的额外假设，以估计参数。形式上，可识别性假设使参数成为观测数据联合分布的独特函数。

要用这两个参数无偏地估计 101 个量，需要幸运地让所有 101 个均值 $\operatorname{E}[Y \mid A = a]$ 都位于一条直线上。当一个模型只有几个参数但被用来估计许多总体量时，我们说该模型是 **简约的（parsimonious）** 。

这里我们将条件均值函数的 **非参数估计量（nonparametric estimators）** 定义为那些从数据中产生估计值，而不对条件均值函数施加任何先验限制的估计量（更严格的定义见精细点 11.1）。对于二分治疗，总体均值 $\operatorname{E}[Y \mid A = a]$ 的非参数估计量的一个例子是其经验版本，即样本均值，或者等价地，本节中描述的饱和模型。

当 $A$ 是具有 100 个水平的离散变量，且样本中没有个体具有 $A = 90$ 时，不存在 $\operatorname{E}[Y \mid A = 90]$ 的非参数估计量。我们在本书第一部分描述的所有因果推断方法——标准化、IP 加权、分层、匹配——都是基于饱和模型下总体量的非参数估计量，因为它们没有对效应估计值施加任何先验限制。

相比之下，本书第二部分描述的大多数因果推断方法依赖于对数据分布某些部分进行估计的 **参数估计量（parametric estimators）** 。当数据（通常如此）无法自我表达时，参数估计是一种用于借用信息的方法。

## 11.4 平滑（Smoothing）

**注意：** 术语“线性”通常有两种不同的含义。当一个模型表示为参数和变量函数的线性组合时，它是*线性*的，即使后者是协变量的非线性函数（例如，高次幂或对数）。

再次考虑图 11.3 中的数据以及线性模型 $\operatorname{E}[Y \mid A] = \theta_0 + \theta_1 A$ 。参数 $\theta_1$ 是每单位治疗剂量 $A$ 的平均结局差异。由于 $\theta_1$ 是单一数字，该模型规定，在整个 $A$ 范围内，每单位治疗 $A$ 的平均结局 $Y$ 的差异必须是恒定的，即模型要求条件平均结局作为治疗剂量 $A$ 的函数遵循一条直线。图 11.4 显示了最佳拟合直线。

但可以想象这样的情况：在低治疗剂量下，每单位变化导致的平均结局差异较大，而在高剂量下，每单位变化导致的差异较小。如果一旦治疗剂量达到一定水平，更高剂量的效果越来越小，就会出现这种情况。在这种情景下，模型 $\operatorname{E}[Y \mid A] = \theta_0 + \theta_1 A$ 是不正确的。然而，线性模型可以变得更灵活。

我们以连续结局的模型为例。同样的推理适用于二分类结局的模型，如 **逻辑斯蒂模型（logistic models）** （见技术要点 11.1）。例如，假设我们对图 11.3 中的数据拟合模型 $\operatorname{E}[Y \mid A] = \theta_0 + \theta_1 A + \theta_2 A^2$ ，其中 $A^2 = A \times A$ 是 $A$ 的平方。这仍然被称为 **线性模型（linear model）** ，因为条件均值被表示为线性组合，即每个协变量（ $A$ 和 $A^2$ ）与其对应系数（参数 $\theta_1$ 和 $\theta_2$ ）的乘积之和，再加上截距（ $\theta_0$ ）。然而，当 $\theta_2$ 不为零时， $(\theta_0, \theta_1, \theta_2)$ 现在定义的是一条曲线——一条抛物线——而非一条直线。

我们将 $\theta_1$ 称为线性项 $A$ 的参数，将 $\theta_2$ 称为二次项 $A^2$ 的参数。三参数线性模型 $\operatorname{E}[Y \mid A] = \theta_0 + \theta_1 A + \theta_2 A^2$ 下的曲线可以通过对图 11.3 中的数据应用 **普通最小二乘估计（ordinary least squares estimation）** 得到。估计出的曲线如图 11.5 所示。参数估计值为 $\widehat{\theta}_0 = -7.41$ ， $\hat{\theta}_1 = 4.11$ ， $\widehat{\theta}_2 = -0.02$ 。在接受治疗剂量 $A = 90$ 的个体中， $Y$ 的预测均值由表达式 $\widehat{\operatorname{E}}[Y \mid A = 90] = \hat{\theta}_0 + 90 \hat{\theta}_1 + 90 \times 90 \hat{\theta}_2 = 197.1$ 得出。

我们可以继续添加参数，用于三次项 $(\theta_3 A^3)$ 、四次项 $(\theta_4 A^4)$ ，……直到达到十五次项 $\left(\theta_{15} A^{15}\right)$ 。此时，模型中的参数个数等于数据点（个体）的个数。曲线的形状会随着参数个数的增加而变化。一般来说，模型中的参数越多，出现的拐点就越多。也就是说，随着参数个数的增加，曲线通常会变得更加“曲折”，或者说更不平滑。

具有 2 个参数的线性模型——一条直线——是最平滑的模型。具有与数据点相同数量参数的线性模型是最不平滑的模型，因为它具有与数据点一样多的可能拐点。事实上，这样的模型对数据进行了 **插值（interpolates）** ，即样本中的每个数据点都位于估计的条件均值函数上。

通常，建模可以被视为一种将噪声数据转换为或多或少平滑曲线的过程。这种平滑之所以发生，是因为模型从许多数据点借用信息，以预测在协变量特定组合取值下的结局值。平滑的结果来自于 $\operatorname{E}[Y \mid A = a]$ 通过借用 $A$ 不等于 $a$ 的个体的信息进行估计。所有 **参数估计量（parametric estimators）** 都包含一定程度的平滑。

平滑程度取决于个体之间借用信息的多少。二参数模型 $\operatorname{E}[Y \mid A] = \theta_0 + \theta_1 A$ 通过借用研究人群中所有个体的信息来找到最小二乘直线，从而估计 $\operatorname{E}[Y \mid A = 90]$ 。具有与个体数量相同参数的模型，在估计数据中出现的 $A$ 值处的 $\operatorname{E}[Y \mid A]$ 时，不会借用任何信息，尽管它会（通过插值）为数据中未出现的 $A$ 值借用信息。

通过使用中等数量的参数，或者更一般地，通过限制对估计有贡献的个体数量，可以实现中等程度的平滑。例如，为了估计 $\operatorname{E}[Y \mid A = 90]$ ，我们可以决定拟合一个二参数模型 $\operatorname{E}[Y \mid A] = \theta_0 + \theta_1 A$ ，但仅限于治疗剂量在 80 到 100 之间的个体。也就是说，我们只借用 $A = 90$ 周围一个 10 单位窗口内的个体信息。 $A = 90$ 周围的窗口越宽，实现的平滑程度就越高。

在我们上述简化的例子中，所有模型都只包含一个协变量（要么是 $A$ 的一个参数，要么是 $A$ 和 $A^2$ 的两个参数），以便曲线可以在二维书页上表示。在实际应用中，模型通常包含许多不同的协变量，因此曲线实际上是 **超维曲面（hyperdimensional surfaces）** 。无论问题的维度如何，平滑的概念保持不变： **模型中的参数越少，预测（响应）曲面就越平滑** 。

## 细要点 11.2

### 模型维度与频率学派区间和贝叶斯区间的关系

在 **频率学派统计推断（frequentist statistical inference）** 中，概率被定义为频率。在 **贝叶斯推断（Bayesian inference）** 中，概率被定义为信念程度——一个与作为频率的概率截然不同的概念（de Finetti, 1972）。第 10 章描述了频率学派统计推断中使用的 **置信区间（confidence intervals）** 。贝叶斯统计推断使用 **可信区间（credible intervals）** ，其解释更为自然：一个贝叶斯 $95\%$ 可信区间意味着，在给定观测数据的情况下，“有 $95\%$ 的概率估计量位于该区间内”。

然而，部分由于需要指定研究者的信念程度，贝叶斯推断的使用频率低于频率学派推断。

有趣的是，在简单、低维的参数模型和大样本量下， $95\%$ 的贝叶斯可信区间也是 $95\%$ 的频率学派置信区间，而在高维或非参数模型中，贝叶斯 $95\%$ 可信区间可能不是 $95\%$ 的置信区间，因为它捕获估计量的概率可能远低于 $95\%$ 。

这些结果的根本原因是贝叶斯推断需要为所有未知参数指定一个 **先验分布（prior distribution）** 。在低维参数模型中，数据中的信息压倒了合理先验中包含的信息。因此，推断对所选的具体先验分布相对不敏感。然而，在高维模型中情况不再如此。因此，如果生成数据的真实参数值在所选的先验分布下不太可能，那么贝叶斯可信区间的中心将被拉离真实参数，朝向先验下概率最大的参数值。

## 11.5 偏差-方差权衡

在前面的章节中，我们使用图 11.3 中的 16 个个体来估计目标人群中接受治疗剂量 $A = 90$ 的个体的平均结局 $\operatorname{E}[Y \mid A = 90]$ 。由于研究人群中没有人接受 $A = 90$ ，我们无法让数据自行说明。因此，我们将数据与线性模型结合起来。

估计值 $\widehat{\operatorname{E}}[Y \mid A = 90]$ 随模型而变化。在二参数模型 $\operatorname{E}[Y \mid A] = \theta_0 + \theta_1 A$ 下，估计值为 216.9（95% 置信区间：172.1, 261.6）。在三参数模型 $\operatorname{E}[Y \mid A] = \theta_0 + \theta_1 A + \theta_2 A^2$ 下，估计值为 197.1（95% 置信区间：142.8, 251.5）。

我们使用了两个不同的参数模型，得到了两个不同的估计值。哪一个更好？216.9 还是 197.1 更接近目标人群中的均值？

如果关系确实是曲线形的，那么二参数模型的估计值将是有 **偏的（biased）** ，因为该模型假设了一条直线。另一方面，如果关系确实是一条直线，那么两个模型的估计值都是有效的。这是因为三参数模型 $\operatorname{E}[Y \mid A] = \theta_0 + \theta_1 A + \theta_2 A^2$ 无论是直线关系（此时 $\theta_2 = 0$ ）还是抛物线曲线（此时 $\theta_2 \neq 0$ ），都是正确设定的。

一个安全的策略是使用三参数模型 $\operatorname{E}[Y \mid A] = \theta_0 + \theta_1 A + \theta_2 A^2$ ，而不是二参数模型 $\operatorname{E}[Y \mid A] = \theta_0 + \theta_1 A$ 。因为三参数模型在直线和抛物线曲线下都是正确设定的，所以它不太可能产生偏差。一般来说，模型中的参数数量越多，模型施加的限制就越少；模型越不平滑，对模型误设带来的偏差的保护就越多。

尽管不平滑的模型可能产生偏差较小的估计值，但它们也会导致更大的方差，即估计值周围更宽的 95% 置信区间。例如，当我们使用三参数模型时， $\widehat{\mathrm{E}}[Y \mid A = 90]$ 周围的估计 95% 置信区间比使用二参数模型时要宽得多。然而，当基于二参数模型的估计值 $\widehat{\mathrm{E}}[Y \mid A = 90]$ 有偏时，标准的（名义上的）95% 置信区间是 **未校准的（not calibrated）** ，即它不会在 95% 的时间内覆盖真实参数 $\operatorname{E}[Y \mid A = 90]$ 。

> **细要点 11.2** 讨论了模型维度对频率学派区间和贝叶斯区间的影响。

这种 **偏差-方差权衡（bias-variance trade-off）** 是许多数据分析的核心。使用模型的研究者需要决定，对偏差的某种保护——例如，通过向模型添加更多参数——是否值得以方差为代价。尽管存在一些正式的程序来辅助这些决策，但在实践中，许多研究者基于传统、参数的可解释性和软件可用性等标准来决定使用哪个模型。

在本书中，我们通常假设我们的参数模型是正确设定的。这是一个不现实的假设，但它使我们能够专注于因果分析特有的问题。毕竟，模型误设是任何类型的数据分析中都可能出现的问题，无论估计值是否具有因果解释。在实践中，细心的研究者总会质疑其模型的有效性，并会在与现有专家知识兼容的不同模型设定下进行替代分析。他们的目标是评估其估计值对模型设定的敏感性。

我们现在准备描述模型在因果推断中的应用。

## 技术要点 11.1

常用模型的分类。正文描述了如下形式的线性条件均值模型：

$$
\operatorname{E}[Y \mid X] = \dot{\theta} X \equiv \sum_{i=0}^{p} \theta_i X_i
$$

其中 $X$ 是协变量 $X_0, X_1, \ldots, X_p$ 的向量，对于所有 $n$ 个个体， $X_0 = 1$ 。这些模型是更大一类 **条件均值模型（conditional mean models）** （McCullagh and Nelder, 1989; McCulloch, Searle, and Neuhaus, 2008）的子集，这类模型有两个组成部分：一个线性函数形式或 **预测变量（predictor）** $\sum_{i=0}^{p} \theta_i X_i$ ，以及一个 **链接函数（link function）** $g\{\cdot\}$ ，使得：

$$
g\{\operatorname{E}[Y \mid X]\} = \sum_{i=1}^{p} \theta_i X_i.
$$

正文中描述的线性条件均值模型使用 **恒等链接函数（identity link function）** 。

对于严格为正的结局（例如计数、发病率的分子）的条件均值模型，通常使用 **对数链接函数（log link function）** ，以确保所有预测值都大于零，即：

$$
\log\{\operatorname{E}[Y \mid X]\} = \sum_{i=0}^{p} \theta_i X_i
$$

因此：

$$
\operatorname{E}[Y \mid X] = \exp\left( \sum_{i=0}^{p} \theta_i X_i \right).
$$

对于二分类结局（即仅取值 0 和 1 的结局）的条件均值模型，通常使用 **逻辑斯蒂链接函数（logit link）** ，即：

$$
\log\left\{\frac{\operatorname{E}[Y \mid \mathbf{X}]}{1 - \operatorname{E}[Y \mid \mathbf{X}]} \right\} = \sum_{i=0}^{p} \theta_i X_i,
$$

因此：

$$
\operatorname{E}[Y \mid X] = \operatorname{expit}\left( \sum_{i=0}^{p} \theta_i X_i \right).
$$

这种链接确保所有预测值都大于 0 且小于 1。使用逻辑斯蒂函数的条件均值模型，称为 **逻辑斯蒂回归模型（logistic regression models）** ，在本书中被广泛使用。

对于这些链接（称为 **规范链接（canonical links）** ），我们可以通过最大似然估计来估计 $\theta$ ，其中恒等链接使用正态工作模型，对数链接使用泊松工作模型，逻辑斯蒂链接使用逻辑斯蒂回归模型。只要 $\operatorname{E}[Y \mid X]$ 的条件均值模型是正确的，这些估计量就是 $\theta$ 的一致估计量。 **广义估计方程（Generalized estimating equation, GEE）** 模型，常用于处理重复测量，是条件均值模型的另一个例子（Liang and Zeger, 1986）。

条件均值模型仅指定了 $\operatorname{E}[Y \mid X]$ 的参数形式，但不对 $Y \mid X$ 的分布或 $X$ 的边缘分布施加其他限制。因此，当 $X$ 或 $Y$ 为连续变量时，参数条件均值模型是数据 $(X, Y)$ 联合分布的 **半参数模型（semiparametric model）** ，因为部分分布是参数化建模的，而其他部分则保持无限制。该模型是半参数的，因为联合分布的所有无限制成分的集合不能用有限数量的参数表示。

条件均值模型本身可以通过放宽 $\operatorname{E}[Y \mid X]$ 采取参数形式的假设来进行推广。例如， **核回归模型（kernel regression model）** 不对 $\operatorname{E}[Y \mid X]$ 施加特定的函数形式，而是通过以下方式估计任意 $x$ 处的 $\operatorname{E}[Y \mid X = x]$ ：

$$
\frac{\sum_{i=1}^{n} w_h\left( x - X_i \right) Y_i}{\sum_{i=1}^{n} w_h\left( x - X_i \right)}
$$

其中 $w_h(z)$ 是一个正函数，称为 **核函数（kernel function）** ，它在 $z = 0$ 处达到最大值，并随着 $\vert z \vert$ 增大而减小到 0，其减小的速率取决于 $w$ 的下标参数 $h$ 。

作为另一个例子， **广义加性模型（generalized additive models, GAMs）** 将条件均值模型的线性组合 $\sum_{i=0}^{p} \theta_i X_i$ 替换为平滑函数的和 $\sum_{i=0}^{p} f_i(X_i)$ 。该模型可以使用 **反向拟合算法（backfitting algorithm）** 进行估计，其中 $f_i(\cdot)$ 在第 $k$ 次迭代时通过，例如，核回归进行估计（Hastie and Tibshirani, 1990）。

在正文中，我们讨论了使用参数模型进行平滑，这些模型为 $\operatorname{E}[Y \mid X = x]$ 指定了先验的函数形式，例如抛物线。在估计 $\operatorname{E}[Y \mid X = x]$ 时，该模型可能会借用远离 $x$ 的 $X$ 值的信息。相比之下，核回归模型不指定先验的函数形式，并且在估计 $\operatorname{E}[Y \mid X = x]$ 时仅借用接近 $x$ 的 $X$ 值的信息。核回归模型是“非参数”回归模型的一个例子。

这里使用的“非参数”一词与我们之前的使用方式不同。我们之前对 $\operatorname{E}[Y \mid X = x]$ 的非参数估计量仅使用了那些 $X$ 恰好等于 $x$ 的个体；即使从近邻也没有借用信息。而这里 $\operatorname{E}[Y \mid X = x]$ 的“非参数”估计量使用 $X$ 值接近 $x$ 的个体。接近程度由一个称为 **带宽（bandwidth）** $h$ 的平滑参数控制。
