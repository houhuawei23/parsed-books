# 第 3 章《干预的效果》全面系统梳理总结

---

## 一、核心问题与章节定位

本章围绕一个根本问题展开： **如何仅从观察性数据（非实验数据）中推断因果效应？** 这是因果推断区别于传统统计学的关键所在。传统统计学强调"相关性不等于因果性"，而本章以图形模型为工具，系统性地展示了从观测数据中识别和估计因果效应的方法体系。

---

## 二、干预的基本概念（3.1 节）

### 2.1 干预与条件化的本质区别

| 维度         | $P(Y \mid X=x)$ 条件化 | $P(Y \mid do(X=x))$ 干预          |
| ------------ | ---------------------- | --------------------------------- |
| **操作**     | 被动观察，筛选子集     | 主动固定变量值，改变系统          |
| **图形操作** | 无                     | 删除所有指向 $X$ 的箭头（图手术） |
| **改变的**   | 我们对世界的认知       | 世界本身                          |
| **数据来源** | 直接从观测数据获得     | 依赖因果图结构推导                |

### 2.2 do-算子（do-operator）

- 记法： $P(Y=y \mid do(X=x))$ 表示"通过干预使 $X=x$ 后， $Y=y$ 的概率"
- 图手术：移除所有指向被干预变量的边，对应截断乘积公式中对相应因子的删除
- 关键假设：干预没有"副作用"（即不会以直接方式改变后续变量的响应机制）

### 2.3 冰淇淋例子

图 3.1-3.2 展示：温度 $Z$ 同时影响冰淇淋销量 $X$ 和犯罪率 $Y$ 。干预冰淇淋销量（关闭冰淇淋店）后， $X$ 和 $Y$ 变得独立——说明 **干预导致与条件化完全不同的依赖模式** 。

## 三、调整公式（3.2 节）

### 3.1 推导过程（以药物-性别-康复为例）

在图 3.3 的模型中（ $Z$ → 性别, $X$ → 用药, $Y$ → 康复），干预 $do(X=x)$ 后，干预后分布 $P_m$ 与干预前分布 $P$ 共享两个不变性：

1.  **边际分布不变** ： $P_m(Z=z) = P(Z=z)$ （性别比例不变）
2.  **条件分布不变** ： $P_m(Y=y \mid Z=z, X=x) = P(Y=y \mid Z=z, X=x)$ （响应机制不变）

由此推导出 **调整公式** ：

$$
P(Y=y \mid do(X=x)) = \sum_z P(Y=y \mid X=x, Z=z) \, P(Z=z) \tag{3.5}
$$

### 3.2 核心规则：规则 1（因果效应规则）

$$
P(Y=y \mid do(X=x)) = \sum_z P(Y=y \mid X=x, PA=z) \, P(PA=z) \tag{3.6}
$$

其中 $PA$ 是 $X$ 的父节点集合。等价地，可写成倾向得分形式：

$$
P(y \mid do(x)) = \sum_z \frac{P(X=x, Y=y, PA=z)}{P(X=x \mid PA=z)} \tag{3.7}
$$

### 3.3 调整还是不调整？

- **辛普森悖论（性别例）** ：需要对性别 $Z$ 进行调整，得出药物有正面效果（ACE=0.0502）
- **血压例** （图 3.5， $X \to Z$ ）：血压是药物的结果而非原因，不需要调整；药物如同随机化
- 通用准则： **应以 $X$ 的父节点 $PA(X)$ 为条件** ，调整公式指示根据因果图确定调整集

### 3.4 多重干预与截断乘积法则（3.2.2 节）

- **截断乘积公式（g-公式）** ：干预多个变量时，从联合分布的乘积分解中删除所有被干预变量对应的因子
- 关键关系： $P(z, y \mid do(x)) = \frac{P(x, y, z)}{P(x \mid z)}$

## 四、后门准则（3.3 节）

### 4.1 核心定义

**定义 3.3.1（后门准则）** ：变量集 $Z$ 满足相对于 $(X,Y)$ 的后门准则，当且仅当：

1.  $Z$ 中没有任何节点是 $X$ 的后代
2.  $Z$ 阻断了 $X$ 和 $Y$ 之间所有包含指向 $X$ 的箭头的路径

若满足，则：

$$
P(Y=y \mid do(X=x)) = \sum_z P(Y=y \mid X=x, Z=z) \, P(Z=z)
$$

### 4.2 设计逻辑（三个要求）

| 要求           | 目的         | 实现方式                    |
| -------------- | ------------ | --------------------------- |
| 阻断伪路径     | 消除混杂     | 阻断所有指向 $X$ 的后门路径 |
| 不干扰有向路径 | 保留因果信息 | 不以 $X$ 的后代为条件       |
| 不创造新伪路径 | 避免对撞偏差 | 避免以对撞节点为条件        |

### 4.3 关键实例

- **图 3.6** （药物-体重-社会经济地位）：即使 $Z$ （社会经济地位）未观测， $W$ （体重）满足后门准则，对 $W$ 调整即可
- **图 2.8** ：无后门路径，空集满足准则， $P(y \mid do(x)) = P(y \mid x)$ ；但对撞节点 $W$ 的调整反而引入偏差

### 4.4 效应修饰与 $w$ -特定效应

计算特定 $W=w$ 下的因果效应 $P(Y=y \mid do(X=x), W=w)$ 需要额外阻断因以对撞节点为条件而打开的路径（公式 3.11）。

### 4.5 学习问题亮点

- **洛德悖论（Lord's Paradox）** ：两位统计学家对同一饮食数据得出相反结论——一位看体重变化（差值为零），另一位按初始体重分层比较（计划 B 更优）。因果图分析揭示了谁是正确的以及为何。

## 五、前门准则（3.4 节）

### 5.1 动机：当后门准则不适用时

吸烟与肺癌（图 3.10a）：未观测基因型 $U$ 同时影响吸烟欲望和肺癌风险，后门路径无法被阻断，因果效应看似不可识别。

### 5.2 前门准则定义与条件

**定义 3.4.1** ：变量集 $Z$ 满足相对于 $(X,Y)$ 的前门准则，如果：

1.  $Z$ 截断所有从 $X$ 到 $Y$ 的有向路径（ $Z$ 是中介变量）
2.  从 $X$ 到 $Z$ 没有后门路径
3.  所有从 $Z$ 到 $Y$ 的后门路径都被 $X$ 阻断

### 5.3 前门公式

$$
P(Y=y \mid do(X=x)) = \sum_z \sum_{x'} P(Y=y \mid Z=z, X=x') \, P(X=x') \, P(Z=z \mid X=x) \tag{3.15}
$$

**推导思路** ：分两步应用后门准则——

1.  $X$ 对 $Z$ 无后门路径 → $P(z \mid do(x)) = P(z \mid x)$
2.  以 $X$ 阻断 $Z \leftarrow X \leftarrow U \rightarrow Y$ → $P(y \mid do(z)) = \sum_x P(y \mid z, x) P(x)$
3.  链式组合： $P(y \mid do(x)) = \sum_z P(y \mid do(z)) P(z \mid do(x))$

### 5.4 重要性

前门准则表明即使后门准则失败，因果效应仍可能识别。与后门准则、调整公式组合覆盖了广泛场景。更一般的情形由 **do-演算（do-calculus）** 处理。

## 六、条件性干预与协变量特定效应（3.5 节）

### 6.1 条件性干预

干预可以是依赖策略的： $do(X = g(Z))$ ，即 $X$ 的值依赖于协变量 $Z$ 。例如，仅对体温超过某阈值的患者给药。

### 6.2 $z$ -特定效应的识别（规则 2）

若存在变量集 $S$ 使 $S \cup Z$ 满足后门准则，则：

$$
P(Y=y \mid do(X=x), Z=z) = \sum_s P(Y=y \mid X=x, S=s, Z=z) \, P(S=s \mid Z=z)
$$

### 6.3 条件性策略评估

$$
P(Y=y \mid do(X=g(Z))) = \sum_z \left. P(Y=y \mid do(X=x), Z=z) \right|_{x=g(z)} P(Z=z)
$$

## 七、逆概率加权（3.6 节）

### 7.1 动机

调整公式需要对 $Z$ 的每个组合进行分层求和，当 $Z$ 维度高时面临计算灾难。逆概率加权提供了一种替代方案。

### 7.2 核心思想

将每个样本按其倾向得分的倒数重新加权：

$$
P(y \mid do(x)) = \sum_z \frac{P(Y=y, X=x, Z=z)}{P(X=x \mid Z=z)}
$$

即每个案例 $(Y=y, X=x, Z=z)$ 的概率乘以 $1 / P(X=x \mid Z=z)$ 。重新加权后的样本表现得如同从干预后分布 $P_m$ 中抽取。

### 7.3 要求与注意事项

- $Z$ 必须满足后门准则
- 当 $Z$ 值数量远大于样本量时，节省显著
- 即使能无偏估计因果效应，精度问题仍需考虑

---

## 八、中介效应（3.7 节）

### 8.1 问题：传统条件化方法的失败

以"资质"为中介分析"性别 → 招聘"的直接效应时，若存在收入这样的混杂因素（同时影响资质和招聘），对中介变量条件化会打开对撞路径，产生虚假关联。

### 8.2 受控直接效应（CDE）

$$
CDE = P(Y=y \mid do(X=x), do(Z=z)) - P(Y=y \mid do(X=x'), do(Z=z)) \tag{3.18}
$$

**关键创新** ：用干预替代条件化来保持中介变量不变，从而避免对撞偏差。

### 8.3 可识别条件

满足两个条件时 CDE 可识别：

1. 存在 $S_1$ 阻断 $Z \to Y$ 的所有后门路径
2. 存在 $S_2$ （删除进入 $Z$ 的箭头后）阻断 $X \to Y$ 的所有后门路径

### 8.4 非线性系统中的局限

间接效应在非线性系统中不能简单定义为总效应减直接效应，需要反事实框架（第 4 章）。

---

## 九、线性系统中的因果推断（3.8 节）

### 9.1 正态性带来的便利

多元正态分布使因果推断极大简化：

- **高效表示** ：只需均值、方差和相关系数
- **期望替代概率** ：条件独立 → 回归系数为零
- **期望线性性** ： $E[Y \mid X_1,\ldots,X_n] = r_0 + r_1x_1 + \cdots + r_nx_n$
- **系数不变性** ：回归系数不依赖回归变量的取值

### 9.2 结构系数 vs. 回归系数

| 结构系数（ $\alpha, \beta$ ） | 回归系数（ $r_1, r_2$ ）    |
| ----------------------------- | --------------------------- |
| 因果/结构方程的参数           | 统计拟合/描述性参数         |
| 代表直接因果效应              | 代表数据的最佳线性近似      |
| 误差项是潜在因素 $U$          | 误差项是拟合残差 $\epsilon$ |

### 9.3 路径系数的因果解释

- 每个路径系数等于直接效应（无论误差项是否相关）
- **总效应 = 所有非后门路径上系数乘积之和** （乘积和规则）

### 9.4 回归识别规则

- **总效应识别** ：找到满足后门准则的 $Z$ ，将 $Y$ 对 $X$ 和 $Z$ 回归， $X$ 的系数即总效应
- **直接效应识别** （ $G_\alpha$ 程序）：移除 $X \to Y$ 边后，若存在 $Z$ 能 d-分离 $X$ 和 $Y$ ，则 $Y$ 对 $X$ 和 $Z$ 回归中 $X$ 的系数即直接效应

### 9.5 工具变量

当不存在能 d-分离的变量集时（如存在未观测混杂），可通过 **工具变量** 识别：在 $G_\alpha$ 中与 $X$ d-连通且与 $Y$ d-分离的变量。直接效应 = $r_1 / r_2$ （ $Y$ 对工具回归系数除以 $X$ 对工具回归系数）。

### 9.6 线性中介分析

线性系统中间接效应 $IE = \tau - DE$ （总效应减直接效应），比非线性系统简单得多。

## 十、关键概念汇总

| 概念                    | 功能                     | 公式/准则                   |
| ----------------------- | ------------------------ | --------------------------- |
| **do-算子**             | 形式化干预操作           | $P(y \mid do(x))$           |
| **调整公式**            | 用观测数据计算干预效应   | $\sum_z P(y \mid x,z)P(z)$  |
| **后门准则**            | 判断/选择调整变量        | 阻断所有指向 $X$ 的后门路径 |
| **前门准则**            | 后门准则失败时的备选方案 | 通过中介变量分步识别        |
| **截断乘积公式**        | 多重干预的通用框架       | 删除被干预变量的因子        |
| **逆概率加权**          | 克服高维调整的计算困难   | 权重 = $1/P(X=x \mid Z=z)$  |
| **受控直接效应（CDE）** | 中介分析中的直接效应     | $do(X=x), do(Z=z)$          |
| **路径系数/总效应**     | 线性系统的因果量化       | 非后门路径系数乘积之和      |
| ** $G_\alpha$ 程序**    | 线性系统中识别直接效应   | 删边后找 d-分离集           |

## 十一、章节架构与逻辑演进

```
干预概念（do-算子，图手术）
    ↓
调整公式（以父节点为条件）
    ↓
后门准则（推广到任意满足条件的调整集）
    ↓
前门准则（后门准则失败时的替代方案）
    ↓
条件性干预与z-特定效应（更复杂的策略评估）
    ↓
逆概率加权（计算层面的优化）
    ↓
中介效应（直接/间接效应的分解）
    ↓
线性系统专论（回归、路径系数、工具变量）
```

本章的核心信息是： **有了正确的因果图，我们可以在不进行随机实验的情况下，仅从观察数据中计算因果效应** 。因果图不仅用于表示，更是发现和证明因果关系的强大工具。
