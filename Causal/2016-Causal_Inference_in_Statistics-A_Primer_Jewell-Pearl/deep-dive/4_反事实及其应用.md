


# 第四章：反事实及其应用——全面梳理与总结

---

## 一、章节概览

第四章是本书承上启下的核心章节。在第三章通过 **do-算子** 建立了干预的数学框架之后，本章进一步引入 **反事实（counterfactuals）** 这一更精细的分析工具，将因果推断从总体层面（群体平均效应）推进到个体层面（特定单元在假设条件下的行为）。本章共分五节，涵盖了反事实的定义、计算、图形表示、实验识别，以及五项重要实际应用。

---

## 二、4.1 反事实：核心概念

### 2.1 什么是反事实

**定义：** 反事实是一种"如果"陈述，其"如果"部分（前件，antecedent）在现实中并未发生或不真实。例如："如果我走了高速公路，我就能更早到家。"

**关键直觉：** 在完全相同的条件下（同一时间、同一驾驶员、同一外部环境），仅改变一个方面（选择高速公路而非地面街道），比较两个可能的结果。

### 2.2 为什么 do-算子不够用

设实际驾驶时间为 $Y = 1$ 小时（走的塞普尔维达大道 $X = 0$），我们想知道如果走高速公路（$X = 1$）需要多长时间。

do-表达式 $E[\text{driving time} \mid do(\text{freeway}), \text{driving time} = 1]$ 会导致冲突——我们试图在同一表达式中同时使用实际观察值（1小时）和假设值。

**根本困难：** do-算子无法区分两个不同世界中的变量：
- 实际世界中的驾驶时间（观察到的 $Y_0$）
- 假设世界中的驾驶时间（反事实的 $Y_1$）

### 2.3 反事实记法

引入下标标记法：

$$E(Y_{X=1} \mid X = 0, Y = Y_0 = 1) \tag{4.1}$$

- $Y_{X=1}$（或 $Y_1$）：如果走了高速公路的驾驶时间（假设变量）
- $X = 0$：实际选择了地面街道（观察到的前件）
- $Y = Y_0 = 1$：实际观察到的驾驶时间

**核心特征：** 反事实表达式中混合了来自不同"世界"的变量——假设变量 $Y_{X=1}$ 以 $X = 1$ 为前提，却以冲突事件 $X = 0$ 和 $Y = 1$ 为条件。这种跨世界事件无法用 do-算子捕获，也无法通过随机对照实验直接估计。

## 三、4.2 反事实的定义与计算

### 3.1 反事实的结构解释（4.2.1 节）

**基本思想：** 结构因果模型（SCM）中的每个外生变量赋值 $U = u$ 唯一确定总体中的一个"单元"（个体或情境）。反事实 $Y_x(u)$ 被定义为：在情境 $U = u$ 中，如果 $X$ 被设为 $x$，则 $Y$ 会取的值。

以线性模型为例：
$$X = aU, \quad Y = bX + U \tag{4.3-4.4}$$

计算 $Y_x(u)$：将第一个方程替换为 $X = x$，代入 $U = u$，得到 $Y_x(u) = bx + u$。

**表 4.1** 展示了 $U$ 取不同值时 $X(u)$、$Y(u)$、$Y_1(u)$、$Y_2(u)$ 等的所有取值。

> **重要区别：** $Y_x(u)$ 给出的是特定个体 $U = u$ 在假设条件下的**确定值**，而 $do(x)$ 算子仅给出总体层面的概率 $E[Y \mid do(x)]$。这是个体层面分析与总体层面分析之间的深刻差异。

### 3.2 反事实的基本定律（4.2.2 节）

**定义 4.2.2（反事实的基本定律）：**

$$Y_x(u) = Y_{M_x}(u) \tag{4.5}$$

其中 $M_x$ 是模型 $M$ 的修改版本，将 $X$ 的结构方程替换为常数方程 $X = x$。

**一致性规则：**

$$\text{if } X = x \text{ then } Y_x = Y \tag{4.6}$$

对于二元变量 $X$，等价的方便形式为：
$$Y = X Y_1 + (1 - X) Y_0$$

**含义：** 如果将 $X$ 设定为其实际已有的值，世界不会发生任何变化，$Y$ 保持其当前值。

### 3.3 从总体数据到个体行为（4.2.3 节）

通过"鼓励设计"案例说明：

**模型 4.1（鼓励设计）：**
$$X = U_X, \quad H = a \cdot X + U_H, \quad Y = b \cdot X + c \cdot H + U_Y$$
参数：$a = 0.5, b = 0.7, c = 0.4$

Joe 的观测：$X = 0.5, H = 1, Y = 1.5$。

**问题：** 如果 Joe 的作业量翻倍（$H = 2$），他的分数会是多少？

**解法：**
1. 从证据推断 $U$：$U_X = 0.5, U_H = 0.75, U_Y = 0.75$
2. 修改模型：将 $H$ 的方程替换为 $H = 2$
3. 计算：$Y_{H=2} = 0.5 \times 0.7 + 2.0 \times 0.4 + 0.75 = 1.90$

### 3.4 计算反事实的三步过程（4.2.4 节）

**确定性反事实的三步法：**

| 步骤 | 名称 | 操作 | 时态隐喻 |
|------|------|------|----------|
| (i) | **溯因（Abduction）** | 利用证据 $E = e$ 更新 $U$ 的值/分布 | 解释过去 |
| (ii) | **行动（Action）** | 修改模型，用 $X = x$ 替换 $X$ 的结构方程 | 改变历史 |
| (iii) | **预测（Prediction）** | 在修改后的模型 $M_x$ 中使用更新后的 $U$ 计算 $Y$ | 预测未来 |

**概率性反事实的推广：**

$$E[Y_{X=x} \mid E = e]$$

三步过程推广为：
- (i) 溯因：$P(U) \to P(U \mid E = e)$
- (ii) 行动：得到修改模型 $M_x$
- (iii) 预测：使用 $M_x$ 和 $P(U \mid E = e)$ 计算 $Y$ 的期望

## 四、4.3 非确定性反事实

### 4.1 反事实的概率（4.3.1 节）

在 $U$ 上赋予概率分布 $P(U = u)$ 后，可以计算：

- **单世界概率：** $P(Y_2 = 3) = 1/2$
- **跨世界联合概率：** $P(Y_2 > 3, Y_1 < 4) = 1/3$
- **反事实条件概率：** $P(Y_3 > Y \mid Y > 2) = 2/3$

> **关键突破：** 即使涉及不同"世界"中发生的事件，联合概率的计算毫无障碍——只需找到两个条件同时为真的 $U$ 行，将概率相加即可。

**方程 (4.7) 的关键例子：**
$$X = U_1, \quad Z = aX + U_2, \quad Y = bZ$$

结构：$X$（教育）$\to Z$（技能）$\to Y$（薪水）

**不等式 (4.8)：**
$$E[Y \mid do(X = 1), Z = 1] \neq E[Y_{X=1} \mid Z = 1]$$

- do-表达式：**仅**涉及干预后世界的事件（都是 $X = 1$ 后）
- 反事实表达式：$X = 1$ 和 $Z = 1$ 分别指涉干预前和干预后两个不同世界

从表 4.2 可得：$E[Y_1 - Y_0 \mid Z = 1] = ab \neq 0$，尽管 $E[Y \mid X, Z] = E[Y \mid Z]$。这意味着：虽然当前技能水平为 $Z = 1$ 的人的薪水仅取决于技能，但如果他们有不同的过去（教育不同），薪水会不同。这种回顾性推理是 do-算子所无法表达的。

**翻译规则：** 干预后条件用反事实记法为 $E[Y_{X=1} \mid Z_{X=1} = 1]$——明确将 $Z = 1$ 标注为干预后事件。

### 4.2 反事实的图形表示（4.3.2 节）

**核心思想：** 根据基本定律 (4.5)，$Y_x$ 就是修改后模型 $M_x$ 中的 $Y$。在 $M_x$ 的图中，移除所有指向 $X$ 的箭头后，$Y$ 节点充当 $Y_x$ 的代理。

**定理 4.3.1（后门准则的反事实解释）：**
若 $Z$ 满足相对于 $(X, Y)$ 的后门准则，则：
$$P(Y_x \mid X, Z) = P(Y_x \mid Z) \tag{4.15}$$

**推论——调整公式的推导：**
$$P(Y_x = y) = \sum_z P(Y = y \mid Z = z, X = x) P(z) \tag{4.16}$$

这同时为"条件可忽略性"假设提供了图形化科学解释。

**图形分析的优势：** 在图 4.3 中，$Z$ 是 $X$ 和 $U_2$ 之间的对撞子，在给定 $Z$ 的条件下 $X$ 和 $Y_x$ 不被 d-分离。仅通过图的简单操作就能确定 $E[Y_x \mid X, Z] \neq E[Y_x \mid Z]$，无需任何参数假设。

### 4.3 实验环境中的反事实（4.3.3 节）

**表 4.3** 展示了 SCM 编码的"合成总体"——每个个体在观测条件和实验条件下都有完整的潜在结果（$Y_0, Y_1, H_0, H_1$ 等）。

**现实约束：** 在实验环境中，每个个体只能被分配到一个处理水平，因此只能观测到 $Y_0$ 或 $Y_1$ 中的一个（表 4.4 中的黑方块）。

**随机化的作用：** 随机分配确保未被观测的潜在结果（黑方块）随机分布，与 $Y_0$、$Y_1$ 的实际值无关，因此样本均值差异依概率收敛于 $E[Y_1 - Y_0]$。

### 4.4 线性模型中的反事实（4.3.4 节）

**定理 4.3.2（线性模型反事实计算捷径）：**
令 $\tau$ 为 $X$ 对 $Y$ 的总效应斜率：
$$\tau = E[Y \mid do(x+1)] - E[Y \mid do(x)]$$

则对任意证据 $Z = e$：
$$E[Y_{X=x} \mid Z = e] = E[Y \mid Z = e] + \tau(x - E[X \mid Z = e]) \tag{4.17}$$

**直观解释：** 先基于证据 $e$ 给出 $Y$ 的最佳估计，再加上将 $X$ 从当前最佳估计移到假设值 $x$ 时 $Y$ 的预期变化量。

**ETT 在线性模型中的简化：** $ETT = E[Y_1 - Y_0 \mid X = 1] = \tau$，与证据无关。这意味着在线性系统中，处理对受处理者的效应等于对全总体的效应。添加交互项（如 $\delta X H$）后，$\tau \neq ETT$。

## 五、4.4 反事实的实际应用

### 5.1 项目招募——处理对受处理者的效应（4.4.1 节）

**问题：** 职业培训项目在随机实验中有效，但批评者质疑自愿参与者（可能更聪明、更有资源）的获益是否确实来自项目。

**目标量——ETT（Effect of Treatment on the Treated）：**
$$ETT = E[Y_1 - Y_0 \mid X = 1] \tag{4.20}$$

**识别条件与公式：** 当存在满足后门准则的协变量集 $Z$ 时：
$$P(Y_x = y \mid X = x') = \sum_z P(Y = y \mid X = x, Z = z) P(Z = z \mid X = x') \tag{4.21}$$

由此：$ETT = E[Y \mid X = 1] - \sum_z E[Y \mid X = 0, Z = z] P(Z = z \mid X = 1)$

与标准调整公式的区别：用条件概率 $P(Z = z \mid X = x')$ 而非边际概率 $P(Z = z)$ 加权。

### 5.2 加性干预（4.4.2 节）

**问题：** 向每个患者添加固定剂量 $q$（而非统一设定为固定值 $x$）。这种干预不能用 do-表达式描述，因为最终 $X$ 值因个体基础水平不同而异。

**解决方案：** 加性干预的效果可表示为 ETT 形式 $E[Y_{x'+q} \mid X = x']$。

**关键不等式：**
$$E[Y \mid \text{add}(q)] = \sum_x E[Y_{x+q} \mid x] P(X = x) \neq \sum_x E[Y_{x+q}] P(X = x)$$

等式仅在 $Y_x$ 与 $X$ 独立（无混杂）时成立。这揭示了"科学知识"（do-表达式）与"政策问题"之间的不匹配，需要通过单位级反事实分析来桥接。

### 5.3 个人决策与因果概率（4.4.3 节）

**背景：** 肿瘤切除术 vs. 肿瘤切除术+放疗的医疗决策。

**三个关键因果概率：**

| 符号 | 名称 | 定义 | 含义 |
|------|------|------|------|
| **PN** | 必要性概率 | $P(Y_0 = 0 \mid X = 1, Y = 1)$ | 给定治疗且成功，若不治疗本不会成功的概率 |
| **PS** | 充分性概率 | $P(Y_1 = 1 \mid X = 0, Y = 0)$ | 给定未治疗且失败，若治疗本会成功的概率 |
| **PNS** | 必要且充分概率 | $P(Y_1 = 1, Y_0 = 0)$ | 治疗对个体既是必要的又是充分的概率 |

**戴利女士的决策逻辑：** 只有当她属于 $Y_1 = 1$ 且 $Y_0 = 0$ 的类型时，接受治疗才真正有价值。

在单调性假设下：$PNS = P(Y = 1 \mid do(X = 1)) - P(Y = 1 \mid do(X = 0))$

代入 Fisher 等人 (2002) 的数据：$PNS = 0.86 - 0.61 = 0.25$，意味着戴利女士有 25% 的概率属于对治疗有反应的类型。

**认知意义：** 反事实推理不仅具有情感价值（遗憾、成功感），还在认知发展和适应性学习中扮演关键角色——通过反事实强化来改进决策过程。

### 5.4 招聘中的歧视（4.4.4 节）

**法律标准：** "如果雇员属于不同的种族/性别/宗教等而其他所有情况都相同，雇主是否会采取相同的行动。"——以反事实术语定义个体层面的歧视。

**数学形式：** 玛丽遭受歧视的概率 = $PS = P(Y_1 = 1 \mid X = 0, Y = 0)$，即给定面试官认为她是同性恋且未被录用，若面试官认为她是异性恋，她本会被录用的概率。

**区别：** 干预的是面试官的**认知**而非性取向本身——这在反事实框架中更容易处理。

### 5.5 中介分析与路径阻断干预（4.4.5 节）

**政策问题：** 减少招聘中的性别差异，应通过性别中立招聘（阻断直接效应）还是消除教育不平等（阻断间接效应）？

下面给出四种效应的反事实定义（与 4.5.2 节合并）。

**自然间接效应（NIE）：**
$$NIE = \sum_q E[Y_{X=1, Q=q}] [P(Q = q \mid X = 0) - P(Q = q \mid X = 1)]$$

在无混杂条件下，可通过**中介公式**估计：
$$NIE = \sum_q E[Y \mid X = 1, Q = q] [P(Q = q \mid X = 0) - P(Q = q \mid X = 1)] \tag{4.52}$$

**核心区别：** NIE 允许中介变量在各单元间"自然地"变化（不同于受控直接效应 CDE 将中介统一固定），通过"冻结"直接效应同时让中介变量自然响应来实现。

## 六、4.5 归因与中介的数学工具包

### 6.1 归因工具包（4.5.1 节）

**核心量——必要性概率 PN：**
$$PN(x, y) = P(Y_{x'} = y' \mid X = x, Y = y) \tag{4.27}$$

**定理 4.5.1（单调性下的 PN 识别）：**
若 $Y_1(u) \geq Y_0(u)$ 对所有 $u$ 成立（单调性），则：
$$PN = \frac{P(y) - P(y \mid do(x'))}{P(x, y)} \tag{4.28}$$

等价分解：
$$PN = \underbrace{\frac{P(y \mid x) - P(y \mid x')}{P(y \mid x)}}_{ERR} + \underbrace{\frac{P(y \mid x') - P(y \mid do(x'))}{P(x, y)}}_{CF} \tag{4.29}$$

- **ERR（超额风险比）：** 观察数据中的关联
- **CF（混杂因子）：** 校正混杂偏倚所需的修正项

**一般情况下的界限（定理 4.5.1 的推广）：**
$$\max\left\{0, \frac{P(y) - P(y \mid do(x'))}{P(x, y)}\right\} \leq PN \leq \min\left\{1, \frac{P(y' \mid do(x')) - P(x', y')}{P(x, y)}\right\} \tag{4.30}$$

**法律应用实例（表 4.5）：**
即使观察数据中 ERR 为负（$-13$），混杂校正项（$+14$）可将 PN 修正为 $1.00$，提供 100% 确定性证明药物对死亡负有责任。

**PNS 在单调性下：**
$$PNS = P(Y_x = 1) - P(Y_{x'} = 1) = P(y \mid do(x)) - P(y \mid do(x')) \tag{4.42}$$

### 6.2 中介分析工具包（4.5.2 节）

**通用模型：**
$$t = f_T(u_T), \quad m = f_M(t, u_M), \quad y = f_Y(t, m, u_Y) \tag{4.43}$$

**四种效应的反事实定义：**

| 效应 | 符号 | 反事实定义 | do-表达式 | 含义 |
|------|------|-----------|-----------|------|
| **总效应** | TE | $E[Y_1 - Y_0]$ | $E[Y \mid do(1)] - E[Y \mid do(0)]$ | 处理变化的总效果 |
| **受控直接效应** | CDE(m) | $E[Y_{1,m} - Y_{0,m}]$ | $E[Y \mid do(1,m)] - E[Y \mid do(0,m)]$ | 固定中介于 $m$ 时的直接效应 |
| **自然直接效应** | NDE | $E[Y_{1,M_0} - Y_{0,M_0}]$ | 非 do-表达式 | $M$ 保持在 $T=0$ 水平时的直接效应 |
| **自然间接效应** | NIE | $E[Y_{0,M_1} - Y_{0,M_0}]$ | 非 do-表达式 | 仅通过 $M$ 传递的间接效应 |

**效应分解关系：**
$$TE = NDE - NIE_r$$

在线性系统中反向 NIE 等于负 NIE，故 $TE = NDE + NIE$。

**识别条件（A-1 至 A-4）：**

| 条件 | 内容 |
|------|------|
| A-1 | $W$ 中无 $T$ 的后代 |
| A-2 | $W$ 阻断 $M \to Y$ 的所有后门路径（移除 $T \to M$ 和 $T \to Y$ 后） |
| A-3 | $T$ 对 $M$ 的 $W$ 特定效应可识别 |
| A-4 | $\{T, M\}$ 对 $Y$ 的 $W$ 特定联合效应可识别 |

**定理 4.5.2（NDE 识别公式）：**
$$NDE = \sum_m \sum_w [E[Y \mid do(1,m), w] - E[Y \mid do(0,m), w]] \times P(M = m \mid do(0), w) P(w) \tag{4.49}$$

**无混杂简化（中介公式）：**
$$NDE = \sum_m [E[Y \mid T = 1, M = m] - E[Y \mid T = 0, M = m]] P(M = m \mid T = 0) \tag{4.51}$$

$$NIE = \sum_m E[Y \mid T = 0, M = m] [P(M = m \mid T = 1) - P(M = m \mid T = 0)] \tag{4.52}$$

**解释性比值：**
- $NDE / TE$：$M$ 被"冻结"时直接传递的响应比例
- $NIE / TE$：仅通过 $M$ 可传递的响应比例
- $(TE - NDE) / TE$：必然由 $M$ 引起的响应比例

**数值示例（表 4.6 和 4.7）：**
- $TE = 0.46$（项目提高成功率 46%）
- $NDE = 0.32$，$NIE = 0.035$
- $NIE/TE = 0.07$，仅 7% 的增长可仅由受刺激的家庭作业解释
- $1 - NDE/TE = 0.304$，30.4% 的增长归因于项目通过刺激家庭作业增加的间接效应

| **反事实 $Y_x(u)$** | $Y_x(u) = Y_{M_x}(u)$ | 单元 $u$ 在 $X = x$ 条件下的结果 |
| **一致性规则** | $X = x \Rightarrow Y_x = Y$ | 反事实与观测值的基本联系 |
| **三步法** | 溯因→行动→预测 | 计算反事实的统一程序 |
| **后门准则（反事实版）** | $P(Y_x \mid X, Z) = P(Y_x \mid Z)$ | 条件可忽略性的图形基础 |
| **ETT** | $E[Y_1 - Y_0 \mid X = 1]$ | 处理对受处理者的效应 |
| **PN** | $P(Y_0 = 0 \mid X = 1, Y = 1)$ | 必要性概率（"若非"标准） |
| **PS** | $P(Y_1 = 1 \mid X = 0, Y = 0)$ | 充分性概率 |
| **PNS** | $P(Y_1 = 1, Y_0 = 0)$ | 必要且充分概率 |
| **NDE** | $E[Y_{1,M_0} - Y_{0,M_0}]$ | 自然直接效应 |
| **NIE** | $E[Y_{0,M_1} - Y_{0,M_0}]$ | 自然间接效应 |
| **线性反事实** | $E[Y_x \mid e] = E[Y \mid e] + \tau(x - E[X \mid e])$ | 定理 4.3.2 |

---

## 八、章节总体评价

第四章完成了从**干预因果**（do-算子）到**反事实因果**（$Y_x$ 记法）的关键飞跃：

1. **概念上**：反事实将因果分析从总体层面推进到个体层面，使功劳（attribution）、责备（blame）、遗憾（regret）等概念可以被概率化地定义和量化。

2. **技术上**：三步骤（溯因-行动-预测）和基本定律 $Y_x(u) = Y_{M_x}(u)$ 提供了统一的计算框架。定理 4.3.1 将图形条件（后门准则）与反事实独立性联系起来，定理 4.3.2 为线性模型提供了捷径。

3. **应用上**：ETT、PN、PS、PNS、NDE、NIE 构成了因果推断在政策评估、法律责任、个人决策、歧视检测、中介分析等领域的核心工具箱。

4. **方法论贡献**：反事实-图形共生（counterfactual-graphical symbiosis）使复杂的识别条件（如 A-1 至 A-4）可以从直观的因果图中机械推导，而无需依赖难以独立验证的可忽略性假设。这是现代因果推断对统计学的关键贡献。
