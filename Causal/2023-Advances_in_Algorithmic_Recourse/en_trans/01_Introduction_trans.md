# 引言（Introduction）

## 1.1 引言（Introduction）

考虑以下场景：一位28岁的女性软件工程师申请抵押贷款购买房屋。进一步假设贷款机构（例如银行）使用一个**二元分类器（binary classifier）**，并根据她的属性拒绝了贷款申请。自然，在这种情况下，回答以下问题对个人来说变得至关重要：

Q1. 为什么我的贷款被拒绝了？  
Q2. 我未来该怎么做才能获得贷款？

在上述示例的场景中，除非银行的政策放宽，否则个人必须付出努力来改变自身状况，以便获得决策系统的有利对待。诸如此类的例子不仅在金融领域普遍存在（Muk+02; BHN17），在司法（例如审前保释）（Ang+16）、医疗保健（例如开具改变生活的药物处方）（BKB17; GB20; BBK19）以及其他广泛归类为**结果性决策（consequential decision-making）**的场景（例如招聘）（Maz+21; NS18; CLM19; Sch+20）中也屡见不鲜（BHN17; Kar+20a; Bur16; CDG18）。鉴于自动化决策系统在这些场景中的快速普及，设计不仅具有高客观准确性，还能为个人提供解释和建议以有利地改变其状况的模型至关重要，甚至被认为是法律上的必要性（GDPR（VB））。这正是**算法补救（algorithmic recourse）**所关注的问题。

## 1.2 背景（Background）

### 1.2.1 补救的定义（Recourse definitions）

在这个相对年轻的领域中，算法补救被定义为，例如，“一个人为了改善其结果而可以采取的一组可操作的改变”（Jos+19）；“一个人从固定模型中获得期望结果的能力”（USL19）；或“在一系列反事实场景中，通过算法和官僚机构逆转不利决策的系统性过程”（VA20）。类似地，**法律补救（legal recourse）**涉及个人或公司为补救法律困难而采取的行动（Wal92）。与此并行的是，**解释（explanations）**旨在至少部分帮助数据主体“理解未来需要改变什么才能获得期望结果”（WMR17）。这种重叠定义的多样性以及其中不断演变的共识，促使我们尝试在补救的框架下提出一个统一的定义。

直观上，这些定义的共同点是希望帮助受到自动化决策系统负面影响的个人改善其处境（体现在个人的**特征集（feature set）**中），以克服不利决策（来自预测模型）。这种帮助可以采取解释（他们需要达到什么状态）或建议（他们应该采取哪些行动才能达到该状态）的形式。

我们认为，如果受影响的个人能够理解（WMR17; Jos+19; Dow+20）并据此采取行动（KSV21; Kar+20b）来缓解不利局面，从而行使**时间延伸的能动性（temporally-extended agency）**（VA20），那么他们就获得了补救。具体来说，在前一节的示例中，当贷款申请人获得两个问题的答案时，就提供了补救：提供关于贷款为何被拒绝的解释（Q1）；以及提供关于未来如何获得贷款的建议（Q2）。下面，我们描述了这些问题之间的相似之处和经常被忽视的差异，以及在一般情况下充分回答每个问题所需的不同假设和工具集。通过从因果关系的角度审视上下文，可以做出这种区分，我们将在下面总结。

### 1.2.2 补救与因果关系（Recourse and causality）

#### 1.2.2.1 对比性（反事实）解释（Contrastive (Counterfactual) Explanations）

在对社会科学文献的广泛调查中，Miller [Mil19] 得出结论，当人们问“为什么是 P？”（例如 Q1）时，他们通常是在问“为什么是 P 而不是 Q？”，其中 Q 通常隐含在上下文中（Hil90; Rob18）。对这种问题的回答通常被称为**对比性解释（contrastive explanation）**，并且有两个吸引人的原因。首先，对比性问题提供了一个进入提问者心智模型的“窗口”，识别出他们原本期望的是什么（即 Q，对比案例），因此，解释可以更好地针对个人的不确定性和理解差距进行调整（Mil18）。其次，提供对比性解释可能比提供建议“更简单、更可行、认知要求更低”（Mil18）。

#### 1.2.2.2 结果性建议（Consequential Recommendations）

向受影响的个人提供建议（例如，对 Q2 的回答）相当于建议一组应执行以在未来获得有利结果的操作（也称为**翻转集（flipsets）**（USL19））。在这方面，一些工作使用对比性解释来直接推断可操作的建议（Jos+19; USL19; SHG19; WMR17），其中行动被视为对个人（P）特征值的独立改变，从而导致对比结果（Q）。然而，最近的工作对此方法提出了警告，指出**可独立操控特征（independently manipulable features）**的隐含假设是一个潜在的局限性，可能导致次优或不可行的行动（VA20; BSR20; MTS19; KSV21）。为了克服这一点，Karimi 等人 [KSV21] 建议，行动应被解释为对行动将要发生的世界的因果模型中的**干预（interventions）**，而不是从对比性解释中推导出的独立特征操控。以这种方式表述，例如使用**结构因果模型（Structural Causal Model, SCM）**（Pea00），在推荐行动时可以直接考虑干预对模型中其他变量（例如被干预变量的后代）的下游影响（BSR20）。因此，在一个由 SCM 支配的世界中，为补救而推荐的一组行动被称为**结果性建议（consequential recommendations）**（KSV21）。

#### 1.2.2.3 澄清术语：对比性、结果性与反事实（Clarifying terminology: contrastive, consequential, and counterfactual）

总而言之，补救解释通常以对比性的方式寻求，而补救建议可以被视为对使用 SCM 建模的变量的干预。因此，我们可以将两个补救问题改写为：

Q1. 什么样的个人资料会导致获得贷款？  
Q2. 什么样的行动会导致我形成这种个人资料？¹

以这种方式看待，对比性解释和结果性建议都可以归类为**反事实（counterfactual）**（MK93），因为每个都考虑了在事件 P 历史中对一个实体的改变，其中 P 是不期望的模型输出。因此，对 Q1（分别地 Q2）的回答也可以被称为反事实解释（分别地反事实建议），意味着可能是什么（分别地可能做了什么）（Byr19）。²

为了更好地说明对比性解释和结果性建议之间的区别，我们参考图 1.1。根据 Lewis [Lew86, p. 217] 的说法，“解释一个事件就是提供关于其因果历史的一些信息”。Lipton [Lip90, p. 256] 认为，为了解释为什么是 P 而不是 $\mathrm { Q }$，“我们必须引用 P 和 not-Q 之间的因果差异，包括 P 的一个原因和 not-Q 历史中相应事件的缺失”。在算法补救设置中，由于模型输出由其输入（在时间上先于预测）决定，因此输入特征可以被视为预测的原因。决定一个人提供的是对比性解释还是结果性建议的因素，因此是考虑因果历史（Rub15）的层级：虽然提供解释只需要关于模型输入 $\{ { \sf X } _ { i } \} _ { i = 1 } ^ { D }$ 和预测 $\hat{Y}$ 之间关系的信息，但建议需要的信息可以追溯到输入之间的因果关系。因此，依赖较少的假设（Mil19; Lip90）解释了为什么生成补救解释比生成补救建议更容易（WMR17; Mil18）。

## 1.3 形式化表述（Formulation）

给定一个固定的预测模型，通常假设为二元分类器 $h \ : \ : \ : \ : \mathcal { X } \to \{ 0 , 1 \}$，其中 $\begin{array} { r c l } { \mathcal { X } } & { = } & { \mathcal { X } _ { 1 } \times \cdot \cdot \cdot \times \mathcal { X } _ { D } } \end{array}$，我们可以将为（事实）输入 $\mathbf { x } ^ { \mathsf { F } } \in \mathbf { \mathcal { X } }$ 的对比性解释集定义为 $\mathcal { E } : = \{ \mathbf { x } ^ { \mathsf { C F } } \in \mathcal { P } ( \mathcal { X } ) \mid h ( \mathbf { x } ^ { \mathsf { C F } } ) \neq h ( \mathbf { x } ^ { \mathsf { F } } ) \}$。这里，$\mathcal { P } ( \mathcal { X } ) \subseteq \mathcal { X }$ 是根据训练数据分布（见 §1.3.3.1）得出的 $\mathbf{x}$ 的一个**合理子空间（plausible subspace）**。描述性地，对比性识别了（在邻近世界 $\left( \mathrm { L e w } _ { 7 3 } \right) )$ 中）导致固定模型产生有利预测的替代特征组合。假设实例之间的**不相似性（dissimilarity）**概念表示为 $\mathrm { d i s t } ( \cdot , \cdot ) : \mathcal { X } \times \mathcal { X } \to \mathbb { R } _ { + }$，则可以按如下方式识别最近的对比性解释（也称为反事实解释）：

$$
\mathbf {x} ^ {* \mathrm{CF}} \in \underset {\mathbf {x} ^ {\mathrm{CF}} \in \mathcal {P} (\mathcal {X})} {\text { argmin }} \qquad \operatorname{dist} (\mathbf {x} ^ {\mathrm{CF}}, \mathbf {x} ^ {\mathrm{F}})
$$

$$
\text { s.t. } \quad h (\mathbf {x} ^ {\mathrm{CF}}) \neq h (\mathbf {x} ^ {\mathrm{F}}) \tag {1.1}
$$

$$
\mathbf {x} ^ {\mathrm{CF}} = \mathbf {x} ^ {\mathrm{F}} + \delta
$$

其中 $\delta$ 是独立应用于特征向量 $\mathbf { x } ^ { \mathsf { F } }$ 以获得反事实实例 $\mathbf { x } ^ { \mathsf { C F E } }$ 的扰动（WMR17）。正如在 $\ S ^ { \mathrm { 1 } . 2 , }$ 中讨论的那样，尽管对比性解释识别了可以实现补救的特征向量，但一般来说，需要执行以实现这些特征的一组行动并不直接由解释隐含得出（KSV21）。

因此，对于（事实）输入 $\mathbf { x } ^ { \mathsf { F } } \in { \mathcal { X } }$ ，一个有意义的建议（consequential recommendation）被定义为 $\mathcal { R } : = \{ a \in \dot { \mathcal { F } } ( \mathbf { x } ^ { \mathsf { F } } ) \mid h \left( \mathbf { x } ^ { \mathsf { S C F } } ( \mathbf { a } ; \mathbf { x } ^ { \mathsf { F } } ) \right) \neq h ( \mathbf { x } ^ { \mathsf { F } } ) \}$ 。这里， $\bar { \mathcal { F } ( \mathbf { x } ^ { \mathsf { F } } ) }$ 是寻求救济（recourse）的个体可以执行的可行行动集合（参见 §1.3.3.2）。在**结构因果模型（Structural Causal Model, SCM）**框架 (KSV21) 中从因果角度处理救济问题时，行动被视为形式为 $\mathbf { \delta } \mathbf { a } = \mathrm { d o } ( \{ \mathsf { X } _ { i } : = x _ { i } ^ { \mathsf { F } } + \theta _ { i } \} _ { i \in \mathbb { Z } } ) \in \mathcal { F } ( \mathbf { x } ^ { \mathsf { F } } )$ 的干预，而 $\mathbf { x } ^ { \mathsf { S C F } } ( \mathsf { a } ; \mathbf { x } ^ { \mathsf { F } } )$ 表示在行动 a 被执行后， $\overset { \cdot } { \mathbf { x } } ^ { \sf F }$ 的结构反事实（structural counterfactual），其他条件保持不变 (Pea00)。最后，给定一个行动成本的概念，该概念通过成本函数 $\operatorname{cost} ( \cdot ; \cdot ) : \mathcal { F } \times \mathcal { X } \rightarrow \mathbb { R } _ { + }$ 来捕捉个体所付出的努力，人们可以按如下方式识别最小的有意义建议：

$$
\mathbf {a} ^ {*} \in \underset {\mathbf {a} \in \mathcal {F} (\mathbf {x} ^ {\mathsf {F}})} {\text { argmin }} \qquad \qquad \operatorname{cost} (\mathbf {a}; \mathbf {x} ^ {\mathsf {F}})
$$

$\begin{array} { r l r } { { \mathrm { s . t . } } \quad } & { { } h ( \mathbf { x } ^ { \mathsf { C F } } ) \neq h ( \mathbf { x } ^ { \mathsf { F } } ) } \end{array}$ (1.2)

$$
\mathbf {x} ^ {\mathrm{CF}} = \mathbf {x} ^ {\mathrm{SCF}} (\mathbf {a}; \mathbf {x} ^ {\mathrm{F}})
$$

重要的是，求解 (1.1) 会得到一个**最近反事实解释（nearest contrastive explanation）** $(\mathrm { i . e . , ~ \hat { { \mathbf x } } ^ { C F } ~ = ~ \hat { { \mathbf x } } ^ { F } + } \delta ^ { * })$ ，但并没有直接映射到一组（最小的）有意义建议 (KSV21)。相反，求解 (1.2) 既能得到一个最小的有意义建议 $(\mathrm { i . e . , ~ } \mathsf { a } ^ { \ast })$ ，也能得到一个反事实解释（即，根据构造， $\begin{array} { r } { \pmb { x } ^ { \mathsf { C F } } = \pmb { x } ^ { \mathsf { S C F } } ( \pmb { a } ^ { * } ; \pmb { x } ^ { \mathsf { F } } ) ) . } \end{array}$ 3

我们的立场是，在以提供救济为目标时，首要目标应是提供最小的有意义建议，这些建议在被执行时会产生一个（不一定最近的）反事实解释。提供那些不一定能通过最小努力达成的最近反事实解释，对个体而言是次要的。然而，在实践中，由于求解 (1.2) 需要额外的假设（特别是计算 $\mathbf { x } ^ { \mathsf { S C F } }$ ），文献中常常采用求解 (1.1) 的方法。尽管存在许多假设特征独立的方法，但我们引用 Karimi 等人 [Kar+20b, prop. 2] 的否定性结论，其中作者表明，在没有完全指定变量间因果关系的情况下，无法保证救济。正如 Chou 等人 [Cho+22] 所指出的，基于非因果的虚假相关性的流行算法得出的解释“可能产生次优的、错误的，甚至是有偏见的解释”。因此，在本节的其余部分，我们假设已知一个 SCM，它允许对救济问题进行确定性公式化，从而同时得到最小的有意义建议和由此产生的反事实解释。稍后在 $\ S 7 { \cdot } 1 , 7 { \cdot } 2 ,$ 中，我们将放宽这些假设，并讨论在因果假设很少或完全没有的情况下相对更简单的设定。这并不是说没有伴随建议行动的反事实解释没有用。相反，正如 (KSV21) 所指出的，反事实解释有望用于“引导数据审计” (WMR17) 以及评估各种期望的模型属性，例如**鲁棒性（robustness）** (SHG19; HL20) 或**公平性（fairness）** (SHG19; Gup+19; USL19; Kar+20a) （另见 §7.1）。除此之外，已有研究表明，可解释机器学习系统的设计者使用反事实解释来预测模型行为 (Lag+19)、发现个体数据画像中的不准确性 (VA20)，以及在假设治疗下进行医疗结果预测 (Mer+20) 或生成逼真的医学图像 (WSP21)。除了上述及 §1.1 中提到的重要领域外，反事实解释已被用于改变源代码的行为 (Cit+21)、通过用合理的反事实修正代表性不足的类别来克服类别不平衡问题 (TK21)，以及辅助分子的可解释设计 (WSW22)。

在本节的剩余部分，我们概述了 (1.1) 和 (1.2) 中使用的目标函数和约束条件，接着描述了救济设定中常用的数据类型。最后，我们以相关公式作为总结。然后在第 1.4 节中，我们回顾用于求解此处定义的公式的工具。

## 1.3.1 优化目标（Optimization objective）

通常，很难定义个体之间的**相异性（dissimilarity, dist）**，或者个体付出努力的**成本函数（cost functions）**。值得注意的是，这一挑战最早在算法公平性文献中被讨论 (Dwo+12; Ilv19)，随后在算法救济学界被反复提及 (VA20; BSR20)。事实上，“法律并未就确定哪些理由最为重要的合适度量标准提供正式指导” (SB18)。尽管如此，现有的工作已经提出了各种具有合理直观依据或实际可行性的特定公式，我们将在下面进行回顾。

## 1.3.1.1 关于相异性（On dist）

Wachter 等人 [WMR17] 将相异性定义为**曼哈顿距离（Manhattan distance）**，并用**逆中位数绝对偏差（Median Absolute Deviation, MAD）** 进行加权：

$$
\operatorname{dist} \left(\mathbf {x}, \mathbf {x} ^ {\mathrm{F}}\right) = \sum_ {k \in [ D ]} \frac {\left| x _ {k} - x _ {k} ^ {\mathrm{F}} \right|}{\mathrm{MAD} _ {k}} \tag {1.3}
$$

$$
\mathrm{MAD} _ {k} = \operatorname{median} _ {j \in P} \left(\left| X _ {j, k} - \operatorname{median} _ {l \in P} \left(X _ {l, k}\right) \right|\right)
$$

这种距离具有几个理想的特性，包括通过 MAD 启发式方法来考虑并校正不同特征的范围差异、通过使用中位数绝对差来对异常值具有鲁棒性，以及最后，通过使用 $\ell _ { 1 }$ 曼哈顿距离来倾向于稀疏解。

Karimi 等人 [Kar+20a] 提出了一种加权组合的 $\ell _ { p }$ 范数，作为跨多种情况的灵活度量。如下所示的权重 $\alpha , \beta , \gamma , \zeta$ 允许实践者在变化的稀疏性（即通过 $\ell _ { 0 }$ 范数）、弹性的距离度量（即通过 $\ell _ { 1 } , \ell _ { 2 }$ 范数）(Dhu+18) 和所有特征上的最大归一化变化（即通过 $\ell _ { \infty }$ 范数）之间取得平衡：

$$
\operatorname{dist} \left(\mathbf {x}; \mathbf {x} ^ {\mathrm{F}}\right) = \alpha | | \delta | | _ {0} + \beta | | \delta | | _ {1} + \gamma | | \delta | | _ {2} + \zeta | | \delta | | _ {\infty} \tag {1.4}
$$

其中 $\boldsymbol { \delta } = [ \delta _ { 1 } , \cdots , \delta _ { D } ] ^ { T }$ 且 $\delta _ { k } : \mathcal { X } _ { k } \times \mathcal { X } _ { k } \to [ 0 , 1 ] \ \forall \ k \in [ D ]$ 。该度量通过根据每个维度的离散程度独立地归一化变化，来考虑**异构特征（heterogeneous features）** 间的变异性（见 §1.3.5）。也可以使用额外的权重来相对强调特定变量的变化。最后，其他工作旨在最小化图流形上的相异性 (Poy+19)、学习特征空间中的欧几里得距离 (Paw+19; Jos+19)，或使用潜在空间中的黎曼度量 (AHH17; AHS20)。

## 1.3.1.2 关于成本（On cost）

与 (Kar+20a) 类似，各种工作探索使用 $\ell _ { p }$ 范数来衡量行动成本。Ramakrishnan 等人 [RLA19] 探讨了 $\ell _ { 1 } , \ell _ { 2 }$ 范数以及采取特定行动时的恒定成本；Karimi 等人 [KSV21; Kar+20b] 最小化 $\mathbf { x } ^ { \mathsf { F } }$ 与行动 a 赋值之间的 $\ell _ { 2 }$ 范数 $(\mathrm { i } . \mathrm { e } . , | | \pmb { \theta } | | _ { 2 } )$ ；Cui 等人 [Cui+15] 探索了在用户指定的成本矩阵上 $\ell _ { 0 } , \ell _ { 1 } , \ell _ { 2 }$ 范数的组合。编码个体依赖性限制至关重要，例如，外国学生比本地居民更难获得信贷。

除了 $\ell _ { p }$ 范数，Ustun 等人 [USL19] 的工作提出了总对数百分位数偏移和最大对数百分位数偏移度量，以自动考虑数据集中点的分布，例如：

$$
\operatorname{cost} (\mathbf {a}; \mathbf {x} ^ {\mathrm{F}}) = \max _ {k \in [ D ]} | Q _ {k} \left(\mathbf {x} _ {k} ^ {\mathrm{F}} + \theta_ {k}\right) - Q _ {k} \left(\mathbf {x} _ {k} ^ {\mathrm{F}}\right) | \tag {1.5}
$$

其中 $Q _ { k } ( \cdot )$ 是目标人群中 $x _ { k }$ 的**累积分布函数（Cumulative Distribution Function, CDF）**。这种度量自然地考虑了移动到数据分布中不太可能（高或低百分位数）区域的相对难度。例如，在学校成绩中从 50 百分位数提高到 55 百分位数比从 90 百分位数提高到 95 百分位数更简单。

## 1.3.1.3 关于相异性和成本的关系（On the relation between dist and cost）

在一个改变一个变量不会影响其他变量的世界里，可以看到 (1.1) 中的反事实实例（即 ${ \bf x } ^ { \complement \mathsf { F } } = { \bf x } ^ { \mathsf { F } } + \delta$）与 (1.2) 中的反事实实例（即 $\pmb { x } ^ { \mathtt { C F } } = \mathbf { x } ^ { \mathtt { S C F } } ( \mathbf { a } ; \mathbf { x } ^ { \mathtt { F } } ) = \mathbf { x } ^ { \mathtt { F } } + \pmb { \theta }$）之间存在相似性。这种镜像形式表明，个体之间的相异性定义（即 dist）和个体付出的努力定义（即 cost）可以互换使用。然而，遵循 (KSV21) 的观点，我们不认为 dist 和 cost 之间存在普遍的一一映射。例如，在一个以用药为头痛父节点的双变量系统中，一个服用超过推荐剂量药物的个体可能头痛仍未缓解，即与另一个服用正确剂量的个体相比，成本更高但症状距离更小。此外，虽然相异性通常被认为是对称的（即 ${ \mathsf { d i s t } } ( \mathbf { x } _ { A } ^ { \mathsf { F } } , \mathbf { x } _ { B } ^ { \mathsf { F } } ) = { \mathsf { d i s t } } ( \mathbf { x } _ { B } ^ { \mathsf { F } } , \mathbf { x } _ { A } ^ { \mathsf { F } } ) )$ ，但从一种状态转换到另一种状态所需的努力不一定满足对称性，例如，花钱比存钱更容易（即成本 $\begin{array} { r } { ( { \mathbf a } = \mathrm { d o } ( \mathsf { X } _ { \mathbb S } : = } \end{array}$ $\begin{array} { r } { \mathbf { x } _ { A , \ S } ^ {  } - \mathfrak { G } 5 0 0 ) ; \mathbf { \bar { x } } _ { A } ^ {  } ) \le \mathrm { c o s t } ( \mathbf { a } = \mathrm { d o } ( X _ { \ S } : = \mathbf { x } _ { B , \ S } ^ {  } + \mathfrak { G } 5 0 0 ) ; \mathbf { x } _ { B } ^ {  } ) } \end{array}$ 这表明跨学科社区必须继续参与，以定义 dist 和 cost 的独特概念，并且这些定义不能仅从技术角度产生。

## 1.3.2 模型约束与反事实约束（Model and counterfactual constraints）

## 1.3.2.1 模型（Model）

文献中已经探索了多种用于生成救济的固定模型。如表 1.1 所示，我们将其大致分为四类：i) 基于树的 (TB)；ii) 基于核的 (KB)；iii) 可微的 (DF)；以及 iv) 其他 (OT) 类型（例如，广义线性模型、朴素贝叶斯、k-最近邻）。虽然关于救济的文献主要集中在二分类设定上，但大多数公式可以很容易地扩展到多分类或回归设定。扩展到这些设定是直接的，只需将模型约束分别替换为目标类别的 $h ( \mathbf { x } ^ { \mathsf { C F } } ) = k$ 或期望回归区间的 $h ( \mathbf { x } ^ { \mathsf { C F } } ) \in [ a , b ]$ 。或者，可以使用软预测代替硬预测，其目标可能是，例如，增加最高预测类别与第二高预测类别之间的预测差距，即 Pred $( \mathsf { x } ^ { \mathsf { C F } } ) _ { i } -$ Pred $( \bar { \mathbf { x } } ^ { \mathsf { C F } } ) _ { j }$ ，其中 $i = a r g m a x _ { k \in K }$ Pred $( { \bf x } ^ { \complement \models } ) _ { k } , j = a r g m a x _ { k \in K \backslash i }$ Pred $( \pmb { x } ^ { \mathsf { C F } } ) _ { k }$ 。最终，表示预测变化的模型约束可能是任意非线性、不可微且非单调的 (BSR20)，这可能会限制解决方案的适用性（参见 §1.4）。

## 1.3.2.2 反事实（Counterfactual）

反事实约束取决于所提供的救济类型。虽然 (1.1) 中的 $\begin{array} { r } { \mathbf { x } ^ { \mathsf { C F } } \ = \ \mathbf { x } ^ { \mathsf { F } } + \delta } \end{array}$ 是一个线性约束，但计算 (1.2) 中的 $\mathbf { x } ^ { \mathsf { C F } } = \mathbf { x } ^ { \mathsf { S C F } } ( \mathbf { a } ; \mathbf { x } ^ { \mathsf { F } } )$ 涉及执行 Pearl 等人 [PGJ16] 的三步**外推-行动-预测（abduction-action-prediction）** 过程，因此可能是非参数且任意复杂的。在 (KSV21) 中给出了用于确定性计算加性噪声模型中反事实的闭式表达式，在 (Kar+20b) 中给出了更一般 SCM 的概率推导。

## 1.3.3 可行动性约束与合理性约束（Actionability and plausibility constraints）

## 1.3.3.1 合理性（Plausibility）

现有文献将**合理性约束（plausibility constraint）**形式化为三类：(i) **领域一致性（domain-consistency）**；(ii) **密度一致性（density-consistency）**；以及 (iii) **原型一致性（prototypical-consistency）**。领域一致性将**反事实实例（counterfactual instance）**限制在特征领域可接受值的范围内 (Kar+20a)，而密度一致性则关注特征（经验）分布中的可能状态 (Lau+19; Jos+19; Paw+19; Kan+20b; Dhu+18; Dhu+19)，识别靠近数据流形的实例。第三类合理性约束选择那些要么直接存在于数据集中 (Wex+19; Poy+19)，要么靠近数据集原型示例 (AH19b; AH19a; VLK19; KU20; Lau+19) 的反事实实例。

## 1.3.3.2 可操作性（Actionability）（可行性（Feasibility））

**可行动作集合（set of feasible actions）** $\mathcal { F } ( \mathbf { x } ^ { \mathsf { F } } )$ 是个体 $\mathbf { x } ^ { \mathsf { F } }$ 能够执行的干预操作集合，即 do $( \{ X _ { i } : = x _ { i } ^ { \mathsf { F } } + \theta _ { i } \} _ { i \in \mathcal { I } } )$ 。为了确定 $\mathcal { F } ( \mathbf { x } ^ { \mathsf { F } } )$ ，我们必须识别出可以对其进行干预的变量集合，以及干预必须满足的前置/后置条件。每个变量的**可操作性（actionability）**分为三类 (Las+17b; KSV21)：

I. **可操作（且可变）**，例如：银行余额；
II. **可变但不可操作**，例如：信用评分；
III. **不可变（且不可操作）**，例如：出生地。

直观上，可变但不可操作的变量并非个体可直接操作的，但可能因其因果祖先的改变而发生变化（例如，定期偿还债务）。

在识别出可操作变量集合后，一项干预可以无条件地改变某个变量的值（例如，银行余额可以增加或减少），或者有条件地将其改变为特定值 (KSV21) 或特定方向 (USL19)。Karimi 等人 [KSV21] 给出了以下示例，以说明对 $\mathsf { X } _ { i }$ 进行干预的可操作可行性可能取决于多种条件：

i. 被干预变量的干预前值 $( \mathrm { i . e . , } x _ { i } ^ { \mathsf { F } } )$ ；例如，个体的年龄只能增加，即 $[ x _ { \mathrm { A G E } } ^ { \mathsf { S C F } } \geq x _ { \mathrm { A G E } } ^ { \mathsf { F } } ]$ ；
ii. 其他变量的干预前值 $( \mathrm { i . e . , ~ } \{ x _ { j } ^ { \mathsf { F } } \} _ { j \subset [ d ] \backslash i } )$ ；例如，持临时签证的个人不能申请信贷，即 $[ x _ { \mathrm { { v I S A } } } ^ { \mathsf { F } } =$ PERMANENT] $\geq [ x _ { \mathrm { C R E D I T } } ^ { \mathsf { S C F } } = \mathsf { T R U E } ]$ ；
iii. 被干预变量的干预后值 $( { \mathrm { i . e . , ~ } } x _ { i } ^ { \mathsf { S C F } } )$ ；例如，个体只有在不会因持续吸烟习惯而导致病情复发的情况下，才能接受心脏手术（一种加法干预），即 $[ x _ { \mathrm { H E A R T } } ^ { \mathsf { S C F } } \neq$ REMISSION]；
iv. 其他变量的干预后值 $( \mathrm { i . e . , ~ \{ } ~ x _ { j } ^ { \mathsf { S C F } } \} _ { j \subset [ d ] \backslash i } )$ ；例如，个体只有在血压 $[ x _ { \tt B P } ^ { \tt S C F } = 0 . \mathsf { K } . ] \geq$ $[ x _ { \mathrm { H E A R T } } ^ { \mathsf { S C F } } = \mathsf { S U R G E R Y } ]$ 正常后才能接受心脏手术。

所有这些可行性条件都可以轻松地编码为布尔/逻辑约束，纳入 $\mathcal { F } ( \mathbf { x } ^ { \mathsf { F } } )$，并在约束优化公式 (1.1)、(1.2) 中共同求解。需要考虑的一个重要附带说明是，$\mathcal { F } ( \mathbf { x } ^ { \mathsf { F } } )$ 不受**结构因果模型（Structural Causal Model, SCM）**假设的限制，而是受个体/上下文相关考虑的约束，这些考虑决定了动作的形式、可行性和范围 (KSV21)。

## 1.3.3.3 关于可操作性与合理性的关系

虽然看似重叠，但**可操作性（actionability）** $( \mathrm { i . e . , ~ } \mathcal { F } ( \pmb { x } ^ { \mathsf { F } } ) )$ 和**合理性（plausibility）** $( \mathrm { i . e . , } \mathcal { P } ( \mathcal { X } ) )$ 是两个截然不同的概念：前者将行动限制为那些可能执行的动作，而后者则要求生成的反事实实例可能是真实的、可信的或现实的。考虑一位被拒绝赴美参加会议签证的中东博士生。虽然来自其他国家的、具有相似特征（合理的性别、研究领域、学术记录等）的外国学生很可能受到优待（即合理的解释），但我们的学生不可能改变其出生地来寻求补救（即一个合理的解释，但一个不可行的建议）。相反，个体可以执行一组可行行动，但这些行动会使他们处于一个不合理状态（例如，小的 $p ( \mathbf { x } ^ { \mathsf { C F } } )$；不在数据集中），导致模型无法以高置信度进行分类。因此，可操作性和合理性约束可以根据它们所描述的补救设置结合使用。

## 1.3.4 多样性与稀疏性约束（Diversity and sparsity constraints）

### 1.3.4.1 多样性（Diversity）

**多样性补救（Diverse recourse）**通常是在存在不确定性的情况下寻求的，例如，在定义 `dist` 和 `cost` 时未知的用户偏好。旨在生成多样化补救的方法通常分为两类：i) 通过对同一公式进行多次运行来实现多样性；或 ii) 通过显式地将多样性约束附加到先前的公式中来实现多样性。

在第一类方法中，Wachter 等人 [WMR17] 表明，在非凸模型（例如多层感知机）上多次运行其基于梯度的优化器，由于随机种子的不同，会产生不同的解。Sharma 等人 [SHG19] 表明，基于遗传的优化方法生成的多个进化实例可以用作多样化的解释，因此无需多次重新运行优化器。Downs 等人 [Dow+20]、Mahajan 等人 [MTS19] 和 Pawelczyk 等人 [Paw+19] 通过将来自事实实例和反事实实例共享的潜在空间的多个样本传递给解码器，并过滤那些正确翻转预测的实例，来生成多样化的反事实。

在第二类方法中，Russell [Rus19] 采用了一种策略，即优化器的后续运行会阻止以与先前解释/建议相同的方式更改特征。Karimi 等人 [Kar+20a] 沿此方向继续研究，并建议后续的补救不应落在任何先前解释/建议周围的 $\ell _ { p ^ { - } }$ 球内。Mothilal 等人 [MST20] 和 Cheng 等人 [CMQ20] 提出了一种可微约束，通过最大化生成的反事实的（核）矩阵的行列式，来最大化生成解释之间的多样性。

### 1.3.4.2 稀疏性（Sparsity）

人们通常认为，更稀疏的解是可取的，因为它们强调更少的更改（在解释中）或更少的变量需要操作（在建议中），因此对个体来说更具可解释性 (Mil56)。虽然这一点并未被普遍接受 (VLK19; PBK20)，但可以将此要求表述为一个额外的约束，例如，$\begin{array} { r } { \mathrm { e . g . , } \vert \vert \delta \vert \vert _ { 0 } \leq s , } \end{array}$ 或 $| | \pmb \theta | | _ { 0 } \leq s$ 。将稀疏性表述为一个额外的（硬性）约束，而不是在目标函数中对其进行优化，这赋予了在确保解稀疏的同时优化不同目标的灵活性。

## 1.3.5 数据类型与编码（Datatypes and encoding）

在后果性决策制定场景中，一个常见主题是使用涉及个体真实世界属性的数据类型。因此，数据集通常是**表格型（tabular）**的，包含异构特征，混合了数值型（实数、整数）、二值型、类别型或有序型变量。最常用的数据集包括 Adult (Adu96)、Australian Credit (DG17)、German Credit (BL13)、GiveMeCredit (YL09)、COMPAS (Lar+16a)、HELOC (HGB) 等，它们都具有高度异构性。

不同的特征类型遵循不同的统计特性，例如，基于整数的心率、实数值的 BMI、类别型的血型和有序型的年龄组，它们的数值范围差异巨大。因此，异构数据需要特殊处理以保留其语义。一种常见方法是根据预定的策略对每个变量进行编码，在模型训练前以及随后的补救生成过程中（针对任一补救类型，即后果性建议或对比性解释）对数据进行预处理。例如，类别型和有序型特征可以分别使用**独热编码（one-hot encoding）**和**温度计编码（thermometer encoding）**进行编码。为了在补救生成过程中保留每个变量的语义，我们还必须确保生成的解释/建议产生的反事实实例也满足编码约束。例如，使用形式为 $\textstyle \sum _ { j } x _ { i , j } \ = \ 1 \ \forall \ x _ { i , j } \ \in \ \{ 0 , 1 \}$ 的布尔和线性约束，以确保多个类别不会同时被激活；并要求温度计编码的有序变量满足 $x _ { i , j } \geq x _ { i , j + 1 } \forall x _ { i , j } \in \{ 0 , 1 \}$ 。有关详细概述，我们参考 Nazabal 等人的工作 [Naz+20]。

除了表格数据外，人们可能还需要基于图像或文本数据集的对比性解释，如表 1.1 所总结。对于基于图像的数据集，算法可以选择在原始数据上操作，或者在超像素或其他形式的提取特征（例如，神经网络中的隐藏表示）上操作。基于文本的数据集也通常被编码为表示**全局词向量（Global Vectors for Word Representation, GloVe）** (PSM14) 或**词袋（bag-of-words）**嵌入 (RSG16) 的向量。

## 1.3.6 相关公式（Related formulations）

补救生成的问题公式，特别是对比性解释 (1.1)，与数据挖掘和机器学习中的其他几个问题广泛相关。例如，**成本最小化逆分类问题（cost-minimizing inverse classification problem）** (Lau+17; ACH10; LLS18; Las+17b; Las+17a; MK00)，旨在识别“为了将某个案例重新分类为另一个更优类别的成员所需的最小更改量？” (MK00)。**可操作知识提取（Actionable knowledge extraction）**在数据挖掘中被用于根据分类器 (CZ06; CLZ07; Cao+09; KR13; Yan+06) 建议“能够将实例状态转变为更优状态的行为” (Du+11)。最后，**对抗性扰动（Adversarial perturbations）**是对分类器输入进行的微小且不易察觉的更改，这些更改会使输出预测变为错误且高置信度的区域 (Pap+17; MD+17; CW17; MDFF16; Pap+16; NYC15; GSS14; Sze+14)。上述方法共享的另一个共同点是它们假设底层模型是固定的。这些方法的扩展，其中模型设计者预期并旨在防止恶意行为，存在于**策略分类（strategic classification）** (Har+16; Don+18; Mil+19a; MMH20; KR20; Liu+20; HIV19; LR21) 和**对抗鲁棒性（adversarial robustness）** (CRK19; Car+19; FFF15; Xie+19) 文献中。关于这些方法之间的相似性和对比的最新阐述，我们参考 (ELR21; Paw+21a; Fre21)。

尽管它们的公式存在很强的相似性，但其差异体现在预期用例和对相关利益方的保证上。例如，与旨在与受影响的个体建立信任的补救不同，可操作知识提取文献中引用的主要用例是提供具有成本效益的行动，以最大化利润或其他业务目标。此外，对比性解释旨在告知个体其情况在哪些方面本可以导致理想结果，而对抗性扰动则旨在通过难以察觉（例如，离开数据分布）来欺骗人类。在某种意义上，难以察觉是可解释性和信任的对立面。最后，基于 §1.2 中的介绍，提供后果性建议依赖于对世界的因果建模，而这在其他方法中基本被忽略。

## 1.4 解决方案（Solution）

根据定义，当个体同时获得**对比性解释（contrastive explanations）**和**后果性建议（consequential recommendations）**时，就提供了补救，这些解释和建议可以分别通过求解 (1.1) 和 (1.2) 获得。值得注意的是，要最小化的目标（即 `dist` 或 `cost`）可能是非线性的、非凸的或不可微的。此外，在不限制分类器族的情况下，模型约束也未必是线性的、单调的或凸的。最后，基于个体/上下文特定的限制，问题设置可能需要在一个受约束的合理实例集合 $\mathcal { P } ( \mathcal { X } )$ ，或可行动作集合 $\check { \mathcal { F } } ( { \mathbf { x } } ^ { \sf F } )$ 上进行优化。⁴ 因此，一个与距离/成本无关且与模型无关的解决方案，同时支持异构数据集上的合理性、可行性、稀疏性和多样性约束，通常需要复杂的方法，并在过程中权衡各种理想属性。下面，我们讨论这些属性的重要性，并提供所用解决方案的概述。

### 1.4.1 属性（Properties）

我们指出，优化器及其产生的解理想情况下应满足一些理想的属性，详见下文。在实践中，方法通常需要在最优保证 $\delta ^ { * }$、完美覆盖 $\Omega ^ { * }$ 或高效运行时间 $\tau ^ { * }$ 之间进行权衡，或者可能需要禁止性地访问底层数据或预测模型。

#### 1.4.1.1 最优性（Optimality）

识别出的反事实实例理想情况下应接近事实实例，对应于个体情况的微小变化。在 (1.1) 和 (1.2) 中优化最小 `dist` 和 `cost` 时，目标函数和约束条件决定了补救的存在性和多重性。对于事实实例 $\mathbf { x } ^ { \mathsf { F } }$ ，可能存在零个、一个或多个⁵ 最优解，因此理想的优化器应能识别出（至少）一个解（分别是解释或建议）（如果存在的话），否则终止并返回 N/A。

#### 1.4.1.2 完美覆盖（Perfect coverage）

**覆盖（Coverage）**定义为算法能够为其识别出合理反事实实例（通过任一补救类型）的个体数量，前提是至少存在一个解 (Kar+20a)。向用户传达适用领域对于建立信任至关重要 (WMR17; MRW19)，理想情况下算法应为所有个体提供补救（即完美覆盖）。

#### 1.4.1.3 高效运行时间（Efficient runtime）

由于解释/建议很可能在对话式环境中提供 (SF18; Hil90; Mil19; HP+18; Wel17)，因此期望在接近实时的条件下生成补救。尽管文献中普遍未报告运行时复杂度，但在表 1.1 中，我们重点介绍了那些报告了高效挂钟运行时间、可能支持算法与个体之间交互的算法。

#### 1.4.1.4 访问权限（Access）

不同的优化方法可能需要对底层数据集或模型具有不同级别的访问权限。对模型的访问可能包括**查询访问（query access）**（仅返回标签）、**梯度访问（gradient access）**（请求输出相对于输入的梯度）、**类别概率访问（class probabilities access）**（从中可以推断预测的置信度），或完全的**白盒访问（white-box access）**（所有模型参数已知）。

自然，每种设置允许的访问程度都有实际影响，这进一步限制了工具的选择。考虑一个旨在为其客户生成补救的组织。除非这些算法由该组织内部运行，否则该组织不太可能将训练数据、模型参数甚至其模型的非速率限制 API 交给第三方来生成补救。

### 1.4.2 工具（Tools）

我们认为已得到充分探索的优化领域 (NW06; BBV04; SNW12) 超出了本工作的范围，仅简要回顾专门用于补救生成的工具，突出其适用范围，并将技术细节留给适当的参考文献。不仅是在一般设置下求解 (1.1) 和 (1.2) 很困难 (Las+17b)，甚至在受限设置下也被证明是 NP-完全或 NP-难的，例如，求解基于整数的变量 (AH19b)、求解加法树模型 (Cui+15; Tol+17; Ate+20) 或神经网络 (Kat+17)，以及求解二次目标和约束 (AH19b; PB17; BBV04)。因此，除了对可能不可数的解集进行穷举搜索外，大多数工作都在受限设置下寻求近似解，权衡上述理想属性（见表 1.1）。解决方案可以大致分为：**基于梯度的优化（gradient-based optimization）**、**基于模型（model-based）**、**基于搜索（search-based）**、**基于验证（verification-based）**和**基于启发式（heuristics-based）**。⁶

在目标和约束可微的情况下，采用诸如 FISTA (BT09) 等基于梯度优化的解决方案 (Dhu+18; Dhu+19; VLK19) 来寻找凸拉格朗日函数下的全局最优解，而一阶方法如 (L-)BFGS 或投影梯度下降可用于识别局部最优解。与此相关，一些工作并未为每个个体独立求解补救，而是采用基于模型的方法，通过梯度优化学习从事实实例到反事实实例的映射 (Paw+19; MTS19)。这些方法享有高效运行时间，但代价是覆盖损失和对异构数据的处理不佳。

对于不可微的设置，基于**分支定界（branch-and-bound）** (LW66) 的方法将搜索域分割成更小的区域，在这些区域内可能更容易找到解。在目标和约束为线性的情况下，当数据类型为离散时，可以使用**整数线性规划（Integer Linear Programming, ILP）**算法 (Cui+15; USL19)，而当某些变量不是离散时，则使用**混合整数线性规划（Mixed-Integer Linear Programming, MILP）**扩展 (Rus19; Kan+20a)。(M)ILP 公式使用强大的现成求解器求解，如 CPLEX (Cpl09) 和 Gurobi (OPT14)。也可以使用迭代二分搜索和验证工具的组合来获得 (1.1) 和 (1.2) 的解。在这里，问题被重新表述为一个约束满足问题，其中对应于目标（`dist` 或 `cost`）的约束在每次迭代中更新，以反映可获得解的边界 (Kar+20a; KSV21; Moh+21)。与 (M)ILP 一样，这种方法得益于现成求解器的存在，例如 $Z _ { 3 }$ (DMB08)、CVC4 (Bar+11) 和 pySMT (GM15)。该问题也可以被转化为**程序合成（program synthesis）** (RLA19; DTLP22) 或**回答集编程（answer-set programming）** (Ber20) 并求解。上述方法通常提供最优性和完美覆盖，同时依赖于对固定模型参数的白盒访问。

还探索了许多基于启发式的方法，例如，在经验图上寻找 $\mathbf { x } ^ { \mathsf { F } }$ 和潜在 $\mathbf { \boldsymbol { x } } ^ { \mathtt { C F } }$ 之间的最短路径（Dijkstra 算法 (Cor+09)），该图中的边连接在相似实例之间（例如，根据高斯核） (Poy+19)。最后，基于遗传的方法 (Whi94; ZT98) 根据各种启发式方法 (Gui+18; SHG19; Dan+20; KU20; BADS20) 在候选解的不同进化过程中寻找解，并且其优点在于仅需对模型进行查询访问，因此与模型/数据类型/范数无关。
