# 附录 公平因果追索权（Fair Causal Recourse）

## d.1 实验细节

在本附录中，我们提供了关于实验设置的额外细节。

## d.1.1 结构因果模型（SCM）规范

首先，我们给出用于生成三个合成数据集 IMF、CAU-LIN 和 CAU-ANM 的 **结构因果模型（Structural Causal Model, SCM）** 的精确形式。除了所需特征——即可独立操作（IMF）或因果依赖（CAU）的特征，以及线性（LIN）或非线性（ANM）的加性噪声关系——之外，我们为每种设置选择了特定的结构方程形式，以使所有特征大致标准化，即它们近似具有零均值和单位方差。

我们使用图 5.3 所示的因果结构。除了希望使因果图相似以便于更好地比较并避免引入额外干扰因素，同时尊重 IMF 和 CAU 设置的不同结构约束之外，这一特定选择的动机是至少有一个特征不是受保护属性 $A$ 的后代。这样做的目的是使得 $\mathrm { L R } / \mathrm { S V M } ( \mathbf { X } _ { \mathrm { n d } ( A ) } )$ 和 $\mathrm { L R } / \mathrm { S V M } ( \mathbf { X } _ { \mathrm { n d } ( A ) } , \mathbf { U } _ { \mathrm { d } ( A ) } )$ 始终能够访问至少一个可操作变量 $( X _ { 2 } )$ ，该变量可以被操控以实现追索。

### d.1.1.1 IMF

对于 IMF 数据集，我们根据以下 SCM 对受保护属性 $A$ 和特征 $X _ { i }$ 进行采样：

$$
\begin{array}{l} A := 2 U _ {A} - 1, \quad U _ {A} \sim \text { Bernoulli } (0. 5) \\ X _ {1} := 0. 5 A + U _ {1}, \quad U _ {1} \sim \mathcal {N} (0, 1) \\ X _ {2} := U _ {2}, \quad U _ {2} \sim \mathcal {N} (0, 1) \\ X _ {3} := 0. 5 A + U _ {3}, \quad U _ {3} \sim \mathcal {N} (0, 1) \\ \end{array}
$$

### d.1.1.2 CAU-LIN

对于 CAU-LIN 数据集，我们根据以下 SCM 对 $A$ 和 $X _ { i }$ 进行采样：

$$
A := 2 U _ {A} - 1, \quad U _ {A} \sim \text { Bernoulli } (0. 5)
$$

$$
X _ {1} := 0. 5 A + U _ {1}, \quad U _ {1} \sim \mathcal {N} (0, 1)
$$

$$
X _ {2} := U _ {2}, \quad U _ {2} \sim \mathcal {N} (0, 1)
$$

$$
X _ {3} := 0. 5 (A + X _ {1} - X _ {2}) + U _ {3}, \quad U _ {3} \sim \mathcal {N} (0, 1)
$$

### d.1.1.3 CAU-ANM

对于 CAU-ANM 数据集，我们根据以下 SCM 对 $A$ 和 $X _ { i }$ 进行采样：

$$
A := 2 U _ {A} - 1, \quad U _ {A} \sim \text { Bernoulli } (0. 5)
$$

$$
X _ {1} := 0. 5 A + U _ {1}, \quad U _ {1} \sim \mathcal {N} (0, 1)
$$

$$
X _ {2} := U _ {2}, \quad U _ {2} \sim \mathcal {N} (0, 1)
$$

$$
X _ {3} := 0. 5 A + 0. 1 (X _ {1} ^ {3} - X _ {2} ^ {3}) + U _ {3}, \quad U _ {3} \sim \mathcal {N} (0, 1)
$$

## d.1.2 标签生成

为了生成不同分类器训练所用的真实标签，我们考虑了线性和非线性逻辑回归。具体来说，我们根据以下公式生成真实标签：

$$
Y := \mathbb {I} \{U _ {Y} <   h (X _ {1}, X _ {2}, X _ {3}) \}, \qquad U _ {Y} \sim \operatorname{Uniform} [ 0, 1 ].
$$

在线性情况下，$h ( X _ { 1 } , X _ { 2 } , X _ { 3 } )$ 由下式给出：

$$
h (X _ {1}, X _ {2}, X _ {3}) = \left(1 + e ^ {- 2 (X _ {1} - X _ {2} + X _ {3})}\right) ^ {- 1}.
$$

在非线性情况下，$h ( X _ { 1 } , X _ { 2 } , X _ { 3 } )$ 由下式给出：

$$
h (X _ {1}, X _ {2}, X _ {3}) = \left(1 + e ^ {4 - (X _ {1} + 2 X _ {2} + X _ {3}) ^ {2}}\right) ^ {- 1}.
$$

## d.1.3 公平模型架构与训练超参数

我们对 **公平支持向量机（FairSVM）** 使用了 Gupta 等人 [Gup+19] 的实现，并对所有其他 SVM 变体使用了 sklearn SVC 类 (Ped+11)。我们考虑以下超参数值（为了便于比较，与 (Gup+19) 中报告的值相同），并通过 5 折交叉验证选择最佳值（除非另有说明）：核类型为线性（linear）、多项式（poly）、径向基函数（rbf），正则化强度 $C ~ \in ~ \{ 1 , 1 0 , 1 0 0 \}$ ，RBF 核带宽 $\begin{array} { r l r } { \gamma _ { \tt R B F } } & { { } \in } & { \{ 0 . 0 0 1 , 0 . 0 1 , 0 . 1 , 1 \} } \end{array}$ ，多项式核度数 $\in \ \{ 2 , 3 , 5 \}$ ；遵循 (Gup+19)，我们还通过交叉验证选择公平性权衡参数 $\lambda = \{ 0 . 2 , 0 . 5 , 1 , 2 , 1 0 , 5 0 , 1 0 0 \}$。

对于非线性逻辑回归模型，我们选择了 sklearn MLPClassifier 类的一个实例，该实例具有两个隐藏层（每层 10 个神经元）和 ReLU 激活函数。然后，使用默认优化器和训练超参数对该模型的输入进行优化。

## d.1.4 优化方法

由于解决因果追索优化问题的算法贡献并非本工作的主要焦点，我们选择离散化可能的追索行动空间，并通过执行暴力搜索来选择最佳（即成本最低）的有效行动。关于解决因果追索优化问题的另一种基于梯度的方法，请参见 (Kar+20b)。

对于每个可操作特征 $X _ { i }$ ，用 max 和 min 分别表示其在训练集中达到的最大值和最小值。给定 $X _ { i }$ 的事实观测值 $x _ { i } ^ { \mathsf { F } }$ ，我们离散化搜索空间，并在范围 $[ x _ { i } ^ { \mathsf { F } } - 2 ( x _ { i } ^ { \mathsf { F } } -$ min ), $x _ { i } ^ { \mathsf { F } } + 2 ( \mathbf { m a x } _ { i } - x _ { i } ^ { \mathsf { F } } ) ]$ 内使用 15 个等间距的区间来选取可能的干预值 $\theta _ { i }$ 。然后，我们考虑所有可操作变量子集上所有可能的干预值组合。我们注意到，对于 $\mathrm { L R / S V M ( X _ { n d } ) }$ 和 $\mathrm { L R / S V M ( X _ { n d } , U _ { d } ) }$ ，只有 $X _ { 2 }$ 是可操作的，而对于其他 LR/SVM， $\{ X _ { 1 } , X _ { 2 } , X _ { 3 } \}$ 全部是可操作的。

## d.1.5 成人数据集案例研究

基于专家知识 (NS18; Chi19) 的成人数据集的因果图如图 5.3c 所示。

由于真实的结构方程未知，我们通过拟合因果图中的每个父-子关系来学习成人数据集的近似 SCM。由于成人数据集中的大多数变量是分类变量，加性噪声对其中大多数变量来说不是一个合适的假设。因此，我们选择使用潜在变量模型来模拟每个结构方程 $X _ { i } : = f _ { i } ( \mathrm { P A } _ { i } , U _ { i } )$ ；具体来说，我们使用 **条件变分自编码器（Conditional Variational Autoencoder, CVAE）** (SLY15)，类似于 (Kar+20b)。

我们使用确定性条件解码器 $D _ { i } ( \mathrm { P A } _ { i } , U _ { i } ; \psi _ { i } )$ ，这些解码器实现为由 $\psi _ { i }$ 参数化的神经网络，并对每个 $X _ { i }$ 使用各向同性高斯先验 $U _ { i } \sim \mathcal { N } ( 0 , \mathbf { I } )$。

对于连续特征，解码器直接输出分配给 $X _ { i }$ 的值，即我们将结构方程近似为：

$$
X _ {i} ^ {\text { continuous }} := D _ {i} (\mathrm{PA} _ {i}, U _ {i}; \psi_ {i}), \quad U _ {i} \sim \mathcal {N} (0, \mathbf {I}). \tag {D.1.1}
$$

对于分类特征，解码器输出一个类别概率向量（通过在最后一层之后应用 softmax 操作）。然后，将 arg max 分配为相应分类特征的值，即：

$$
X _ {i} ^ {\text { categorical }} := \operatorname{argmax} D _ {i} (\mathrm{PA} _ {i}, U _ {i}; \psi_ {i}), \quad U _ {i} \sim \mathcal {N} (0, \mathbf {I}). \tag {D.1.2}
$$

解码器 $D _ { i } ( \mathrm { P A } _ { i } , U _ { i } ; \psi _ { i } )$ 使用标准变分框架 $( \mathrm { K W 1 4 } ; \mathrm { R M W 1 4 } )$ 进行训练，并通过近似高斯后验 $q _ { \phi _ { i } } ( U _ { i } | X _ { i } , \mathrm { P A } _ { i } )$ 进行摊销，其均值和方差由编码器计算，编码器形式为具有参数 $\phi _ { i }$ 的神经网络。对于连续特征，我们使用实值预测与目标之间的标准重构误差，即 $\mathrm { L } 2 / \mathrm { M S E } ( X _ { i } , D _ { i } ( \mathrm { P A } _ { i } , U _ { i } ; \psi _ { i } ) )$ ，而对于分类特征，我们则使用 $X _ { i }$ 的独热编码值与预测的类别概率向量之间的交叉熵损失，即 CrossEnt $( X _ { i } ,$ , softmax $\left( D _ { i } ( \mathrm { P A } _ { i } , U _ { i } ; \psi _ { i } ) \right)$ 。

CVAE 在 6,000 个训练样本上进行训练，使用固定的学习率 0.05，批量大小为 128，训练 100 个 epoch，并在包含 250 个样本的保留验证集上进行早停。对于每个父-子关系，我们训练 10 个模型，编码器的隐藏层数和单元数从以下配置中随机抽取： $\begin{array} { l l l } { { \mathrm { e n c } _ { \mathrm { a r c h } } } } & { { = } } & { { \left\{ ( \zeta , 2 , 2 ) , ( \zeta , 3 , 3 ) , ( \zeta , 5 , 5 ) , ( \bar { \zeta } , 3 2 , 3 2 , 3 2 ) \right\} } } \end{array}$ ，其中 $\zeta$ 是输入维度；解码器类似地从以下配置中抽取： $\mathbf { d e c } _ { \mathrm { a r c h } } = \{ ( 2 , \eta ) , ( 2 , 2 , \eta ) , ( 3 , 3 , \eta ) , ( 5 , 5 , \eta ) , ( 3 2 , 3 2 , 3 2 , \eta ) \}$ ，其中 $\eta$ 对于连续变量为 1，或者对于分类变量为独热编码的大小（例如，工作类别、婚姻状况和职业分别有 7、10 和 14 个类别）。此外，我们还从 1、3、5 中随机选取一个潜在维度。然后，我们选择在训练后真实实例与解码器样本之间具有最小 **最大均值差异（Maximum Mean Discrepancy, MMD）** 分数 (Gre+12) 的模型。

为了使用这种近似的 CVAE-SCM 进行反事实推理的溯因，我们从近似后验中采样 $U _ { i }$ 。进一步讨论请参见 (Kar+20b) 的附录 C。

最后，使用这个近似的 SCM，我们类似于上述合成实验来解决追索优化问题。这种方法的局限性（以及任何缺乏真实 SCM 的真实世界数据集）在于，我们无法保证在近似 SCM 假设下生成的特定追索行动在由真实（未知）SCM 支配的真实世界中执行时能够保证追索。

## d.2.2 使用不同的 SCM 进行追索

主要章节 $\ S 5 { \cdot } 4 { \cdot } 1$ 中呈现的结果使用了真实 SCM $\mathcal { M } ^ { \star }$ 的估计量 $\hat { \mathcal { M } } _ { \mathrm { K R } }$ （通过核岭回归在加性噪声假设下学习）来解决追索优化问题。

在表 D.1 中，我们展示了更完整的结果记录，其中还包括使用真实 SCM $\mathcal { M } ^ { \star }$ 或其线性估计 $ ( \hat { \mathcal { M } } _ { \mathrm { L I N } } )$ 作为计算追索行动基础的情况。当使用 SCM 估计进行追索时，我们仅考虑有效行动来计算 $\scriptstyle \Delta _ { \mathsf { c o s t } }$ 和 $\Delta _ { \mathrm { i n d v } }$ ，其中行动的有效性由该行动是否根据预言机 $\mathcal { M } ^ { \star }$ 导致预测改变来确定。

我们发现，正如预期的那样，使用不同的 SCM 不会影响 Acc 或 $\Delta _ { \mathsf { d i s t } }$ ，因为这些指标根据定义与 SCM 编码的底层因果生成过程无关。然而，使用估计的 SCM 代替真实的 SCM 可能会导致 $\Delta _ { \mathsf { c o s t } }$ 和 $\Delta _ { \mathrm { i n d v } }$ 的不同值，因为这些指标考虑了追索行动对其他特征的下游影响，因此依赖于底层的 SCM，参见定义 5.3.1 和 5.3.2。

我们观察到，使用估计的 SCM 可能导致低估或高估真实的公平因果追索指标（没有明显的趋势表明何时会发生哪一种情况）。此外，当真实 SCM 实际上是非线性时（即在 CAU-ANM 数据集上），使用线性 SCM 估计 $\hat { \mathcal { M } } _ { \mathrm { L I N } }$ 时，公平因果追索指标的误估尤其明显。这种行为是直观且符合预期的，并应警示在估计用于（公平）追索的 SCM 时，避免使用过强的假设或过于简单的参数模型。我们还注意到，在实践中，低估真实公平性指标可能比高估更成问题。

## d.2.3 通过交叉验证选择核函数

为完整起见，我们执行了与表 D.1 所示相同的一组实验，但在此处我们通过交叉验证选择核函数，而不是像之前那样将其固定为线性核或多项式核。结果如表 D.2 所示，总体趋势同样基本保持不变。

正如预期，由于核函数选择不同，我们观察到与表 D.1 相比的精度变化。也许最有趣的是，当给予“自由”选择核函数时，**公平支持向量机（FairSVM）** 在 $\Delta _ { \mathsf { d i s t } }$ 方面似乎通常表现略好，尤其是在前三个具有线性生成标签的数据集上。这表明使用非线性核可能对 FairSVM 实现其目标很重要。

然而，我们提醒，表 D.2 中的结果可能不易在不同分类器之间进行比较，因为距离是在诱导的特征空间中计算的，这些特征空间可能是低维的（在线性核的情况下）、高维的（在多项式核的情况下）或无限维的（在 RBF 核的情况下），这也是我们在 $\ S 5 { . } 4$ 中选择报告基于相同核类型的结果的原因。
