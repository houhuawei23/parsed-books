# 第 12 章 IP 加权和边际结构模型（IP Weighting and Marginal Structural Models）

第二部分围绕因果问题“戒烟对体重增加的平均因果效应是什么？”展开。在本章中，我们描述如何使用 **IP 加权（IP weighting）** 从观测数据中估计这一效应。尽管 IP 加权在第 2 章中已经介绍，但我们当时仅将其描述为一种非参数方法。现在，我们将描述模型与 IP 加权结合使用的方法，在额外假设下，这将使我们能够处理包含许多协变量和非二分类治疗的高维问题。

为了估计戒烟对体重增加的影响，我们将使用来自 **NHEFS** 的真实数据，该缩写代表（准备好迎接一个长名称了吗？） **国家健康和营养检查调查 I 流行病学随访研究（National Health and Nutrition Examination Survey Data I Epidemiologic Follow-up Study）** 。NHEFS 由 **国家卫生统计中心（National Center for Health Statistics）** 和 **国家老龄化研究所（National Institute on Aging）** 与美国公共卫生服务其他机构合作共同发起。关于 NHEFS 的详细描述，以及公开可用的数据集和文档，可在 wwwn.cdc.gov/nchs/nhanes/nhefs/ 找到。对于本章及后续章节，我们将使用本书网站上提供的 NHEFS 数据子集。我们鼓励读者改进和完善我们的分析。

我们的目标是估计戒烟（治疗） $A$ 对体重增加（结局） $Y$ 的平均因果效应。为此，我们将使用来自 1566 名年龄在 25-74 岁之间的吸烟者的数据，这些吸烟者作为 NHEFS 的一部分，在基线访视和大约 10 年后的随访访视中均有记录。个体被分类为接受治疗 $A = 1$ ，如果他们在随访访视前报告已戒烟；否则被分类为未接受治疗 $A = 0$ 。每个个体的体重增加 $Y$ 被测量（单位为 kg）为随访访视时的体重减去基线访视时的体重。大多数人体重增加，但戒烟者平均体重增加更多。

戒烟者的平均体重增加为 $\widehat{\mathrm{E}}[Y \vert A = 1] = 4.5$ kg，非戒烟者的平均体重增加为 $\widehat{\mathrm{E}}[Y \vert A = 0] = 2.0$ kg。因此，差异 $\mathrm{E}[Y \vert A = 1] - \mathrm{E}[Y \vert A = 0]$ 估计为 2.5，95% 置信区间为 1.7 到 3.4。

我们将 $\mathrm{E}[Y^{a = 1}]$ 定义为如果人群中所有个体在随访访视前都戒烟时观察到的平均体重增加，将 $\mathrm{E}[Y^{a = 0}]$ 定义为如果人群中所有个体都没有戒烟时观察到的平均体重增加。我们将加法尺度上的平均因果效应定义为 $\mathrm{E}[Y^{a = 1}] - \mathrm{E}[Y^{a = 0}]$ ，即如果所有人都接受治疗与所有人都未接受治疗时观察到的平均体重差异。这是我们在本章及后续章节中主要关注的因果效应。

我们在本节第一段中估计的 **关联性差异（associational difference）** $\mathrm{E}[Y \vert A = 1] - \mathrm{E}[Y \vert A = 0]$ 通常不同于 **因果差异（causal difference）** $\mathrm{E}[Y^{a = 1}] - \mathrm{E}[Y^{a = 0}]$ 。如果戒烟者和非戒烟者在影响体重增加的特征上存在差异，前者一般不具有因果解释。例如，戒烟者平均比非戒烟者年长 4 岁（戒烟者年龄超过 50 岁的可能性比非戒烟者高 44%），而老年人无论是否戒烟，体重增加都比年轻人少。我们说年龄是 $A$ 对 $Y$ 效应的一个（替代）混杂因素，我们的分析需要调整年龄。未调整的估计值 2.5 可能低估了真实的因果效应 $\mathrm{E}[Y^{a = 1}] - \mathrm{E}[Y^{a = 0}]$ 。

如表 12.1 所示，戒烟者和非戒烟者在其他变量如性别、种族、教育程度、基线体重和吸烟强度的分布上也存在差异。如果这些变量是混杂因素，那么它们也需要在分析中进行调整。在第 18 章中，我们讨论混杂因素选择的策略。这里我们假设以下 9 个在基线时测量的变量足以调整混杂：性别（0：男性，1：女性）、年龄（岁）、种族（0：白人，1：其他）、教育程度（5 个类别）、吸烟强度和持续时间（每天吸烟支数和吸烟年数）、日常生活中的体力活动（3 个类别）、娱乐性运动（3 个类别）和体重（kg）。即 $L$ 表示一个包含 9 个测量协变量的向量。在下一节中，我们使用 IP 加权来调整这些协变量。

## 12.2 通过建模估计 IP 权重（Estimating IP weights via modeling）

**IP 加权（IP weighting）** 创建了一个伪总体，在该总体中，从协变量 $L$ 到治疗 $A$ 的箭头被移除。更精确地说，该伪总体具有以下两个性质： $A$ 和 $L$ 在统计上独立，并且伪总体中的均值 $\mathrm{E}_{ps}[Y \mid A = a]$ 等于实际总体中的标准化均值 $\sum_l \mathrm{E}[Y \mid A = a, L = l] \, \mathrm{Pr}[L = l]$ 。即使在实际总体中 **条件可交换性（conditional exchangeability）** $Y^a \perp\perp A \mid L$ 不成立，这些性质也成立（参见 **技术点 2.3（Technical Point 2.3）** ）。

现在，如果实际总体中条件可交换性 $Y^a \perp\perp A \mid L$ 成立，那么这些性质意味着：

(i) $Y^a$ 的均值在两个总体中相同，  
(ii) 伪总体中 **无条件可交换性（unconditional exchangeability）** （即无混杂）成立，  
(iii) 实际总体中的反事实均值 $\mathrm{E}[Y^a]$ 等于伪总体中的 $\mathrm{E}_{ps}[Y \mid A = a]$ ，并且  
(iv) 在伪总体中，关联即为因果。

如果您需要复习 IP 加权，请重新阅读第 2 章。

> 治疗的条件概率 $\mathrm{Pr}[A = 1 \mid L]$ 被称为 **倾向得分（propensity score）** 。更多关于倾向得分的内容见第 15 章。  
>  **维度灾难（curse of dimensionality）** 在第 10 章中介绍。

非正式地说，伪总体是通过对每个个体按其实际接受的治疗水平的条件概率的倒数（逆）进行加权而创建的。治疗 $A$ 的个体特异性 IP 权重定义为 $W^A = 1 / f(A \mid L)$ 。对于我们的二分类治疗 $A$ ，IP 权重的分母 $f(A \mid L)$ 是：对于戒烟者，是在测量混杂因素条件下戒烟的概率 $\mathrm{Pr}[A = 1 \mid L]$ ；对于非戒烟者，是在测量混杂因素条件下不戒烟的概率 $\mathrm{Pr}[A = 0 \mid L]$ 。我们只需要估计 $\mathrm{Pr}[A = 1 \mid L]$ ，因为 $\mathrm{Pr}[A = 0 \mid L] = 1 - \mathrm{Pr}[A = 1 \mid L]$ 。

在第 2.4 节中，我们非参数地估计了量 $\mathrm{Pr}[A = 1 \mid L]$ ：我们简单地统计了每个 $L$ 层中有多少人接受了治疗（ $A = 1$ ），然后将该计数除以该层中的个体数。计算所需的所有信息来自一个具有 4 个分支（2 个用于 $L$ 乘以 2 个用于 $A$ ）的因果解释结构树状图。但是，当像我们的例子中那样，我们有包含许多混杂因素的高维数据，其中一些因素有多个水平时，对 $\mathrm{Pr}[A = 1 \mid L]$ 进行非参数估计是不可能的。即使我们愿意将除年龄外的所有 9 个混杂因素重新编码为最多 6 个类别，我们的树仍然会有超过 200 万个分支。如果我们使用吸烟持续时间和强度以及体重的实际值范围，则分支数还会增加数百万。当 1566 个个体分布在数百万个层中时，我们无法获得有意义的非参数层特异性估计。我们需要诉诸建模。

为了在由 $L$ 定义的数百万个层中的每一个中获得 $\mathrm{Pr}[A = 1 \mid L]$ 的参数估计，我们拟合了一个戒烟概率的 **逻辑回归模型（logistic regression model）** ，将所有 9 个混杂因素作为协变量纳入。我们对（准）连续协变量年龄、体重、吸烟强度和持续时间使用了线性和二次项，并且没有在协变量之间纳入乘积项。也就是说，我们的模型限制了 $\mathrm{Pr}[A = 1 \mid L]$ 的可能值，使得在 logit 尺度上，连续协变量与戒烟风险之间的条件关系可以用抛物线曲线表示，并且每个协变量对（logit 变换后的）风险的贡献独立于其他协变量。在这些参数限制下，我们能够为每个 $L$ 值组合获得一个估计值 $\widehat{\mathrm{Pr}}[A = 1 \mid L]$ ，从而为研究人群中的 1566 个个体中的每一个获得该估计值。

下一步是计算由估计的 IP 权重创建的伪总体中的差异 $\widehat{\mathrm{E}}_{ps}[Y \mid A = 1] - \widehat{\mathrm{E}}_{ps}[Y \mid A = 0]$ 。如果在伪总体中 $A$ 的效应没有混杂，并且 $\mathrm{Pr}[A = 1 \mid L]$ 的模型是正确的，那么关联即为因果，并且伪总体中关联性差异 $\mathrm{E}_{ps}[Y \mid A = 1] - \mathrm{E}_{ps}[Y \mid A = 0]$ 的无偏估计量也是实际总体中因果差异 $\mathrm{E}[Y^{a = 1}] - \mathrm{E}[Y^{a = 0}]$ 的无偏估计量。

我们估计伪总体中 $\mathrm{E}_{ps}[Y \mid A = 1] - \mathrm{E}_{ps}[Y \mid A = 0]$ 的方法是拟合（饱和的）线性均值模型 $\mathrm{E}[Y \mid A] = \theta_0 + \theta_1 A$ ，使用 **加权最小二乘法（weighted least squares）** ，个体按其估计的 IP 权重 $\widehat{W}$ 加权：戒烟者为 $1 / \widehat{\mathrm{Pr}}[A = 1 \mid L]$ ，非戒烟者为 $1 / (1 - \widehat{\mathrm{Pr}}[A = 1 \mid L])$ 。

> 估计的 IP 权重 $\widehat{W}^A$ 范围从 1.05 到 16.7，其均值为 2.00。  
>  $\mathrm{E}[Y \mid A] = \theta_0 + \theta_1 A$ 是一个饱和模型，因为它有 2 个参数 $\theta_0$ 和 $\theta_1$ 来估计两个量 $\mathrm{E}[Y \mid A = 1]$ 和 $\mathrm{E}[Y \mid A = 0]$ 。在这个模型中， $\theta_1 = \mathrm{E}[Y \mid A = 1] - \mathrm{E}[Y \mid A = 0]$ 。

## 技术点 12.1（Technical Point 12.1）

**Horvitz-Thompson 估计量（Horvitz-Thompson estimators）。** 在技术点 3.1（Technical Point 3.1）中，我们定义了治疗水平 $a$ 的“表观”IP 加权均值：

$$
\operatorname{E} \left[ \frac{I(A = a) Y}{f(A \mid L)} \right]
$$

在 **正性（positivity）** 和 **可交换性（exchangeability）** 条件下，该值等于反事实均值 $\operatorname{E}[Y^a]$ 。这个 IP 加权均值由原始的 Horvitz-Thompson (1952) 估计量一致估计：

$$
\widehat{\operatorname{E}} \left[ \frac{I(A = a) Y}{f(A \mid L)} \right]
$$

其中 $\widehat{\operatorname{E}}$ 是样本平均算子， $f(A \mid L)$ 假设为已知。

然而，在本章中，我们通过 IP 加权最小二乘估计值 $\widehat{\theta}_0 + \widehat{\theta}_1 a$ 来估计 $\operatorname{E}[Y^a]$ ，对于二分类 $A$ ，这是一个修正的 Horvitz-Thompson 估计量，通常被称为 **Hájek 估计量（Hájek estimator）** （Hájek 1971）。

Hájek 估计量是以下量的（渐近）无偏估计量：

$$
\frac{\operatorname{E} \left[ \frac{I(A = a) Y}{f(A \mid L)} \right]}{\operatorname{E} \left[ \frac{I(A = a)}{f(A \mid L)} \right]}
$$

在正性条件下，该值等于 $\operatorname{E} \left[ \frac{I(A = a) Y}{f(A \mid L)} \right]$ ，因为 $\operatorname{E} \left[ \frac{I(A = a)}{f(A \mid L)} \right] = 1$ 。

在实践中，Hájek 估计量更受青睐，因为与 Horvitz-Thompson 估计量不同，对于二分类 $Y$ ，即使当 $f(A \mid L)$ 未知并被从错误指定模型拟合得到的预测值 $\hat{f}(A \mid L)$ 替代时，它也保证位于 0 和 1 之间。

另一方面，如果正性不成立，则该比值等于：

$$
\sum \operatorname{E} [Y \mid A = a, L = l, L \in Q(a)] \cdot \Pr[L = l \mid L \in Q(a)]
$$

并且，如果可交换性成立，则它等于 $\operatorname{E}[Y^a \mid L \in Q(a)]$ ，其中：

$$
Q(a) = \{l ; \Pr(A = a \mid L = l) > 0 \}
$$

是使得 $A = a$ 能够以正概率被观测到的取值 $l$ 的集合。

因此，正如技术要点 3.1 中所讨论的，在缺乏 **积极性（positivity）** 的情况下，取 $a = 1$ 与 $a = 0$ 的 **Hájek 估计量** 之间的差异 **不** 具有因果解释。在非积极性条件下， **Horvitz-Thompson 估计量** 的极限与 Hájek 估计量的极限之比不再是 1，而是 $\Pr[Q(a)]$ ，因为 Hájek 估计量的分母收敛于 $\Pr[Q(a)]$ 而非 1。

以 $W$ 为权重的 $\theta_0$ 和 $\theta_1$ 的加权最小二乘估计量 $\hat{\theta}_0^{\ \tiny \sim}$ 和 $\widehat{\theta}_1$ 是以下函数的最小化子：

$$
\sum_i \widehat{W}_i \left[ Y_i - (\theta_0 + \theta_1 A_i) \right]^2
$$

如果对所有个体 $i$ 都有 $\widehat{W}_i = 1$ ，则得到上一章所述的普通最小二乘估计量。

---

参数估计值 $\widehat{\theta}_1$ 为 **3.4** 。也就是说，我们估计戒烟平均会使体重增加 $\hat{\theta}_1 = 3.4 \ \mathrm{kg}$ 。关于该估计量的正式定义，请参见技术要点 12.1。

为了获得点估计值 $\hat{\theta}_1 = 3.4$ 周围的 **95% 置信区间** ，我们需要一种考虑 **逆概率加权（IP weighting）** 的方法。一种可能性是利用统计理论推导出相应的方差估计量。这种方法要求数据分析人员自行编写估计量的程序，而这在标准统计软件中通常无法直接获得。

第二种可能性是通过 **非参数自助法（nonparametric bootstrapping）** 来近似估计方差。对于大型数据库，这种方法需要充足的计算资源或极大的耐心。

第三种可能性是使用 **稳健方差估计量（robust variance estimator）** （例如，用于具有独立工作相关性的 **广义估计方程（GEE）** 模型中的方法），这是大多数统计软件包中的标准选项。基于稳健方差估计量的 95% 置信区间是有效的，但与上述分析法和自助法估计量不同，它是 **保守的** ——即其对超总体参数的覆盖率超过 95%。

$\widehat{\theta}_1$ 的保守 95% 置信区间为 **(2.4, 4.5)** 。在本章中，所有针对逆概率加权估计量的置信区间都是保守的。如果 $\Pr[A = 1 \mid L]$ 的模型被错误设定，则 $\theta_0$ 和 $\theta_1$ 的估计将存在偏倚，并且正如我们在上一章中讨论的，置信区间对真实值的覆盖率可能低于 95%。

## 12.3 稳定化逆概率权重（Stabilized IP weights）

逆概率加权的目标是创建一个 **伪总体（pseudo-population）** ，在该总体中协变量 $L$ 与处理 $A$ 之间不存在关联。在第 2 章中，我们展示了如何通过使用逆概率权重 $W^{A} = 1 / f(A | L)$ 将图 2.1 中的原始研究总体转换为图 2.3 中的伪总体。该伪总体的大小是原始研究总体的两倍，这反映了权重 $W^{A}$ 的平均值为 2。非正式地说，这些权重模拟了一个由原始研究总体的两个副本构成的伪总体，其中一个副本接受了处理，另一个未接受处理。

然而，还有其他方法可以创建一个 $A$ 与 $L$ 独立的伪总体。例如，一个伪总体中所有个体接受 $A = 1$ 的概率为 0.5，接受 $A = 0$ 的概率也为 0.5，与他们的 $L$ 值无关。这样的伪总体是通过使用逆概率权重 $0.5 / f(A | L)$ 构建的。这个伪总体的大小与研究总体相同，并且如果所有权重都除以 2，它在代数上等于上一段中描述的伪总体。因此，权重 $0.5 / f(A | L)$ 的期望均值为 1，并且由权重 $0.5 / f(A | L)$ 创建的伪总体中获得的效应估计值等于由权重 $1 / f(A | L)$ 创建的伪总体中获得的估计值（你可以使用图 2.1 中的数据对此进行实证检验，或参见技术要点 12.2 中的证明）。对于任何满足 $0 < p \leq 1$ 的逆概率权重 $p / f(A | L)$ ，情况也是如此。权重 $W^{A} = 1 / f(A | L)$ 只是 $p = 1$ 时逆概率权重的一个特例。

让我们进一步深入思考。进行 **混杂因素调整（confounding adjustment）** 的关键要求是，在伪总体中，处理 $A$ 的概率不依赖于混杂因素 $L$ 。我们可以通过为伪总体中的每个人分配相同的处理概率 $p$ 来满足这一要求。但我们也可以通过创建一个伪总体来实现，其中不同的人有不同的处理概率，只要处理概率不依赖于 $L$ 的值。例如，一个常见的选择是，为接受处理者分配其在原始总体中接受处理的概率 $\operatorname{Pr}[A = 1]$ ，而为未接受处理者分配其在原始总体中未接受处理的概率 $\operatorname{Pr}[A = 0]$ 。因此，逆概率权重对于接受处理者为 $\operatorname{Pr}[A = 1] / f(A | L)$ ，对于未接受处理者为 $\operatorname{Pr}[A = 0] / f(A | L)$ ，或者更简洁地表示为 $f(A) / f(A | L)$ 。

图 12.1 展示了将逆概率权重 $f(A) / f(A | L)$ 应用于图 2.1 中的数据时所创建的伪总体，其中 $\operatorname{Pr}[A = 1] = 13 / 20 = 0.65$ ， $\operatorname{Pr}[A = 0] = 7 / 20 = 0.35$ 。在第 3 章的可识别性条件下，这个伪总体类似于一个假设的随机化实验，其中研究总体中 65% 的个体被随机分配到 $A = 1$ ，35% 的个体被分配到 $A = 0$ 。请注意，为了保持 65/35 的比例，每个分支中的个体数不能是整数。幸运的是，在数学中，非整数个体并非大问题。

在我们的戒烟例子中，逆概率权重 $f(A) / f(A | L)$ 的范围是从 0.33 到 4.30，而逆概率权重 $1 / f(A | L)$ 的范围是从 1.05 到 16.7。

> 接受处理子总体中的 **平均因果效应（average causal effect）** 可以通过使用分子为 $\operatorname{Pr}[A = 1 | L]$ 的逆概率权重来估计。参见技术要点 4.1。

分子中的稳定化因子 $f(A)$ 导致了 $f(A) / f(A | L)$ 权重的范围更窄。逆概率权重 $W^{A} = 1 / f(A | L)$ 被称为 **非稳定化权重（nonstabilized weights）** ，而逆概率权重 $SW^{A} = f(A) / f(A | L)$ 被称为 **稳定化权重（stabilized weights）** 。稳定化权重的均值预期为 1，因为伪总体的大小等于研究总体的大小。

如果非稳定化和稳定化逆概率权重得到相同的估计值，那为什么还要使用稳定化逆概率权重呢？因为稳定化权重通常比非稳定化权重产生更窄的 95% 置信区间。然而，稳定化权重的统计优势仅当（逆概率加权）模型非饱和时才能体现。在我们上面的例子中，两参数模型 $\operatorname{E}[Y | A] = \theta_0 + \theta_1 A$ 是饱和的，因为处理 $A$ 只能取 2 个可能的值。在许多情况下（例如，时变处理或连续处理），加权模型不可能饱和，因此稳定化权重更受青睐。

## 精细要点 12.2

**检查积极性。** 在我们的研究中，有 4 名 66 岁的白人女性，她们都没有戒烟。也就是说， $A = 1$ 在（ $L$ 的子集）条件下的概率为 0。作为逆概率加权条件的积极性在经验上被违反了。积极性可能被违反的方式有两种：

- **结构性违反：** 第 3 章中描述的那种违反类型。具有某些 $L$ 值的个体不可能接受处理（或未接受处理）。例如：在估计接触某些化学品对死亡率的影响时，不上班是一个重要的混杂因素，因为不上班的人更可能生病和死亡，同时它也是化学品接触的一个决定因素——人们只有在工作时才能接触到化学品。也就是说，问题的结构决定了在处理条件为不上班时，处理概率恰好为 0（结构零）。当我们以该混杂因素为条件进行分层时，总会发现零单元格。
- **随机性违反：** 本精细要点第一段中描述的那种违反类型。我们的样本是有限的，因此，如果我们根据多个混杂因素进行分层，即使目标总体中的处理概率实际上并非为零，我们也会在某些地方开始发现零单元格。这是对积极性的随机性违反，而非结构性违反，因为零值在目标总体的不同样本中随机出现在不同位置。例如：我们的研究恰好包含了“66 岁白人女性”和“67 岁白人女性”这两个分层中接受处理人数为零的情况，但在“65 岁白人女性”和“69 岁白人女性”分层中则包含了正数的接受处理个体。

每种类型的积极性违反都有不同的后果。在存在结构性违反的情况下，不能使用逆概率加权或 **标准化（standardization）** 对整个总体进行因果推断。推断必须限制在结构性积极性成立的分层内。详情请参见技术要点 12.1。

在存在随机性违反的情况下，我们使用参数模型，利用来自其他分层中个体的数据来估计具有随机零值分层中的处理概率。换句话说，我们使用参数模型来平滑这些零值。例如，第 12.2 节中使用的逻辑回归模型通过插值研究中的所有其他个体，估计了 66 岁白人女性戒烟的概率。每当我们使用参数方法估计存在零单元格情况下的逆概率权重时——就像我们在估计 $\hat{\theta}_1 = 3.4$ 时所做的——我们实际上是在假设随机非积极性。此时使用稳定化权重。下一节将描述连续处理情况下稳定化权重的使用。

## 12.4 边际结构模型（Marginal Structural Models）

这是一个针对二分类处理 $A$ 的（饱和的） **边际结构均值模型（marginal structural mean model）** 。考虑如下关于处理水平 $a$ 下均值结局的线性模型：

$$
\operatorname{E}[Y^a] = \beta_0 + \beta_1 a
$$

这个模型与我们迄今为止描述的所有模型都不同：该模型的结局变量是 **反事实的（counterfactual）** ——因此通常是无法观测的。所以该模型无法适用于任何真实世界研究的数据。用于描述反事实结局边际均值的模型被称为 **边际结构均值模型** 。

**结构均值模型（structural mean models）** 中的处理参数对应于 **平均因果效应（average causal effects）** 。在上述模型中，参数 $\beta_1$ 等于 $\operatorname{E}[Y^{a=1}] - \operatorname{E}[Y^{a=0}]$ ，因为当 $a = 0$ 时， $\operatorname{E}[Y^a] = \beta_0$ ；当 $a = 1$ 时， $\operatorname{E}[Y^a] = \beta_0 + \beta_1$ 。在前几节中，我们估计了戒烟行为 $A$ 对体重变化 $Y$ 的平均因果效应，定义为 $\operatorname{E}[Y^{a=1}] - \operatorname{E}[Y^{a=0}]$ 。

**边际结构模型（marginal structural models）** 的一个理想特性是 **零效应保持性（null preservation）** （见第 9 章）：当无平均因果效应的零假设为真时，边际结构模型永远不会被错误设定。例如，在此零假设下，边际结构模型 $\operatorname{E}[Y^a] = \beta_0 + \beta_1 a + \beta_2 a^2$ 将被正确设定，其中 $\beta_1 = \beta_2 = 0$ ，且对于任意 $a$ 有 $\beta_0 = \operatorname{E}[Y^a]$ 。如果条件可交换性（conditional exchangeability）成立，则 $\operatorname{E}[Y] = \beta_0$ 。

换句话说，我们估计了边际结构模型的参数 $\beta_1$ 。具体来说，我们使用 **逆概率加权（IP weighting）** 构建了一个伪总体，然后通过 IP 加权最小二乘法，在伪总体数据上拟合模型 $\operatorname{E}[Y \mid A] = \theta_0 + \theta_1 A$ 。根据我们的假设，在伪总体中，关联即因果。也就是说，来自 IP 加权关联模型 $\operatorname{E}[Y \mid A] = \theta_0 + \theta_1 A$ 的参数 $\theta_1$ 可以被赋予与来自结构模型 $\operatorname{E}[Y^a] = \beta_0 + \beta_1 a$ 的参数 $\beta_1$ 相同的因果解释。因此，伪总体中关联参数的一致估计量 $\widehat{\theta}_1$ 也是总体中因果效应 $\beta_1 = \operatorname{E}[Y^{a=1}] - \operatorname{E}[Y^{a=0}]$ 的一致估计量。

边际结构模型 $\operatorname{E}[Y^a] = \beta_0 + \beta_1 a$ 是饱和的，因为戒烟行为 $A$ 是一个二分类处理变量。也就是说，该模型在方程两边各有 2 个未知数：左边是 $\operatorname{E}[Y^{a=1}]$ 和 $\operatorname{E}[Y^{a=0}]$ ，右边是 $\beta_0$ 和 $\beta_1$ 。因此，在伪总体中计算的样本均值足以估计我们关心的因果效应。

但处理变量通常是多分类的或连续的。例如，考虑一个新的处理变量 $A$ ——“吸烟强度的变化”，定义为 1982 年每天吸烟的数量减去基线时每天吸烟的数量。处理变量 $A$ 现在可以取许多值，例如，如果一个人每天吸烟数量减少了 25 支，则为 $-25$ ；如果一个人每天吸烟数量增加了 40 支，则为 40。假设我们有兴趣估计在基线时每天吸烟 25 支或更少的 1162 名个体中，不同处理强度变化下的平均体重变化差异。也就是说，我们想要估计任意值 $a$ 和 $a'$ 下的 $\operatorname{E}[Y^a] - \operatorname{E}[Y^{a'}]$ 。

由于处理变量 $A$ 可以取数十个值，一个具有同样多参数的饱和模型变得不切实际。我们将不得不考虑一个非饱和的结构模型来指定处理变量 $A$ 对平均结局 $Y$ 影响的剂量-反应曲线。如果我们认为抛物线恰当地描述了剂量-反应曲线，那么我们将提出以下边际结构模型：

$$
\operatorname{E}[Y^a] = \beta_0 + \beta_1 a + \beta_2 a^2
$$

其中 $a^{2} = a \times a$ 是 $a$ 的平方，且 $\operatorname{E}[Y^{a=0}] = \beta_{0}$ 是在 $a = 0$ 下的平均体重增加，即在基线与 1982 年之间吸烟强度没有变化的情况。

假设我们想要估计与无变化相比，每天吸烟强度增加 20 支的平均因果效应，即 $\mathrm{E}[Y^{a=20}] - \operatorname{E}[Y^{a=0}]$ 。根据我们的结构模型， $\operatorname{E}[Y^{a=20}] = \beta_{0} + 20\beta_{1} + 400\beta_{2}$ ，因此 $\operatorname{E}[Y^{a=20}] - \operatorname{E}[Y^{a=0}] = 20\beta_{1} + 400\beta_{2}$ 。现在我们需要估计参数 $\beta_{1}$ 和 $\beta_{2}$ 。

为此，我们需要估计 IP 权重 $SW^{A}$ ，以创建一个不存在 $L$ 所导致的混杂的伪总体，然后在伪总体数据上拟合关联模型 $\operatorname{E}[Y | A] = \theta_{0} + \theta_{1}A + \theta_{2}A^{2}$ 。

为了估计稳定化权重 $SW^{A} = f(A) / f(A | L)$ ，我们需要估计 $f(A | L)$ 。对于二分类处理变量 $A$ ， $f(A | L)$ 是一个概率，因此我们使用逻辑模型来估计 $\operatorname{Pr}[A = 1 | L]$ 。对于连续处理变量 $A$ ， $f(A | L)$ 是一个 **概率密度函数（probability density function, pdf）** 。不幸的是，概率密度函数通常很难估计，特别是当 $L$ 是高维且包含连续分量时，这就是为什么对连续处理变量使用 IP 加权常常是危险的原因。

在我们的例子中，我们假设密度 $f(A | L)$ 是正态（高斯）分布，其均值为 $\mu_{L} = \operatorname{E}[A | L]$ ，方差 $\sigma^{2}$ 恒定。然后我们使用线性回归模型来估计所有 $L$ 值组合下的均值 $\operatorname{E}[A | L]$ 和残差方差 $\sigma^{2}$ 。我们还假设分子中的密度 $f(A)$ 是正态分布。在对连续处理变量使用 IP 加权时应格外小心，因为效应估计可能对用于估计条件密度 $f(A | L)$ 的模型或算法的选择极其敏感。

## 12.5 效应修饰与边际结构模型（Effect modification and marginal structural models）

当目标参数是总体中的平均因果效应时，边际结构模型不包含协变量。然而，我们可以在边际结构模型中包含协变量（可能是非混杂因素）以评估 **效应修饰（effect modification）** 。假设戒烟的效果因性别 $V$ （0：男性，1：女性）而异。为了检验这一假设，我们将协变量 $V$ 添加到我们的边际结构均值模型中：

$$
\operatorname{E}[Y^{a} | V] = \beta_{0} + \beta_{1} a + \beta_{2} V a + \beta_{3} V
$$

参数 $\beta_{3}$ 通常不具有作为 $V$ 效应的因果解释。请记住，我们假设的是处理变量 $A$ 的可交换性、正性和一致性，而不是针对性别 $V$ 。

如果 $\beta_{2} \neq 0$ ，则存在 **加性效应修饰（additive effect modification）** 。从技术上讲，这不再是一个边际模型——因为它是基于 $V$ 的条件模型——但术语“边际结构模型”仍然适用。

我们可以通过 **加权最小二乘法（weighted least squares）** ，使用 IP 权重 $W^{A}$ 或 $SW^{A}$ 拟合线性回归模型

$$
\operatorname{E}[Y \mid A, V] = \theta_{0} + \theta_{1} A + \theta_{2} V A + \theta_{3} V
$$

来估计模型参数。在大多数情况下，协变量向量 $L$ 应包括 $V$ 。即使 $V$ 和 $A$ 在给定 $L$ 的其他分量时是独立的，并且不需要 $V$ 来确保可交换性，将 $V$ 包含在 $L$ 中通常也会提高估计边际结构模型参数的效率。

因为我们正在考虑一个关于 $V$ 各水平内处理效应的模型，我们现在可以选择在稳定化权重的分子中使用 $f[A]$ 或 $f[A \mid V]$ 。基于稳定化权重

$$
SW^{A}(V) = \frac{f[A \mid V]}{f[A \mid L]}
$$

的 IP 加权通常会导致效应估计的置信区间更窄。关于 $SW^{A}(V)$ 通常能提高统计效率的一些直觉是，权重 $SW^{A}(V)$ 的方差小于权重 $SW^{A}$ 的方差。我们使用与 $SW^{A}$ 相同的方法来估计 $SW^{A}(V)$ ，只是我们在权重分子的逻辑模型中添加了协变量 $V$ 。

在第一部分中，我们讨论了效应修饰和混杂是两个逻辑上不同的概念。尽管如此，许多学生难以理解它们的区别，因为相同的统计方法——分层（第 4 章）或回归（第 15 章）——常常同时用于混杂调整和效应修饰的检测。因此，使用边际结构模型来教授这些概念可能有一些优势，因为这样用于混杂调整的方法（IP 加权）与用于检测效应修饰的方法（向边际结构模型添加处理-协变量乘积项）是截然不同的。

## 12.6 删失与缺失数据（Censoring and missing data）

在估计戒烟 $A$ 对体重增加 $Y$ 的因果效应时，我们将分析限制在 1566 名在 1982 年随访结束时拥有体重测量值的个体。然而，另有 63 名符合我们纳入标准的个体因 1982 年的体重未知而被排除在分析之外。

正如第 8 章所讨论的，仅选择结局值未缺失的个体——即，从分析中删失那些具有缺失值的个体——可能会引入 **选择偏倚（selection bias）** 。

令删失 $C$ 为 1982 年体重测量的指示变量：如果体重未测量（即个体被删失），则为 1；如果体重已测量（即个体未被删失），则为 0。我们的分析必然限制在未删失的个体，即那些 $C = 0$ 的个体，因为只有这些个体的结局 $Y$ 值是已知的。也就是说，在第 12.2 和 12.4 节中，我们拟合的并不是（加权）结局回归模型 $\operatorname{E}[Y \mid A] = \theta_0 + \theta_1 A$ ，而是将模型 $\operatorname{E}[Y \mid A, C = 0] = \theta_0 + \theta_1 A$ 限制在 $C = 0$ 的个体上。

不幸的是，即使在零假设下，当 $C$ 要么是处理变量 $A$ 和结局 $Y$ 路径上的一个 **碰撞器（collider）** ，要么是此类碰撞器的后代时，仅选择未删失个体进行分析预计会引入偏倚。参见图 8.3 至 8.6 中的因果图。

我们的数据与这些因果图所描绘的结构一致：处理变量 $A$ 与删失 $C$ 相关——5.8% 的戒烟者与 3.2% 的非戒烟者被删失——并且至少一些 $Y$ 的预测因子与 $C$ 相关——删失个体的平均基线体重为 76.6 千克，而未删失个体为 70.8 千克。

用于删失和处理的 IP 权重为：

$$
W^{A,C} = 1 / f(A, C = 0 \mid L)
$$

其中 $A$ 和 $C$ 的联合密度被分解为：

$$
f(A, C = 0 \mid L) = f(A \mid L) \times \Pr[C = 0 \mid L, A]
$$

$L$ 中的某些变量在模型 $f(A \mid L)$ 中的系数可能为零，但在模型 $\Pr[C = 0 \mid L, A]$ 中则不然，反之亦然。尽管如此，在大样本中，将那些独立预测结局的所有变量 $L$ 保留在两个模型中总是更有效。

当模型 $\Pr[C = 0 \mid A]$ 被正确设定时，估计的 IP 权重 $SW^{C}$ 的均值为 1。有关稳定化 IP 权重的更多信息，请参见技术要点 12.2。

因为由于失访导致的删失会引入选择偏倚，我们通常感兴趣的是如果研究总体中没有人被删失时的因果效应。在我们的例子中，目标是估计如果每个人都戒烟并且没有人的结局被删失时的平均体重增加 $\operatorname{E}[Y^{a=1, c=0}]$ ，以及如果没有人戒烟并且没有人的结局被删失时的平均体重增加 $\operatorname{E}[Y^{a=0, c=0}]$ 。那么感兴趣的因果效应是：

$$
\operatorname{E}[Y^{a=1, c=0}] - \operatorname{E}[Y^{a=0, c=0}]
$$

这是 $A$ 和 $C$ 的联合效应，正如我们在第 8 章中讨论的那样。使用上标 $c = 0$ 明确了许多人在提及处理变量 $A$ 的因果效应时所想到的因果对照，即使他们选择不使用上标 $c = 0$ 。

这个因果效应可以通过使用 IP 权重 $W^{A,C} = W^{A} \times W^{C}$ 来估计，其中对于未删失个体 $W^{C} = 1 / \Pr[C = 0 \mid L, A]$ ，对于删失个体 $W^{C} = 0$ 。在联合处理变量 $(A, C)$ 关于 $L$ 的条件可交换性——即 $Y^{a, c=0} \perp\!\!\!\perp (A, C) \mid L$ ——联合正性对于 $(A = a, C = 0)$ ，以及一致性的可识别性条件下，IP 权重 $W^{A,C}$ 调整了混杂和选择偏倚。

如果 $L$ 中的某些变量受到处理变量 $A$ 的影响，如图 8.4 所示，条件独立性 $Y^{a, c=0} \perp\!\!\!\perp (A, C) \mid L$ 通常将不成立。在第三部分中，我们将展示存在替代的可交换性条件，当 $L$ 的某些分量受处理影响时，该条件允许我们使用 IP 加权来估计 $A$ 和 $C$ 的联合效应。

请记住，权重 $W^{C} = 1 / \Pr[C = 0 \mid L, A]$ 创建了一个与删失前原始研究总体大小相同的伪总体，并且在该伪总体中，没有从 $L$ 或 $A$ 指向 $C$ 的箭头。在我们的例子中，对删失的 IP 权重 $W^{C}$ 的估计将创建一个（大约）有 $1566 + 63 = 1629$ 个个体的伪总体，根据我们的假设，在该伪总体中没有选择偏倚，因为不存在选择。也就是说，我们用权重 $W^{A,C}$ 拟合加权模型 $\operatorname{E}[Y \mid A, C = 0] = \theta_0 + \theta_1 A$ ，以估计整个总体中边际结构模型 $\operatorname{E}[Y^{a, c=0}] = \beta_0 + \beta_1 a$ 的参数。

或者，可以使用稳定化 IP 权重 $SW^{A,C} = SW^{A} \times SW^{C}$ 。删失权重：

$$
SW^{C} = \Pr[C = 0 \mid A] / \Pr[C = 0 \mid L, A]
$$

创建了一个与删失后原始研究总体大小相同的伪总体，并且在该伪总体中，没有从 $L$ 指向 $C$ 的箭头。在我们的例子中，对删失的 IP 权重 $SW^{C}$ 的估计将创建一个（大约）有 1566 个未删失个体的伪总体。也就是说，稳定化权重并不消除伪总体中的删失；它们使删失相对于测量的协变量 $L$ 随机发生。因此，根据我们对删失和未删失个体在给定 $L$ （和 $A$ ）下条件可交换性的假设，伪总体中删失个体的比例与研究总体中的比例相同：存在选择，但不存在选择偏倚。

为了在我们的例子中获得 $\Pr[C = 0 \mid L, A]$ 的参数估计，我们对研究总体中的 1629 个个体拟合了一个关于未删失概率的逻辑回归模型。该模型包含了我们之前用于估计处理权重的相同协变量。在这些参数限制下，我们为 1566 个未删失个体中的每一个获得了估计值 $\widehat{\Pr}[C = 0 \mid L, A]$ 和 $SW^{C}$ 的估计值。使用稳定化权重 $SW^{A,C} = SW^{A} \times SW^{C}$ ，我们估计戒烟会增加体重。

## 技术要点 12.2（Technical Point 12.2）

更多关于稳定化权重。稳定化权重

$$
S W^{A} = \frac{f[A]}{f[A \mid L]}
$$

是属于更广泛的稳定化权重类别

$$
\frac{g[A]}{f[A \mid L]}
$$

的一部分，其中 $g[A]$ 是 $A$ 的任意函数，而不是 $L$ 的函数。当使用非饱和结构模型时，权重

$$
\frac{g[A]}{f[A \mid L]}
$$

优于权重

$$
\frac{1}{f[A \mid L]}
$$

因为存在某些函数 $g[A]$ （通常 $f[A]$ 是一个），可用于在非饱和边际结构模型中构建更有效的因果效应估计量。

尽管使用权重 $\frac{g[A]}{f[A \mid L]}$ 的 IP 加权均值

$$
\operatorname{E}\left[ \frac{g(A) I(A = a) Y}{f(A \mid L)} \right]
$$

在可交换性和正性下不再等于反事实均值 $\operatorname{E}[Y^{a}]$ ，但 IP 加权均值的 Hajek 版本

$$
\frac{\operatorname{E}\left[ \frac{g(A) I(A = a) Y}{f(A \mid L)} \right]}{\operatorname{E}\left[ \frac{g(A) I(A = a)}{f(A \mid L)} \right]}
$$

确实等于 $\operatorname{E}[Y^{a}]$ ，因为

$$
\operatorname{E}\left[ \frac{g(A) I(A = a) Y}{f(A \mid L)} \right] = g(a) \operatorname{E}\left[ \frac{I(A = a) Y}{f(A \mid L)} \right] = g(a) \operatorname{E}[Y^{a}]
$$

且

$$
\operatorname{E}\left[ \frac{g(A) I(A = a)}{f(A \mid L)} \right] = g(a).
$$

Hajek 均值是方程

$$
\operatorname{E}\left[ \frac{g[A]}{f[A \mid L]} (Y - u) \right] = 0.
$$

的解 $u$ 。

类似地，在最简单的边际结构模型

$$
\operatorname{E}[Y^{a}] = \beta_{0} + \beta_{1} a,
$$

中，使用权重 $\frac{g[A]}{f[A \mid L]}$ 的加权最小二乘估计量 $(\widehat{\beta}_{0}, \widehat{\beta}_{1})$ 求解估计方程

$$
\widehat{\operatorname{E}}\left\{\frac{g[A]}{f[A \mid L]} [Y - (\beta_{0} + \beta_{1} A)] \begin{pmatrix} 1 \\ A \end{pmatrix} \right\} = 0.
$$

$\operatorname{E}[Y^{0}]$ 的估计值 $\widehat{\beta}_{0}$ 和 $\operatorname{E}[Y^{1}]$ 的估计值 $\widehat{\beta}_{0} + \widehat{\beta}_{1}$ 正是加权均值的 Hajek 版本，其中期望被样本平均值取代。

最后，如同技术要点 2.2 中论证的那样，可以证明，在使用权重 $\frac{g[A]}{f[A \mid L]}$ 创建的伪总体中，给定 $A = a$ 时 $Y$ 的均值仍然等于 $\operatorname{E}[Y^{a}]$ 。
