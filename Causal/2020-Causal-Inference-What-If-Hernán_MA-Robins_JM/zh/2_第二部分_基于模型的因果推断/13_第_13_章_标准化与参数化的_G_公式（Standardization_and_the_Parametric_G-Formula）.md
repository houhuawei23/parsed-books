# 第 13 章 标准化与参数化的 G 公式（Standardization and the Parametric G-Formula）

在本章中，我们将描述如何使用 **标准化（standardization）** 来估计戒烟对体重增加的平均因果效应。我们使用与上一章相同的观测数据集。尽管标准化在第 2 章中已经介绍过，但我们仅将其描述为一种非参数方法。现在我们描述模型与标准化的结合使用，这将使我们能够处理包含多个协变量和非二分治疗的 **高维问题（high-dimensional problems）** 。与上一章一样，我们提供进行分析的计算机代码。

在实践中，研究者通常可以在 **逆概率加权（IP weighting）** 和标准化之间进行选择，作为从观测数据中获得效应估计的分析方法。这两种方法基于相同的可识别性条件，但基于不同的建模假设。

## 13.1 标准化作为逆概率加权的替代方法（Standardization as an alternative to IP weighting）

在上一章中，我们使用逆概率加权估计了戒烟 $A$ （1：是，0：否）对体重增加 $Y$ （以公斤为单位）的平均因果效应。在本章中，我们将使用标准化来估计相同的效应。我们的分析也将基于 **国家健康与营养检查调查（National Health and Nutrition Examination Survey, NHANES）** 数据，该数据来自 1629 名年龄在 25-74 岁之间、有基线访视和约 10 年后随访访视的吸烟者。其中，1566 人在随访访视时测量了体重，因此未被删失（ $C = 0$ ）。

我们定义 $\operatorname{E}[Y^{a, c = 0}]$ 为如果所有个体都接受了治疗水平 $a$ 并且没有个体被删失时将会观察到的平均体重增加。戒烟的 **平均因果效应（average causal effect）** 可以表示为差值 $\operatorname{E}[Y^{a = 1, c = 0}] - \operatorname{E}[Y^{a = 0, c = 0}]$ ，即如果所有人都接受了治疗且未被删失与所有人都未接受治疗且未被删失时将会观察到的平均体重之差。

如表 12.1 所示，戒烟者（ $A = 1$ ）和未戒烟者（ $A = 0$ ）在体重增加预测因子的分布上存在差异。观察到的关联性差异 $\operatorname{E}[Y \mid A = 1, C = 0] - \operatorname{E}[Y \mid A = 0, C = 0] = 2.5$ 预计将与因果差异 $\operatorname{E}[Y^{a = 1, c = 0}] - \operatorname{E}[Y^{a = 0, c = 0}]$ 不同。再次假设变量向量 $L$ 足以调整 **混杂（confounding）** 和 **选择偏倚（selection bias）** ，并且 $L$ 包括以下基线变量：性别（0：男性，1：女性）、年龄（岁）、种族（0：白人，1：其他）、教育程度（5 个类别）、吸烟强度和持续时间（每天吸烟支数和吸烟年数）、日常生活中的体力活动（3 个类别）、休闲运动（3 个类别）和体重（公斤）。

与上一章一样，我们将假设调整 $C$ 所需的 $L$ 的各分量不受 $A$ 的影响。否则，我们将需要使用第三部分中描述的更一般的方法。

调整变量 $L$ 的一种方法是 **逆概率加权（IP weighting）** ，该方法创建一个伪总体，在该伪总体中，处理组和未处理组中变量 $L$ 的分布相同。然后，在给定 $L$ 的可交换性和正性假设下，我们通过简单地计算伪总体中的 $\widehat{\mathrm{E}}[Y \mid A = a, C = 0]$ 来估计 $\operatorname{E}[Y^{a, c = 0}]$ 。如果 $A$ 是连续治疗（与我们的例子相反），我们还需要一个 **结构模型（structural model）** 来估计伪总体中所有可能的 $A$ 值的 $\operatorname{E}[Y \mid A, C = 0]$ 。

> **精细要点 13.1（Fine Point 13.1）**  
>  **结构性正性（Structural positivity）。** 缺乏结构性正性会阻碍使用逆概率加权识别整个总体中的平均因果效应。正性对于标准化也是必要的，因为当 $\operatorname{Pr}[A = a \mid L = l] = 0$ 且 $\operatorname{Pr}[\mathcal{L} = l] \neq 0$ 时，条件均值结果 $\operatorname{E}[Y \mid A = a, L = l]$ 是未定义的。
>
> 但是，偏离正性的实际影响在依赖于参数模型的逆概率加权估计和标准化估计之间可能有很大差异。在使用标准化时，如果愿意依赖参数外推，可以忽略正性的缺乏。也就是说，可以拟合一个 $\operatorname{E}[Y \mid A, L]$ 的模型，该模型将对具有结构性零值的层进行平滑处理。这种平滑会在估计中引入偏倚，因此估计值周围的标称 95%置信区间覆盖真实效应的次数将少于 95%的时间。此外，请注意在这种具有结构性正性的情况下建模的不同目的：我们建模不是因为我们缺乏足够的数据，而是因为我们想要估计一个即使拥有无限数据也无法识别的量（由于结构性非正性）。这是一个重要的区别。
>
> 一般来说，在存在违反或接近违反正性的情况下，标准化的治疗效应标准误将小于逆概率加权。这并不一定意味着标准化优于逆概率加权；偏倚的差异可能会淹没标准误的差异。
>
> 技术要点 2.3 证明，在条件可交换性、正性和一致性下，处理组的标准化均值等于如果所有人都接受治疗时的均值。对删失的扩展是简单的：只需在证明和定义中用 $(A = a, C = 0)$ 替换 $A = a$ 。
>
> 处理组中的平均因果效应可以通过技术要点 4.1 中描述的标准化来估计。只需将右侧表达式中的 $\operatorname{Pr}[L = l]$ 替换为 $\operatorname{Pr}[L = l \mid A = 1]$ 。

逆概率加权需要估计治疗和删失的联合分布。对于二分治疗戒烟，我们估计了 $\operatorname{Pr}[A = a, C = 0 \mid L]$ ，并用该联合概率作为分母计算了逆概率权重。

正如第 2 章所讨论的，逆概率加权的替代方法是标准化。在给定变量 $L$ 的条件可交换性和正性下，未删失处理组的标准化均值结果是对如果所有人都接受了治疗并保持未删失时的均值结果 $\operatorname{E}[Y^{a = 1, c = 0}]$ 的一致估计。类似地，未删失未处理组的标准化均值结果是对如果所有人都未接受治疗并保持未删失时的均值结果 $\operatorname{E}[Y^{a = 0, c = 0}]$ 的一致估计。关于正性偏离在逆概率加权和标准化中的相对影响的讨论，请参见精细要点 13.1。

为了计算未删失处理组的标准化均值结果，我们首先需要计算混杂因素 $L$ 的每个层 $\Delta l$ 中未删失处理组的均值结果，即每个层 $\Delta l$ 中的条件均值 $\operatorname{E}[Y \mid A = 1, C = 0, L = l]$ 。在我们的戒烟例子中，我们需要计算在由 $L$ 中 9 个变量的值组合定义的每个（可能有数百万个）层中，戒烟并保持未删失者的平均体重增加 $Y$ 。

然后，未删失处理组的标准化均值就是这些条件均值的加权平均，权重使用研究总体中每个值 $l$ 的 **流行率（prevalence）** ，即 $\operatorname{Pr}[L = l]$ 。也就是说，具有最多个体数的层的条件均值在标准化均值的计算中具有最大的权重。未删失未处理组的标准化均值以类似方式计算，只是条件事件中的 $A = 1$ 被替换为 $A = 0$ 。

更简洁地说，接受了治疗水平 $a$ 的未删失者的标准化均值为

$$
\sum_{l} \operatorname{E}[Y \mid A = a, C = 0, L = l] \times \Pr[L = l]
$$

当像我们的例子一样， $L$ 中的一些变量是连续变量时，需要将 $\operatorname{Pr}[L = l]$ 替换为 **概率密度函数（probability density function, pdf）** $f_L[l]$ ，上述求和将变为积分。

接下来的两节将描述如何估计结果变量 $Y$ 的条件均值和混杂因素 $L$ 的分布，这是估计标准化均值所需的两种量。

## 13.2 通过建模估计均值结果（Estimating the mean outcome via modeling）

理想情况下，我们会非参数地估计条件均值 $\operatorname {E} [ Y | A = 1 , C = 0 , L = l ]$ 的集合。我们将计算由变量 $L$ 的不同值组合定义的每个层中未删失处理组的平均结果。这正是我们在第 2.3 节中所做的，其中该计算所需的所有信息都来自表 2.2。

但是，当像我们当前的例子一样，我们拥有包含许多混杂因素的高维数据，其中一些具有多个水平时，对 $\operatorname {E} [ Y | A = 1 , C = 0 , L = l ]$ 进行非参数估计是不可能的。当只有 403 个处理个体分布在数百万个层中时，我们无法获得有意义的非参数层特异性处理组均值结果估计。我们需要求助于建模。同样的原理也适用于未删失未处理组的条件均值结果 $\operatorname {E} [ Y | A = 0 , C = 0 , L = l ]$ 。

为了获得由 $L$ 定义的数百万个层中每个层的 $\operatorname {E} [ Y | A = a , C = 0 , L = l ]$ 的参数估计，我们拟合了一个平均体重增加的 **线性回归模型（linear regression model）** ，将治疗 $A$ 和 $L$ 中的所有 9 个混杂因素作为协变量纳入。我们对（准）连续协变量年龄、体重、吸烟强度和吸烟持续时间使用了线性和二次项。也就是说，我们的模型限制了 $\operatorname {E} [ Y | A = a , C = 0 , L = l ]$ 的可能值，使得连续协变量与均值结果之间的条件关系可以用抛物线曲线表示。我们纳入了戒烟 $A$ 与吸烟强度之间的乘积项。也就是说，我们的模型施加了限制，即每个协变量对均值的贡献不依赖于其他协变量的贡献，除了戒烟 $A$ 的贡献随先前吸烟强度线性变化。

在这些参数限制下，我们获得了每个 $A$ 和 $L$ 值组合的估计值 ${\widehat {\mathrm {E}}} [ Y | A = a , C = 0 , L = l ]$ ，因此也获得了研究总体中 403 个未删失处理个体（ $A = 1 , C = 0$ ）和 1163 个未删失未处理个体（ $A = 0 , C = 0$ ）中每个个体的估计值。例如，我们估计具有值组合{未戒烟者、男性、白人、年龄 26 岁、大学辍学、每天 15 支烟、吸烟习惯 12 年、中度运动、非常活跃、体重 $\mathrm {1 1 2 ~ k g}$ }的个体的平均体重增加为 0.34 公斤（具有唯一标识符 24770 的个体恰好具有这些值组合，您可以查看他的预测值）。总体而言，估计体重增加的平均值为 2.6 公斤，与观测到的体重增加的平均值相同，观测到的体重增加在不同协变量组合下从 $- 4 1 . 3$ 到 48.5 公斤不等。

请记住，我们的目标是估计处理组（ $A = 1$ ）和未处理组（ $A = 0$ ）中的标准化均值

$$
\sum_{l} \operatorname {E} [ Y | A = a , C = 0 , L = l ] \times \mathrm {P r} [ L = l ]
$$

更正式地说，标准化均值应该写成积分形式，因为 $L$ 中的一些变量本质上是连续的，因此它们的分布不能用概率函数表示。无论这些符号问题如何，我们已经估计了所有治疗 $A$ 和混杂因素 $L$ 值的均值 $\operatorname {E} [ Y | A = a , C = 0 , L = l ]$ 。

一般来说， $Y$ 的标准化均值写为

$$
\int \operatorname {E} \left[ Y | A = a , C = 0 , L = l \right] d F_{L} \left( l \right)

其中 $F_{L} \left( \cdot \right)$ 是 $L$ 中随机变量的联合 **累积分布函数（cumulative distribution function, cdf）** 。当像本章中一样， $L$ 是不受治疗影响的基线协变量向量时，我们可以对 $L$ 的观测值进行平均，以非参数地估计该积分。

标准化均值是条件均值 $\operatorname{E}[Y \mid A = a, C = 0, L = l]$ 的加权平均。当 $L$ 中的所有变量都是离散变量时，每个均值获得的权重等于具有值 $L = l$ 的个体比例，即 $\operatorname{Pr}[L = l]$ 。

原则上，这些比例 $\operatorname{Pr}[\mathcal{L} = l]$ 可以从数据中非参数地计算：我们将由 $L = l$ 定义的层中的个体数除以总体中的总个体数。这正是我们在第 2.3 节中所做的，其中该计算所需的所有信息都来自表 2.2。然而，对于包含许多混杂因素的高维数据（其中一些具有多个水平），如我们的戒烟例子，这种方法变得繁琐。

幸运的是，我们不需要估计 $\operatorname{Pr}[\mathcal{L} = l]$ 。我们只需要为研究中每个个体 $i$ 的 $l$ 值估计 $\operatorname{E}[Y \mid A = a, C = 0, L = l]$ ，然后计算平均值

$$
\frac{1}{n} \sum_{i=1}^{n} \widehat{\operatorname{E}}[Y \mid A = a, C = 0, L_i]
$$

其中 $n$ 是研究中的个体数量。这是因为加权平均值

$$
\sum_{l} \operatorname{E}[Y \mid A = a, C = 0, L = l] \operatorname{Pr}[L = l]
$$

也可以写成 **双重期望（double expectation）**

$$
\operatorname{E}[\operatorname{E}[Y \mid A = a, C = 0, L]].
$$

我们现在描述一种简单的计算方法，用于在存在多个 **混杂因素（confounders）** 的情况下，估计 **处理组（treated）** ( $A = 1$ ) 和 **未处理组（untreated）** ( $A = 0$ ) 的标准化均值

$$
\sum_{l} \operatorname{E}[Y \mid A = a, C = 0, L = l] \times \operatorname{Pr}[L = l]
$$

而无需显式估计 $\operatorname{Pr}[L = l]$ 。我们首先将这种方法应用于表 2.2 的数据，其中没有删失，混杂因素 $L$ 仅是一个具有两个水平的变量，且 $Y$ 是一个二分类结局，即均值 $\operatorname{E}[Y \mid A = a, C = 0, L = l]$ 是发生结局的风险 $\operatorname{Pr}[Y = 1 \mid A = a, L = l]$ 。然后，我们将其应用于存在删失和多个混杂因素的真实数据。该方法包含 4 个步骤： **数据集扩展（expansion of dataset）** 、 **结局建模（outcome modeling）** 、 **预测（prediction）** 和 **通过平均进行标准化（standardization by averaging）** 。

表 2.2 有 20 行，每行对应研究中的一个个体。我们现在创建一个新数据集，将表 2.2 的数据复制三次。也就是说，分析数据集有 60 行，分为三个区块，每个区块 20 个个体。我们保持第一个 20 行的区块不变，即第一个区块与表 2.2 中的数据相同。我们修改第二个和第三个区块的数据，如边栏所示。在第二个区块中，我们将所有 20 个个体的 $A$ 值设为 0（未处理）；在第三个区块中，我们将所有个体的 $A$ 值设为 1（处理）。在第二个和第三个区块中，我们删除所有个体的结局数据，即变量 $Y$ 被赋值为缺失值。如下所述，我们将使用第二个区块来估计未处理组的标准化均值，使用第三个区块来估计处理组的标准化均值。

接下来，我们使用这个三区块数据集，针对给定的处理 $A$ 和混杂因素 $L$ ，拟合一个结局均值的回归模型。我们添加一个乘积项 $A \times L$ 以使模型饱和。请注意，只有数据集中第一个区块（实际数据）的行会对模型参数的估计有贡献，因为第二个和第三个区块中所有行的结局都是缺失的。

下一步是使用第一个区块的参数估计值来预测第二个和第三个区块中所有行的结局值。（也就是说，我们将列 $L$ 和 $A$ 的值与回归估计值结合起来，以 **插补（impute）** 结局 $Y$ 的缺失值。）第二个区块的预测结局值是 $L$ 和 $A = 0$ 各值组合的均值估计，第三个区块的预测值是 $L$ 和 $A = 1$ 各值组合的均值估计。

最后，我们计算第二个区块中所有预测值的平均值。由于 60% 的行具有 $L = 1$ 值，40% 的行具有 $L = 0$ 值，因此该平均值赋予了 $L = 1$ 的行更大的权重。也就是说，第二个区块中所有预测值的平均值正是未处理组的标准化均值结局。至此完成。要估计处理组的标准化均值结局，我们计算第三个区块中所有预测值的平均值。

上述过程得到的标准化均值估计值（两者均为 0.5）与第 2.3 节中的直接计算完全一致。两种方法都是完全 **非参数（nonparametric）** 的。在本章中，我们没有直接估计 $L$ 的分布，而是对 $L$ 的观测值求平均，即其 **经验分布（empirical distribution）** 。

在更现实的例子中，例如我们的戒烟研究，当 $L$ 是高维时，使用经验分布进行标准化是可行的方法。我们研究的程序与上述表 2.2 数据的程序类似。我们向数据集中添加第二个和第三个区块，按照前一节所述拟合 $\operatorname{E}[Y \mid A = a, C = 0, L = l]$ 的回归模型，并生成预测值。第二个区块的平均预测值——未处理组的标准化均值——为 1.66，第三个区块的平均预测值——处理组的标准化均值——为 5.18。因此，我们对因果效应

$$
\operatorname{E}[Y^{a=1, c=0}] - \operatorname{E}[Y^{a=0, c=0}]
$$

的估计值为 $5.18 - 1.66 = 3.5$ 公斤。为了获得该估计值的 95% 置信区间，我们使用了称为 **自助法（bootstrapping）** 的统计技术（参见技术要点 13.1）。总之，我们估计戒烟会使体重增加 3.5 公斤（95% 置信区间：2.6, 4.5）。

## 13.4 IP 加权还是标准化？（IP weighting or standardization?）

我们现在描述了两种使用建模来估计处理平均因果效应的方法： **IP 加权（IP weighting）** （上一章）和标准化（本章）。在我们的戒烟例子中，两者得出的效应估计值几乎完全相同。事实上，技术要点 2.3 证明了标准化均值等于 IP 加权均值。

那么，既然我们已经在上一章估计了 IP 加权均值，为什么还要在本章费心估计标准化均值呢？事实证明，只有当不使用任何模型来估计它们时，IP 加权均值和标准化均值才完全相等。否则，它们预计会有所不同。

为了理解这一点，请考虑实施 IP 加权或标准化时需要建模的量。

- **IP 加权** 对 $\operatorname{Pr}[A = a, C = 0 \mid L]$ 建模，我们在上一章中通过拟合 $\operatorname{Pr}[A = a \mid L]$ 和 $\operatorname{Pr}[C = 0 \mid A = a, L]$ 的 **参数逻辑回归模型（parametric logistic regression models）** 来估计它。
- **标准化** 对条件均值 $\operatorname{E}[Y \mid A = a, C = 0, L = l]$ 建模，我们在本章中使用 **参数线性回归模型（parametric linear regression model）** 来估计它。

在实践中，所有模型都不可避免地存在一定程度的 **错误设定（misspecification）** ，模型错误设定会引入一些 **偏倚（bias）** 。但是， **处理模型（treatment model）** （IP 加权）和 **结局模型（outcome model）** （标准化）的错误设定是不同的。

## 技术要点 13.1（Technical Point 13.1）

**自助法（Bootstrapping）。** 在第 10 章中，我们讨论了因果效应随机变异性的基础。效应估计值需要伴随 **标准误（standard error）** （或标准误的函数，如 $95\%$ 置信区间）等变异度量来呈现。由于获得精确估计值在计算上存在困难，在实践中，标准误估计通常基于 **大样本近似（large-sample approximations）** ，这依赖于渐近考量。然而，有时即使是大样本近似也过于复杂而难以计算。

自助法是估计标准误和计算 $95\%$ 置信区间的一种替代方法。我们在下面概述最简单的版本—— **非参数自助法（nonparametric bootstrap）** ，我们用它来计算戒烟效应估计值周围的 $95\%$ 置信区间。

以 1629 个个体的研究人群为例。从研究人群中 **有放回地抽样（sample with replacement）** 1629 个个体，这样一些原始个体可能出现多次，而另一些个体可能根本未被包含在内。这个大小为 1629 的新样本被称为一个“自助法样本”。计算自助法样本中感兴趣的效应（例如，使用正文中描述的标准化方法）。现在，再次通过有放回地抽样 1629 个个体来创建第二个自助法样本。使用与第一个自助法样本相同的方法计算第二个自助法样本中感兴趣的效应。由于偶然性，第一个和第二个自助法样本通常包含每个个体的不同副本数量，因此会产生不同的效应估计值。在大量（例如，1000 个）自助法样本中重复该过程。

事实证明，自助法样本中这 1000 个效应估计值的标准差能够一致地估计研究人群中效应估计值的标准误。然后使用通常的正态近似计算 $95\%$ 置信区间： $\pm 1.96$ 乘以标准误的估计值。关于自助法背后的统计理论介绍，请参见，例如，Wasserman (2004)。

我们使用这种具有 1000 个自助法样本的自助法方法，获得了正文中描述的标准化均值差的 $95\%$ 置信区间。自助法是一种适用于大样本的通用方法：通常，当估计量的极限分布是正态分布时，以估计量为中心、标准误由非参数自助法估计的 $95\%$ Wald 置信区间在大样本下将是校准的。因此，如果标准误由自助法估计，则来自边际结构模型的 IP 加权估计值的 $95\%$ Wald 置信区间将是校准的；但如果由之前描述的 **稳健方差估计量（robust variance estimator）** 的（平方根）估计，则通常会保守且更宽。

尽管非参数自助法是一种简单的方法，但对于非常大的数据集，它可能计算量很大。因此，常见到已发表的估计值仅基于 200–500 个自助法样本。虽然在我们的例子中，这种样本量的减少会得到几乎相同的置信区间，但情况并非总是如此。在保留自助法优势的同时克服这些计算挑战的一个更好方法是称为“小自助包（bag of little bootstraps）”（Kleiner et al. 2014）的巧妙方法。

---

通常，这不会导致效应估计值偏倚的幅度和方向相同。因此，由于不可避免的模型错误设定会对点估计值产生不同的影响，IP 加权估计值通常与标准化估计值不同。IP 加权估计值与标准化估计值之间的巨大差异将警示我们，至少其中一个估计值存在严重的模型错误设定。微小的差异并不能保证不存在严重的模型错误设定，但会令人感到放心——尽管逻辑上可能，但两种方法都因错误设定严重而导致偏倚幅度和方向相似的可能性不大。

在我们的戒烟例子中，IP 加权估计值和标准化估计值相似。四舍五入到一位小数后，由于戒烟导致的估计体重增加均为 3.5 公斤，无论我们是拟合处理 $A$ 的模型（IP 加权）还是结局 $Y$ 的模型（标准化）。在这两种情况下，我们都没有拟合混杂因素 $L$ 的模型，因为我们不需要混杂因素的分布来获得 IP 加权估计值，并且我们能够使用 $L$ 的经验分布（一种非参数方法）来计算标准化估计值。

> Robins (1986) 描述了标准化向 **时变处理与时变混杂因素（time-varying treatments and confounders）** 的推广，并将其命名为 ** $g$ -计算算法公式（ $g$ -computation algorithm formula）** 。由于这个名称非常长，一些作者将其缩写为 ** $g$ -公式（ $g$ -formula）** ，其他作者则缩写为 g-computation。尽管 g-formula 和 g-computation 是同义词，但本书仅使用前一个术语，因为后一个术语经常与第 14 章描述的不同方法 **g-估计（g-estimation）** 混淆。

IP 加权和标准化都是 **g-公式（g-formula）** 的估计量，g-公式是一种首次于 1986 年描述的因果推断通用方法。（第三部分在时变处理的设定下提供了 g-公式的定义。）我们说标准化是一个 **插件式（plug-in）** $g$ -公式估计量，因为它简单地将 g-公式中的条件均值结局替换为其估计值。当像本章这样，这些估计值来自参数模型时，我们将该方法称为 **参数 g-公式（parametric $g$ -formula）** 。由于我们这里只对平均因果效应感兴趣，我们参数化地估计了条件均值结局。

更一般地，用于 **概率密度函数（probability density function, pdf）** 的参数 g-公式需要估计在 $A$ 和 $L$ 各水平内结局的条件分布，以计算其标准化值。在没有时变混杂因素的情况下（参见第三部分），参数 g-公式不需要对混杂因素的分布进行参数建模。

通常没有必要在 IP 加权和参数 g-公式之间做出选择。当两种方法都可用来估计因果效应时，就同时使用这两种方法。此外，尽可能使用 **双重稳健（doubly robust）** 方法，这些方法在同一估计量中结合了处理模型和结局模型。在给定 $L$ 下的可交换性和正性条件下，如果处理模型或结局模型中的一个是正确的，则双重稳健估计量能够一致地估计平均因果效应，而无需知道两个模型中哪一个是正确的。一种特定的双重稳健估计量，即 **双重稳健插件估计量（doubly robust plugin estimator）** ，在要点 13.2 中讨论。第二种双重稳健估计量，即 **增广 IP 加权估计量（augmented IP weighted estimator）** ，在技术要点 13.2 中讨论。两者之间的数学关系在技术要点 13.3 中讨论。

最后，请注意我们使用参数 g-公式来估计整个目标人群的平均因果效应。如果我们对人群中特定子集的平均因果效应感兴趣，我们可以将计算限制在该子集上。例如，如果我们对性别可能产生的 **效应修饰（effect modification）** 感兴趣，我们将分别估计男性和女性的标准化均值。IP 加权和参数 g-公式都可用于估计整个人群或其子集的平均因果效应。

## 13.5 我们应如何认真对待我们的估计值？（How seriously do we take our estimates?）

我们在本书的第一部分回顾了平均因果效应的定义、估计所需的条件以及许多潜在的偏倚。讨论纯粹是概念性的，数据例子也过于简单化。一个关键信息是，当明确模拟一个（假设的）随机实验—— **目标试验（target trial）** 时，对观察性数据的因果分析会更加清晰。

本章和上一章中的分析是我们首次尝试从真实数据估计因果效应。使用 IP 加权和参数 g-公式，我们估计如果每个人都戒烟，平均体重增加将是 5.2 公斤，而如果没有人戒烟，则为 1.7 公斤。两种方法估计，在这个特定人群中，戒烟平均会使体重增加 3.5 公斤（95% 置信区间：2.5, 4.5）。在接下来的章节中，我们将看到，使用 **g-估计（g-estimation）** 、 **结局回归（outcome regression）** 和 **倾向评分（propensity scores）** 也会得到相似的估计值。

各种方法估计值的一致性令人感到放心，因为每种方法都依赖于不同的建模假设。

### 精细要点 13.2

**双重稳健的插件估计量（Doubly robust plug-in estimator）** 。前一章描述了 **逆概率加权（IP weighting）** ，该方法需要针对 **治疗 $A$ ** 在 **混杂因素 $L$ ** 条件下的正确模型。本章描述了 **标准化（standardization）** ，该方法需要针对 **结果 $Y$ ** 在 **治疗 $A$ ** 和 **混杂因素 $L$ ** 条件下的正确模型。那么，是否存在一种方法仅需要针对 **治疗 $A$ ** 或 **结果 $Y$ ** 其中一个模型正确即可？这正是 **双重稳健估计（doubly robust estimation）** 所实现的。

在通常的可识别性假设下，如果两个模型中至少有一个是正确的（且无需知道哪个模型正确）， **双重稳健估计量（doubly robust estimator）** 就能一致地估计因果效应。也就是说，双重稳健估计量给了我们两次获得正确结果的机会。

双重稳健估计量有多种类型。这里我们描述一种针对 **二分类治疗 $A$ ** 对 **结果 $Y$ ** 的平均因果效应的双重稳健估计量（Bang and Robins, 2005）。为简化起见，我们考虑无删失的情况。

要获得平均因果效应的双重稳健估计，首先按照前一章所述估计 **逆概率权重 $W^{A} = 1 / f \left( A | L \right)$ ** 。然后拟合一个如本章所述的结果回归模型——一个具有 **典型连接函数（canonical link）** 的 **广义线性模型（generalized linear model）** ——用于 $\operatorname{E}[Y | A, L, R]$ ，并添加协变量 $R$ ，其中如果 $A = 1$ 则 $R = W^{A}$ ，如果 $A = 0$ 则 $R = -W^{A}$ 。最后，使用将每个个体的 $A$ 设为 1 时的结果模型预测值，得到在 $A = 1$ 下的标准化平均结果估计值，再重复此过程但将 $A$ 设为 0，得到在 $A = 0$ 下的标准化平均结果估计值。这两个估计量之差即为平均因果效应的双重稳健插件估计量。

> **精细要点 13.1**  
> 基于结果回归的方法（包括双重稳健方法）可以在缺乏正性（positivity）的情况下使用，前提是假设结果模型被正确设定以推断超出数据范围的情况。

当这些估计值用于指导公共政策或临床医学中的决策时，数值估计对具体干预措施的依赖性是重要的（Hernán, 2016）。该方法的估计值基于不同的建模假设。然而，观察性效应估计总是容易受到严重质疑。

即使我们不想将效应估计值推广到其他人群（第 4 章），并且即使个体之间不存在干扰，我们针对目标人群的估计值的有效性也需要许多条件。我们将这些条件分为三类。

**第一** ，需要满足 **可交换性（exchangeability）** 、 **正性（positivity）** 和 **一致性（consistency）** 的可识别性条件（第 3 章），以使观察性研究类似于目标试验。戒烟者和非戒烟者需要在 9 个测量的协变量 $L$ 条件下可交换（见精细要点 14.2）。未测量的混杂（第 7 章）或选择偏倚（第 8 章，精细要点 12.2）会妨碍条件可交换性。正性要求戒烟者中协变量 $L$ 的分布与非戒烟者中的分布完全重叠。精细要点 13.1 讨论了偏离正性对非参数逆概率加权和标准化的不同影响。关于一致性，请注意戒烟（例如逐渐戒烟、突然戒烟）和不戒烟（例如每天增加 2 支香烟的吸烟强度、减少强度但不减至零）都存在多种版本。我们的效应估计对应于目标人群中一个有些模糊的假设干预，该干预以与研究人群中实际出现的相同频率随机分配这些治疗版本。其他假设干预可能导致不同的效应估计。

**第二** ，分析中使用的所有变量都需要被正确测量。治疗 $A$ 、结果 $Y$ 或混杂因素 $L$ 中的测量误差通常会导致偏倚（第 9 章）。在实践中，大多数变量存在一定程度的测量不准确是不可避免的。

**第三** ，分析中使用的所有模型都需要被正确设定（第 11 章）。假设治疗模型中连续协变量年龄的正确函数形式不是我们使用的抛物线曲线，而是由复杂多项式表示的曲线。那么，即使所有混杂因素都被正确测量并包含在 $L$ 中，逆概率加权也无法完全调整混杂。模型设定错误对混杂因素测量误差有类似的影响。

我们因果推断的有效性需要以下条件：

- 可交换性
- 正性
- 一致性
- 无测量误差
- 无模型设定错误

> **技术要点 7.3 和 7.4**  
> 在存在未测量混杂因素的情况下，替代的可识别性条件集是 **近端因果推断（proximal causal inference）** （技术要点 7.3）和 **前门准则（front door criterion）** （技术要点 7.4）。

确保这些条件中的每一个至少近似成立，是研究者最重要的任务。如果这些条件能够保证成立，那么数据分析就变得微不足道了。问题当然在于，我们永远不能期望这些条件中的任何一个会完美成立。未测量的混杂因素、非重叠的混杂因素分布、定义不明确的干预、测量不准确的变量以及设定错误的模型通常会潜伏在我们的估计值背后。其中一些问题可以通过实证方式解决，但其他问题仍将依赖于学科判断，因此容易受到无法被我们的数据反驳的批评。例如，我们可以提出不同的模型设定，但我们无法调整未测量的变量。

上述报告的效应估计值只有在所有这些（苛刻的）条件都成立时，才对戒烟的平均因果效应无偏。我们的研究与这些条件的偏离越大，我们的效应估计值可能越有偏。这些条件无法通过实证检验，因为我们缺乏反事实结果分布的数据。因此，在实践中，我们假设上述条件近似满足。我们的假设需要得到专家知识的支持，正如我们在第 7.6 节中针对因混杂导致的可交换性缺失所讨论的那样。

然而，专家知识是不完整的。因此，现有的专家知识通常与一系列条件兼容，从基本完美的可交换性（因为所有已知混杂因素都被测量）到中等程度的可交换性缺失（因为可能我们不知道某些混杂因素）。因此，在实践中，我们需要在不同的假设下进行分析，以探索我们的效应估计值对原始假设的敏感性。在本书中，我们提及针对混杂的 **敏感性分析（sensitivity analysis）** （见精细要点 7.1 中的引文），通过 **阴性结果对照（negative outcome controls）** （技术要点 7.5）和 **g-估计（g-estimation）** （精细要点 14.2），针对选择偏倚（精细要点 12.1），以及针对模型设定错误（第 11.5 节）。效应估计值对我们依赖不可验证条件的敏感性也可以通过 **定量偏倚分析（quantitative bias analysis）** （精细要点 10.2）来探索，或者有时通过使用替代的不可验证条件（如 **工具变量估计（instrumental variable estimation）** 所需的条件，见第 16 章）来探索。理想情况下，所有因果推断研究项目都应纳入敏感性分析。

对从观察性数据得出的因果推断保持健康的怀疑态度是必要的。要使这种怀疑态度富有成效，它需要基于关于我们假设有效性的专家知识。迈向不那么随意的因果推断的关键一步是认识到讨论应主要围绕上述每个假设展开。我们对待效应估计值的重视程度，应与赋予它们因果解释所需条件的重视程度相当。

## 技术要点 13.2

**增广逆概率加权估计量（Augmented IP weighted estimator）** 。假设我们有一个二分类治疗 $A$ 、一个结果 $Y$ 和一个满足正性和可交换性的测量变量向量 $L$ （假设一致性成立）。为简化起见，我们考虑在治疗条件下反事实平均结果的估计 $\operatorname{E}[Y^{a=1}]$ 而非因果效应。那么 $\operatorname{E}[Y^{a=1}]$ 可以写成：

- 一个插件 g $\mathrm{E}[b(L)]$ ，其中 $b(L) = \operatorname{E}[Y | A = 1, L]$ 。
- 或者 $\operatorname{E}\left[ \frac{A Y}{\pi(L)} \right]$ ，其中 $\pi(L) = \operatorname{Pr}[A = 1 | L]$ 。

在本章中，来自 $\frac{1}{n} \sum_{i=1}^{n} \hat{b}(L_i)$ 的估计值使用了一个（例如线性的）参数回归模型来估计 $b(L)$ ，并在研究中的所有 $n$ 个个体上求平均。在前一章中， $\frac{1}{n} \sum_{i=1}^{n} \frac{A_i Y_i}{\hat{\pi}(L_i)}$ 用一个（例如逻辑的）参数回归模型估计 $\pi(L)$ 来替代治疗概率，并在 $n$ 个个体上求平均。

如果估计值 $\hat{b}(L)$ 与 $b(L)$ 相差甚远，则插件 g-公式估计量的偏倚会很大；如果 $\hat{\pi}(L)$ 与 $\pi(L)$ 相差甚远，则逆概率加权估计量的偏倚会很大。 $\operatorname{E}[Y^{a=1}]$ 的双重稳健估计量恰当地结合了来自结果模型的估计值 $\hat{b}(L)$ 和来自治疗模型的估计值 $\hat{\pi}(L)$ 。

双重稳健估计量有多种形式，如精细要点 13.2 中描述的平均因果效应的估计量。所有双重稳健估计量都涉及通过一个包含治疗模型的函数对结果回归模型进行修正，这也可以看作是通过一个包含结果回归模型的函数对 **霍维茨-汤普森估计量（Horvitz-Thompson estimator）** 进行修正。例如，考虑以下 $\operatorname{E}[Y^{a=1}]$ 的双重稳健估计量：

$$
\widehat{\operatorname{E}}[Y^{a=1}]_{DR} = \frac{1}{n} \sum_{i=1}^{n} \left[ \widehat{b}(L_i) + \frac{A_i}{\widehat{\pi}(L_i)} \left(Y_i - \widehat{b}(L_i)\right) \right],
$$

这也可以写成：

$$
\frac{1}{n} \sum_{i=1}^{n} \left[ \frac{A_i Y_i}{\hat{\pi}(L_i)} - \left( \frac{A_i}{\hat{\pi}(L_i)} - 1 \right) \hat{b}(L_i) \right].
$$

受后一个公式的启发， $\widehat{\operatorname{E}}[Y^{a=1}]_{DR}$ 被称为 **增广逆概率加权估计量（augmented IP weighted estimator）** 。

在可交换性和正性条件下，如果估计值 $\hat{b}(L)$ 接近 $b(L)$ 或估计值 $\hat{\pi}(L)$ 接近 $\pi(L)$ ，则这个 $\operatorname{E}[Y^{a=1}]$ 的双重稳健估计量的偏倚很小。具体来说，差值 $\widehat{\operatorname{E}}[Y^{a=1}]_{DR} - \operatorname{E}[Y^{a=1}]$ 将依概率收敛于：

$$
\operatorname{E} \left[ \pi(L) \left(\frac{1}{\pi(L)} - \frac{1}{\pi^{*}(L)}\right) (b(L) - b^{*}(L)) \right],
$$

其中 $\pi^{*}(l)$ 和 $b^{*}(l)$ 分别是 $\hat{\pi}(l)$ 和 $\hat{b}(l)$ 的概率极限。由此可知，当参数结果模型正确时 [即 $b^{*}(l) = b(l)$ ] 或参数治疗模型正确时 [即 $\pi^{*}(l) = \pi(l)$ ]，我们的双重稳健估计量是（渐近）无偏的。此外，我们无需知道这两个模型中哪一个正确。

当然，如果向量 $L$ 的维度非常高，我们不会期望任何参数模型能被正确设定，因此即使是双重稳健估计量的偏倚也可能很大。然而，所有双重稳健估计量都具有这样的性质：偏倚取决于估计 $\frac{1}{\pi(l)}$ 时的误差 $\frac{1}{\pi(l)} - \frac{1}{\widehat{\pi}(l)}$ 与估计 $b(l)$ 时的误差 $b(l) - \hat{b}(l)$ 的乘积。

正如我们在第 18 章中讨论的，这一性质——被称为 **二阶偏倚（second-order bias）** ——使我们能够通过使用机器学习估计量而非标准参数模型来估计 $\pi(l)$ 和 $b(l)$ ，从而构建可能具有小偏倚的 $\operatorname{E}[Y^{a=1}]$ 的双重稳健估计量。这是因为，在可获得大量数据的高维设定中，基于复杂算法的机器学习估计量能比标准参数模型产生更精确的 $\pi(l)$ 和 $b(l)$ 估计值。

## 技术要点 13.3

**增广逆概率加权估计量与双重稳健插件估计量之间的关系** 。再次考虑反事实平均结果 $\operatorname{E}[Y^a] \equiv \psi_a$ ，并假设可识别性条件成立。那么， $\psi_a = \mathrm{E}[b(a, L)]$ ，其中 $b(a, L) = \operatorname{E}[Y \mid A = a, L]$ ；同时， $\psi_a = \mathrm{E}\left[\mathrm{I}(A = a) Y / f(a \mid L)\right]$ 。

如技术要点 13.2 所述，反事实平均结果 $\operatorname{E}[Y^a] \equiv \psi_a$ 的 **增广逆概率加权（AIPW）估计量** $\widehat{\psi}_{a, \text{AIPW}}$ 为：

$$
P_n \left[ \frac{\operatorname{I}(A = a) Y}{\widehat{f}(A \mid L)} - \left( \frac{\operatorname{I}(A = a)}{\widehat{f}(A \mid L)} - 1 \right) \widehat{b}(a, L) \right] = P_n \left[ \widehat{b}(a, L) + \operatorname{I}(A = a) \left\{Y - \widehat{b}(A, L) \right\} / \widehat{f}(A \mid L) \right]
$$

其中，对于任意 $H$ ， $P_n[H] \equiv \frac{1}{n} \sum_{i=1}^n H_i$ ，而 $\widehat{f}(a \mid L)$ 和 $\widehat{b}(a, L)$ 分别是 $f(a \mid L)$ 和 $b(a, L)$ 的估计量（Robins et al. 1994; Robins and Ritov 1997）。

该估计量是双重稳健的，因为：

- (i) 如果 $\widehat{f}(a \mid L)$ 是一致的，则上述等式左侧依概率收敛于 $\psi_a = \mathrm{E}\left[\mathrm{I}(A = a) Y / f(a \mid L)\right]$ ；且
- (ii) 如果 $\widehat{b}(a, L)$ 是一致的，则等式右侧收敛于 $\psi_a = \mathrm{E}[b(a, L)]$ 。

由此可知，平均因果效应 $\operatorname{E}[Y^1] - \operatorname{E}[Y^0] = \psi_1 - \psi_0$ 的 AIPW 估计量 $\widehat{\psi}_{1, \text{AIPW}} - \widehat{\psi}_{0, \text{AIPW}}$ 是双重稳健的，因为如果 (i) $\widehat{f}(a = 1 \mid L) = 1 - \widehat{f}(a = 0 \mid L)$ 是一致的，或者 (ii) $\widehat{b}(1, L)$ 和 $\widehat{b}(0, L)$ 都是一致的，则它是一致的。

现在我们有了双重稳健的 AIPW 估计量，如何获得精细要点 13.2 中的双重稳健插件估计量呢？从上述等式的右侧，我们有：

$$
\widehat{\psi}_{1, \text{AIPW}} - \widehat{\psi}_{0, \text{AIPW}} = P_n\left[ \widehat{b}(1, L) \right] - P_n\left[ \widehat{b}(0, L) \right] - P_n\left[ \frac{\left\{Y - \widehat{b}(A, L) \right\}}{\widehat{f}(A \mid L)} \left\{\mathrm{I}(A = 1) - \mathrm{I}(A = 0) \right\} \right].
$$

如果我们想要一个双重稳健的插件估计量 $P_n\left[ \widehat{b}(1, L) \right] - P_n\left[ \widehat{b}(0, L) \right]$ ，我们需要在每个样本中满足：

$$
P_n\left[ \frac{Y - \widehat{b}(A, L)}{\widehat{f}(A \mid L)} \left\{\mathrm{I}(A = 1) - \mathrm{I}(A = 0) \right\} \right] = 0.
$$

如果 $\widehat{b}(A, L) = b\left( A, L; \widehat{\beta}, \widehat{\theta} \right)$ 是以下模型的 **迭代重加权最小二乘（IRLS）** 估计值，则上述等式成立：

$$
\operatorname{E}[Y \mid A, L] = b\left( A, L; \beta, \theta \right) = \phi\left[ m(A, L; \beta) + \theta \left\{\frac{\mathrm{I}(A = 1) - \mathrm{I}(A = 0)}{\widehat{f}(A \mid L)} \right\} \right],
$$

其中 $\phi$ 是典型连接函数（如对数、逻辑或线性连接）的逆函数。这是因为上述等式是对应于参数 $\theta$ 的 **得分方程（score equation）** （Robins 1999; Bang and Robins 2005; Scharfstein et al. 1999）。

得到的插件估计量正是精细要点 13.2 中的估计量。该估计量是一种 **基于目标最小损失的估计量（TMLE）** ，也称为目标最大似然估计量，并且：

$$
\frac{\left\{\mathrm{I}(A = 1) - \mathrm{I}(A = 0) \right\}}{\widehat{f}(A \mid L)} = \frac{A}{\widehat{\pi}(\mid L)} - \frac{(1 - A)}{(1 - \widehat{\pi}(\mid L))}
$$

是 van der Laan 和 Rubin（2006）后来引入的术语中的“ **巧妙协变量（clever covariate）** ”。

存在不止一种模型选择可以确保上述显示的等式成立。例如，我们可以使用 $\operatorname{E}[Y \mid A, L]$ 的模型，将上述模型中的 $\theta$ 项替换为和：

$$
\theta_1 \frac{A}{\widehat{\pi}(\mid L)} + \theta_2 \frac{(1 - A)}{(1 - \widehat{\pi}(\mid L))}
$$

并估计 $\theta_1$ 和 $\theta_2$ （Scharfstein et al. 1999; Bang and Robins 2005）。后一种估计量也是 TMLE，但现在有两个巧妙协变量： $\frac{A}{\widehat{\pi}(\mid L)}$ 和 $\frac{(1 - A)}{(1 - \widehat{\pi}(\mid L))}$ 。

双巧妙协变量模型相对于单巧妙协变量模型的一个优点是， $P_n\left[ \widehat{b}(1, L) \right]$ 和 $P_n\left[ \widehat{b}(0, L) \right]$ 现在也分别是 $\operatorname{E}[Y^{a=1}]$ 和 $\mathrm{E}[Y^{a=0}]$ 的双重稳健插件估计量，而 $P_n\left[ \widehat{b}(1, L) \right] - P_n\left[ \widehat{b}(0, L) \right]$ 仍然是平均治疗效应的双重稳健估计量。
