# 第 20 章 治疗-混杂反馈（TREATMENT-CONFOUNDER FEEDBACK）

上一章将 **序贯可交换性（sequential exchangeability）** 确定为识别时变治疗因果效应的关键条件。假设我们有一项研究，其中最强形式的序贯可交换性成立：测量的时变混杂因子足以有效估计任何治疗策略的因果效应。那么问题就变成了使用哪种混杂调整方法。这个问题的答案凸显了时变治疗因果推断中的一个关键问题： **治疗-混杂反馈（treatment-confounder feedback）** 。

当存在治疗-混杂反馈时，使用传统的调整方法可能会在效应估计中引入偏倚。也就是说，即使我们拥有有效估计任何治疗策略的平均因果效应所需的所有信息，我们通常也无法做到这一点。本章描述了治疗-混杂反馈的结构以及传统调整方法失败的原因。

图 20.1 中的因果图（与图 19.2 相同）代表了研究的前两个月。时变协变量 $L_k$ 是时变混杂因子。（与上一章一样，我们在此示例中假设没有删失，以便专注于混杂问题。）

图 20.1 中还发生了其他事情。不仅存在从 CD4 细胞计数 $L_k$ 到治疗 $A_k$ 的箭头，还存在从治疗 $A_{k-1}$ 到未来 CD4 细胞计数 $L_k$ 的箭头——因为接受治疗 $A_{k-1}$ 会增加未来的 CD4 细胞计数 $L_k$ 。也就是说，混杂因子影响治疗，治疗也影响混杂因子。这就存在 **治疗-混杂反馈** （另见细节点 20.1）。

请注意，时变混杂可以在没有治疗-混杂反馈的情况下发生。图 20.2 中的因果图与图 20.1 相同，只是删除了从治疗 $A_{k-1}$ 到未来 $L_k$ 和 $U_k$ 的箭头。在此图所代表的场景中，时变协变量 $L_k$ 是时变混杂因子，但它们不受先前治疗的影响。因此，存在时变混杂，但不存在治疗-混杂反馈。

治疗-混杂反馈为因果推断带来了一个有趣的问题。为了以最简单的形式陈述这个问题，让我们进一步简化图 20.1 中的因果图。图 20.3 是图 20.1 的最小子集，它说明了具有两个时间点的序贯随机试验中的治疗-混杂反馈。在绘制图 20.3 中的因果图时，我们做了四个简化：

由于我们的兴趣在于 $L_1$ 混杂的影响，我们未费心纳入基线 CD4 细胞计数的节点 $L_0$ 。只需假设治疗 $A_0$ 是边际随机化的，而治疗 $A_1$ 是在给定 $L_1$ 条件下的随机化。

未测量变量 $U_0$ 未被包含在内。

从 $A_0$ 到 $A_1$ 没有箭头，这意味着治疗的分配仅使用 $L_1$ 的信息。

从 $A_0$ 、 $L_1$ 和 $A_1$ 到 $Y$ 没有箭头，如果治疗对任何个体的结局 $Y$ 没有因果效应，即 **尖锐零假设（sharp null hypothesis）** 成立，就会出现这种情况。

这些简化都不会影响下面的论证。一个更复杂的因果图不会为本节的讨论增加任何概念上的洞见；它只会更难阅读。

现在假设治疗对任何个体的 $Y$ 都没有效应，这意味着图 20.3 中的因果图是正确的，但研究者并不知道这一点。还假设我们有关于第 0 月的治疗 $A_{0}$ 和第 1 月的治疗 $A_{1}$ 、第 1 月初的混杂因素 CD4 细胞计数 $L_{1}$ 以及随访结束时的结局 $Y$ 的数据。

我们希望使用这些数据来估计静态治疗策略“始终治疗”（ $a_{0} = 1, a_{1} = 1$ ）相比于静态治疗策略“从不治疗”（ $a_{0} = 0, a_{1} = 0$ ）对结局 $Y$ 的平均因果效应，即：

$$
\mathrm{E} \left\lfloor Y^{a_{0}=1, a_{1}=1} \right\rfloor - \mathrm{E} \left\lfloor Y^{a_{0}=0, a_{1}=0} \right\rfloor.
$$

根据图 20.3，真实但研究者未知的平均因果效应为 0，因为从任何一个治疗变量到结局都没有前向路径。也就是说，不能从 $A_{0}$ 或 $A_{1}$ 出发，沿着箭头方向到达 $Y$ 。

图 20.3 可以描述一个 **序列随机试验（sequentially randomized trial）** ，因为没有从未测量的 $U$ 到治疗变量的直接箭头。因此，正如我们在前一章讨论的，我们应该能够使用 $A_{0}$ 、 $L_{1}$ 、 $A_{1}$ 和 $Y$ 的观测数据得出结论：

$$
\mathrm{E} \left\lfloor Y^{a_{0}=1, a_{1}=1} \right\rfloor - \mathrm{E} \left\lfloor Y^{a_{0}=0, a_{1}=0} \right\rfloor
$$

等于 0。然而，正如我们在下一节中解释的，当我们使用传统方法（如分层、结局回归和匹配）调整 $L_{1}$ 时，通常无法正确估计因果效应。也就是说，在此示例中，尝试使用这些方法调整混杂因素 $L_{1}$ 通常会导致效应估计值不同于 0，因此是无效的。

图 20.3 表示一个序列随机试验或一个没有未测量混杂的观察性研究；图 20.4 表示一个观察性研究。

换句话说，当存在时依混杂因素和治疗-混杂因素反馈时，传统方法无法用于正确调整这些混杂因素。即使我们有足够的纵向数据来确保 **序列可交换性（sequential exchangeability）** ，传统方法通常也无法提供任何治疗策略因果效应的有效估计。相比之下， **g-方法（g-methods）** 即使在存在治疗-混杂因素反馈的情况下，也能适当地调整时依混杂因素。

传统方法的这种局限性适用于时依混杂因素受先前治疗影响的情况（如图 20.3 所示），也适用于时依混杂因素与先前治疗共享原因 $W$ 的情况（如图 20.4 所示，它是图 19.4 的子集）。我们将图 20.3 和图 20.4（以及图 19.2 和图 19.4）都称为治疗-混杂因素反馈的示例。下一节将解释为什么传统方法无法充分处理治疗-混杂因素反馈。

如果存在额外的时间点 $k$ ，使得治疗 $A_k$ 受 $L_k$ 影响，那么 $L_k$ 将是一个 **时依混杂因素（time-varying confounder）** 。图 20.3 表示零假设，因为从 $L_1$ 到 $Y$ 没有箭头。否则， $A_0$ 将通过 $L_1$ 对 $Y$ 产生效应。

为了说明传统方法的偏倚，让我们考虑一个（假设的）序列随机试验，包含 32,000 名 HIV 感染者，以及两个时间点 $k = 0$ 和 $k = 1$ 。治疗 $A_0 = 1$ 在基线以 0.5 的概率随机分配。治疗 $A_1$ 在第 1 个月随机分配，其概率仅取决于第 1 月初的 CD4 细胞计数 $L_1$ 的值——如果 $L_1 = 0$ （高），则为 0.4；如果 $L_1 = 1$ （低），则为 0.8。结局 $Y$ 在随访结束时测量，是 CD4 细胞计数、血清病毒浓度和其他临床指标的函数， $Y$ 的值越高表示健康状况越好。

表 20.1 显示了该试验的数据。为节省空间，该表按 $A_0$ 、 $L_1$ 和 $A_1$ 值的每种组合显示一行，而不是每个个体一行。对于八种组合中的每一种，该表提供了受试者数量 $N$ 和结局的均值 $\operatorname{E}[Y \mid A_0, L_1, A_1]$ 。因此，第 1 行显示， $(A_0 = 0, L_1 = 0, A_1 = 0)$ 的 2400 个个体的均值为 $\operatorname{E}[Y \mid A_0 = 0, L_1 = 0, A_1 = 0] = 84$ 。

在这个序列随机试验中， **可识别性条件（identifiability conditions）** ——序列可交换性、正性、一致性——成立。根据设计， $A_0$ 对 $Y$ 的效应没有混杂因素，而 $L_1$ 是 $A_1$ 对 $Y$ 效应的唯一混杂因素，因此（在给定 $L_1$ 的条件下）序列可交换性成立。通过检查表 20.1，我们可以得出结论，正性条件得到满足，因为否则八行中的一行或多行将会有零个个体。

快速检查该表显示，治疗 $A_1$ 的平均因果效应在由 $A_0$ 和 $L_1$ 定义的所有四个层中确实为零。考虑 $A_0 = 0$ 和 $L_1 = 0$ 的 4000 个个体中 $A_1$ 的效应，其数据显示在表 20.1 的第 1 行和第 2 行。在第 1 个时间点未接受治疗的个体中的平均结局 $\operatorname{E}[Y \mid A_0 = 0, L_1 = 0, A_1 = 0]$ 为 84，而在第 1 个时间点接受治疗的个体中的平均结局

> #### 技术要点 20.1
>
> G-零检验。假设尖锐零假设为真。那么任何反事实结局 $Y^g$ 就是观测到的结局 $Y$ 。在此设定下，所有 $Y^g$ 的序列可交换性可以写作 $Y \bot A_0 \mid L_0$ 和 $Y \bot \bot A_1 \mid A_0, L_0, L_1$ （在一个有两个时间点的研究中）。（我们使用了这样一个事实：对于任何 $a_0$ 和 $l_0$ 的值，存在策略 $g$ 使得 $a_0 = g(l_0)$ 。）因此，在序列可交换性下，对这些条件独立性的检验就是对尖锐零假设的检验。这就是 $\mathsf{g}$ -零检验（G-null test）（Robins 1986）。注意，第一个独立性意味着 $A_0$ 在任何由 $L_0$ 定义的层中没有因果效应，第二个独立性意味着 $A_1$ 在任何由 $L_1$ 和 $A_0$ 定义的层中没有因果效应。
>
> 更一般地，Robins (1986) 的 $\mathsf{g}$ -零定理指出，在对于所有 $g$ 的序列随机化下，当且仅当 $Y^g$ 的分布以及因此均值 $\operatorname{E}[Y^g]$ 对于所有 $g$ 都相同，并且也等于观测到的 $Y$ 的分布和均值时，上述两个独立性才成立。

$$
\begin{array}{c}
\text{加权平均为} \\
\frac{2400}{16000} \times 84 + \frac{1600}{16000} \times 84 + \\
\frac{2400}{16000} \times 52 + \frac{9600}{16000} \times 52 = 60
\end{array}
$$

$\operatorname{E}[Y \mid A_0 = 0, L_1 = 0, A_1 = 1]$ 也是 84。因此，差值

$$
\operatorname{E}[Y \mid A_0 = 0, L_1 = 0, A_1 = 1] - \operatorname{E}[Y \mid A_0 = 0, L_1 = 0, A_1 = 0]
$$

为零。由于可识别性条件成立，这个关联性差异有效估计了层 $(A_0 = 0, L_1 = 0)$ 中的平均因果效应

$$
\operatorname{E}[Y^{a_1 = 1} \mid A_0 = 0, L_1 = 0] - \operatorname{E}[Y^{a_1 = 0} \mid A_0 = 0, L_1 = 0].
$$

类似地，通过分别比较第 3 行和第 4 行、第 5 行和第 6 行、第 7 行和第 8 行之间的平均结局，可以很容易地检查出治疗 $A_1$ 对 $Y$ 的平均因果效应在其余三个层 $(A_0 = 0, L_1 = 1)$ 、 $(A_0 = 1, L_1 = 0)$ 、 $(A_0 = 1, L_1 = 1)$ 中也为零。

我们现在可以证明 $A_0$ 的平均因果效应也为零。为此，我们需要计算关联性差异 $\operatorname{E}[Y \mid A_0 = 1] - \operatorname{E}[Y \mid A_0 = 0]$ ，由于随机化，该差异是因果对比 $\operatorname{E}[Y^{a_0 = 1}] - \operatorname{E}[Y^{a_0 = 0}]$ 的有效估计量。在第 0 个时间点接受治疗的 $16,000$ 个个体的平均结局 $\operatorname{E}[Y \mid A_0 = 0]$ 是第 1、2、3 和 4 行中平均结局的加权平均值，为 60。而 $\operatorname{E}[Y \mid A_0 = 1]$ ，类似计算，也是 60。因此， $A_0$ 的平均因果效应为零。

我们已经确认，当我们将 $A_0$ 和 $A_1$ 分别视为时间固定治疗时， $A_0$ 和 $A_1$ （在给定过去的条件下）的因果效应为零。现在，如果我们将联合治疗 $(A_0, A_1)$ 视为一个时依治疗并比较两种治疗策略，会怎样？例如，假设我们想比较策略“始终治疗”与“从不治疗”，即 $(a_0 = 1, a_1 = 1)$ 与 $(a_0 = 0, a_1 = 0)$ 。由于可识别性条件成立，表 20.1 中的数据应足以有效估计此效应。

由于策略的每个单独组成部分 $a_0$ 和 $a_1$ 的效应为零，根据 g-零定理（见技术要点 20.1），平均因果效应 $\operatorname{E}[Y^{a_0 = 1, a_1 = 1}] - \operatorname{E}[Y^{a_0 = 0, a_1 = 0}]$ 为零。但是，如果我们使用常规分析方法，这是我们从数据中得出的结论吗？为了回答这个问题，让我们进行两项数据分析。在第一项分析中，我们不调整混杂因素 $L_1$ ，这应该会给我们一个不正确的效应估计。在第二项分析中，我们通过分层来调整混杂因素 $L_1$ 。

1. 我们比较在两个时间点都接受治疗的 9600 个个体（表 20.1 的第 6 行和第 8 行）的平均结局与在两个时间点都未接受治疗的 4800 个个体（第 1 行和第 3 行）的平均结局。各自的平均值分别为 $\operatorname{E}[Y \mid A_0 = 1, A_1 = 1] = 54.7$ ，和 $\operatorname{E}[Y \mid A_0 = 0, A_1 = 0] =$

$$
\begin{aligned}
\operatorname{E}[Y \mid A_0 = 1, A_1 = 1] & = \frac{3200}{9600} \times 76 + \frac{6400}{9600} \times 44 = 54.7 \\
\operatorname{E}[Y \mid A_0 = 0, A_1 = 0] & = \frac{2400}{4800} \times 84 + \frac{2400}{4800} \times 52 = 68.0
\end{aligned}
$$

注意，由于在 $L_1$ 的两个层中效应均为 $10^{-8}$ ，因此层特异性效应的加权平均不可能得到正确值 0.68。关联性差异为 $54.7 - 68 = -13.3$ ，如果从因果角度解释，这意味着在两个时间点均不接受治疗比在两个时间点均接受治疗更好。该分析给出了错误答案——一个非零差异——因为 $\operatorname{E}[Y \mid A_0 = a_0, A_1 = a_1]$ 不是 $\operatorname{E}[Y^{a_0, a_1}]$ 的有效估计量。需要对混杂因素 $L_1$ 进行调整。

2. 我们通过分层（stratification）对 $L_1$ 进行调整。也就是说，我们在 $L_1$ 的各层内，比较在两个时间点均接受治疗的个体与均未接受治疗的个体的平均结局。例如，以 $L_1 = 0$ 层为例。在两个时间点均接受治疗的个体的平均结局 $\operatorname{E}[Y \mid A_0 = 1, L_1 = 0, A_1 = 1]$ 为 76（第 6 行）。在两个时间点均未接受治疗的个体的平均结局 $\operatorname{E}[Y \mid A_0 = 0, L_1 = 0, A_1 = 0]$ 为 84（第 1 行）。关联性差异为 $76 - 84 = -8$ ，如果从因果角度解释，这意味着在 $L_1 = 0$ 层中，在两个时间点均不接受治疗比在两个时间点均接受治疗更好。

类似地，在 $L_1 = 1$ 层中，差异 $\operatorname{E}[Y \mid A_0 = 1, L_1 = 1, A_1 = 1] - \operatorname{E}[Y \mid A_0 = 0, L_1 = 1, A_1 = 0]$ 也为 $-8$ 。

怎么回事？我们说过效应估计应为 0，而非 $-8$ 。为什么调整了混杂因素的分析也给出了错误答案？该估计反映了在存在 **治疗-混杂因素反馈（treatment-confounder feedback）** 时，传统方法调整混杂的偏差。下一节将解释偏差产生的原因。

## 20.3 传统方法为何失败（Why Traditional Methods Fail）

表 20.1 展示了一个存在治疗-混杂因素反馈的 **序贯随机试验（sequentially randomized trial）** 的数据，如图 20.3 的因果图所示。尽管没有未测量变量 $U_1$ （免疫抑制水平）的数据，但所有三个可识别性条件均成立：如果我们有混杂因素 $L_1$ 的数据，则不需要 $U_1$ 。因此，如第 19 章所述，我们应该能够正确估计涉及任何静态或动态治疗策略的因果效应。然而，我们在上一节中的分析，无论是否调整 $L_1$ ，均未得到正确答案。

问题在于我们没有使用正确的方法来调整混杂。分层是一种常用的调整混杂的方法，但它无法处理治疗-混杂因素反馈。分层意味着在由混杂因素（本例中为 $L_1$ ）定义的研究人群子集（层）中估计治疗与结局之间的关联。由于变量 $L_1$ 只能取两个值——如果 CD4 细胞计数低则为 1，否则为 0——本例中存在两个这样的层。为了估计 $L_1 = l$ 的个体中的因果效应，我们选择了（即条件于或分层于）值为 $L_1 = l$ 的人群子集。

但是，当在由先前治疗 $A_0$ 引起的变量 $L_1$ 的各层内计算关联度量时，分层可能产生非预期效应。事实上，图 20.5 显示，对 $L_1$ （一个碰撞因子（collider））条件化打开了路径 $A_0 \longrightarrow L_1 \longleftarrow U_1 \longrightarrow Y$ 。也就是说，在 $L_1$ 的各层内，分层诱导了时间 0 的治疗 $A_0$ 与未测量变量 $U_1$ 之间的非因果关联，进而诱导了 $A_0$ 与结局 $Y$ 之间的非因果关联。在 CD4 计数低（ $L_1 = 1$ ）的个体中，接受治疗（ $A_0 = 1$ ）成为严重免疫抑制（ $U_1$ 高值）的标志；在 CD4 水平高（ $L_1 = 0$ ）的个体中，未接受治疗（ $A_0 = 0$ ）成为较轻免疫抑制（ $U_1$ 低值）的标志。因此，分层的副作用是诱导了治疗 $A_0$ 与结局 $Y$ 之间的关联。

### 精要 20.2（Fine Point 20.2）

**因果路径上的混杂因素（Confounders on the causal pathway）。** 对受先前治疗影响的混杂因素 $L_1$ 条件化可能产生 **选择偏倚（selection bias）** ，即使该混杂因素不在治疗与结局之间的因果路径上。事实上，在图 20.5 和 20.6 中并不存在这样的因果路径。

另一方面，在图 20.7 中，后续治疗 $A_1$ 的混杂因素 $L_1$ 位于从早期治疗 $A_0$ 到结局 $Y$ 的因果路径上，即路径 $A_0 \longrightarrow L_1 \longrightarrow Y$ 。如果 $U_1$ 不是图 20.7 中 $L_1$ 和 $Y$ 的共同原因（即如果没有选择偏倚），则 $L_1$ 各层内的 $A-Y$ 关联将是 $A_0$ 对 $Y$ 不通过 $L_1$ 的 **直接效应（direct effects）** 的无偏估计，但仍然不是 $\bar{A}$ 对 $Y$ 的总效应的无偏估计，因为 $A_0$ 通过 $L_1$ 中介的效应未被包含在内。

有时人们认为，位于治疗与结局之间因果路径上的变量不能被视为混杂因素，因为调整这些变量将导致有偏的效应估计。然而，对于 **时变治疗（time-varying treatments）** ，这种对混杂因素的刻画是不准确的。图 20.7 显示，后续治疗 $A_1$ 的混杂因素可以位于过去治疗 $A_0$ 与结局之间的因果路径上。至于对因果路径上的混杂因素进行调整是否会导致治疗策略效应的偏倚，这取决于调整方法的选择。分层确实会诱导偏倚；而 **g-方法（g-methods）** 则不会。

### 20.4 为何传统方法无法修复（Why Traditional Methods Cannot Be Fixed）

数据组合的数量甚至更大，因为在每个时间点 $k$ 测量了多个混杂因素 $L_k$ 。

我们证明了，当存在治疗-混杂因素反馈时，分层不能用作混杂调整方法。但其他传统方法呢？例如，我们可以使用参数化的结局回归（parametric outcome regression），而非非参数分层，来调整混杂。在单纯分层失效的情况下，结局回归能否成功？

这个问题对于高维数据场景尤为重要，因为在高维场景中，我们无法像上一节那样进行简单的分层分析。考虑在图 20.5 下生成的数据。治疗 $A_k$ 发生在两个时间点 $k = 0, 1$ ，这意味着只有 $2^2 = 4$ 种静态治疗策略 $\bar{a}$ 。但当治疗 $A_k$ 发生在多个时间点 $k = 0, 1, \dots, K$ 时，我们将无法呈现包含所有治疗值组合的表格。如果在实践中并不罕见地， $K$ 达到 100 的量级，那么就有 $2^{100}$ 种静态治疗策略 $\bar{a}$ ，这个惊人的数字远远超过任何研究的样本量。当我们同时考虑动态策略时，治疗策略的总数更大。

正如自第 11 章以来我们一直论证的那样，当存在许多可能的治疗策略 $\bar{a}$ 时，我们需要建模来估计涉及 $\mathrm{E}[Y^{\bar{a}}]$ 的平均因果效应。为此，我们需要假设治疗史 $\bar{a}$ 对平均结局 $Y$ 的效应的 **剂量-反应函数（dose-response function）** 。一种可能是假设治疗策略 $\bar{a}$ 的效应随每种策略下的累积治疗量线性增加。在此假设下，所有恰好分配三个月治疗的策略具有相同的效应，无论这三个月的治疗发生在哪个时期——随访的前三个月、随访的后三个月等。为建模付出的代价是由于剂量-反应函数可能 **模型误设（model misspecification）** 而对估计的有效性构成另一威胁。

然而，付出这一代价并不能为传统方法的失败提供任何保护。在存在治疗-混杂因素反馈的情况下，回归建模不可能消除传统基于分层的方法的偏倚，因为回归本身就是一种传统的基于分层的方法。例如，假设我们有在图 20.5 下生成的数据。定义累积治疗 $\operatorname{cum}(\bar{\mathcal{A}}) = \mathcal{A}_0 + \mathcal{A}_1$ ，它可以取 3 个值：0（如果个体在两个时间点均未接受治疗），1（如果个体仅在时间 1 或仅在时间 2 接受治疗），以及 2（如果个体在两个时间点均接受治疗）。那么感兴趣的治疗策略可以表示为“始终治疗” $\operatorname{cum}(\bar{a}) = 2$ 和“从不治疗” $\operatorname{cum}(\bar{a}) = 0$ ，平均因果效应为：

$$
\operatorname{E}[Y^{\operatorname{cum}(\bar{a}) = 2}] - \operatorname{E}[Y^{\operatorname{cum}(\bar{a}) = 0}].
$$

同样，任何有效的方法都应估计该差异的值为 $0$ 。

在假设平均结局 $\mathrm{E}[Y \mid \bar{A}, L_1]$ 线性依赖于协变量 $\operatorname{cum}(\bar{A})$ 的条件下，我们可以拟合结局回归模型：

$$
\operatorname{E}[Y \mid \bar{A}, L_1] = \theta_0 + \theta_1 \operatorname{cum}(\bar{A}) + \theta_2 L_1.
$$

关联性差异 $\mathrm{E}[Y \mid \operatorname{cum}(A) = 2, L_1] - \mathrm{E}[Y \mid \operatorname{cum}(A) = 0, L_1]$ 等于 $\theta_1 \times 2$ 。（该模型正确假设该差异在 $L_1 = 1$ 和 $L_1 = 0$ 层中相同。）因此，有些人可能希望将 $\theta_1 \times 2$ 解释为在协变量 $L_1$ 各层内“始终治疗”与“从不治疗”的平均因果效应。但这种因果解释是不合理的，因为如图 20.5 所示，对 $L_1$ 条件化诱导了 $A_0$ （治疗 $\operatorname{cum}(\bar{A})$ 的一个组成部分）与结局 $Y$ 之间的关联。这意味着即使真实因果效应为零且 $\mathrm{E}[Y \mid A, L_1]$ 的回归模型正确， $\theta_1$ ——以及因此的均值关联性差异——也是非零的。类似的论证可应用于 **匹配（matching）** 。

需要 **g-方法（G-methods）** 来在存在治疗-混杂因素反馈时适当调整时变混杂因素。

在讨论 g-方法之前还有一点。为简化起见，我们迄今为止在简化的因果图下描述了治疗-混杂因素反馈，其中过去治疗不直接影响后续治疗。也就是说，图 20.3 和 20.4 中的因果图没有包含从 $A_{0}$ 到 $A_{1}$ 的箭头。现在我们考虑更一般的情况，即过去治疗可能直接影响后续治疗。

例如，假设我们 HIV 研究中的医生在决定是否在时间 $k$ 开处方治疗 $A_{k}$ 时，使用了关于过去治疗史 $A_{k-1}$ 的信息。为了表示这种情况，我们在图 20.3 和 20.4 的因果图中添加了从 $A_{0}$ 到 $A_{1}$ 的箭头，如图 20.8 和 20.9 所示。

图 20.8 和 20.9 的因果图显示，在存在治疗-混杂因素反馈的情况下，对 $L_{1}$ 条件化不足以阻断治疗 $A_{1}$ 与结局 $Y$ 之间的所有后门路径（backdoor paths）。事实上，对 $L_{1}$ 条件化打开了图 20.8 中的路径 $A_{1} \leftarrow A_{0} \rightarrow L_{1} \leftarrow U_{1} \rightarrow Y$ ，以及图 20.9 中的路径 $A_{1} \leftarrow A_{0} \leftarrow W_{0} \rightarrow L_{1} \leftarrow U_{1} \rightarrow Y$ 。

当然，无论是否存在治疗-混杂因素反馈，当过去治疗对结局有非零效应时，如图 20.10 的因果图所示，始终需要对过去治疗史进行条件化。在此图下，治疗 $A_{0}$ 是治疗 $A_{1}$ 效应的混杂因素。

因此，时间 $k$ 的 **序贯可交换性（sequential exchangeability）** 通常需要对 $k$ 之前的治疗史 $\bar{A}_{k-1}$ 进行条件化；仅对协变量 $L$ 条件化是不够的。这就是为什么在本章和前一章中，所有表示序贯可交换性的条件独立陈述都条件于治疗史。

过去治疗在估计 **时间固定治疗（time-fixed treatments）** 的效应中也起着重要作用。假设我们感兴趣的是估计时间固定治疗 $A_{1}$ 对 $Y$ 的效应——而不是涉及 $A_{0}$ 和 $A_{1}$ 两者的治疗策略的效应。（有时 $A_{1}$ 的效应被称为时变治疗 $A$ 的 **短期效应（short-term effect）** 。）那么，如果存在治疗-混杂因素反馈，缺乏对过去治疗 $A_{0}$ 的调整通常会导致选择偏倚；如果过去治疗 $A_{0}$ 直接影响结局 $Y$ ，则会导致混杂。

换句话说，即使治疗 $A_{1}$ 对任何个体的结局 $Y$ 都没有影响，如图 20.8–20.10 所示，差异 $\operatorname{E}[Y \mid A_{1}=1, L_{1}] - \operatorname{E}[Y \mid A_{1}=0, L_{1}]$ 也不会为零。在实践中，当对时间固定治疗进行因果推断时，比较当前使用者（ $A_{1}=1$ ）与非使用者（ $A_{1}=0$ ）的分析中可能会出现偏倚。为避免偏倚，可以调整先前的治疗史，或将分析限制在具有特定治疗史的个体中。这就是时间固定治疗的 **“新用户设计（new-user designs）”** 背后的思想：将分析限制在过去未使用过治疗的个体中。

如果能够正确调整过去治疗，则分析无需限制在新用户。Robins（1987）表明，随机测量错误的治疗可能导致偏离零假设的偏倚。

当过去治疗被测量错误时，调整过去治疗的要求会产生额外的偏倚影响。如第 9.3 节所述，测量错误的混杂因素可能导致效应估计有偏，无论是向上还是向下。在我们的 HIV 示例中，假设研究者无法获取研究参与者的医疗记录。相反，为了确定先前的治疗，研究者必须通过问卷询问参与者。由于并非所有参与者都能准确回忆他们的治疗史，治疗 $A_{0}$ 的测量存在误差。研究者拥有的是测量错误的变量 $A_{0}^{\ast}$ 的数据，而非变量 $A_{0}$ 的数据。

为了在图 20.8–20.10 中描述这一情况，我们添加了从真实治疗 $A_{0}$ 到测量错误的治疗 $A_{0}^{\ast}$ 的箭头，这表明对 $A_{0}^{\ast}$ 条件化无法阻断 $A_{1}$ 和 $Y$ 之间通过 $A_{0}$ 的偏倚路径。因此，研究者将得出结论，即使在调整了 $A_{0}^{\ast}$ 和 $L_{1}$ 之后， $A_{1}$ 和 $Y$ 之间仍存在关联，尽管 $A_{1}$ 对 $Y$ 没有效应。

因此，当时变治疗时，我们发现，与普遍看法相反，治疗的测量错误——即使测量误差是独立且非差异性的——可能在零假设下引起偏倚。这种偏倚的产生是因为过去治疗是后续治疗效应的混杂因素，即使过去治疗对结局没有因果效应。此外，在备择假设下，这种不完美的偏倚调整可能导致对效应的夸大估计。
