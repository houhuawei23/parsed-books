# 观察性研究中的重叠：困难与机遇

## 20.1 重叠的含义

在本书的第三部分中，基于观察性研究的因果推断依赖于两个关键假设：**无混杂性（unconfoundedness）**

$$
Z \bot \{Y (1), Y (0) \} \mid X
$$

和**重叠性（overlap）**

$$
0 <   e (X) <   1.
$$

D'Amour 等人 (2021) 指出了这两个假设之间的张力：通常，更多的协变量使得无混杂性假设更合理（忽略第 16.3.1 节讨论的 M-偏倚），但更多的协变量使得重叠假设更不合理，因为处理变得更容易预测。

如果某些单元有 $e ( X ) = 0 { \mathrm { ~ o r ~ } } e ( X ) = 1$ ，那么我们在思考反事实潜在结果时会遇到哲学上的困难 (King and Zeng, 2006)。特别是，如果一个单元确定性地接受了处理，那么构想其在对照条件下的潜在结果可能没有意义；反之亦然。即使真实的倾向性得分并不恰好为 0 或 1，在有限样本中估计的倾向性得分也可能非常接近 0 或 1，这使得基于逆概率加权的估计量在数值上不稳定。许多统计分析实际上需要严格版本的重叠：

**假设 20.1（严格重叠，strict overlap）** 对于某个 $\eta \in ( 0 , 1 / 2 )$，有 $\eta \leq e ( X ) \leq 1 - \eta$。

然而，D'Amour 等人 (2021, 推论 1) 表明，假设 20.1 具有非常强的含义。为简单起见，我仅介绍他们的一个结果。令 $X _ { k } \ ( k = 1 , \ldots , p )$ 为协变量 $X =$ $( X _ { 1 } , \ldots , X _ { p } )$ 的第 k 个分量，且 $e = \operatorname { p r } ( Z = 1 )$ 为处理组单元的比例。

**定理 20.1** 假设 20.1 意味着 $\eta \leq e \leq 1 - \eta$ 且

$$
\begin{array}{l} p ^ {- 1} \sum_ {k = 1} ^ {p} \left| E (X _ {k} \mid Z = 1) - E (X _ {k} \mid Z = 0) \right| \\ \leq p ^ {- 1 / 2} C ^ {1 / 2} \left\{e \lambda_ {1} ^ {1 / 2} + (1 - e) \lambda_ {0} ^ {1 / 2} \right\}, \tag {20.1} \\ \end{array}
$$

其中

$$
C = \frac {(e - \eta) (1 - e - \eta)}{e ^ {2} (1 - e) ^ {2} \eta (1 - \eta)}
$$

是一个仅依赖于 $( e , \eta )$ 的正常数，而 $\lambda _ { 1 }$ 和 $\lambda _ { 0 }$ 分别是协方差矩阵 $\operatorname{cov} ( X \mid Z = 1 )$ 和 $\operatorname { c o v } ( X \mid Z = 0 )$ 的最大特征值。

定理 20.1 中最大特征值的阶数是多少？D'Amour 等人 (2021) 表明，除非 X 的分量高度相关，否则它通常小于 $O ( p )$。如果 X 的分量高度相关，那么在包含其他分量后，某些分量是冗余的。如果 $X$ 的分量不是高度相关的，那么右侧收敛到零。因此，协变量均值的平均差异接近零，即处理组和对照组在协变量所有维度上的均值近似平衡。从数学上讲，(20.1) 的左侧收敛到零排除了 X 的所有维度在处理组和对照组之间均值差异非零的可能性。这在具有许多协变量的观察性研究中是一个强要求。

## 20.1.1 有限重叠情况下的修剪

当假设 20.1 不成立时，通常基于估计的倾向性得分对单元进行修剪 (Crump 等人, 2009; Yang and Ding, 2018)。修剪会丢弃重叠区域较小的单元，这会改变总体和估计目标。假设 20.1 中重叠的限制性含义表明，必须更频繁地使用修剪，并且可能需要修剪大比例的单元才能在高维中实现理想的重叠。

## 20.1.2 有限重叠情况下的结果建模

D'Amour 等人 (2021) 中有些消极的结果也突显了在有限重叠情况下仅关注倾向性得分的局限性。对于高维协变量，结果建模变得更加重要。特别是，如果结果均值仅依赖于原始协变量的某个函数，即

$$
E \{Y (z) \mid X \} = f _ {z} (r (X)), \quad (z = 0, 1)
$$

那么只需控制 $r ( X )$ 即可，它是原始协变量的一个低维摘要。由于降维，对 $r ( X )$ 的严格重叠条件可能比对 X 的严格重叠条件弱得多。这在概念上很直观，但相应的理论和方法尚缺失。

## 20.2 无重叠情况下的因果推断：断点回归

从单变量 X 的简单情况开始。一种极端的处理分配机制是确定性的：

$$
Z = 1 (X \geq x _ {0}),
$$

其中 x0 是预定阈值。这种分配的一个有趣结果是，无混杂性假设自动成立：

$$
Z \bot \{Y (1), Y (0) \} \mid X
$$

因为 Z 是 X 的确定性函数。然而，重叠假设按定义被违反：

$$
e (X) = \operatorname{pr} (Z = 1 \mid X) = 1 (X \geq x _ {0}) = \left\{ \begin{array}{l l} 1 & \text { if } X \geq x _ {0}, \\ 0 & \text { if } X <   x _ {0}. \end{array} \right.
$$

因此，我们在第四部分讨论的分析策略在此不再适用。我们必须改变视角。

这里的讨论似乎有些牵强，因为涉及确定性的处理分配。有趣的是，它在实践中有许多应用，被称为**断点回归（regression discontinuity）**。下面，我首先回顾一些经典例子，然后给出这类研究的数学表述。

## 20.2.2 断点回归的数学表述

决定处理的变量 X 的技术术语是**运行变量（running variable）**。直观上，断点回归可以识别在断点 x0 处的局部平均因果效应：

$$
\tau (x _ {0}) = E \{Y (1) - Y (0) \mid X = x _ {0} \}.
$$

具体来说，对于处理下的潜在结果，我们有

$$
E \{Y (1) \mid X = x _ {0} \} = \lim _ {\varepsilon \rightarrow 0 +} E \{Y (1) \mid X = x _ {0} + \varepsilon \} \tag {20.2}
$$

$$
= \lim _ {\varepsilon \rightarrow 0 +} E \{Y (1) \mid Z = 1, X = x _ {0} + \varepsilon \} \tag {20.3}
$$

$$
= \lim _ {\varepsilon \to 0 +} E (Y \mid Z = 1, X = x _ {0} + \varepsilon), \tag {20.4}
$$

其中 (20.2) 在 $E \{ Y ( 1 ) \mid X = x \}$ 在 $x _ { 0 }$ 处右连续时成立，(20.3) 由 Z 的定义得出。类似地，对于对照下的潜在结果，我们有

$$
E \{Y (0) \mid X = x _ {0} \} = \lim _ {\varepsilon \rightarrow 0 +} E (Y \mid Z = 0, X = x _ {0} - \varepsilon)
$$

如果 $E \{ Y ( 0 ) \mid X = x \}$ 在 $x _ { 0 }$ 处左连续。因此，在 $x _ { 0 }$ 处的局部平均因果效应可以通过这两个极限的差来识别。下面我总结关键识别结果。

**定理 20.2** 假设 $E \{ Y ( 1 ) \mid X = x \}$ 在 $x _ { 0 }$ 处右连续，且 $E \{ Y ( 0 ) \mid X = x \}$ 在 $x _ { 0 }$ 处左连续。则在 $X = x _ { 0 }$ 处的局部平均处理效应由下式识别：

$$
\tau (x _ {0}) = \lim _ {\varepsilon \to 0 +} E (Y \mid Z = 1, X = x _ {0} + \varepsilon) - \lim _ {\varepsilon \to 0 +} E (Y \mid Z = 0, X = x _ {0} - \varepsilon).
$$

由于上述等式的右侧仅涉及可观测变量，参数 $\tau ( x _ { 0 } )$ 是非参数可识别的。然而，识别公式的形式与我们之前推导的完全不同。特别是，识别公式涉及两个条件期望函数的极限。

## 20.2.3 边界附近的回归

如果幸运的话，图形诊断有时可以清晰地显示断点处的因果效应。然而，许多结果是有噪声的，因此图形诊断不够。图 20.3 显示了两个在断点处有明显跳跃的例子和两个没有明显跳跃的例子，尽管底层的数据生成过程都存在不连续性。

假设 $E ( Y \mid Z = 1 , X = x ) = \gamma _ { 1 } + \beta _ { 1 } x$ 和 $E ( Y \mid Z = 0 , X = x ) =$ $\gamma _ { 0 } + \beta _ { 0 } x$ 关于 x 是线性的。我们可以基于处理组和对照组数据分别运行 OLS，得到拟合线 $\hat { \gamma } _ { 1 } + \hat { \beta } _ { 1 } x$ 和 $\hat { \gamma } _ { 0 } + \hat { \beta } _ { 0 } x$。然后我们可以估计在点 $X = x _ { 0 }$ 处的平均因果效应为

$$
\hat {\tau} (x _ {0}) = (\hat {\gamma} _ {1} - \hat {\gamma} _ {0}) + (\hat {\beta} _ {1} - \hat {\beta} _ {0}) x _ {0}.
$$

数值上，$\hat { \tau } ( x _ { 0 } )$ 等于 OLS 中 $Z _ { i }$ 的系数

$$
Y _ {i} \sim \{1, Z _ {i}, X _ {i} - x _ {0}, Z _ {i} (X _ {i} - x _ {0}) \}, \tag {20.5}
$$

并且它也等于 OLS 中 $Z _ { i }$ 的系数

$$
Y _ {i} \sim \{1, Z _ {i}, R _ {i}, L _ {i} \}, \tag {20.6}
$$

其中

$$
R _ {i} = \max (X _ {i} - x _ {0}, 0), \quad L _ {i} = \min (X _ {i} - x _ {0}, 0)
$$

分别表示 $X _ { i } - x _ { 0 }$ 的右侧和左侧部分。我将代数细节留作问题 20.1。

然而，这种方法可能对线性模型的违反敏感。理论建议仅使用断点附近的局部观测值进行回归。但是，选择"局部点"的规则相当复杂。幸运的是，R 语言中 rdrobust 包的 rdrobust 函数实现了"局部点"的各种选择。由于选择"局部点"是断点回归的关键，因此报告基于不同"局部点"选择的估计值和置信区间似乎更为合理。

## 20.2.4 一个例子

Lee (2008) 给出了一个使用断点回归研究美国众议院在任优势（incumbency advantage）的著名例子。他写道："在任者，根据定义，是在上次选举中成功的政治家。如果使他们成功的因素在时间上具有一定的持续性，那么他们在竞选连任时应该预期会更为成功。"因此，这是一个具有根本挑战性的因果推断问题。断点回归是研究这个问题的巧妙研究设计。

运行变量是以上次选举的投票结果为中心归零后的滞后投票（lagged vote），结果变量是当前选举的投票结果，单元是国会选区。处理是某选区当前是否由在任党派的二元指标，由滞后投票决定。图 20.4 显示了原始数据。

rdrobust 函数给出三组点估计和置信区间。它们都表明在任优势为正。

```txt

> library(rddtools)
> data(house)
> RDDest = rdrobust(house$y, house$x)

```

## 20.2.5 断点回归的问题

断点回归分析可能出现什么问题？技术挑战在于指定断点附近的邻域。我们已经在上面讨论过这个问题。

此外，定理 20.2 在连续性条件下成立。在实践中它可能被违反。例如，如果死亡率在 21 岁时跳跃，那么图 20.2 中的跳跃可能不是由于法定饮酒年龄导致的饮酒行为变化所致。然而，经验上很难检验连续性条件的违反。

McCrary (2008) 提出了一个检验断点回归有效性的间接方法。他建议检查运行变量在断点处的密度。运行变量密度在断点处的不连续性可能表明某些单元能够完美地操纵其处理状态。
