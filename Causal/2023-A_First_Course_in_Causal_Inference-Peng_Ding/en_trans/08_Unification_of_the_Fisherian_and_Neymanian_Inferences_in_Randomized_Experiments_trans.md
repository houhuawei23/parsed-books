# 随机化实验中Fisher推断与Neyman推断的统一（Unification of the Fisherian and Neymanian Inferences in Randomized Experiments）

前几章涵盖了不同类型实验的Fisher推断（Fisherian inference）和Neyman推断（Neymanian inference）。Fisher视角关注的是用于检验**强零假设（strong null hypothesis）**（即任何单元均无因果效应）的**有限样本精确p值（finite-sample exact p-value）**，而Neyman视角关注的是针对**平均因果效应（average causal effect）** 的无偏估计以及保守的大样本置信区间。两者均由实验的物理随机化所保证。它们是基于设计（design-based）或基于随机化（randomization-based）的因果推断的两种重要形式。它们相互关联，但也具有各自鲜明的特征。

1935年，Neyman向皇家统计学会（Royal Statistical Society）提交了其关于基于随机化推断的开创性论文。他的论文（Neyman, 1935）在讨论环节受到了Fisher的抨击。Sabbaghi和Rubin（2014）回顾了这场著名的Neyman–Fisher之争，并针对这一老问题提出了一些新结果。本章不深入探讨哲学问题，而是提供一个统一的讨论。

## 8.1 在完全随机化实验（CRE）中检验强零假设与弱零假设

让我们重新审视处理组-对照组**完全随机化实验（Complete Randomization Experiment, CRE）**。Fisher视角关注的是检验强零假设

$$
H _ {0 \mathrm{F}}: Y _ {i} (1) = Y _ {i} (0) \text {  对于所有单元   } i = 1, \dots , n.
$$

**Fisher随机化检验（Fisher Randomization Test, FRT）** 提供了有限样本精确的 $p_{\text{FRT}}$。

根据置信区间与假设检验的对偶性，Neyman视角给出了对弱零假设

$$
H _ {0 \mathrm{N}}: \tau = 0 \Longleftrightarrow H _ {0 \mathrm{N}}: \bar {Y} (1) = \bar {Y} (0)
$$

的检验，该检验基于

$$
t = \frac {\hat {\tau}}{\sqrt {\hat {V}}} = \sqrt {\frac {\operatorname{var} (\hat {\tau})}{\hat {V}}} \times \frac {\hat {\tau}}{\sqrt {\operatorname{var} (\hat {\tau})}} \xrightarrow {\mathrm{d}} C \times \mathrm{N} (0, 1),
$$

其中 $C \leq 1$ 。使用 $\mathrm { { N } } ( 0 , 1 )$ 分位数对学生化统计量 $t$ 进行推断，我们得到了针对 $H _ { \mathrm { 0 N } }$ 的一个保守的大样本检验。

此外，Ding和Dasgupta（2017）证明，使用学生化统计量 $t$ 的FRT具有双重保证：

1.  在 $H _ { \mathrm { 0 F } }$ 下，关联的 $p _ { \mathrm { F R T } }$ 是有限样本精确的；
2.  在 $H _ { \mathrm { 0 N } }$ 下，它是渐近保守的。

重要的是，这是学生化统计量 $t$ 的一个特性。Ding和Dasgupta（2017）指出，使用其他检验统计量的FRT可能不具备这种双重保证。特别是，使用 $\hat { \tau }$ 的FRT在 $H _ { \mathrm { 0 N } }$ 下可能是渐近反保守的。下面我给出一些启发式说明，以阐述在FRT中学生化的重要性。

在 $H _ { \mathrm { 0 N } }$ 下，我们有

$$
\hat {\tau} \dot {\sim} \mathrm{N} \left(0, \frac {S ^ {2} (1)}{n _ {1}} + \frac {S ^ {2} (0)}{n _ {0}} - \frac {S ^ {2} (\tau)}{n}\right).
$$

FRT假定科学表（Science Table）为 $( Y _ { i } , Y _ { i } ) _ { i = 1 } ^ { n }$ ，因此 $\hat { \tau }$ 的置换分布为

$$
(\hat {\tau}) ^ {\pi} \dot {\sim} \mathrm{N} \left(0, \frac {s ^ {2}}{n _ {1}} + \frac {s ^ {2}}{n _ {0}}\right),
$$

其中 $( \cdot ) ^ { \pi }$ 表示置换分布，$s ^ { 2 }$ 是观测结果的样本方差。基于第 $s$ 章的 $(3.7)$，我们可以近似 $H _ { \mathrm { 0 F } }$ 下 $( \hat { \tau } ) ^ { \pi }$ 的渐近方差为

$$
\begin{array}{l} \frac {s ^ {2}}{n _ {1}} + \frac {s ^ {2}}{n _ {0}} = \frac {n}{n _ {1} n _ {0}} \left\{\frac {n _ {1} - 1}{n - 1} \hat {S} ^ {2} (1) + \frac {n _ {0} - 1}{n - 1} \hat {S} ^ {2} (0) + \frac {n _ {1} n _ {0}}{n (n - 1)} \hat {\tau} ^ {2} \right\} \\ \approx \frac {\hat {S} ^ {2} (1)}{n _ {0}} + \frac {\hat {S} ^ {2} (0)}{n _ {1}} \\ \approx \frac {S ^ {2} (1)}{n _ {0}} + \frac {S ^ {2} (0)}{n _ {1}}, \\ \end{array}
$$

这与 $\hat{\tau}$ 的渐近方差不匹配。理想情况下，我们应该基于 $\hat{\tau}$ 的真实分布来计算 $H _ { \mathrm { 0 N } }$ 下的 $p$ 值，然而该分布依赖于未知的潜在结果。相比之下，我们使用FRT基于置换分布 $( \hat { \tau } ) ^ { \pi }$ 来计算 $p _ { \mathrm { F R T } }$ ，即使在样本量很大时，该置换分布也与 $H _ { \mathrm { 0 N } }$ 下 $\hat { \tau }$ 的真实分布不匹配。因此，即使在样本量很大时，使用 $\hat { \tau }$ 的FRT也可能无法控制 $H _ { \mathrm { 0 N } }$ 下的第一类错误率。

幸运的是，如果我们将检验统计量 $\hat{\tau}$ 替换为学生化版本 $t$，则使用 $\hat { \tau }$ 的FRT的不良特性就会消失。在 $H _ { \mathrm { 0 N } }$ 下，我们有

$$
t \dot {\sim} \mathrm{N} (0, C ^ {2})
$$

其中 $C ^ { 2 } \leq 1$ ，当对所有单元 $i = 1 , \ldots , n$ 有 $Y _ { i } ( 1 ) - Y _ { i } ( 0 ) = \tau$ 时等号成立。FRT生成的置换分布为

$$
t ^ {\pi} \dot {\sim} \mathrm{N} (0, 1)
$$

其方差等于1，因为FRT使用的科学表具有零个体因果效应。在 $H _ { \mathrm { 0 N } }$ 下，由于 $t$ 的真实分布比相应的置换分布更分散，因此基于 $t$ 的 $p_{\text{FRT}}$ 是渐近保守的。

## 8.2 完全随机化实验（CRE）中协变量调整的FRT

将8.1节的讨论扩展到包含协变量的情况，Zhao和Ding（2021a）建议使用基于学生化的Lin（2013）估计量的FRT：

$$
t _ {\mathrm{L}} = \frac {\hat {\tau} _ {\mathrm{L}}}{\sqrt {\hat {V} _ {\mathrm{L}}}},
$$

这是将 $Y _ { i }$ 对 $1 , Z _ { i } , X _ { i }$ 以及 $Z _ { i } X _ { i }$ 进行**普通最小二乘（Ordinary Least Squares, OLS）** 拟合时，$Z _ { i }$ 系数的稳健t统计量。他们证明，使用 $t _ { \mathrm { L } }$ 的FRT具有多重保证：

1.  在 $H _ { \mathrm { 0 F } }$ 下，关联的 $p _ { \mathrm { F R T } }$ 是有限样本精确的；
2.  在 $H _ { \mathrm { 0 N } }$ 下，它是渐近保守的；
3.  当 $H _ { \mathrm { 0 N } }$ 不成立且协变量对结果有预测性时，它比使用 $t$ 的FRT渐近更有效；
4.  即使线性结果模型设定错误，上述性质依然成立。

类似地，这是学生化统计量 $t _ { \mathrm { L } }$ 的一个特性。Zhao和Ding（2021a）指出，第6.2.1节中回顾的其他协变量调整的FRT，在 $H _ { \mathrm { 0 N } }$ 下可能是反保守的，或者当 $H _ { \mathrm { 0 N } }$ 不成立时，其功效低于使用 $t _ { \mathrm { L } }$ 的FRT。

## 8.3 一般性建议

如果同时对强零假设和弱零假设感兴趣，那么针对**分层随机化实验（Stratified Randomization Experiment, SRE）** 的建议与针对CRE的建议相似。在没有额外协变量的情况下，Zhao和Ding（2021a）建议使用基于以下统计量的FRT：

$$
t _ {\mathrm{S}} = \frac {\hat {\tau} _ {\mathrm{S}}}{\sqrt {\hat {V} _ {\mathrm{S}}}};
$$

在有额外协变量的情况下，他们建议使用基于以下统计量的FRT：

$$
t _ {\mathrm{L,S}} = \frac {\hat {\tau} _ {\mathrm{L,S}}}{\sqrt {\hat {V} _ {\mathrm{L,S}}}}.
$$

对**回归不连续设计（Regression Discontinuity Design, ReM）** 的分析更为棘手。Zhao和Ding（2021a）指出，使用 $t$ 的FRT不具备8.1节中的双重保证，但使用 $t _ { \mathrm { L } }$ 的FRT仍然具备8.2节中的保证。这突显了在ReM中协变量调整和学生化的重要性。

对于**匹配对实验（Matched Pair Experiment, MPE）**，类似的结果也成立。在没有协变量的情况下，我们建议使用基于将 $\hat { \tau } _ { i }$ 对1进行OLS拟合时截距项t统计量的FRT；在有协变量的情况下，我们建议使用基于将 $\hat { \tau } _ { i }$ 对1和 $\widehat { \tau } _ { x , i }$ 进行OLS拟合时截距项t统计量的FRT。第7章的图7.2即基于这些推荐的FRT。

总的来说，使用学生化统计量的FRT是更安全的选择。当学生化统计量的大样本正态近似准确时，FRT给出的 $p _ { \mathrm { F R T } }$ 与基于正态近似的p值几乎相同。当大样本近似不准确时，FRT至少能保证在强零假设下p值是有效的。这是本书的建议。

## 8.4 案例研究

Chong等人（2016）在2009学年对秘鲁卡哈马卡地区一所农村中学的219名学生进行了一项随机实验。他们首先向村诊所提供铁补充剂，并培训当地工作人员向任何亲自前来索取的青少年免费分发一粒铁片。然后，他们将学生随机分配到三个组，分别观看三种不同类型的视频：在第一个视频中，一位受欢迎的足球运动员鼓励使用铁补充剂以最大化能量（“足球”组）；在第二个视频中，一位医生鼓励使用铁补充剂以改善整体健康（“医生”组）；第三个视频完全不提及铁（“对照组”）。该实验按年级（1-5级）进行分层。各年级内处理组和对照组的样本量如下所示：

|         | 1年级 | 2年级 | 3年级 | 4年级 | 5年级 |
| :------ | :---- | :---- | :---- | :---- | :---- |
| 足球组  | 16    | 19    | 15    | 10    | 10    |
| 医生组  | 17    | 20    | 15    | 11    | 10    |
| 对照组  | 15    | 19    | 16    | 12    | 10    |

一个感兴趣的结果是2009年第三和第四季度的平均成绩，一个重要的背景协变量是基线时的贫血状况。我们对“足球”组与“对照组”以及“医生”组与“对照组”进行成对比较。我们还比较了使用和不使用指示基线贫血状况协变量的FRT。我们使用他们的数据集来说明完全随机化和分层随机化中的FRT。同一年级内的十个子组分析使用基于 $t$ 和 $t _ { \mathrm { L } }$ 的FRT（针对CRE），而两个跨所有年级的总体分析使用基于 $t_{\mathrm{S}}$ 和 $t _ { \mathrm { L } , \mathrm { S } }$ 的FRT（针对SRE）。

表8.1展示了点估计量、标准误、基于稳健t统计量正态近似的p值，以及基于FRT的p值。在大多数层中，协变量调整减小了标准误，因为基线贫血状况对结果具有预测性。表8.1也展示了两个例外：在2年级内，比较“足球”组和“对照组”时，协变量调整增加了标准误；在4年级中，比较“医生”组和“对照组”时，协变量调整也增加了标准误。这是由于这些层内的组样本量较小，使得渐近近似变得可疑。然而，在这两种情况下，标准误的差异出现在第三位小数。来自正态近似和FRT的p值很接近，在大多数情况下后者略大。基于理论，应信任基于FRT的p值，因为它在尖锐零假设下具有有限样本精确性的额外保证。在本例中这一点变得重要，因为各层内的组样本量非常小。

我们赞同Bind和Rubin（2020）的建议，即在进行FRT时，不仅应报告p值，还应报告检验统计量的随机化分布。图8.1比较了稳健t统计量随机化分布的直方图与渐近近似。在子组分析中，我们可以观察到随机化分布与 $\mathrm{N}(0, 1)$ 之间的差异；平均所有年级后，这种差异变得不明显。总体而言，在此应用中，基于正态近似的p值与基于FRT的p值没有实质性差异。两种方法得出了连贯的结论：医生告知铁补充剂益处的视频提高了学业成绩，且该效应在3年级学生中最为显著；相比之下，著名足球运动员告知铁补充剂益处的视频没有产生任何显著效应。
