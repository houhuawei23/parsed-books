# 学习因果模型（Learning Cause-Effect Models）

熟悉基于条件统计独立性从观测数据中进行因果发现的读者 [Pearl, 2009, Spirtes et al., 2000]，可能会对讨论仅有两个观测变量情况下的因果推断章节感到惊讶，因为在这种情况下不存在非平凡的条件独立性。本章介绍了在仅有两个观测变量的情况下进行因果推断所需的假设。

其中一些假设可能看起来过于强而不切实际，但应当牢记，经验推断即使不涉及因果问题，也需要强假设。特别是在处理高维数据和低样本量时更是如此。因此，过度简化的模型无处不在，并且已被证明在许多学习场景中是有帮助的。

假设列表是多样化的，我们也确信它是不完整的。当前研究仍处于探索能产生因果可识别性的巨大假设空间的阶段。我们希望本章能启发读者，使其能够添加其他——希望是现实的——可用于学习因果结构的假设。

我们在 **4.1 节** 中提供假设和理论可识别性结果；**4.2 节** 展示在有限数据情况下如何将这些结果用于结构识别。

## 4.1 结构可识别性（Structure Identifiability）

### 4.1.1 为什么需要额外假设

在第 3 章中，我们介绍了 **结构因果模型（Structural Causal Models, SCMs）**，其中效应 E 通过函数赋值从原因 C 计算得出。人们可能会疑惑，这种数据生成过程的不对称性（即 E 由 C 计算得出，而非反之）是否能仅通过观察 $P _ { C , E }$ 而显现。也就是说，两个变量 X、Y 的联合分布 $P _ { X , Y }$ 是否能告诉我们它是由从 X 到 Y 还是从 Y 到 X 的 SCM 诱导的？换句话说，结构是否能从联合分布中识别？以下已知结果表明，如果允许一般 SCM，答案是"否"。

**命题 4.1（图结构的非唯一性）** 对于任意两个实值变量的联合分布 $P _ { X , Y }$，存在一个 SCM：

$$
Y = f _ {Y} (X, N _ {Y}), \quad X \perp \perp N _ {Y},
$$

其中 $f _ { Y }$ 是一个可测函数，$N _ { Y }$ 是一个实值噪声变量。

**证明** 类似于 Peters [2012, Proposition 2.6 的证明]，定义条件累积分布函数：

$$
F _ {Y | x} (y) := P (Y \leq y | X = x).
$$

然后定义：

$$
f _ {Y} (x, n _ {Y}) := F _ {Y | x} ^ {- 1} (n _ {Y}),
$$

其中 $F _ { Y | x } ^ { - 1 } ( n _ { Y } ) : = \operatorname* { i n f } \{ x \in \mathbb { R } : F _ { Y | x } ( x ) \geq n _ { Y } \}$。然后，令 $N _ { Y }$ 在 [0, 1] 上均匀分布且独立于 X。

该结果可应用于 $X = C$ 且 $Y = E$ 的情况，也可应用于 $X = E$ 且 $Y = C$ 的情况。因此，每个联合分布 $P _ { X , Y }$ 在两个方向上都允许 SCM。由于这个原因，人们通常认为仅凭被动观测无法推断两个观测变量之间的因果方向。我们将在第 7 章看到，这一论断符合仅基于（条件）统计独立性的因果推断框架 [Spirtes et al., 2000, Pearl, 2009]。在此框架下，因果结构 $X \rightarrow Y$ 和 $Y \rightarrow X$ 是无法区分的。对于仅有两个变量，唯一可能的（条件）独立性是对空集进行条件化，这不会使 X 和 Y 独立，除非因果影响是非一般的¹。最近，这一观点受到了使用条件独立性之外的其他联合分布信息的方法的挑战。这些方法依赖于关于概率分布与因果关系之间关系的额外假设。

第 4.1 节的剩余部分讨论在哪些假设下可以从联合分布中恢复图结构（结构可识别性）。第 4.2 节随后描述从有限数据集估计图的方法（结构识别）。这些统计方法不需要由可识别性结果的证明来驱动。紧密遵循证明的方法通常在利用数据方面效率较低。

### 4.1.2 假设类型概述

**模型类别的先验限制** 区分原因和效应的一种可能方法是定义一类"特别自然"的条件分布 $P _ { E | C }$ 和边缘分布 $P _ { C }$。对于若干这样的类别，有理论结果表明，当交换 X 和 Y 时，边缘分布 $P _ { X }$ 和条件分布 $P _ { Y | X }$ 的"一般"组合会诱导出无法由同一类别描述的联合分布。这类陈述也称为可识别性结果，我们将在第 4.1 节的剩余部分看到这样的例子。

例如，可以通过限制函数 $f _ { E }$ 的类别（参见 (3.2)）和/或 (3.1) 和 (3.2) 中的噪声分布类别来定义条件分布 $P _ { E | C }$ 和边缘分布 $P _ { C }$ 的类别，这将在第 4.1.3–4.1.6 节中讨论。从机器学习的角度来看，这种方法似乎特别自然，因为在回归和分类等标准任务中，限制函数的复杂性无处不在。需要注意的是，通过限制函数类别推断因果方向隐含着噪声变量仍然是独立的，这与 SCM 的定义一致（参见定义 3.1）。在这个意义上，可以说这些方法利用了图 2.2 中的噪声独立性，但需记住，噪声的独立性只有在限制函数类别后才使因果方向可识别（参见命题 4.1）。

另一类选择可以在 Sun et al. [2006]、Janzing et al. [2009b] 以及 Comley and Dowe [2003] 中找到。例如，Sun et al. [2006] 和 Janzing et al. [2009b] 考虑了二阶指数模型，其中 $P _ { E | C }$ 和 $P _ { C }$ 的对数密度分别是 e 和 c 的二阶多项式（直至配分函数），或者仅是 c 的二阶多项式。

我们以两个问题结束本部分：首先，应如何定义能够描述现实生活中合理比例的经验数据的模型类别？其次，给定一个经验分布恰好在一个方向上允许这样的模型，为什么这应该是因果方向？第一个问题实际上并非因果推断所特有；构建描述观测变量之间关系的函数总是需要我们从"合理"类别中拟合函数。第二个问题似乎是关于概率与因果关系之间关系的最深层次问题之一。我们只能给出一些直观且模糊的想法，如下所述。

我们首先提供一个与通常机器学习依赖受限模型类别的原因相关的直观动机。如第 1 章所述，每当我们从一个小函数类中找到适合有限数据的模型时，我们期望该模型也能拟合未来的观测。因此，从小类别中找到适合数据的模型对于泛化到未来观测的能力至关重要。形式上，学习因果模型与通常的学习场景有本质不同，因为它旨在推断一个描述系统在干预下行为的模型，而不仅仅是来自同一分布的观测。因此，没有直接的方法从统计学习理论中借用论证来获得因果关系的学习理论。尽管如此，我们相信从小类别中找到模型表明——在一定的误差概率内——该模型在不同的背景条件下也成立。我们进一步相信，在多种不同背景条件下成立的模型比仅适合单个数据集观测的模型更可能是因果模型（参见第 7.1.6 节的"不同环境"）。这样，通过限制模型类别进行因果效应推断与统计学习理论的思想有模糊的联系，尽管确切的联系有待未来建立。上述关于使用小类别因果模型的非正式论证不应被误解为认为自然界的因果关系确实简单。我们是否经常能用简单函数拟合数据，这是一个完全不同的问题。我们仅论证这样的信念：**如果**存在一个简单函数拟合数据，那么它更可能也描述因果关系。此外，我们将在第 4.1.9 节中建立限制模型类别与原因和机制独立性之间的一个联系。为准备这些相当形式化的推导，我们首先提供一个相当不现实的玩具模型，我们将其视为一个隐喻而非严肃的例子。

**原因与机制的独立性** 第 2.1 节描述了 $P _ { C }$ 和 $P _ { E | C }$ 对应于自然的两个独立机制的观点。因此，它们通常不包含关于彼此的信息（参见原则 2.1 和图 2.2 中的中间框）。自然，假设 $P _ { C }$ 和 $P _ { E | C }$ 在它们不包含关于彼此的信息的意义上是独立的，这引发了关于所指的是什么类型的信息的问题。没有明显的方式可以将该假设形式化为可通过统计独立性检验检查的条件。这是因为我们讨论的是一个固定的联合分布 $P _ { C , E }$ 可见的场景，而不是一组分布，我们可以在其中检查假设原因的分布和给定原因的假设效应的分布是否以依赖的方式变化（这本质上是图 2.2 中左框和中间框之间的差异）。为了将原因和机制的独立性转化为 SCM 的语言，我们假设原因的分布应独立于表示因果机制的函数和噪声分布。注意，这再次先验地不是关于统计独立性的陈述。相反，它表明 $f _ { E }$ 和 $P _ { N _ { E } }$ 不包含关于 $P _ { C }$ 的信息，反之亦然。这个事实只有在所有描述从 E 到 C 的 $P _ { C , E }$ 的结构模型都违反独立性时，才能用于因果推断。

第 4.1.7 和 4.1.8 节描述了两种玩具场景，其中可以给出独立性与依赖性的明确定义。最后，在第 4.1.9 节中，我们描述了一种 $P _ { C }$ 和 $P _ { E | C }$ 独立性的形式化，它适用于更一般的场景，而不限于第 4.1.7 和 4.1.8 节中的简单玩具场景。这里，依赖性通过算法互信息来衡量，这是一个基于 **Kolmogorov 复杂度（Kolmogorov complexity）** 意义上的描述长度的概念。由于后者不可计算，它应被视为一个哲学原则而非一种方法。其实践意义有两个方面。首先，它可能启发新方法的开发；其次，现有方法的合理性可以基于它。例如，独立性原则可以证明基于先验限制模型类别的推断方法是合理的；参见第 4.1.9 节的具体例子。为了直观理解独立性与限制模型类别的关系，考虑一个思想实验：$P _ { C }$ 从包含 $k$ 个不同边缘分布的类别中随机选择。同样，假设 $P _ { E | C }$ 从另一个包含 $\ell$ 个不同条件分布的类别中选择。这产生了 $k \cdot \ell$ 个不同的联合分布 $P _ { C , E }$。在一般情况下（除非类别以相当特殊的方式定义），这产生了 $k \cdot \ell > k$ 个不同的边缘分布 $P _ { E }$ 和 $k \cdot \ell > \ell$ 个不同的条件分布 $P _ { C | E }$。因此，$P _ { C }$ 和 $P _ { E | C }$ 的典型组合会诱导出联合分布 $P _ { E , C }$，其"反向边缘和条件" $P _ { E }$ 和 $P _ { C | E }$ 将不在原始类别中，而需要更大的模型类别。换句话说，无论选择多大的 $P _ { C }$ 和 $P _ { E | C }$ 的可能集合，所诱导的 $P _ { C | E }$ 和 $P _ { E }$ 的集合甚至更大。这个思想实验更像是一个隐喻，因为它基于从有限集合中随机选择的朴素图景。尽管如此，它激发了这样的信念：在因果方向上，边缘分布和条件分布更可能允许从先验选择的小集合中进行描述，前提是该集合是以合理方式构建的。

第 4.1.3 至 4.1.6 节描述了具有先验限制模型类别的模型假设，而第 4.1.7 至 4.1.9 节形式化了独立性假设。然而，第 4.1.9 节扮演着特殊角色，因为它应被视为一个基础性原则而非其自身的推断方法。

### 4.1.3 具有非高斯加性噪声的线性模型（Linear Models with Non-Gaussian Additive Noise）

虽然具有高斯噪声的线性结构方程已被广泛研究，但最近观察到 [Kano and Shimizu, 2003, Shimizu et al., 2006, Hoyer et al., 2008a]，**线性非高斯无环模型（linear non-Gaussian acyclic models, LiNGAMs）** 允许新的因果推断方法。特别是，从观测数据中区分 X 导致 Y 和 Y 导致 X 变得可行。假设是效应 E 是原因 C 的线性函数加上加性噪声项：

$$
E = \alpha C + N _ {E}, \quad N _ {E} \perp C,
$$

其中 $\alpha \in \mathbb { R }$（这是第 4.1.4 节中介绍的加性噪声模型的特例）。以下结果表明，这一假设足以识别原因和效应。

**定理 4.2（线性非高斯模型的可识别性）** 假设 $P _ { X , Y }$ 允许线性模型：

$$
Y = \alpha X + N _ {Y}, \quad N _ {Y} \perp \perp X, \tag {4.1}
$$

其中 X、$N _ { Y }$ 和 Y 是连续随机变量。那么存在 $\beta \in \mathbb { R }$ 和一个随机变量 $N _ { X }$ 使得：

$$
X = \beta Y + N _ {X}, \quad N _ {X} \perp \perp Y, \tag {4.2}
$$

当且仅当 $N _ { Y }$ 和 X 是高斯分布。

因此，只要 C 或 $N _ { E }$ 是非高斯的，就足以使因果方向可识别；参见图 4.1 的示例。

让我们更详细地探讨这一结果是如何证明的。定理 4.2 是 Shimizu 等人 [2006] 引入的 **LiNGAM** 模型类的**双变量情形**，他们使用**独立成分分析（Independent Component Analysis, ICA）** [Comon, 1994, 定理 11] 证明了定理 4.2 的**多变量版本**。ICA 的证明基于一个由 Skitovic 和 Darmois 独立证明的高斯分布特征化 [Skitoviˇc, 1954, 1962, Darmois, 1953]，我们现在陈述该定理。

定理 4.3 (Darmois-Skitovic) 设 $X _ { 1 } , \ldots , X _ { d }$ 是独立的、非退化随机变量（见附录 A.1）。如果存在非零系数 $a _ { 1 } , \ldots , a _ { d }$ 和 $b _ { 1 } , \ldots , b _ { d }$（即对于所有 i，$a _ { i } \neq 0 \neq b _ { i }$），使得以下两个线性组合

$$
l _ {1} = a _ {1} X _ {1} + \dots + a _ {d} X _ {d},
$$

$$
l _ {2} = b _ {1} X _ {1} + \ldots + b _ {d} X _ {d}
$$

是独立的，那么每个 $X_i$ 都服从正态分布。

事实证明，可以将定理 4.2 中陈述的双变量版本作为 Darmois-Skitovic 定理的一个简短而直接的推论来证明；为了说明目的，我们在附录 C.1 中附上了这个证明。此外，可以证明**双变量 SCM 的可识别性**可以推广到**多变量 SCM 的可识别性** [Peters et al., 2011b]。有了这个结果，LiNGAM 的多变量可识别性便从定理 4.2 中得出。

具有**非高斯加性噪声**的线性模型也可以应用于一个从机器学习角度看似乎不常见、但从理论物理学角度却很有趣的问题：从数据中**估计时间之箭**。Peters 等人 [2009b] 表明，**自回归模型（autoregressive models）**是**时间可逆的**，当且仅当噪声变量服从正态分布。为了探索经验时间序列的不对称性，他们通过拟合两个自回归模型来推断时间方向：一个像标准做法那样从过去到未来，另一个从未来到过去。在他们的实验中，前一个方向的噪声变量确实倾向于比反向时间方向更独立（参见第 4.2.1 节）。Bauer 等人 [2016] 将该想法扩展到多变量时间序列。Janzing [2010] 将这种观察到的不对称性与**热力学时间之箭**联系起来，这表明本书讨论的因果之间的不对称性也与统计物理学中的基本问题相关。

### 4.1.4 非线性加性噪声模型（Nonlinear Additive Noise Models）

我们现在描述**加性噪声模型（Additive Noise Models, ANMs）**，这是对 SCM 类的一个不那么极端的限制，但仍然足够强，使得因果推断变得可行。

定义 4.4 (ANMs) 如果存在一个可测函数 $f _ { Y }$ 和一个噪声变量 $N _ { Y }$，使得

$$
Y = f _ {Y} (X) + N _ {Y}, \quad N _ {Y} \perp X. \tag {4.3}
$$

则称联合分布 $P _ { X , Y }$ 从 X 到 Y 允许一个 ANM。通过重载术语，如果 (4.3) 成立，我们说 $P _ { Y | X }$ 允许一个 ANM。

以下定理表明，“一般地”，一个分布不会同时允许两个方向的 ANM。

定理 4.5 (ANMs 的可识别性) 出于本定理的目的，如果 $N_Y$ 和 $X$ 具有严格正密度 $p _ { N _ { Y } }$ 和 $p _ { X }$，并且 $f _ { Y } , p _ { N _ { Y } }$ 和 $p _ { X }$ 是三次可微的，则称 ANM (4.3) 是光滑的。

假设 $P _ { Y | X }$ 允许一个从 X 到 Y 的光滑 ANM，并且存在一个 $y \in \mathbb { R }$，使得对于所有但可数多个 x 值，有

$$
(\log p _ {N _ {Y}}) ^ {\prime \prime} (y - f _ {Y} (x)) f _ {Y} ^ {\prime} (x) \neq 0 \tag {4.4}
$$

那么，使得得到的联合分布 $P _ { X , Y }$ 允许一个从 Y 到 X 的光滑 ANM 的对数密度 $\log p _ { X }$ 的集合包含在一个 3 维仿射空间中。

证明. (思路概述。详情见 Hoyer 等人 [2009]) 从 Y 到 X 的 ANM 由下式给出

$$
p (x, y) = p _ {Y} (y) p _ {N _ {X}} (x - f _ {X} (y)), \tag {4.5}
$$

这意味着

$$
\log p (x, y) = \log p _ {Y} (y) + \log p _ {N _ {X}} (x - f _ {X} (y)).
$$

可以证明 $\log p ( x , y )$ 随后满足以下微分方程：

$$
\frac {\partial}{\partial x} \left(\frac {\partial^ {2} \log p (x , y) / \partial x ^ {2}}{\partial^ {2} \log p (x , y) / (\partial x \partial y)}\right) = 0. \tag {4.6}
$$

另一方面，从 X 到 Y 的 ANM 表示为

$$
p (x, y) = p _ {N _ {X}} (x) p _ {N _ {Y}} (y - f _ {Y} (x)). \tag {4.7}
$$

对 (4.7) 取对数得到

$$
\log p (x, y) = \log p _ {X} (x) + \log p _ {N _ {Y}} (y - f _ {Y} (x)). \tag {4.8}
$$

将 (4.6) 应用于 (4.8) 得到一个关于 $\log p_X$ 的三阶导数的微分方程，该方程用 $f _ { X }$ 和 $\log p _ { N _ { Y } }$ 的（一阶、二阶和三阶）导数表示。因此，$f _ { X }$ 和 $p _ { N _ { E } }$（它们是条件分布 $P _ { Y \mid X }$ 的性质）决定了 $\log p _ { X }$，直到三个自由参数：在任意点 $\nu$ 处的 $\log p _ { N _ { X } } ( \nu )$ 、$( \log p _ { N _ { X } } ) ^ { \prime } ( \nu )$ 和 $( \log p _ { N _ { X } } ) ^ { \prime \prime } ( \nu )$。

定理 4.5 陈述了“一般”情况下的可识别性，其中“一般”由诸如 (4.4) 和三维子空间等复杂条件所刻画。对于 $p _ { X }$ 和 $p _ { N _ { Y } }$ 是高斯分布的情况，有一个更简单的可识别性陈述，即只有线性函数 $f$ 生成的分布才允许反向的 ANM [参见 Hoyer 等人, 2009, 推论 1]。图 4.2 可视化了允许两个方向加性噪声模型的双变量分布的两个“非一般”例子。首先，是双变量高斯的明显情况；其次，是一个复杂的情况，需要在 $p _ { X }$ 和 $N _ { X }$ 之间进行精细调整 [Mooij 等人, 2016]。

为了将定理 4.5 与因果语义联系起来，首先假设我们先验地知道原因和结果的联合分布 $P _ { X , Y }$ 允许一个从 C 到 E 的 ANM，但我们不知道 $X = C$ 和 $Y = E$ 还是反过来。定理 4.5 随后表明，一般情况下不会存在从 E 到 C 的 ANM，因此我们可以轻松地决定哪个变量是原因 C。

然而，一般情况下，自然界的条件分布 $P _ { E | C }$ 并没有受到如此严格的限制以至于它们必然允许一个 ANM。但是否可能 $P _ { C }$ 和 $P _ { E | C }$ 随后诱导出一个联合分布 $P _ { C , E }$，该分布允许从 $E$ 到 $C$ 的 ANM？（在这种情况下，我们会推断出错误的因果方向。）我们在第 4.1.9 节中论证，如果 $P _ { C }$ 和 $P _ { E | C }$ 是独立选择的，这种情况不太可能发生。

### 4.1.5 离散加性噪声模型（Discrete Additive Noise Models）

加性噪声不仅可以为实值变量定义，也可以为任何在环中取值的变量定义。Peters 等人 [2010, 2011a] 为环³ $\mathbb{Z}$ 和 $\mathbb{Z} / m \mathbb{Z}$ 引入了 ANM。即整数集和模 $m \in \mathbb{Z}$ 的整数集。在后一个环中，我们识别除以 m 后具有相同余数的数。例如，整数 132 和 4 在除以 8 后都有余数（即 4），我们写作 $132 \equiv 4 \mod 8$。当某个域具有循环结构时，这种模运算可能是合适的。例如，如果我们考虑一年中的天数，我们可能希望 12 月 31 日和 1 月 1 日之间的距离与 8 月 25 日和 8 月 26 日之间的距离相同。

与连续情况一样，我们可以证明在一般情况下，一个联合分布最多允许一个方向的 ANM。以下结果考虑了环 $\mathbb{Z}$ 的例子。

定理 4.6 (离散 ANMs 的可识别性) 假设分布 $P _ { X , Y }$ 允许一个从 X 到 Y 的 ANM $Y = f ( X ) + N _ { Y }$，并且 X 或 Y 具有有限支撑。$P _ { X , Y }$ 允许一个从 Y 到 X 的 ANM 当且仅当存在一个不交分解 $\cup _ { i = 0 } ^ { l } C _ { i } = \operatorname* { s u p p } X$，使得以下条件 a)、b) 和 c) 成立：

a) $C _ { i }$ 是彼此的平移版本

$$
\forall i \exists d _ {i} \geq 0: C _ {i} = C _ {0} + d _ {i}
$$

并且 f 是分段常数：$\forall i: f | _ { C _ { i } } \equiv c _ { i }$。

b) $C _ { i }$ 上的概率分布是彼此的平移和缩放版本，平移常数与上述相同：对于 $x \in C _ { i }$，$P ( X = x )$ 满足

$$
P (X = x) = P (X = x - d _ {i}) \cdot \frac {P (X \in C _ {i})}{P (X \in C _ {0})}.
$$

c) 集合 $c _ { i } + \operatorname { s u p p } N _ { Y } : = \{ c _ { i } + h : P ( N _ { Y } = h ) > 0 \}$ 是互不相交的集合。

（由对称性，对于 Y 的支撑也存在满足相同准则的这样的分解。）图 4.3 显示了一个允许两个方向 ANM 的例子 [Peters 等人, 2011a]。

对于模 m 的离散 ANM，也有类似的结果。我们推荐读者参考 Peters 等人 [2011a] 了解所有细节；然而，我们想提一下，均匀噪声分布扮演着一个特殊角色：$Y \equiv f ( X ) + N _ { Y } \mod m$，其中噪声变量在 $\{ 0 , \ldots , m - 1 \}$ 上均匀分布，会导致 X 和 Y 独立，因此也允许从 Y 到 X 的 ANM。

离散 ANM 对底层过程施加了很强的假设，这些假设在实践中经常被违反。与连续情况一样，我们想要论证，如果过程允许一个方向的离散 ANM，那么将该方向推断为因果关系可能是合理的（另见第 4.1.9 节）。

### 4.1.6 后非线性模型（Post-nonlinear Models）

Zhang 和 Hyvärinen [2009] 分析了一个比第 4.1.4 节中介绍的更一般的模型类；早期参考文献见 Zhang 和 Chan [2006]。

定义 4.7 (后非线性模型) 如果存在函数 $f _ { Y } , g _ { Y }$ 和一个噪声变量 $N _ { Y }$，使得

$$
Y = g _ {Y} (f _ {Y} (X) + N _ {Y}), \quad N _ {Y} \perp X. \tag {4.9}
$$

则称分布 $P _ { X , Y }$ 允许一个后非线性模型。

以下结果本质上表明，除了某些“罕见”的非一般情况外，后非线性模型最多存在于一个方向⁴。

定理 4.8 (后非线性模型的可识别性) 设 $P _ { X , Y }$ 允许一个从 X 到 Y 的后非线性模型，如 (4.9) 所示，并且 $p _ { X } , f _ { Y } , g _ { Y }$ 是三次可微的。那么，它允许一个从 Y 到 X 的后非线性模型，仅当 $p_X , f_Y , g_Y$ 在 Zhang 和 Hyvärinen [2009] 描述的微分方程意义上相互调整。

### 4.1.7 信息几何因果推断（Information-Geometric Causal Inference）

为了提供如何形式化 $P _ { E | C }$ 和 $P _ { C }$ 之间独立性的思路，本节描述**信息几何因果推断（Information-Geometric Causal Inference, IGCI）**。IGCI，特别是这里描述的简单版本，是一个高度理想化的玩具场景，很好地说明了在一个方向的独立性如何意味着另一个方向的相关性 [Daniusis 等人, 2010, Janzing 等人, 2012]。它依赖于（诚然是强的）假设，即 X 和 Y 在两个方向上都存在确定性关系；也就是说，

$$
Y = f (X) \quad \text { and } \quad X = f ^ {- 1} (Y).
$$

换句话说，(3.2) 中的噪声变量是常数。那么第 4.1.2 节中描述的**原因与机制独立性原理**简化为 $P _ { X }$ 和 $f$ 的独立性。值得注意的是，这种独立性意味着 $P _ { Y }$ 和 $f ^ { - 1 }$ 之间的相关性。为了展示这一点，我们考虑 Daniusis 等人 [2010] 更一般设置中的以下特例。

定义 4.9 (IGCI 模型) 这里，如果满足以下条件，则称 $P _ { X , Y }$ 满足从 X 到 Y 的 IGCI 模型：$Y = f ( X )$，其中 $f$ 是 [0, 1] 上的一个微分同胚⁵，严格单调，并且满足 $f ( 0 ) = 0$ 和 $f ( 1 ) = 1$。此外，$P _ { X }$ 具有严格正的连续密度 $p _ { X }$，使得以下“独立性条件”成立：

$$
\operatorname{cov} \left[ \log f ^ {\prime}, p _ {X} \right] = 0, \tag {4.10}
$$

其中 $\log f ^ { \prime }$ 和 $p _ { X }$ 被视为赋予均匀分布的概率空间 [0, 1] 上的随机变量⁶。

注意，(4.10) 中的协方差明确由下式给出

$$
\begin{array}{l} \operatorname{cov} \left[ \log f ^ {\prime}, p _ {X} \right] = \int_ {0} ^ {1} \log f ^ {\prime} (x) p _ {X} (x) d x - \int_ {0} ^ {1} \log f ^ {\prime} (x) d x \int_ {0} ^ {1} p _ {X} (x) d x \\ = \int_ {0} ^ {1} \log f ^ {\prime} (x) p _ {X} (x) d x - \int_ {0} ^ {1} \log f ^ {\prime} (x) d x. \\ \end{array}
$$

以下结果在 Daniusis 等人 [2010] 和 Janzing 等人 [2012] 中给出。

定理 4.10 (IGCI 模型的可识别性) 假设分布 $P _ { X , Y }$ 允许一个从 X 到 Y 的 IGCI 模型。那么反函数 $f ^ { - 1 }$ 满足

$$
\operatorname{cov} [ \log f ^ {- 1 ^ {\prime}}, p _ {Y} ] \geq 0, \tag {4.11}
$$

当且仅当 $f$ 是恒等映射时取等号。

### 4.1.8 迹方法（Trace Method）

Janzing 等人 [2010] 和 Zscheischler 等人 [2011] 描述了当 C 和 E 是由线性 SCM 耦合的高维变量时，$P _ { C }$ 和 $P _ { E | C }$ 之间的一种与 IGCI 相关的独立性：

定义 4.11 (迹条件) 设 X 和 Y 分别是取值于 $\mathbb { R } ^ { d }$ 和 $\mathbb { R } ^ { e }$ 的变量，满足线性模型

$$
\mathbf {Y} = A \mathbf {X} + N _ {\mathbf {X}}, \quad N _ {\mathbf {X}} \perp \perp \mathbf {X}, \tag {4.12}
$$

其中 A 是一个 $e \times d$ 的结构系数矩阵。那么，如果协方差矩阵 $\Sigma _ { \mathbf { X } \mathbf { X } }$ 和 A 在以下意义上是“独立”的，则称 $P _ { \mathbf { X } , \mathbf { Y } }$ 满足从 X 到 Y 的迹条件：

$$
\tau_ {e} (A \Sigma_ {\mathbf {X X}} A ^ {T}) = \tau_ {d} (\Sigma_ {\mathbf {X X}}) \tau_ {e} (A A ^ {T}), \tag {4.13}
$$

其中 $\tau _ { k } ( B ) : = \mathrm { t r } ( B ) / k$ 表示矩阵 B 的归一化迹。

违反迹条件的一个简单情况是由一个矩阵 A 给出的，该矩阵收缩 $\Sigma _ { \mathbf { X } \mathbf { X } }$ 中对应大特征值的所有特征向量，并拉伸那些对应小特征值的特征向量。这肯定表明 A 不是独立于 $\Sigma _ { \mathbf { X } \mathbf { X } }$ 选择的。粗略地说，(4.13) 描述了 $\Sigma _ { \mathbf { X } \mathbf { X } }$ 的特征值与 A 改变相应特征向量长度的因子之间的不相关性。更正式地说，(4.13) 可以通过一个生成模型来论证，该模型具有大的 d, e，其中 $\Sigma _ { \mathbf { X } \mathbf { X } }$ 和 A 根据适当的（旋转不变的）先验概率独立随机选择。那么它们以高概率近似满足 (4.13) [Besserve 等人, 准备中]。

对于确定性可逆关系，因果方向是可识别的。

定理 4.12 (通过迹条件的可识别性) 设变量 X 和 Y 都是 d 维的，且 $\mathbf { Y } = A \mathbf { X }$，其中 A 是可逆的。如果从 X 到 Y 的迹条件 (4.13) 成立，那么反向模型

$$
\mathbf {X} = A ^ {- 1} \mathbf {Y}

满足

$$
\tau_ {d} (A ^ {- 1} \Sigma_ {\mathbf {Y Y}} A ^ {- T}) \leq \tau_ {d} (\Sigma_ {\mathbf {Y Y}}) \tau_ {d} (A ^ {- 1} A ^ {- T}),
$$

当且仅当 A 的所有奇异值具有相同的绝对值时取等号。

### 4.1.9 算法信息论作为可能的基础（Algorithmic Information Theory as Possible Foundation）

本节描述了一个独立性原则，尽管它依赖于一个明确定义的数学形式体系，但其在实践中如何应用尚不清楚。因此，它扮演了一个中间角色：一方面联系着第2.1节中关于因果推断基础的、非正式的哲学讨论；另一方面联系着第4.1.3至4.1.8节中关于原因与结果之间可能存在的不对称性的具体结论，这些结论依赖于相当具体的模型假设。

对于比第4.1.7和4.1.8节中考虑的模型更一般的模型，要将 $P _ { E }$ 和 $P _ { C | E }$ 彼此不包含对方信息这一概念形式化，是很有挑战性的。这需要一种涉及随机变量之外的其他对象的信息概念。这是因为 $P _ { E }$ 和 $P _ { C | E }$ 本身不是随机变量，而是描述随机变量的分布。**柯尔莫哥洛夫复杂度（Kolmogorov complexity）** 提供了一种有趣的信息概念，我们现在简要解释一下。

**算法信息论的概念（Notions of Algorithmic Information Theory）** 我们首先介绍柯尔莫哥洛夫复杂度：考虑一个通用图灵机 T，即一台理想计算机的抽象，其意义在于拥有无限的内存空间。对于任何二进制字符串 s，我们将 $K _ { T } ( s )$ 定义为能使 T 输出 s 然后停止的最短程序7的长度，记为 $s ^ { * }$ [Solomonoff, 1964, Kolmogorov, 1965, Chaitin, 1966, Li and Vitanyi, 1997]。我们可以称 $s ^ { * }$ 为 s 的最短压缩，但要记住 $s ^ { * }$ 包含了 T 运行解压所需的所有信息。因此，

$$
K _ {T} (s) := | s ^ {*} |,
$$

其中 |·| 表示一个二进制字的位数。这定义了一个相对于给定图灵机 T 的、无概率的信息内容概念。在下文中，我们将参考某个固定的 T，因此省略下标。尽管 $K ( s )$ 是不可计算的，即不存在从 s 计算 $K ( s )$ 的算法 [Li and Vitanyi, 1997]，但它对于形式化概念性思想仍然有用，正如本节所做的那样。

给定 t 时 s 的**条件算法信息（conditional algorithmic information）** 记为 $K ( s | t )$，定义为从输入字符串 t 生成输出 s 然后停止的最短程序的长度。然后我们可以将**互信息（mutual information）** 定义为8

$$
I (s: t) := K (s) - K (s | t ^ {*}).
$$

特别地，我们有 [Chaitin, 1966]：

$$
I (s: t) \stackrel {+} {=} K (s) + K (t) - K (s, t), \tag {4.14}
$$

其中符号 $\stackrel { + } { = }$ 表示等式仅在常数项范围内成立；也就是说，存在一个误差项，其长度可以被独立于 s 和 t 长度的界限所限定。为了定义对 $( s , t )$ 的柯尔莫哥洛夫复杂度 $K ( s , t )$，我们首先使用某种字符串枚举法，然后使用 N 与 $\mathbb { N } \times \mathbb { N }$ 之间的标准双射，构造一个从字符串到字符串对的双射。

(4.14) 的一个简单解释是，**算法互信息（algorithmic mutual information）** 量化了将 s 和 t 联合压缩与独立压缩相比所节省的内存空间量。Janzing 和 Scholkopf [2010] 认为，如果两个对象的二进制描述 s 和 t 具有大量的互信息，那么它们很可能是因果相关的。换句话说，正如随机变量之间的统计相关性表明因果关系一样（参见原则1.1），对象之间的算法相关性表明对象之间的因果关系。例如，观察到两家不同公司生产的、具有相似设计的 T 恤，可能表明一家公司抄袭了另一家公司。实际上，现实生活中的模式相似性可以通过算法互信息来描述，前提是首先就一种将模式编码为二进制字的“适当”方式达成一致，然后就一个“适当”的图灵机达成一致。关于“适当”意味着什么这个难题，另请参见 Janzing 等人 [2016] 引言中对“相对因果性”的简要讨论。

**条件分布的算法独立性（Algorithmic Independence of Conditionals）** **算法独立条件分布（algorithmically independent conditionals）** 原则由 Janzing 和 Scholkopf [2010] 以及 Lemeire 和 Janzing [2013] 针对多变量因果结构提出，但它在双变量情形下已经产生了非平凡的含义。

对于两个变量 C 和 E，分别是原因和结果，我们假设 $P _ { C }$ 和 $P _ { E | C }$ 可以分别由二进制字符串 s 和 t 有限描述。在参数化设定中，s 和 t 可以描述相应参数空间中的点。或者，可以将 s 和 t 视为计算所有具有有限描述长度的值 $c , e$ 的 $p ( c )$ 和 $p ( e | c )$ 的程序。然后，我们用 $I ( s : t )$ 来表示 $I ( P _ { C } : P _ { E | C } )$，并假设：

**原则 4.13（算法独立条件分布）（Principle 4.13 (Algorithmically independent conditionals)）** $P _ { C }$ 和 $P _ { E | C }$ 是算法独立的，即

$$
I (P _ {C}: P _ {E | C}) \stackrel {\pm} {=} 0, \tag {4.15}
$$

或者等价地，

$$
K (P _ {C, E}) \stackrel {+} {=} K (P _ {C}) + K (P _ {E | C}). \tag {4.16}
$$

(4.15) 和 (4.16) 的等价性是直接的，因为描述对 $( P _ { C } , P _ { E | C } )$ 等价于描述联合分布 $P _ { C , E }$。原则 4.13 的思想是，$P _ { C }$ 和 $P _ { E | C }$ 是因果上不相关的自然对象。这当然是一个理想化的假设，但对于 X 导致 Y 或 Y 导致 X 的设定，它建议：当 $P _ { X }$ 和 $P _ { Y | X }$ 之间的算法依赖性弱于 $P _ { X | Y }$ 和 $P _ { Y }$ 之间的算法依赖性时，推断 $X  Y$。然而，将此应用于经验数据会引发一个问题，即在算法互信息不可计算的问题之上，$P _ { X , Y }$ 无法从有限数据中确定。

尽管存在这些问题，原则 4.13 有助于证明实际因果推断方法的合理性，我们现在以 **ANM** 为例进行描述。Janzing 和 Steudel [2010] 认为，**结构因果模型（Structural Causal Model, SCM）** $Y : = f _ { Y } ( X ) + N _ { Y }$ 意味着 $y \mapsto \log p ( y )$ 的二阶导数由 $( x , y ) \mapsto \log p ( x | y )$ 的偏导数决定。因此，知道 $P _ { X | Y }$ 就允许对 $P _ { Y }$ 进行简短描述（达到一定精度）。只要 $K ( P _ { Y } )$ 大于这个少量的信息，Janzing 和 Steudel [2010] 就得出结论，应该拒绝 $Y  X$，因为 $P _ { Y }$ 和 $P _ { X | Y }$ 是算法相关的。对于任何给定的数据集，我们不能仅仅因为存在从 Y 到 X 的 ANM 就保证 $\dot { K } ( P _ { Y } )$ 足够大以至于可以拒绝 $Y  X$。然而，当将基于 ANM 原则的推断应用于大量不同的分布时，我们知道大多数分布 $P _ { Y }$ 是足够复杂的（因为低复杂度分布的集合很小），这足以证明拒绝那些在相反方向上引入 ANM 的因果模型是合理的。此外，图 5.4 的左侧和右侧展示了两个简单的玩具示例，其中仅观察 $P _ { X }$ 就能为联合分布 $P _ { X , Y }$ 提供一个简单的猜测。实际上，可以证明这相当于 $P _ { X }$ 和 $P _ { Y | X }$ 之间的算法依赖性，如 Janzing 和 Scholkopf [2010，方程 (27) 后的评论] 对左侧情况所示。

我们还应该指出，(4.15) 蕴含

$$
K (P _ {C}) + K (P _ {E | C}) \stackrel {+} {=} K (P _ {C, E}) \stackrel {+} {\leq} K (P _ {E}) + K (P _ {C | E}). \tag {4.17}
$$

等式成立是因为描述 $P _ { C , E }$ 等价于描述对 $( P _ { C } , P _ { E | C } )$，这并不比分别描述边际分布和条件分布更短。不等式成立是因为 $P _ { E }$ 和 $P _ { C | E }$ 也决定了 $P _ { C , E }$。换句话说，条件分布的独立性意味着联合分布在因果方向上的描述比在反因果方向上的描述更短。9 这个推论从**最小描述长度原则（minimum description length principle）** [Grunwald, 2007] 和**奥卡姆剃刀（Occam’s razor）** 精神的角度来看也很自然。然而，请注意，条件 $K ( P _ { C } ) + K ( P _ { E | C } ) \stackrel { + } { \leq } K ( P _ { E } ) + K ( P _ { C | E } )$ 严格弱于 (4.15)，因为 $P _ { C , E }$ 的最短描述可能不使用两种可能的分解中的任何一种，例如当存在隐藏的共同原因时就会发生这种情况 [Janzing and Scholkopf, 2010, p. 16]。

原则 6.53 将原则 4.13 推广到了多变量设定。

## 4.2 结构识别的方法（Methods for Structure Identification）

我们现在介绍如何利用第4.1节中获得的**可识别性（identifiability）** 结果进行因果发现的几种不同思路。也就是说，这些方法从有限数据集中估计出一个图。这些是具有挑战性的统计问题，可以通过多种不同的方法来解决。我们试图聚焦于方法论思想，并不声称我们提出的方法能最高效地利用数据。未来的研究很有可能产生新颖且成功的方法。我们将注意力限制在几个例子上，主要是那些我们对其性能有合理经验的例子。

### 4.2.1 加性噪声模型（Additive Noise Models）

对于基于定理4.5中 ANM 可识别性的因果学习方法，我们主要参考多变量章节（第7.2节）。在这里，我们勾画两种方法，但不声称其最优性。第一种方法检验残差的独立性，它是**回归与后续独立性检验（Regression with Subsequent Independence Test, RESIT）** 算法的一个特例（见第7.2节）。

1.  将 Y 对 X 进行回归；即使用某种回归技术将 Y 写成 X 的函数 $\hat { f } _ { Y }$ 加上一些噪声。
2.  检验 $Y - { \hat { f } } _ { Y } ( X )$ 是否与 X 独立。
3.  交换 X 和 Y 的角色，重复上述过程。
4.  如果对一个方向接受独立性而对另一个方向拒绝独立性，则推断前者为因果方向。

图4.5展示了在模拟数据集上的这个过程；底层分布见图4.1。至少在连续设定中，前两个步骤是机器学习和统计学的标准问题（见附录A.1和A.2），但额外的挑战在于它们是耦合的：$\hat { f } _ { Y }$ 偏离 $f _ { Y }$ 可能会隐藏或创建噪声与输入变量之间的依赖性。一般来说，任何基于估计残差的检验都可能失去其第一类错误控制。一个可能的解决方案是使用**样本分割（sample splitting）** [Kpotufe 等人，2014]。此外，选择一个能够处理高阶统计量而不仅仅是检验相关性的独立性检验非常重要。任何最小化二次误差的回归技术，如果包含线性分量和截距，都会产生不相关的噪声。10 在实践中，可以使用例如**希尔伯特-施密特独立性准则（Hilbert-Schmidt Independence Criterion, HSIC）** [Gretton 等人，2008]，我们在附录A.2中简要介绍。Mooij 等人 [2016，定理20] 利用 HSIC 的连续性性质表明，即使没有样本分割，在无限数据的极限下也能获得 HSIC 的正确值（然而，没有关于检验 p 值的声明）。最后，最后一步值得我们特别关注，因为它涉及概率与因果性之间的关系。根据拒绝和接受独立性的显著性水平，我们可能会在两个方向上都得到 ANM，或者都没有，或者只在一个方向上得到。为了强制做出决定，我们只需推断出拒绝独立性的 p 值较高的那个方向为因果方向。

最近的研究提供了一些证据，表明该方法在真实数据上的成功率高于随机水平 [Mooij 等人，2016]。图4.6显示了真实世界数据11的散点图，这些数据仅在因果方向上较好地满足 ANM。关于离散数据的修改，我们参考相应的文献 [Peters 等人，2011a]。请注意，**后非线性模型（post-nonlinear model）** (4.9) 在实践中比更标准的非线性回归模型 (4.3) 更难拟合。

作为前述方法的替代方案，也可以使用基于**最大似然（maximum likelihood）** 的方法。例如，考虑一个具有加性高斯误差项的非线性 SCM。然后，可以通过比较两个模型的似然分数来区分 X → Y 和 X ← Y。为此，我们首先执行 Y 对 X 的非线性回归，以获得残差 $R _ { Y } : = Y - \hat { f } _ { Y } ( X )$。然后我们比较

$$
L _ {X \rightarrow Y} = - \log \widehat {\operatorname{var}} [ X ] - \log \widehat {\operatorname{var}} [ R _ {Y} ] \tag {4.18}
$$

与交换 X 和 Y 角色后得到的类似版本

$$
L _ {X \leftarrow Y} = - \log \widehat {\operatorname{var}} [ R _ {X} ] - \log \widehat {\operatorname{var}} [ Y ] \tag {4.19}
$$

不难证明（见问题4.16），当我们使用真实的条件均值 ${ \hat { f } } _ { Y } ( x ) = \mathbb { E } [ Y | X = x ]$（以及类似的 ${ \hat { f } } _ { X }$）而不是执行回归时，这确实对应于似然的比较。然而，和之前一样，这种先执行回归再计算样本方差的两步法需要证明其合理性。Buhlmann 等人 [2014] 使用**经验过程理论（empirical process theory）** [van de Geer, 2009] 来证明其一致性。如果噪声不一定服从高斯分布，我们必须调整评分函数，用误差项的**微分熵（differential entropy）** 估计值替换残差经验方差的对数 [Nowzohour and Buhlmann, 2016]。

**代码片段 4.14（Code Snippet 4.14）** 以下代码展示了一个有限数据集的示例。它使用了代码包 `dHSIC` [Pfister 等人，2017] 和 `mgcv` [Wood, 2006]。前者包含函数 `dhsic.test`，是 [Gretton 等人，2008] 提出的独立性检验的实现；后者包含函数 `gam`，我们在第10和11行将其用作非线性回归方法（见第A.1节）。只有在反向方向上，残差和输入之间的独立性被拒绝，见第15和17行。在第21和23行，我们看到高斯似然分数也偏向于正向方向；另见方程 (4.18) 和 (4.19)。

### 4.2.2 信息几何因果推断（Information-Geometric Causal Inference）

我们简要概述 **信息几何因果推断（Information-Geometric Causal Inference, IGCI）** 的实现，详细内容请参考 Mooij 等人 [2016] 的工作。其理论基础由定理 4.10 中的可辨识性结果及其一些简单推论给出。可以证明，独立性条件 (4.10) 意味着

$$
C _ {X \rightarrow Y} \leq C _ {Y \rightarrow X}
$$

如果定义

$$
C _ {X \rightarrow Y} := \int_ {0} ^ {1} \log f ^ {\prime} (x) p (x) d x,
$$

并且 $C _ { Y  X }$ 的定义类似。这里，使用以下直接估计量：

$$
\hat {C} _ {X \rightarrow Y} := \frac {1}{N - 1} \sum_ {j = 1} ^ {N - 1} \log \frac {\left| y _ {j + 1} - y _ {j} \right|}{\left| x _ {j + 1} - x _ {j} \right|},
$$

其中 $x _ { 1 } < x _ { 2 } < \dots < x _ { N }$ 是按升序排列的观测到的 $x$ 值。如果 $Y$ 是 $X$ 的增函数，则 $y$ 值也是有序的，但对于真实数据，通常情况并非如此。估计量 $\hat { C } _ { Y  X }$ 的定义类似，并且当 $\hat { C } _ { X  Y } < \hat { C } _ { Y  X }$ 时，推断出 $X  Y$。除了所谓的基于斜率的方法外，还有一种基于熵的方法。可以证明，(4.10) 也意味着

$$
H (X) \leq H (Y),
$$

其中 $H$ 表示**微分香农熵（differential Shannon entropy）**

$$
H (X) := - \int_ {0} ^ {1} p (x) \log p (x) d x.
$$

直观上，原因在于将非线性函数 $f$ 应用于 $p _ { X }$ 会产生额外的非正则性（除非 $f$ 的非线性与 $p _ { X }$ 相匹配），从而使 $p _ { Y }$ 比 $p _ { X }$ 更不均匀。因此，具有较大熵的变量被认为是原因。为了估计 $H _ { \cdot }$ ，可以使用文献中的任何标准熵估计量。

### 4.2.3 迹方法（Trace Method）

回顾一下，该方法依赖于高维变量 $X$ 和 $Y$ 之间的线性关系。首先假设样本量足够大（相对于 $X$ 和 $Y$ 的维度），以便通过标准线性回归估计协方差矩阵 $\Sigma _ { \mathbf { X X } }$ 和 $\Sigma _ { \mathbf { Y Y } }$ 以及结构矩阵 $A \mathbf { \hat { Y } }$ 和 $A \mathbf { x }$ 。为了利用定理 4.12 中的可辨识性结果，可以计算**迹依赖比（tracial dependency ratio）**

$$
r _ {X \to Y} := \frac {\tau (A _ {\mathbf {Y}} \Sigma_ {\mathbf {X X}} A _ {\mathbf {Y}} ^ {T})}{\tau (A _ {\mathbf {Y}} A _ {\mathbf {Y}} ^ {T}) \tau (\Sigma_ {\mathbf {X X}})},
$$

类似地计算 $r _ { Y  X }$ （通过交换 $X$ 和 $Y$ 的角色），并推断更接近 1 的那个值对应于因果方向 [Janzing 等人，2010]。

Zscheischler 等人 [2011] 描述了一种方法来评估偏离 1 是否显著，该方法基于一个生成模型，在该模型中，两个矩阵 $A$ 和 $\Sigma _ { \mathbf { X X } }$ 的独立性通过某种随机正交映射（使它们相互旋转）来模拟。利用**自由概率论（free probability theory）** [Voiculescu, 1997]（一个描述大随机矩阵渐近行为的数学框架）的思想，Zscheischler 等人 [2011] 构建了一种在维度大于样本量的情况下实现迹条件的方法。他们表明，在无噪声情况下，尽管没有足够的数据来估计 $\Sigma _ { \mathbf { X } \mathbf { X } }$ 和 $A$，但在对 $A$ 和 $X$ 的经验协方差矩阵附加独立性假设的前提下，仍然可以估计 $r _ { X  Y }$ 。因此，只要估计量显著偏离 1，就可以拒绝假设 $\mathbf X \to \mathbf Y$ 。此时，要么附加的独立性假设是错误的，要么 $r _ { X  Y }$ 显著偏离 1。

### 4.2.4 监督学习方法（Supervised Learning Methods）

最后，我们描述一种从更机器学习的角度处理因果学习的方法。原则上，它能够利用受限的函数类或独立性条件。假设我们得到了形式为 $( \mathcal { D } _ { 1 } , A _ { 1 } ) , \ldots , ( \mathcal { D } _ { n } , A _ { n } )$ 的标记训练数据。这里，每个 $\mathcal { D } _ { i }$ 是一个数据集

$$
\mathcal {D} _ {i} = \left\{\left(X _ {1}, Y _ {1}\right), \dots , \left(X _ {n _ {i}}, Y _ {n _ {i}}\right) \right\}
$$

$( X _ { 1 } , Y _ { 1 } ) , \ldots , ( X _ { n _ { i } } , Y _ { n _ { i } } ) \overset { \mathrm { i i d } } { \sim } P _ { X , Y } ^ { i }$ ，并且 $A _ { i } \in \{ \right. , \left. \}$ 描述了数据集 $\mathcal { D } _ { i }$ 对应于 $X  Y$ 还是 $X  Y$ 。这样，因果学习就变成了一个经典的预测问题，我们可以训练分类器，希望它们能够从已知真实标签的数据集泛化到未见过的测试数据集。

据我们所知，Guyon [2013] 是第一个以挑战赛形式系统研究这种方法的人（提供了合成和真实数据集的混合作为已知真实标签的数据）。很明显，该方法无法通过利用对称特征（如相关性或协方差）来成功。

挑战赛中许多有竞争力的分类器都基于手工制作的特征；例如，边际分布的熵估计，或者由 $X$ 对 $Y$ 或 $Y$ 对 $X$ 进行回归得到的残差分布的熵估计。有趣的是，这些特征可以与**加性噪声模型（Additive Noise Models, ANMs）** 的概念相关联。例如，对于高斯分布的变量，熵是方差对数的线性函数，因此这些特征足以重构得分 (4.18) 和 (4.19)。考虑熵而不是方差的对数，相当于放宽了高斯假设 [Nowzohour and Buhlmann, 2016]。

Lopez-Paz 等人 [2015] 旨在自动构建此类特征。其思想是将联合分布 $P _ { X , Y } ^ { i } , i = 1 , \dots , n$ 映射到一个**再生核希尔伯特空间（reproducing kernel Hilbert space）**（参见附录 A.2），并在该空间中进行分类。在实践中，我们无法获得完整的分布 $P _ { X , Y } ^ { i }$ ，而是使用经验分布作为近似。（类似的方法已被用于区分时间反转的时间序列与其原始版本 [Peters 等人，2009a]。）由于对因果关系的分类似乎依赖于联合分布的相对复杂属性，因此训练集需要大量的样本量 $n$。为了添加有用的模拟数据集，这些数据集必须从可辨识的案例中生成。例如，Lopez-Paz 等人 [2015] 使用了来自 ANMs 的额外样本。

监督学习方法目前还不能作为因果学习的独立方法使用。然而，它们可能被证明是有用的统计工具，能够有效利用已知的可辨识性属性或其组合。

$$

并且 $M _ { X }$ 与 $M _ { Y }$ 独立。

b) 类似于 a) 部分，考虑 SCM

其中 $N _ { X }$ 在 1 和 3 之间均匀分布，$N _ { Y }$ 在 −0.5 和 0.5 之间均匀分布，且与 $N_X$ 独立。同样，画出 $P _ { X , Y }$ 的支撑集，并确信不存在从 $Y$ 到 $X$ 的 ANM。

**习题 4.16 (最大似然估计)**
假设我们有一个来自以下模型的 i.i.d. 数据集 $( X _ { 1 } , Y _ { 1 } ) , \ldots , ( X _ { n } , Y _ { n } )$

$$
Y = f (X) + N _ {Y}, \text {   with   } X \sim \mathcal {N} (\mu_ {X}, \sigma_ {X} ^ {2}), \text {   and   } N _ {Y} \sim \mathcal {N} (\mu_ {N _ {Y}}, \sigma_ {N _ {Y}} ^ {2}) \text {   independent },
$$

其中函数 $f$ 被认为是已知的。

a) 证明 $f ( x ) = \mathbb { E } [ Y | X = x ]$ 。

b) 记 $\mathbf { x } : = ( x _ { 1 } , \ldots , x _ { n } ) , \mathbf { y } : = ( y _ { 1 } , \ldots , y _ { n } )$ 并考虑对数似然函数

$$
\ell_ {\theta} (\mathbf {x}, \mathbf {y}) = \ell_ {\theta} \left(\left(x _ {1}, y _ {1}\right), \dots , \left(x _ {n}, y _ {n}\right)\right) = \sum_ {i = 1} ^ {n} \log p _ {\theta} \left(x _ {i}, y _ {i}\right),
$$

其中 $p _ { \theta }$ 是 $( X , Y )$ 的联合密度，$\theta : = ( \mu _ { X } , \mu _ { N _ { Y } } , \sigma _ { X } ^ { 2 } , \sigma _ { N _ { Y } } ^ { 2 } )$ 。证明对于某个 $c _ { 1 } , c _ { 2 } \in \mathbb { R }$ 且 $c _ { 2 } > 0$

$$
\max _ {\theta} \ell_ {\theta} (\mathbf {x}, \mathbf {y}) = c _ {2} \cdot (c _ {1} - \log \widehat {\mathrm{var}} [ \mathbf {x} ] - \log \widehat {\mathrm{var}} [ \mathbf {y} - f (\mathbf {x}) ]), \tag {4.20}
$$

其中 $\begin{array} { r } { \widehat { \mathrm { v a r } } [ \mathbf { z } ] : = \frac { 1 } { n } \sum _ { i = 1 } ^ { n } ( z _ { i } - \frac { 1 } { n } \sum _ { k = 1 } ^ { n } z _ { k } ) ^ { 2 } } \end{array}$ 估计方差。

方程 (4.20) 为比较表达式 (4.18) 和 (4.19) 提供了动机。主要区别在于，在本练习中，我们使用了条件均值，而不是回归方法的结果。可以证明，渐近地，后者仍然会产生正确的结果 [Buhlmann 等人，2014]。
