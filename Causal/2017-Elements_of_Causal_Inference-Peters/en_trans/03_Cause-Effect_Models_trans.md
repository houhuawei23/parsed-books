# 因果模型（Cause-Effect Models）

本章将针对仅包含两个变量的因果模型，形式化阐述因果关系的一些基本概念。假设这两个变量之间存在非平凡的相关性，且它们的依赖关系并非完全由共同原因导致，这就构成了一个**因果模型（cause-effect model）**。我们将简要介绍**结构因果模型（Structural Causal Models, SCMs）**、**干预（interventions）**和**反事实（counterfactuals）**。所有这些概念都将在多变量因果模型（第6章）的背景下再次定义，我们希望通过首先在双变量情形下介绍这些概念，能使这些思想更易于理解。

## 3.1 结构因果模型（Structural Causal Models）

**结构因果模型（SCMs）** 是连接因果陈述与概率陈述的重要工具。

**定义 3.1（结构因果模型）** 一个具有图 $C \to E$ 的 SCM $\mathfrak{C}$ 由以下两个赋值方程组成：

$$
C := N_C, \tag{3.1}
$$

$$
E := f_E(C, N_E), \tag{3.2}
$$

其中 $N_E \perp \perp N_C$，即 $N_E$ 与 $N_C$ 独立。

在这个模型中，我们将随机变量 $C$ 称为**原因（cause）**，将 $E$ 称为**结果（effect）**。此外，我们称 $C$ 是 $E$ 的直接原因，并将 $C \to E$ 称为**因果图（causal graph）**。例如在示例3.2中讨论干预时，这种表示法有望澄清并符合读者的直觉。

## 3.2 干预（Interventions）

正如第1.4.2节所讨论的，我们通常对系统在干预下的行为感兴趣。被干预的系统会产生另一个分布，该分布通常与观测分布不同。如果任何类型的干预都能导致系统的任意变化，那么这两个分布将变得不相关，我们可能将这两个系统视为两个独立的系统，而不是联合研究它们。这引出了这样一种观点：干预发生后，只有**数据生成过程（data-generating process）**的一部分发生改变。例如，我们可能对这样一种情况感兴趣：变量 $E$ 被设置为值 4（与 $C$ 的值无关），而不改变生成 $C$ 的机制 (3.1)。也就是说，我们将赋值 (3.2) 替换为 $E := 4$。这被称为**（硬）干预（(hard) intervention）**，记作 $do(E := 4)$。修改后的 SCM（其中 (3.2) 被替换）隐含了一个关于 $C$ 的分布，我们将其记为 $P_C^{do(E:=4)}$ 或 $P_C^{\mathfrak{C}; do(E:=4)}$，后者明确指出了 SCM $\mathfrak{C}$ 是我们的起点。相应的密度记作 $c \mapsto p^{do(E:=4)}(c)$，或者稍微滥用符号，记作 $p^{do(\hat{E}:=4)}(c)$。然而，操作可以更加通用。例如，干预 $do\big(E := g_E(C) + \tilde{N}_E\big)$ 保留了关于 $C$ 的函数依赖性，但改变了噪声分布。这是一个**软干预（soft intervention）**的例子。我们可以替换这两个方程中的任意一个。

以下示例阐明了“原因”和“结果”命名的动机：

**示例 3.2（因果干预）** 假设分布 $P_{C,E}$ 由 SCM $\mathfrak{C}$ 蕴含：

$$
C := N_C
$$

$$
E := 4 \cdot C + N_E, \tag{3.3}
$$

其中 $N_C, N_E \overset{\mathrm{iid}}{\sim} \mathcal{N}(0, 1)$，图为 $C \to E$。那么，

$$
P_E^{\mathfrak{C}} = \mathcal{N}(0, 17) \neq \mathcal{N}(8, 1) = P_E^{\mathfrak{C}; do(C:=2)} = P_{E|C=2}^{\mathfrak{C}}
$$

$$
\neq \mathcal{N}(12, 1) = P_E^{\mathfrak{C}; do(C:=3)} = P_{E|C=3}^{\mathfrak{C}}.
$$

对 $C$ 进行干预会改变 $E$ 的分布。但另一方面，

$$
P_C^{\mathfrak{C}; do(E:=2)} = \mathcal{N}(0, 1) = P_C^{\mathfrak{C}} = P_C^{\mathfrak{C}; do(E:=314159265)} \left(\neq P_{C|E=2}^{\mathfrak{C}}\right). \tag{3.4}
$$

无论我们如何强烈地干预 $E$，$C$ 的分布都保持不变。这种模型行为很好地符合我们对 $C$ “导致” $E$ 的直觉：例如，无论我们如何美白某人的牙齿，这都不会影响此人的吸烟习惯。（重要的是，给定 $E=2$ 时 $C$ 的条件分布与干预并将 $E$ 设为 2 后 $C$ 的分布是不同的。）

原因与结果之间的这种不对称性也可以表述为一个独立性陈述。当我们用 $E := \tilde{N}_E$ 替换赋值 (3.3) 时（可以想象为随机化 $E$），我们就打破了 $C$ 和 $E$ 之间的依赖关系。在

$$
P_{C,E}^{\mathfrak{C}; do\left(E := \tilde{N}_E\right)}
$$

中，我们发现 $C \perp \perp E$。这种独立性在随机化 $C$ 时不成立。只要 $\text{var}\left[\tilde{N}_C\right] \neq 0$，我们就会在

$$
P_{C,E}^{\mathfrak{C}; do\left(C := \tilde{N}_C\right)}
$$

中发现 $C \not\perp \perp E$；$C$ 和 $E$ 之间的相关性保持非零。

## 3.3 反事实（Counterfactuals）

另一种可能的 **结构因果模型（Structural Causal Model, SCM）** 修改方式会改变其所有噪声分布。这种改变可以由观测数据引发，并使我们能够回答反事实问题。为了说明这一点，请设想以下假设场景：

**示例 3.4（眼病）** 对于一种眼病，存在一种相当有效的治疗方法。对于 99% 的患者，治疗有效且患者康复 $( B = 0 )$；如果未接受治疗，这些患者会在一天内失明 $( B = 1 )$。对于其余 1% 的患者，治疗会产生相反的效果，他们会在一天内失明 $( B = 1 )$。如果未接受治疗，他们会恢复正常视力 $( B = 0 )$。

患者属于哪一类别由一种罕见病症 $( N _ { B } = 1 )$ 控制，医生对此并不知情，因此医生是否决定施治 $( T = 1 )$ 与 $N _ { B }$ 无关。我们将其写为一个噪声变量 $N _ { T }$。

假设底层 SCM 为

$$
\mathfrak {C}: \begin{array}{l l l} T & := & N _ {T} \\ B & := & T \cdot N _ {B} + (1 - T) \cdot (1 - N _ {B}) \end{array} \tag {3.5}
$$

其中 $N _ { B } \sim \mathrm { B e r } ( 0 . 0 1 )$ 服从伯努利分布（Bernoulli distribution）；注意相应的因果图（causal graph）为 $T  B$。

现在设想一位视力不佳的特定患者来到医院，在医生施治 $( T = 1 )$ 后失明 $( B = 1 )$。我们可以提出反事实问题：“如果医生施治 $T = 0$，会发生什么？” 令人惊讶的是，这个问题是可以回答的。观测值 $B = T = 1$ 结合 (3.5) 意味着，对于该患者，我们有 $N _ { B } = 1$。这进而让我们能够计算 $do ( T : = 0 )$ 的效果。

为此，我们首先以观测结果为条件，更新噪声变量上的分布。正如我们所看到的，以 $B = T = 1$ 为条件，$N _ { B }$ 和 $N _ { T }$ 的分布坍缩为 1 上的点质量，即 $\delta _ { 1 }$。这导致了一个修改后的 SCM：

$$
\mathfrak {C} | B = 1, T = 1: \begin{array}{l l l} T & := & 1 \\ B & := & T \cdot 1 + (1 - T) \cdot (1 - 1) = T \end{array} \tag {3.6}
$$

请注意，我们只更新了噪声分布；条件作用（conditioning）不会改变赋值结构本身。其思想是物理机制（在我们的例子中，是什么导致了治愈、什么导致了失明）保持不变，但我们获得了关于该患者先前未知的噪声变量的知识。

接下来，我们计算对该患者执行 $do (T = 0)$ 的效果：

$$
\mathfrak {C} | B = 1, T = 1; d o (T := 0): \begin{array}{l l l} T & := & 0 \\ B & := & T \end{array} \tag {3.7}
$$

显然，其所蕴含的分布将所有质量置于 $(0, 0)$ 上，因此

$$
P ^ {\mathfrak {C} | B = 1, T = 1; d o (T := 0)} (B = 0) = 1.
$$

这意味着，如果医生没有给该患者施治，即执行 $do ( T : = 0 )$，患者本来会康复 $(B = 0)$。然而，由于

$$
P ^ {\mathfrak {C}; d o (T := 1)} (B = 0) = 0. 9 9 \quad \text { 和 }
$$

$$
P ^ {\mathfrak {C}; d o (T := 0)} (B = 0) = 0. 0 1,
$$

我们仍然可以论证医生（根据现有知识）采取了最优行动。

有趣的是，示例 3.4 表明，我们可以使用反事实陈述来证伪底层因果模型（参见第 6.8 节）。设想稀有病症 $N _ { B }$ 是可以检测的，但检测结果需要超过一天时间。在这种情况下，我们可能会观察到与 $N _ { B }$ 测量结果相矛盾的反事实陈述。Pearl [2009, p.220, point (2)] 也给出了相同的论证。由于反事实的科学内容一直备受争议，需要强调的是，这里的反事实陈述是可证伪的，因为噪声变量原则上并非不可观测，而只是在医生必须做出决策的时刻不可观测。

## 3.4 结构因果模型的规范表示（Canonical Representation of Structural Causal Models）

我们讨论了 SCM 所蕴含的两种因果陈述：首先，系统在潜在干预下的行为；其次，反事实陈述。为了进一步理解它们之间的区别，我们引入以下 SCM 的“规范表示”。根据结构赋值

$$
E = f _ {E} (C, N _ {E}),
$$

对于噪声 $N _ { E }$ 的每个固定值 $n _ { E }$，$E$ 是 $C$ 的一个确定性函数：

$$
E = f _ {E} (C, n _ {E}). \tag {3.8}
$$

换句话说，如果 $C$ 和 $E$ 分别取值于 $C$ 和 $E$，那么噪声 $N _ { E }$ 会在从 $C$ 到 $E$ 的不同函数之间切换。因此，不失一般性，我们可以假设 $N _ { E }$ 取值于从 $C$ 到 $E$ 的函数集合，记作 $\mathcal { E } ^ { \mathcal { C } }$。使用这一约定，我们也可以将 (3.8) 重写为

$$
E = n _ {E} (C), \tag {3.9}
$$

并称之为联系 $C$ 和 $E$ 的结构方程（structural equation）的规范表示。

现在让我们解释，为什么具有不同规范表示的两个 SCM 可能诱导相同的干预概率（interventional probabilities），尽管它们的反事实陈述不同。为此，我们将注意力限制在 $C$ 取值于有限集合 ${ \mathcal { C } } = \{ 1 , \ldots , k \}$ 的情况。那么，从 $C$ 到 $E$ 的函数集合由 $k$ 重笛卡尔积（Cartesian product）给出：

$$
\mathcal {E} ^ {k} := \underbrace {\mathcal {E} \times \cdots \times \mathcal {E}} _ {k \text { 次}},
$$

其中第 $j$ 个分量描述了当 $C = j$ 时 $E$ 取何值。相应地，分布 $P _ { N _ { E } }$ 由 $\mathcal { E } ^ { k }$ 上的一个联合分布（joint distribution）给出，其第 $j$ 个分量的边际分布（marginal distribution）决定了条件分布 $P _ { E | C = j }$。由于 $P _ { E } ^ { d o \left( C : = j \right) } = P _ { E | C = j }$，干预概率和观测条件概率是一致的。因此，SCM 的干预因果含义完全由向量值噪声变量 $N _ { E }$ 每个分量的边际分布决定，尽管 SCM 包含了 $P _ { N _ { E } }$ 的精确规范，即所有分量的联合分布。虽然涉及效果的噪声变量 $N _ { E }$ 各分量之间的统计依赖性（statistical dependences）与干预因果陈述无关，但它们对反事实陈述确实很重要。为了说明这一点，设 $C$ 和 $E$ 为二值变量，即 ${ \mathcal { C } } = { \mathcal { E } } = \{ 0 , 1 \}$。从 {0, 1} 到 {0, 1} 的函数集合为 $\mathcal { E } ^ { \mathcal { C } } = \{ \mathbf { 0 } , \mathbf { 1 } , \mathrm { I D } , \mathrm { N O T } \}$，其中 0、1 分别表示取值为 0 和 1 的常函数，ID 和 NOT 分别表示恒等函数和取反函数。为了构造两个不同的分布 $P _ { N _ { E } } ^ { 1 }$ 和 $P _ { N _ { E } } ^ { 2 }$，使其诱导相同的条件分布 $P _ { E | C = 0 } , P _ { E | C = 1 }$，首先选择 0 和 1 的均匀混合，其次选择 ID 和 NOT 的均匀混合。在这两种情况下，$C$ 和 $E$ 统计独立，并且 $E$ 的分布不受 $C$ 上干预的影响，因为无论 $C$ 如何，$E$ 仍然是一个无偏的抛硬币结果。在笛卡尔积表示中，这四个

函数为 $\mathcal { E } ^ { \mathcal { C } } = \{ ( 0 , 0 ) , ( 1 , 1 ) , ( 0 , 1 ) , ( 1 , 0 ) \}$，第一个和第二个分量分别表示 $C = 0$ 和 $C = 1$ 的像。显然，$( 0 , 0 )$ 和 (1, 1) 的均匀混合与 (0, 1) 和 $( 1 , 0 )$ 的均匀混合都在笛卡尔积的第一个和第二个分量上诱导出相同的边际分布——这与我们关于它们诱导相同干预分布的评论一致。然而，反事实陈述“如果 $C$ 被设为另一个不同的值，$E$ 会达到一个不同的值”仅对 ID 和 NOT 的混合成立，而对 0 和 1 的混合不成立。因此，反事实陈述不仅依赖于噪声变量 $N _ { E }$ 各分量的边际分布，还依赖于笛卡尔积分量之间的统计依赖性。

请注意，两个形式上不同的 SCM 可能不仅诱导相同的干预分布，甚至蕴含相同的反事实陈述：给定赋值

$$
E := f _ {E} (C, N _ {E}),
$$

对 $N _ { E }$ 的重参数化显然无关紧要。更明确地说，对于 $N _ { E }$ 值域上的某个双射（bijection）$g$，我们可以设

$$
E := \tilde {f} _ {E} (C, \tilde {N} _ {E}) = f _ {E} (C, g ^ {- 1} (\tilde {N} _ {E})),
$$

并通过 $\tilde { N } _ { E } : = g ( N _ { E } )$ 重新定义噪声变量。使用规范表示 (3.9)，我们摆脱了这种额外的自由度，否则它会使关于反事实的讨论变得混乱。
