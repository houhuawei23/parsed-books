## 前言（Preface）

**机器学习（Machine Learning）**和**因果推断（Causal Inference）**在过去几十年中已在学术界和工业界引起了广泛关注，但它们主要被视为独立的研究领域。近年来，一些**机器学习模型（machine learning models）**（例如，基于树的模型、深度表示学习模型、对抗学习模型和图神经网络）已被越来越多地用于各种**因果推断问题（causal inference problems）**，如**反事实推断（counterfactual inference）**、**处理效应估计（treatment effect estimation）**和**因果发现（causal discovery）**。此外，**因果性（causality）**已被用来辅助一些具有挑战性的机器学习任务，如**可解释性（explainability）**、**公平性（fairness）**和**领域泛化（domain generalization）**。这种机器学习与因果推断之间的融合促使我们编写本书，以总结该领域的最新研究进展。我们非常幸运地获得了许多机器学习与因果推断领域的顶尖科学家的巨大支持，他们贡献了各章节，对新兴研究课题进行了全面综述。

本书旨在从多个视角为读者提供关于机器学习与因果推断之间关系的见解。它深入探讨了诸如因果推断基础、利用机器学习进行因果效应估计、因果推断在可信机器学习中的贡献，以及因果推断在各个领域的实际应用等主题。

本书由4个部分组成，共包含14章。

- **第一部分**（Part I）在第1章给出了本书概述，并在第2章涵盖了因果推断的基础知识。
- **第二部分**（Part II）侧重于机器学习与因果效应估计。具体而言，第3章讨论了估计因果效应的基本方法，第4章介绍了图上的因果推断，第5章全面讨论了处理效应估计任务的三个核心组成部分（即处理变量、协变量和结果变量）所面临的挑战与机遇。
- **第三部分**（Part III）介绍了因果推断与可信机器学习之间的关系。具体而言，第6章提出了一个基于因果性的公平感知机器学习框架，第7章讨论了因果可解释人工智能系统的设计，第8章介绍了因果感知的领域泛化。
- **第四部分**（Part IV）介绍了因果推断和机器学习在不同领域的应用。第9章讨论了自然语言处理（Natural Language Processing, NLP）中的因果推断。第10章讨论了如何引入不同的因果推断技术来解决推荐系统中的挑战。第11章提出了一个结构因果模型，可用于计算机视觉中实例相关的标签噪声学习。第12章提出了一种带有可解释注意力模块的因果三元注意力时间序列预测模型，该模型利用因果推断来消除混淆效应。第13章介绍了持续因果推断问题，并提出了一个从增量可用的观测数据中估计因果效应的新框架。第14章对本书进行了总结。

总的来说，本书提供了对因果推断方法论的全面回顾、对近期研究工作的及时总结，以及因果推断的各种实际应用，这将使来自不同背景的读者（如高年级本科生和研究生、研究人员、讲师及从业者）受益。
