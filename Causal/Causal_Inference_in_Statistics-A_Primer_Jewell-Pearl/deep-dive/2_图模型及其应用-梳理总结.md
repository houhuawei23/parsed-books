# 📘 第 2 章《图模型及其应用》系统梳理总结

## 一、核心主题与总体框架

本章旨在将 **概率** 、 **图** 和 **结构方程模型（SCM）** 三者联系起来，构建一个统一的框架，使得：

- **拥有 SCM 的研究人员** ，仅凭模型图的结构（无需函数或误差分布的具体信息），即可 **预测数据中的独立性模式** ；
- **观测数据中的独立性模式** ，反过来可用于 **检验假设模型的正确性** ；
- 图的结构与数据结合，可在第 3 章中用于 **定量预测干预的效果** 。

## 二、三大基本结构（三大构件）

### 1. 链（Chain）

**结构：** $X \rightarrow Y \rightarrow Z$

**特性：**

- $X$ 与 $Y$ 可能相关， $Y$ 与 $Z$ 可能相关， $X$ 与 $Z$ 也可能相关
- **条件独立性：** $X$ 与 $Z$ 在给定 $Y$ 的条件下独立
- Y 是链上的 **中间变量** ，拦截了 X → Z 的路径

  **规则 1：** 两个变量 X 和 Y 在给定 Z 的条件下是条件独立的，如果 X 和 Y 之间只有一条单向路径，且 Z 是拦截该路径的任何变量集合。

> **关键前提：** 误差项 $U_X, U_Y, U_Z$ 相互独立。

**例子（SCM 2.2.1-2.2.3）：** 学校资金（X）→ SAT 分数（Y）→ 大学录取率（Z）；开关（X）→ 电路（Y）→ 灯泡（Z）；工作时间（X）→ 训练时间（Y）→ 比赛完成时间（Z）。

### 2. 叉（Fork）

**结构：** $X \leftarrow Y \rightarrow Z$ 或更常见形式： $X \rightarrow Y$ 且 $X \rightarrow Z$

**特性：**

- $X$ 与 $Y$ 可能相关， $X$ 与 $Z$ 可能相关， $Y$ 与 $Z$ 也可能相关
- **条件独立性：** $Y$ 与 $Z$ 在给定 $X$ 的条件下独立
- $X$ 是 $Y$ 和 $Z$ 的 **共同原因（common cause）**

**规则 2：** 叉中的中间变量是其他两个变量及其任何后代的共同原因；当以叉的中心节点为条件时，其子节点之间独立。

**例子（SCM 2.2.5-2.2.6）：** 温度（X）→ 冰淇淋销量（Y）且温度（X）→ 犯罪数量（Z）；开关（X）→ 灯泡 1（Y）且开关（X）→ 灯泡 2（Z）。

### 3. 碰撞器（Collider）

**结构：** $X \rightarrow Z \leftarrow Y$

**特性（与直觉相反！）：**

- $X$ 与 $Z$ 可能相关， $Y$ 与 $Z$ 可能相关
- **边缘独立性：** $X$ 与 $Y$ 无条件 **独立**
- **条件依赖性：** $X$ 与 $Y$ 在给定 $Z$ 的条件下 **很可能依赖**

**规则 3：** 如果变量 Z 是两个变量 X 和 Y 之间的碰撞节点，且 X 和 Y 之间只有一条路径，那么 X 和 Y 是无条件独立的，但在以 Z 和 Z 的任何 **后代** 为条件时是相关的。

> 💡 **核心洞察：** 对碰撞器取条件会在其父节点之间 **人为制造相关性** ——这是统计学中许多悖论和偏倚的根源。

**经典例证：**

1.  **独立硬币抛掷 + 铃铛：** 两枚独立硬币（X, Y），铃铛（Z）在至少一枚为正面时响铃。无条件时 X 与 Y 独立，但听到铃响后两者变得依赖（表 2.1-2.2）。
2.  **蒙提霍尔问题（Monty Hall Problem）：** 你最初选择的门与汽车所在位置独立，但蒙蒂打开一扇有山羊的门（碰撞节点）后，两者变得依赖。
3.  **奖学金类比：** 音乐天赋和学业成就通常独立，但知道某人获得奖学金后，两者的信息变得相关。

## 三、d-分离（d-separation）——核心工具

### 定义与意义

**d-分离（有向分离）** 是一个通用算法，适用于 **任意复杂程度** 的有向无环图（DAG），用于判断任意两个节点之间是否存在条件独立性。

- **d-分离（d-separated）：** 两节点之间所有路径都被阻塞 → **确定独立**
- **d-连通（d-connected）：** 至少一条路径畅通 → **可能相关**

> 🚰 管道比喻：路径如同水管，相关性如水流。一条管道只要有一处堵塞，水就无法流动；但即使多条管道仅一条畅通，水就能流过。

### 路径阻塞的判定（定义 2.4.1）

一条路径 $p$ 被节点集 $Z$ 阻塞，当且仅当 **至少满足以下一个条件** ：

| 条件 | 含义 |
| - | |
| **① 链或叉中的中间节点在 Z 中** | $A \rightarrow B \rightarrow C$ 或 $A \leftarrow B \rightarrow C$ ，且 $B \in Z$ |
| **② 碰撞器不在 Z 中且其后代也不在 Z 中** | $A \rightarrow B \leftarrow C$ ，且 $B \notin Z$ ，且 $B$ 的任何后代都不在 $Z$ 中 |

**结论：** 如果 Z 阻塞了 X 和 Y 之间的 **每一条** 路径，则 X 和 Y 在给定 Z 的条件下 d-分离 → 条件独立。

### 直观记忆口诀

| 节点类型   | 无条件时      | 以该节点为条件时     |
| ---------- | ------------- | -------------------- |
| **链节点** | 相关性可通过  | **阻塞** 路径        |
| **叉节点** | 相关性可通过  | **阻塞** 路径        |
| **碰撞器** | **阻塞** 路径 | 相关性可通过（解锁） |

## 四、模型检验与因果搜索

### 1. 模型检验原理

- 因果图 G 通过 d-分离产生一系列 **可检验的条件独立性** 声明
- 若数据反驳了这些声明（即数据中应有的独立关系不存在）→ **拒绝该模型**
- 优势：
  - ✅ **非参数化：** 不依赖函数形式或分布假设
  - ✅ **局部检验：** 可定位模型的具体错误区域，而非整体拒绝
  - ✅ 即使某些参数无法估计，仍可检验其他部分

### 2. 全局检验 vs. d-分离检验

| 对比维度 | 全局检验（如似然比检验） | d-分离检验 |
| -- | | |
| 参数依赖 | 需要估计参数 | 非参数，仅需图结构 |
| 检验范围 | 整体模型 | 可局部检验 |
| 错误定位 | 无法确定错误位置 | 可定位具体缺陷 |
| 适用场景 | 线性高斯模型等 | 任意函数形式 |

### 3. 等价类（Equivalence Class）

- 多个不同的图可能产生 **相同的可检验含义** （相同的 d-分离集合）
- 两个图属于同一等价类的条件：
  1. 共享相同的 **骨架（skeleton）** ——即相同的边（无视方向）
  2. 共享相同的 **v-结构（v-structures）** ——即父节点不相邻的碰撞器
- 这意味着：从观测数据中，我们最多只能识别到等价类，而非单个图

### 4. 因果搜索（Causal Search）

- 从数据出发， **反向推理** 出可能生成该数据的因果模型
- 通过检验许多候选模型的 d-分离条件，逐步缩减可能的模型集合
- 参考：Pearl (2000), Spirtes & Glymour (1991) 等
