# 第11章 溢出效应与干扰（Spillovers and Interference）

在我们迄今为止的讨论中，我们一直依赖于 **SUTVA 假设**，即对一个人的处理仅影响该目标个体，而不影响他人。这一假设在许多情境下是合理的，例如在医学中评估癌症治疗的益处，或在市场营销中评估客户保留计划的有效性。然而，在其他情境下，这一假设显然存在问题，跨单元的处理溢出效应是一个首要关注的问题。

**例11.** Cai, Janvry 和 Sadoulet [2015] 在中国农村进行了一项随机实验，以了解是否可以通过详细介绍保险产品运作方式的信息会议，促进政府补贴的天气保险的参保率。作者既关注干预措施对参加信息会议者的 **直接效应**，也关注其对参会者朋友的 **溢出效应**。询问溢出效应反映了这样一种潜在信念：给予某些人的信息可能会影响其他人（即他们的朋友）的保险参保决策。

**例12.** Blattman 等人 [2021] 报告了哥伦比亚波哥大犯罪减少措施的随机评估结果。该市将 1,919 条街道确定为犯罪热点地区，并将其随机分配接受增加警力巡逻、增加市政服务、两者同时实施或两者均不实施；作者旨在衡量这些措施对暴力犯罪或财产犯罪的任何影响。分析中的一个担忧是，某些局部干预措施可能不会抑制犯罪，而只是将其转移到邻近街道；作者为此开发了评估此类溢出效应的技术。

**例13.** 网约车平台旨在连接潜在乘客与自由职业司机。许多现有平台预先报价，即它们首先以给定价格向乘客推送行程信息，然后在收到行程请求后寻求与司机匹配。进行实验以优化这些价格以维持健康的市场行为是很自然的，但在此过程中正确考虑溢出效应至关重要。例如，如果随机分配司机激励措施，预计获得此类激励的司机每小时收入将高于未获得的司机。然而，正如 Hall, Horton 和 Knoepfle [2023] 所报告的，向所有人提供此类激励可能不会增加司机的每小时收入——因为激励措施可能吸引更多司机为该平台工作，从而降低现有司机的利用率（即现有司机在积极运送乘客时每小时可能赚得更多，但这一收益可能被增加的闲置时间所抵消）。换句话说，溢出效应通过市场再均衡而产生。

**例14.** 传染病疫苗提供两种针对疾病传播的保护：在可比情况下，接种疫苗的人比未接种疫苗的人感染的可能性更低，并且为足够大比例的人口接种疫苗可能产生 **群体免疫（herd-immunity）** 现象，未接种疫苗的人也能从中受益。群体免疫的出现是一种与评估疫苗接种的公共卫生效益相关的溢出效应；Ogburn 和 VanderWeele [2017] 讨论了一个用于估计这些效应的建模框架。

上述所有例子中的溢出机制各不相同。然而，最终结果是相同的：SUTVA 不成立，需要新的思路来评估干预措施的效果。本章将介绍用于建模和检验溢出效应存在性，以及更广泛的跨单元干扰（即对一个人的处理影响他人）的方法；在下一章中，我们将转向估计和构建置信区间的问题。为简化起见，本章和下一章我们将重点讨论 **随机对照试验（Randomized Controlled Trial, RCT）** 设置。

## 11.1 暴露映射（Exposure mappings）

如第1章所述，我们假设有 $i = 1 , \dots , n$ 个个体的数据，每个个体接受随机二元处理 $W _ { i } \in \{ 0 , 1 \}$，然后经历一个结果 $Y _ { i } \in \mathbb { R }$。然而，在存在干扰的情况下，仅为每个单元定义两个潜在结果已不再合理；相反，每个单元现在可以有最多 $2 ^ { n }$ 个潜在结果 $\{ Y _ { i } ( \mathbf { w } ) : \mathbf { w } \in \{ 0 , 1 \} ^ { n } \}$，对应于整个研究的每种可能的处理分配。相关的潜在结果一致性假设为：

$$
Y _ {i} = Y _ {i} (\mathbf {W}), \quad \mathbf {W} = (W _ {i}) _ {i = 1} ^ {n}. \tag {11.1}
$$

虽然这种表示法与第1章中使用的相似，但问题在实质上更加困难，我们面临一个明显的 **维度灾难（curse of dimensionality）**，即潜在结果的数量随研究规模呈指数级增长。

任何在干扰下进行因果推断的方法都需要对潜在结果施加一些结构，以便能够准确估计处理效应。在此，我们将通过假设一个 **暴露映射（exposure mapping）** 来实现：每个单元都有一个暴露函数 $H _ { i } : \{ 0 , 1 \} ^ { n } \to \{ \mathcal { H } _ { i }$，其性质是 $Y _ { i }$ 仅通过 $H _ { i } ( \mathbf { W } )$ 依赖于完整潜在结果向量 W。

**假设 11.1.** 一个暴露映射是一组特定于单元的函数 $H _ { i } : \{ 0 , 1 \} ^ { n } \to \{ \mathcal { H } _ { i }$。该暴露映射是良好指定的假设意味着，对于所有成对的 w, $\mathbf { w } ^ { \prime } \in \{ 0 , 1 \} ^ { n }$，我们有：

$$
Y _ {i} (\mathbf {w}) = Y _ {i} \left(\mathbf {w} ^ {\prime}\right) \text { whenever } H _ {i} (\mathbf {w}) = H _ {i} \left(\mathbf {w} ^ {\prime}\right). \tag {11.2}
$$

在没有混淆风险时，我们使用重载表示法，例如 $Y _ { i } = Y _ { i } ( H _ { i } ( \mathbf { W } ) )$ 或 $Y _ { i } = Y _ { i } ( H _ { i } )$。

在统计上最容易处理的暴露映射类型是 **聚类干扰模型（cluster-interference model）**。在聚类干扰下，实验单元被划分为不重叠的聚类，使得聚类内的溢出效应可以是任意形式的，但聚类之间不存在溢出效应。形式上，在假设 11.1 的背景下，聚类干扰假设 $H _ { i } ( \mathbf { w } ) = ( w ) _ { j \in C _ { i } }$，其中 $C _ { i }$ 是与第 i 个单元同一聚类中的单元集合。聚类干扰在统计上易于处理的原因是，我们可以简单地将这些聚类重新定义为我们关注的实验单元。那么，不存在跨聚类干扰意味着 SUTVA 在聚类层面成立；因此，我们可以运行一个聚类随机实验，然后使用标准技术进行分析。

**例15.** Crépon 等人 [2013] 研究了求职援助项目的社区层面效应。这类求职援助项目帮助项目参与者找到工作；但作者担心这可能以牺牲非参与者为代价。为了衡量社区效应，他们确定了 235 个独立的劳动力市场（例如城市），并将每个市场随机分配接受不同饱和度（0%、25%、50%、75% 或 100%）的针对活跃求职者的求职援助。然后，作者进行分析，比较不同饱和度水平的市场之间的社区层面结果，即他们将数据作为 RCT 进行分析，其中每个劳动力市场是一个单元，给予该单元的处理是求职援助的饱和度水平。这一分析背后的暴露映射是聚类干扰模型，其中求职者按劳动力市场聚类。

其他应用需要更复杂的暴露映射。例如，在例11的设置中，作者假设某个农民的保险决策可能受到其朋友直接收到的信息以及其自身直接收到的信息的影响。这建议使用农民的社会网络来定义暴露映射，例如通过下面的 **网络干扰模型（network-interference model）**（其中朋友充当网络邻居）。

**定义 11.1.** 在 **网络干扰模型** 下，我们假设每个单元 $i = 1 , \ldots , n$ 有一组网络邻居 $\mathcal { N } _ { i } \subset \{ 1 , \ldots , n \}$，约定 $i \not \in \mathcal { N } _ { i }$，使得以下暴露映射成立：

$$
Y _ {i} = Y _ {i} (H _ {i} (\mathbf {W})), \quad H _ {i} (\mathbf {w}) = (w _ {j}) _ {j \in \{i \} \cup \mathcal {N} _ {i}}. \tag {11.3}
$$

换句话说，网络干扰模型是聚类干扰模型的推广，允许溢出效应的非传递性，并且如果我们对所有 $j \in \mathcal N _ { i }$ 施加传递性 $\{ i \} \cup \mathcal { N } _ { i } = \{ j \} \cup \mathcal { N } _ { j }$，则网络干扰模型简化为聚类干扰模型。在网络干扰下，我们通常无法再通过聚类消除所有溢出效应（因为底层网络可能是完全连通的）；因此需要更仔细的推断技术。我们将在第12章中回到在网络干扰下估计处理效应的问题。然而，在此之前，我们将首先讨论如何检验干扰的存在性。

## 11.2 置换检验（Permutation tests）

在示例 11 中，Cai、Janvry 和 Sadoulet [2015] 对衡量社交网络中信息共享的**溢出效应（spillovers）**感兴趣。假设对于每个单位 $i$，我们知道可能影响其保险选择的友人集合 ${ \mathcal { N } } _ { i }$ 。最简洁的溢出效应模型可能是什么样子的？定义 11.1 中的**网络干扰模型（network interference model）**提供了一个可能的答案，但是否有证据表明需要该模型的全部通用性？

在此设定下，我们很容易想象出一系列替代的**暴露映射（exposure mappings）**层级结构，如下所示：

• $H _ { 0 } { \mathrm { : } }$ **无因果效应（No causal effects）**。 $H _ { i } ( \mathbf { w } ) = \varnothing$ ，且无论处理如何， $Y _ { i } = Y _ { i } ( \emptyset )$ 。
• $H _ { 1 } { \mathrm { : } }$ **无溢出效应（No spillovers）**。 $H _ { i } ( \mathbf { w } ) = w _ { i }$ ，且如第 1 章所述， $Y _ { i } = Y _ { i } ( W _ { i } )$ 。
• $H _ { 2 } ;$ **匿名网络干扰（Anonymous network interference）**。 $H _ { i } ( \mathbf { w } ) ~ = ~ ( w _ { i } , z _ { i } )$ ，其中 $z _ { i } =$ $\textstyle \sum _ { j \in { \mathcal { N } } _ { i } } w _ { i } / \left| \{ { \mathcal { N } } _ { i } \} \right|$ 是已处理友人的比例，且 $Y _ { i } = Y _ { i } ( W _ { i } , Z _ { i } )$ 。
• $H _ { 3 } { \mathrm { : } }$ **网络干扰（Network interference）**。 $H _ { i } ( \mathbf { w } ) = ( w _ { j } ) _ { j \in \{ i \} \cup N _ { i } }$ ，且 $Y _ { i } = Y _ { i } ( H _ { i } )$ 。
• $H _ { 4 } { \mathrm { : } }$ **通用溢出效应（Generic spillovers）**。 $H _ { i } ( \mathbf { w } ) = \mathbf { w }$ ，且 $Y _ { i } = Y _ { i } ( \mathbf { W } )$ 。

上一段中关于处理效应结构的问题随后可以通过**零假设检验（null-hypothesis testing）**来形式化。例如，研究者可能首先想要检验零假设“ $H _ { 0 }$ ：无因果效应”，然后，如果该检验被拒绝，再检验“ $H _ { 1 }$ ：无溢出效应”，依此类推，直到找到一个在当前数据下未被拒绝的暴露映射。

我们的任务是开发方法来检验这些零假设中的每一个。在这里，我们将通过**置换检验（permutation testing）**来实现。我们将为 $H _ { 0 }$ 和 $H _ { 1 }$ 提出具体的检验方法，并给出一个可用于设计后续假设检验的通用结果。

置换检验的主要思想是选择一个检验统计量，然后以在提出的零假设下不应影响该检验统计量的方式打乱处理分配。根据构造，我们预期——如果零假设成立——那么基于原始数据计算的检验统计量应能舒适地落在打乱后获得的检验统计量范围之内；而如果原始检验统计量实际上是一个离群值，我们将此视为反对零假设的证据。

**注 11.1.** 在下面的讨论中，我们将为各个假设开发检验方法。似乎上述方案，即我们依次检验假设直到一个无法被拒绝为止，需要进行多重检验校正。然而，这里实际上不存在多重检验的问题，因为所有的零假设都是嵌套的，并且根据**闭合检验原则（closed testing principle）**[Marcus, Peritz, and Gabriel, 1976]，从最严格到最不严格的零假设依次运行检验直到其中一个无法被拒绝（然后停止），这一过程同时对所有零假设都是有效的。

**检验尖锐零假设** 我们首先考虑针对无因果效应零假设 $H _ { 0 }$ 设计一个置换检验。这是一个“尖锐”零假设，因为它完全指定了处理如何影响结果（即，完全不影响），因此可以使用 Fisher [1935] 的经典方法来处理：我们首先选择一个在零假设不成立时可能取较大值的检验统计量，例如：

$$
T \left(\mathbf {Y}, \mathbf {w}\right) = \left| \frac {\sum_ {\{i : w _ {i} = 1 \}} Y _ {i}}{| \{i : w _ {i} = 1 \} |} - \frac {\sum_ {\{i : w _ {i} = 0 \}} Y _ {i}}{| \{i : w _ {i} = 0 \} |} \right|, \tag {11.4}
$$

然后，如果基于已实现处理向量计算的检验统计量，相对于我们本可能（但实际上未）获得的其他处理随机化下的检验统计量值异常地大，我们就拒绝零假设。实现该方法的一个重要事实是，在 $H _ { 0 }$ 下，处理对结果没有影响，因此

$$
T \left(\mathbf {Y}, \mathbf {w}\right) = T \left(\mathbf {Y} (\mathbf {w}), \mathbf {w}\right) \text {for all} \mathbf {w} \in \{0, 1 \} ^ {n}, \tag {11.5}
$$

这意味着——同样在零假设下——我们能够推算在不同处理随机化下本会计算出的实际检验统计量。

**假设 11.2.** 处理是根据**完全随机化设计（completely randomized design）**分配的：存在一个可能的处理向量集合 $\mathcal{W}$ 位于 $\{ 0 , 1 \} ^ { n }$ 上，使得对于所有 $\mathbf { w } \in \mathcal { W }$ ，有 $\mathbb{P} [ \mathbf { W } = \mathbf { w } ] = 1 / \left| \boldsymbol { \mathcal { W } } \right|$ ，且与潜在结果独立。

**定理 11.1.** 假设假设 11.2 成立。任选一个检验统计量 $T \left( \mathbf { Y } , \mathbf { W } \right)$ 和置换次数 $B \leq | \mathcal { W } | - 1$ ，并令 $\mathbf { W } _ { 1 } ^ { \prime } , \ldots , \mathbf { W } _ { B } ^ { \prime }$ 是从 ${ \mathcal { W } } \backslash \mathbf { W }$ 中均匀随机且无放回地抽取。那么，置换 $p$ 值 $^{63}$

$$
p = \frac {1}{1 + B} \left(1 + \sum_ {b = 1} ^ {B} 1 \left(\{T (\mathbf {Y}, \mathbf {W}) \leq T (\mathbf {Y}, \mathbf {W} _ {b} ^ {\prime}) \}\right)\right) \tag {11.6}
$$

对零假设是有效的，即在 $H _ { 0 }$ 下，对于所有 $0 \leq \alpha \leq 1$ ，有 $\mathbb { P } \left[ p \leq \alpha \right] \leq \alpha$ 。

**证明.** 令 ${ \mathcal { W } } ^ { \prime } = \{ \mathbf { W } , \mathbf { W } _ { 1 } ^ { \prime } , \dots , \mathbf { W } _ { B } ^ { \prime } \}$ 是所考虑的置换的无序集合。根据假设 11.2，在 $H _ { 0 }$ 下，

$$
\mathbb {P} \left[ \mathbf {W} = \mathbf {w}   |   \mathbf {W} \in \mathcal {W} ^ {\prime},   \mathbf {Y} \right] = \frac {1}{1 + B} \text { for all } \mathbf {w} \in \mathcal {W} ^ {\prime}. \tag {11.7}
$$

因此，记 $\mathcal { T } ^ { \prime } = \{ T ( \mathbf { Y } , \mathbf { w } ) : \mathbf { w } \in \mathcal { W } ^ { \prime } \}$ 为所考虑的检验统计量的集合，我们看到，在条件于 $\mathbf{Y}$ 和 $\mathbf { W } \in \mathcal { W } ^ { \prime }$ 的情况下，已实现的检验统计量值 $T \left( \mathbf { Y } , \mathbf { W } \right)$ 在 $\tau ^ { \prime }$ 内均匀取值。由此可知，在假设 11.2 和 $H _ { 0 }$ 下，如果 $\tau ^ { \prime }$ 中没有并列情况，则 (11.6) 中的 $p$ 在 $\{ 1 / ( 1 + B ) , 2 / ( 1 + B ) , \ldots , 1 \}$ 上均匀随机取值，而并列情况只会使 $p$ 严格更大。□

**检验干扰** 下一个问题是设计一个针对 $H _ { 1 }$ 的检验，即检验 **SUTVA** 是否成立，或者是否存在溢出效应的证据。首先，我们同样需要选择一个能够有效衡量与零假设偏差的检验统计量——实现这一点的方法有很多。遵循 Aronow [2012] 的方法，我们在这里考虑这样一种检验统计量：它首先选择一个**焦点单位（focal units）**集合 ${ \mathcal { F } } \subset \{ 1 , \ldots , n \}$ ，并将 $T = T _ { \mathcal { F } } \left( \mathbf { Y } , \mathbf { w } \right)$ 设置为某个仅考虑焦点集合内结果的预先指定的函数。例如，在相信溢出效应仅会真正体现在未处理单位上的设定中（例如示例 11 中的信息干预），一个自然的选择是使用回归中的 $z$ 系数作为我们的检验统计量：

$$
T _ {\mathcal {F}} \left(\mathbf {Y}, \mathbf {w}\right) = \operatorname{OLS} \left(Y _ {i} \sim z _ {i}: i \in \mathcal {F}, w _ {i} = 0\right), \quad z _ {i} = \sum_ {j \in \mathcal {N} _ {i}} w _ {j} / | \{\mathcal {N} _ {i} \} | \tag {11.8}
$$

然而，在这一点上，我们面临一个挑战。在检验尖锐零假设时，(11.5) 使我们能够在 $H _ { 0 }$ 下为任何处理分配 $\mathbf{w}$ 计算反事实检验统计量。但现在，在 $H _ { 1 }$ 下，处理可以通过直接效应影响结果，因此我们只能得到较弱的保证：

$$
T _ {\mathcal {F}} (\mathbf {Y}, \mathbf {w}) = T _ {\mathcal {F}} (\mathbf {Y} (\mathbf {w}), \mathbf {w}) \text {if} w _ {i} = W _ {i} \text {for all} i \in \mathcal {F}. \tag {11.9}
$$

因此，在设计针对 $H _ { 1 }$ 的置换检验时，我们只能考虑那些在焦点集合上与已实现处理 $\mathbf{W}$ 相匹配的处理分配 $\mathbf{w}$ 。这样做需要更精细的方法，这将在下面给出的通用结果中阐述。

**注 11.2.** 对于任何基于焦点单位的方法，我们需要焦点单位集合 $\mathcal { F }$ 既不能太大也不能太小，以便 $T$ 具有检验功效。如果焦点单位集合 $\mathcal { F }$ 太小，回归 (11.8) 将充满噪声；而如果焦点单位集合 $\mathcal { F }$ 太大，则允许的、在 $\mathcal { F }$ 上保持处理分配不变的置换集合将太小，从而再次导致检验功效的损失。 $\mathcal { F }$ 的最优大小将取决于具体应用。

**复合零假设的置换检验** 在我们的设定中，**复合零假设（composite null）**是指任何允许 $\mathbf{W}$ 对 $\mathbf{Y}$ 有某种影响，但限制这些效应如何表现的零假设。为了理解如何为复合零假设设计置换检验，回顾一下使我们的 $H _ { 0 }$ 检验有效的要素是有帮助的：

1.  我们对随机化设计的了解使我们能够创建一个可能的处理分配集合 $\mathcal { W } ^ { \prime }$ （其中包含已实现的分配）。
2.  在零假设下，对于所有 ${ \textbf { w } } \in \mathcal { W } ^ { \prime }$ ，有 $T ( \mathbf { Y } ( \mathbf { w } ) , \mathbf { w } ) \ = \ T ( \mathbf { Y } ( \mathbf { W } ) , \mathbf { w } )$ ，因此我们可以仅使用观察到的结果 $\mathbf { Y } = \mathbf { Y } ( \mathbf { W } )$ 来推算在替代随机化下本会观察到的反事实检验统计量 $T ( \mathbf { Y } ( \mathbf { w } ) , \mathbf { w } )$ 。
3.  在条件于我们在步骤 1 中选择了集合 $\mathcal { W } ^ { \prime }$ 的情况下， $\mathbf{W}$ 在 $\mathcal { W } ^ { \prime }$ 上的分布是均匀随机的。

这里的关键步骤是步骤 2；并且在尖锐零假设 $H _ { 0 }$ 下，很容易看出我们总是可以从 $\mathbf{Y}$ 为任何检验统计量 $T$ 和任何处理向量 $\mathbf{w}$ 推算 $T ( \mathbf { Y } ( \mathbf { w } ) , \mathbf { w } )$ 。

相比之下，在复合零假设下，我们将不再能够为所有 $\mathbf{w}$ 推算任何和所有的检验统计量，因为处理现在可以对结果产生某些（受限的）影响。通过更谨慎地选择 $T$ 和所考虑处理的集合 $\mathcal { W } ^ { \prime }$ ，我们仍然能够取得进展；然而，这样做会在上述步骤 3 中带来微妙的挑战。

为通用复合零假设 $H$ 设计置换检验的总体路线图包括：首先观察已实现处理 $\mathbf{W}$，然后选择一个替代处理分配集合 $\mathcal { W } ^ { \prime }$ ，该集合允许我们在 $H$ 下推算检验统计量 $T$。以下结果给出了此类置换检验的通用保证。

**定理 11.2.** 假设我们想要检验一个复合零假设 $H$，并且假设 11.2 成立。在观察到 $\mathbf{W}$ 后，我们选择一个（可能随机的）处理向量集合 $\warrow \subseteq \warrow$，其中 $\mathbf { W } \in \mathcal { W } ^ { \prime }$ ，以及一个（可能随机的）检验统计量，该统计量具有以下性质：在 $H$ 下，对于所有 $\mathbf { w } \in \mathbf { W }$ ，有 $T ( \mathbf { Y } ( \mathbf { w } ) , \mathbf { w } ) =$ $T ( \mathbf { Y } ( \mathbf { W } ) , \mathbf { w } )$ 。令

$$
\varphi_ {\mathbf {w}} \left(\mathcal {W} ^ {\prime}, T\right) = \mathbb {P} \left[ \mathcal {W} ^ {\prime}, T \mid \mathbf {W} = \mathbf {w} \right] \tag {11.10}
$$

表示在给定已实现处理向量为 $\mathbf{w}$ 的条件下，选择处理集合 $\mathcal { W } ^ { \prime }$ 和检验统计量 $T$ 的概率。那么，重新加权的置换 $p$ 值

$$
p = \frac {\sum_ {\mathbf {w} \in \mathcal {W} ^ {\prime}} \varphi_ {\mathbf {w}} \left(\mathcal {W} ^ {\prime} , T\right) 1 \left(\left\{T (\mathbf {Y} , \mathbf {W}) \leq T (\mathbf {Y} , \mathbf {w}) \right\}\right)}{\sum_ {\mathbf {w} \in \mathcal {W} ^ {\prime}} \varphi_ {\mathbf {w}} \left(\mathcal {W} ^ {\prime} , T\right)} \tag {11.11}
$$

对零假设是有效的，即在 $H$ 下，对于所有 $0 \leq \alpha \leq 1$ ，有 $\mathbb { P } \left[ p \leq \alpha \right] \leq \alpha$ 。

**证明.** 对 $( \mathcal { W } , T )$ 的选择仅基于对 $\mathbf{W}$ 的了解，并且受限于必须满足 $\mathbf { W } \in \mathcal { W } ^ { \prime }$ 的约束。因此，根据假设 11.2，我们可以使用贝叶斯法则来验证，在条件于知道 $\mathcal { W } ^ { \prime }$ 被选为所考虑的随机化集合且 $\mathbf{Y}$ 被观察到的情况下，

$$
\mathbb {P} \left[ \mathbf {W} = \mathbf {w} \mid \mathcal {W} ^ {\prime}, \mathbf {Y} \right] = \varphi_ {\mathbf {w}} \left(\mathcal {W} ^ {\prime}, T\right) / \sum_ {\mathbf {w} ^ {\prime} \in \mathcal {W} ^ {\prime}} \varphi_ {\mathbf {w} ^ {\prime}} \left(\mathcal {W} ^ {\prime}, T\right) \tag {11.12}
$$

对于所有 $\mathbf { w } \in \mathcal { W } ^ { \prime }$ 成立。后续证明与定理 11.1 中使用的论证完全相同。令 $T$ 如定理 11.1 证明中所定义，并令 $S _ { ( 1 ) } \geq S _ { ( 2 ) } \geq . . . \geq S _ { ( | \mathcal { W } ^ { \prime } | ) }$ 为检验统计量的顺序统计量，其对应的权重 $\varphi _ { ( 1 ) } , \ldots , \varphi _ { ( | \mathcal { W } ^ { \prime } | ) }$ 用于 (11.11)。如果 $\tau$ 中没有并列情况

$$
\mathbb {P} \left[ p \leq \alpha   |   \mathcal {W} ^ {\prime},   \mathbf {Y} \right] = \max \left\{t = \sum_ {j = 1} ^ {k} \varphi_ {(j)} / \sum_ {j = 1} ^ {| \mathcal {W} ^ {\prime} |} \varphi_ {(j)}: t \leq \alpha \right\}, \tag {11.13}
$$

而并列情况的存在再次只会使 $p$ 严格更大。□

**应用：检验 $H _ { 1 }$** 我们现在回到如何使用检验统计量 (11.8) 为存在干扰设计一个置换检验的问题。使用定理 11.2 中的符号，基于焦点单位的检验统计量的可推算性质 (11.9) 意味着我们可以将它们与置换集合结合使用：

$$
\mathcal {W} ^ {\prime} \left(\mathcal {F}\right) = \left\{w \in \mathcal {W}: w _ {i} = W _ {i} \text {   for   all   } i \in \mathcal {F} \right\}. \tag {11.14}
$$

然后定理 11.2 直接适用。剩余的挑战是，我们现在需要考虑权重 $\varphi _ { \mathbf { w } } ( \mathcal { F } ) = \mathbb { P } \lceil \mathcal { F } \rceil \mathbf { W } = \mathbf { w } \rceil$ ，它衡量了我们对焦点单位的选择与已实现随机化之间的依赖关系。原则上，我们可以计算这些量并直接应用 (11.11)；然而，在现有文献中，大多数提议都寻求通过构造来避免考虑权重的 $\mathcal { F }$ 选择。

Athey、Eckles 和 Imbens [2018a] 讨论了一种规避此挑战的方法，即在不观察 $\mathbf{W}$ 的情况下，确定性地选择焦点单位集合 $\mathcal { F }$ 。在这种情况下， $\mathbb { P } \lceil \mathcal { F } \rceil \mathbf { W } = \mathbf { w } \rceil = 1$ ，权重消失，因此可以忽略。然而，这种方法在检验功效方面可能不是最优的；例如，如果我们使用 (11.8) 作为检验统计量，那么将任何已处理单位包含在 $\mathcal { F }$ 中似乎没有价值（因为它们被检验统计量忽略了）。

Basse、Feller 和 Toulis [2019] 指出，在某些设定中，我们也可以构造随机化的选择 $\mathcal{F}$，使得权重 $\varphi _ { \mathbf { w } } ( \mathcal { F } )$ 消失——并且这有助于提高检验功效。主要思想是，如果我们能保证对于所有 $\mathbf { w } \in \mathcal { W } ^ { \prime }$ ， $\varphi _ { \mathbf { w } } ( \mathcal { F } )$ 是常数，那么我们可以忽略权重，因为它们在 (11.11) 中相互抵消。例如，考虑一种设计，其中所有单位首先被分成大小相等的簇 $C _ { k }$ （ $k = 1 , \ldots , K$ ），然后我们将 $n _ { 1 }$ 个单位随机分配到处理组，使得每个簇中最多有一人被处理，即我们在以下集合上运行一个完全随机化实验：

$$
\mathcal {W} = \left\{\mathbf {w} \in \{0, 1 \} ^ {n}: \sum_ {i} w _ {i} = n _ {1}, \sum_ {\{i \in C _ {k} \}} w _ {i} \leq 1 \text { for all } 1 \leq k \leq K \right\}. \tag {11.15}
$$

然后，如果我们通过从每个簇中恰好选择一个对照单位来构造 $\mathcal{F}$，可以验证实际上对于所有 $\mathbf { w } \in \mathcal { W } ^ { \prime }$ ， $\varphi _ { \mathbf { w } } ( \mathcal { F } )$ 是常数。

## 11.3 参考文献注释（Bibliographic notes）

在干扰（interference）条件下，使用扩展的**潜在结果（potential outcomes）**集合来建模因果效应的一般方法，可追溯到 Halloran 和 Struchiner [1995]、Hudgens 和 Halloran [2008] 以及 Sobel [2006] 的早期工作。使用**暴露映射（exposure mappings）**来缓解**维度灾难（curse of dimensionality）**的方法由 Aronow 和 Samii [2017] 以及 Manski [2013] 引入。

第 11.2 章中使用的因果推断范式，即专注于检验各种限制处理如何影响潜在结果的**零假设（null hypotheses）**，通常被称为“**费舍尔方法（Fisherian approach）**”，以表彰 Fisher [1935] 在**排列检验（permutation testing）**方面的开创性工作。费舍尔方法与“**奈曼方法（Neymanian approach）**”形成对比，后者侧重于估计**平均处理效应（average treatment effects）**（而非对潜在结果的精确限制）——这也是本书大部分内容所关注的方法。当需要区分时，**严格零假设（sharp null）**（例如，对所有 $i$ 有 $Y_i(0) = Y_i(1)$）通常被称为**费舍尔零假设（Fisher null）**，而通常的（或弱的）零假设（例如，$\sum_i (Y_i(1) - Y_i(0)) = 0$）被称为**奈曼零假设（Neyman null）**；进一步的讨论参见 Ding [2017]。

我们对干扰下排列检验的讨论改编自 Athey、Eckles 和 Imbens [2018a] 以及 Basse、Feller 和 Toulis [2019]。本章中我们未过多强调的排列检验的一个方面是**检验统计量（test statistic）**的选择：我们仅仅使用了在各种备择假设下可能非零的量的点估计，例如 (11.4) 中的均值差。排列检验在严格零假设下是精确的，无论我们如何选择检验统计量。然而，检验统计量的选择会影响我们在各种感兴趣的备择假设下获得的**检验功效（power）**，而基于处理效应点估计的检验统计量（例如 (11.4) 中使用的均值差）可能表现得出乎意料地差。

为了理解功效问题，考虑在以下设定中排列检验的大样本行为：

$$
\binom {Y _ {i} (0)} {Y _ {i} (1)} \sim \mathcal {N} \left(\binom {\mu_ {0}} {\mu_ {1}}, \left( \begin{array}{c c} \sigma_ {0} ^ {2} & 0 \\ 0 & \sigma_ {1} ^ {2} \end{array} \right)\right), \tag {11.16}
$$

且 $n_1 / n = \pi \in (0, 1)$。原始数据上的均值差检验统计量具有分布 $T_0 = \mathcal{N}(\mu_1 - \mu_0, \sigma_T^2 / n)$，其中 $\sigma_T^2 = \sigma_0^2 / (1 - \pi) + \sigma_1^2 / \pi$。通常的 t 检验会在比值 $\sqrt{n} T_0 / \sigma_T$ 远离 0 时拒绝零假设。另一方面，由于排列检验会打乱数据，可以验证 $T_b'$ 的行为依赖于混合数据的矩，并且排列分布可以近似为 [Romano, 1990]：

$$
\mathcal{L}(T_b') \approx \mathcal{N}(0, \sigma_Y^2 / n), \quad \sigma_Y^2 = \pi(1 - \pi)(\mu_1 - \mu_0)^2 + \frac{(1 - \pi)\sigma_0^2 + \pi\sigma_1^2}{\pi(1 - \pi)}, \tag{11.17}
$$

因此，实际上，排列检验在 $\sqrt{n} T_0 / \sigma_Y$ 远离 0 时拒绝零假设。我们可以从这种比较中直接读出排列检验的几种意外行为。如果 $\sigma_0^2 = \sigma_1^2$ 且 $\mu_1 \neq \mu_0$（即处理改变了均值但未改变方差），则 $\sigma_Y^2 > \sigma_T^2$，因此排列检验的功效将低于通常的 t 检验。另一方面，使用均值差检验统计量的排列检验，在奈曼零假设（即平均效应为零）成立的设定中可能具有非平凡的检验功效，即它们通常（即使在渐近意义上）对奈曼零假设无效。为了理解这一点，注意当 $\mu_1 = \mu_0$、$\pi < 0.5$ 且 $\sigma_1^2 > \sigma_0^2$ 时，$\sigma_Y^2 < \sigma_T^2$，因此排列检验必须比通常的 t 检验具有更高的功效（而通常的 t 检验在此处具有名义水平）。

解决这个问题——并普遍改进排列检验的大样本行为——的一种方法是使用**学生化检验统计量（studentized test statistics）**，例如，使用**双样本 t 统计量（two-sample t-statistic）**代替 (11.4)，或使用**异方差稳健回归 t 统计量（heteroskedasticity-robust regression t-statistic）**代替 (11.8)。Chung 和 Romano [2013] 的结果表明，至少在定理 11.1 的设定中，使用学生化检验统计量的排列检验，在对严格（费舍尔）零假设具有有限样本有效性的同时，在大样本中匹配了通常检验针对奈曼零假设（即平均处理效应为零）的行为。Cohen 和 Fogarty [2022] 讨论了关于统一奈曼方法和费舍尔方法以检验因果效应存在性的进一步结果。
