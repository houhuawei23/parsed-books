### 2.1 问题意识与问题导向 ⭐【高频考点】

**核心论断**（必须记忆）：

| 来源  | 原文                          |
| --- | --------------------------- |
| 习近平 | **"理论创新只能从问题开始"**           |
| 习近平 | **"问题是时代的声音"**              |
| 习近平 | "科技攻关要坚持问题导向，奔着最紧急、最紧迫的问题去" |

**三个层次的问题导向**：
- 卡点堵点问题（制约构建新发展格局和推动高质量发展）
- 痛点难点问题（发展环境和民生领域）
- 焦点热点问题（有悖社会公平正义）

**方法论意义**：抓住问题 = 抓住具体与关键；问题意识需与**把握机遇**相结合。

---

### 2.2 分析与综合 ⭐⭐

#### （一）基本定义

| 方法 | 定义 | 方向 |
|------|------|:---:|
| **分析** | 在思维中把对象分解为各个部分、方面、属性、阶段，分别加以研究考察 | 整体→部分 |
| **综合** | 在思维中把各部分按内在联系有机统一为整体，掌握全貌、本质和规律 | 部分→整体 |

#### （二）辩证关系（核心考点）

> 分析是研究，**综合是创造**。

| 关系类型 | 具体内涵 |
|----------|----------|
| 相互渗透 | 分析的目的是为了在思维中综合认识对象 |
| 相互转化 | 综合以分析为基础，没有分析的综合不是深刻的综合 |
| 不可分割 | 构成认识事物**部分与整体**辩证关系的完整过程 |

---

### 2.3 归纳与演绎 ⭐⭐

#### （一）基本定义与对比

| 维度       | 归纳                                             | 演绎          |
| -------- | ---------------------------------------------- | ----------- |
| **方向**   | 个别→一般                                          | 一般→个别       |
| **推理性质** | **或然性**推理（非必然）                                 | **必然性**推理   |
| **局限性**  | "归纳问题"——结论不完全                                  | 无法推进新发现、新发明 |
| **经典引用** | "单凭观察所得的经验，决不能充分证明必然性"——恩格斯                    |             |
|          | "以最简单的归纳方法获得的最简单的真理，<br>总是不完全的，因为经验总是未完成的"——列宁 |             |

#### （二）辩证关系

> "归纳和演绎，正如综合和分析一样，必然是相互关联的。"——恩格斯

- **归纳是演绎的基础**
- **演绎为归纳确定合理性和方向**
- 相互渗透、相互转化

---

### 2.4 从抽象到具体 ⭐⭐

#### （一）两个关键概念

| 概念       | 定义                                               |
| -------- | ------------------------------------------------ |
| **抽象**   | 从许多事物中舍弃个别的、非本质的属性，<br>抽出共同的、本质的属性的过程，是形成概念的必要手段 |
| **感性具体** | 人们面对客观事物本身所获得的感性表象                               |
| **理性具体** | 反映事物本质规定的、与科学实践相结合的理论内容                          |

#### （二）两次飞跃（核心考点）


第一次飞跃：感性的现实具体 ──→ 思维抽象
-   （建立在实践基础上的经验总结提升）

第二次飞跃：科学的思维抽象 ──→ 理性的思维具体
 - （把抽象概念和理论返回科学实践，赋予理论具体内容）


> 经典引用："从生动的直观到抽象的思维，并从抽象的思维到实践，这就是认识真理、认识客观实在的辩证途径。"——列宁

---

### 2.5 历史与逻辑的统一 ⭐⭐

#### （一）概念辨析

| 概念     | 定义                                            |
| ------ | --------------------------------------------- |
| **历史** | 重视历史过程与事物演化的思维方式；过程研究方法                       |
| **逻辑** | 反映理性要求的思维规则和形式；以抽象为基本特征；<br>基本形式：**概念、判断、推理** |

#### （二）双重统一（核心考点）

| 统一的内涵 | 具体要求 |
|------------|----------|
| **思维的逻辑进程与客观的历史进程相统一** | 历史起点 = 逻辑起点；历史进程 = 逻辑进程；按历史发展的必然性揭示规律 |
| **思维的逻辑进程与思维的历史进程相统一** | 逻辑进程是对思维历史进程的概括；思维历史进程是逻辑进程的基础 |

#### （三）方法论意义

> 使科学家与工程师：**既横向又纵向**把握科学技术研究的脉络和前景；既具有理性缜密的思维修养，也具有宏观开阔的全局视野和战略思维。

### 3.1 核心总论

> **"惟创新者进，惟创新者强，惟创新者胜。"**——习近平

- 创新 = 思维要素的辩证组合与重新配置
- 创造性思维 + 批判性思维 = **互补**关系
- 创新思维核心特征：在具有对立方向的特性之间**保持张力**

---

### 3.2 收敛性与发散性 ⭐⭐

| 维度     | 收敛思维            | 发散思维           |
| ------ | --------------- | -------------- |
| **别名** | 聚合思维/求同思维/集中思维  | 放射思维/求异思维/扩散思维 |
| **方向** | 集中于同一方向         | 沿各种不同途径        |
| **目的** | 条理化、简明化、逻辑化、规律化 | 探求多种答案         |
| **目标** | 旨在取得结果          | 创造性思维最重要的特点之一  |

#### 辩证关系

> **只发散，不收敛，劳而无功；只收敛，不发散，难有创造。**
>
> 只重视其中一个 → 形而上学思维；两者结合 → 辩证思维。
>
> 在收敛中注意发散，在发散中注意收敛——**保持张力**。

---

### 3.3 逻辑性与非逻辑性 ⭐⭐

#### （一）创造性思维的特性

> 创造性思维不是独立的思维形式，而是**能够提出创见的思维**。

**五大特点**：
- 思维方向的**求异性**
- 思维结构的**灵活性**
- 思维进程的**飞跃性**
- 思维效果的**整体性**
- 思维表达的**新颖性**

> 核心：**逻辑思维与非逻辑思维的辩证统一、抽象思维与形象思维的辩证统一**

#### （二）逻辑性方面

- 演绎、类比推理、归纳
- **类比推理**在科学发现与创造中作用很大——从已知跨越到未知的桥梁
- 类比推理是**或然性推理**

#### （三）非逻辑性方面

| 形式 | 说明 |
|------|------|
| 联想 | 知识经验的重新组合 |
| **想象** | 对知识、经验、方法重新组合的思维活动；**爱因斯坦：想象力比知识更重要**；常常触发"灵感" |
| 隐喻 | |
| 灵感 | |
| 直觉与顿悟 | 创造性成果突现方面尤为突出 |

#### 辩证关系

> 非逻辑思维**开拓思路**，逻辑思维**整理思路**，完成创新的理性建构。
>
> 非逻辑思维之前也有逻辑思维（比较、分类、归纳等）为其作铺垫准备。

---

### 3.4 直觉与顿悟 ⭐

| 维度     | 直觉                                | 顿悟                            |
| ------ | --------------------------------- | ----------------------------- |
| **定义** | 不以人类意志控制的特殊思维特性，<br>基于职业、阅历、知识和本能 | 长期思考未果时，<br>突然获得解决问题思路的豁然开朗状态 |
| **特性** | 直接性、迅捷性、**或然性**                   | 突发性、诱发性、偶然性、极度快乐感             |

---

### 3.5 思维的批判性 ⭐

**定义**：以批判性思考的方式**质疑和评估**思考过程与结果。

**核心技巧**：提出**探索性问题**。

| 对比 | 非批判性思考 | 批判性思考 |
|------|:----------:|:--------:|
| 对他人观点 | 不假思索轻易接受 | 质疑准确性，追问隐藏含义，扩展深度广度 |

**特征**：
- 认识固有观念可能有错
- 对思维、结论和研究过程作**实践、逻辑的检验**
- 识别和避免思维中的**常见谬误**

---

### 3.6 移植、交叉与跨学科研究方法 ⭐⭐

#### 当代背景

> "科学研究向极宏观拓展、向极微观深入、向极端条件迈进、**向极综合交叉发力**"——习近平

#### （一）移植方法

| 类型 | 说明 |
|------|------|
| 概念移植 | |
| 对象移植 | 把其他学科的方法/研究方式移到新领域 |
| 方法或技术移植 | |

#### （二）学科交叉方法与跨学科方法

| 方法 | 定义 | 关键区别 |
|------|------|----------|
| **学科交叉方法** | 两门或以上学科方法研究同一对象，从不同学科角度对比研究 | 借鉴其他学科→思考**本学科**问题 |
| **跨学科方法** | 跨越学科界限，多学科协作共同解决同一问题 | 多学科融合（多维融贯） |

#### （三）社会认识辩证方法

**核心问题**（最重要）：
1. 说明与解释的关系
2. 人及其社会关系这一复杂系统变量的解释
3. **客观性与以人为本的主体性的辩证关系**

### 4.1 数学方法及其作用 ⭐

> "数学：辩证的辅助手段和表达方式。"——恩格斯

**数学方法的本质**：
- 关注事物的**形式和抽象结构**，抽象表达事物的空间关系与数量关系；
- 把不确定性尽量转为确定性；
- **精准思维**的具体方法。

| 方法类型 | 核心说明 |
|----------|----------|
| **数学方程方法** | 把关键关系抽象出来建立数学模型（如洛特卡-沃尔泰拉方程） |
| **数学建模方法** | 模型是科学抽象，数学模型比实物模型更能反映内在抽象关系 |
| **数学统计方法** | 对总体数量、类型及其关系的认识方法 |
| **数学实验方法** | 计算机+数学方法，理想化的数学实践，丰富了实验概念 |

---

### 4.2 系统方法及其作用 ⭐⭐

> "必须坚持系统观念。万事万物是相互联系、相互依存的。"——习近平

#### （一）系统分析与系统综合

| 方法       | 定义                                         |
| -------- | ------------------------------------------ |
| **系统分析** | 对系统进行分解，对要素进行分析，找出可行方案的思维方法                |
| **系统综合** | 把对象看作系统综合体，对要素、层次、结构、功能、联系方式、发展趋势等进行辩证综合考察 |

> 系统综合强调：从系统**整体**出发，综合和分析同步进行，以**综合统摄分析**。

#### （二）硬系统与软系统方法论

| 类型 | 适用场景 | 特点 |
|------|----------|------|
| **硬系统分析** | 问题确定、任务范围完全确定 | 明确规则与方法，可用技术手段操作 |
| **软系统分析** | 问题不够明确、任务范围无法完全确定 | "软问题"无法精确定义，采取现实与模型对应方式 |

#### （三）反馈与控制方法

| 概念      | 定义                                                   |
| ------- | ---------------------------------------------------- |
| **反馈**  | 将系统的输出返回到输入端，以某种方式改变输入，进而影响系统功能                      |
| **负反馈** |                                                      |
| **正反馈** |                                                      |
| **控制**  | 对事物起因、发展及结果的**全过程**把握；核心是在系统视野中处理好**控制主体与控制客体**的辩证关系 |

#### （四）信息方法

> 运用信息观点，把系统运动过程看作**信息传递和信息转换**的过程，通过对信息流程的分析和处理获得规律性认识。

**优点**：不割断系统联系，通过流经系统结构的信息考察结构和功能及变化发展。

---

### 4.3 复杂性思维及其方法 ⭐⭐

#### （一）复杂性思维

| 维度        | 说明                   |
| --------- | -------------------- |
| 时间        | 20世纪90年代以后，伴随复杂性科学兴起 |
| 对立面       | 简单性思维                |
| 核心特征      | **多样性、相关性、整体性**      |
| 与马克思主义的关系 | 在更高层次上体现当代马克思主义的辩证思维 |

#### （二）复杂性方法的六大考察特性


① 自组织性 → 注意事物自我发展演化，不过分和直接干预
② 多样性   → 多个侧面认识和把握对象
③ 融贯性   → 历史考察与逻辑认知统一，多样性与统一性统一，整体与部分统一
④ 整体性   → 首先作为整体考察，力图超越还原论
⑤ 协同性   → 研究对象各方面的协同研究
⑥ 相关性   → 内部因素关系、与环境关系、核心与大量因素的相互作用


**方法论特征**：集多学科或跨学科的**多维融贯**方法；侧重定性判断与定量计算、微观分析与宏观分析、还原论与整体论、科学推理与哲学思考的**结合**。

**理论来源**：耗散结构理论、协同学、突变论、混沌理论、超循环理论等。

---

### 4.4 战略性思维及其方法 ⭐⭐

#### （一）战略性思维

> "要善于进行战略思维，善于从战略上看问题、想问题。"——习近平

**定义**：高瞻远瞩、统揽全局、善于把握事物发展**总体趋势和方向**的思维方法。

**决定因素**：思考问题的**高度** + 理论研究的**深度** + 知识视野的**广度** + 对全局**时间跨度**的认识与把握

#### （二）战术性思维

> 在具体操作层面，具体问题具体分析，一定要**细致**。

#### （三）战略与战术的辩证统一

> "战略和策略是辩证统一的关系，要把战略的坚定性和策略的灵活性结合起来。"——习近平

| 只有战术/策略 | 只有战略 |
|:---:|:---:|
| 站不高、看不远 | 无法具体展开研究 |

#### （四）顶层设计

> 最高层次的思考，力图在最高层次上寻求问题解决之道；采取**自上而下**的办法。

**要素**：战略目标、战略重点、优先顺序、主攻方向、工作机制、推进方式、总体方案、路线图、时间表

### 5.1 科学实践的方法 ⭐⭐

#### （一）科学观察

| 维度     | 内容                                             |
| ------ | ---------------------------------------------- |
| **定义** | 有目的、有计划地感知和描述**自然状态**下的客观事物                    |
| **特点** | ①有理性目标的感性活动；<br>②有目的有计划；<br>③**不干预**自然状态下的研究对象 |

#### （二）科学实验

| 维度     | 内容                                                                   |
| ------ | -------------------------------------------------------------------- |
| **定义** | 在**人为控制或变革**客观事物的条件下获得科学事实                                           |
| **特性** | ①纯化和简化观察对象；<br>②强化对象及其条件；<br>③**可重复性**；<br>④可模拟研究对象属性及变化；<br>⑤较为经济可靠 |

**与观察的关键区别**：实验既有观察的内容与任务，也有**介入自然对象**的可控实践任务。

#### （三）机遇

> 在科学研究中能够通过意外事件把握机会而导致科学上的新发现，称为**机遇**。把握机遇是科学研究的**创造性能力**。

#### （四）观察、实验与理论的辩证关系 ⭐⭐⭐【核心考点】

| 观点流派       | 主张                     | 评价                |
| ---------- | ---------------------- | ----------------- |
| 逻辑经验主义     | 观察是中性的，理论依赖观察，观察不受理论制约 |                   |
| "观察渗透理论"   | 观察受理论制约                | 曾为主流，导致逻辑实证主义衰落   |
| 科学实验哲学（新近） | **实验有自己独立的生命**         | 反对实验完全负载理论        |
| **马克思主义**  | 观察/实验与理论**双向相互作用**     | 实验比理论更具基础地位、更积极活跃 |

> **马克思主义核心观点**：
> - 实验的新发现不断推动理论进步、修正理论、指引理论发展
> - 理论一旦建立，就**规范着实验**，为实验设计提供理论框架和指导

#### （五）科学仪器的作用

> 科学仪器是科学技术发展的**"倍增器""指示剂"和"先行官"**。

马克思：使用什么劳动资料进行生产 → 划分经济时代的**指示器**。

#### （六）科学实验室与人工自然——四大作用

| 作用 | 说明 |
|------|------|
| ① **建构**特定的微观人工世界 | 规避现象本性所包含的巨量复杂性 |
| ② **隔离和突出**研究对象 | 隔离外部影响，突出建构现象中的若干要素 |
| ③ **操纵和介入** | 科学家不是袖手旁观者，而是**行动者、参与者和实践者**；不仅是"看"，更重要的是**"做"** |
| ④ **追踪**微观世界 | 从最初建构到全程控制，使微观世界事件变成可观察现象 |

### 5.2 技术活动的方法 ⭐⭐

#### （一）技术思维与科学思维的五大区别（核心考点）

| 编号  | 维度   | 科学思维         | 技术思维                                     |
| :-: | ---- | ------------ | ---------------------------------------- |
|  1  | 关注点  | 更关注**普遍性**   | 更关注**可行性**                               |
|  2  | 价值取向 | 更关注**创造性**   | 更关注**价值性**                               |
|  3  | 限制性  | 没有限制，可任凭思维跳跃 | **限制性思维**，在已有原理基础上思考如何实现                 |
|  4  | 思维类型 |              | **联系性思维**（两极思维），联通科学理论↔技术实际，要求"**顶天立地**" |
|  5  | 系统性  |              | **系统思维**，多方面协同、整体要求                      |

#### （二）技术活动方法的五种类型

| 方法类型         | 核心内容                                                                                  |
| ------------ | ------------------------------------------------------------------------------------- |
| **① 技术构思方法** | 对设计对象进行结构、功能和工艺构思；<br>分为**经验方法**（模仿创新、技术改制）和**科学方法**<br>（原理推演法、科学实验提升法、模型模拟法、移植法、回采法） |
| **② 技术发明方法** | 创造人工自然物的方法；代表：**TRIZ**（发明问题解决理论），<br>从10万份专利中提炼出40种基本措施和53种成对/成组措施                    |
| **③ 技术试验方法** | 对技术思想、技术设计、技术成果进行探索、考察、检验的实践活动                                                        |
| **④ 技术预测方法** | 三种基本类型：**类比性预测、归纳性预测、演绎性预测**                                                          |
| **⑤ 技术评估方法** | 按机构：内部评估/外部评估；按时间：前期/中期/后期/事后评估                                                       |

> TRIZ 精髓：离不开**辩证思维和生活实践**，需要在不同方法之间保持思维张力。

## 📌 六、思考题参考答案要点

### 6.1 马克思主义科学技术方法论与科学研究中具体方法的关系？

- 马克思主义科学技术方法论以**辩证唯物主义**为基础
- 是对具体科学研究方法的**概括和升华**，而非替代
- 将**辩证法贯彻**到科学技术研究中
- 将辩证思维与系统思维**渗透**到具体研究过程中
- 是一种**元方法论**层面的指导

### 6.2 辩证思维如何渗透在科学研究的全部过程中？

- 从**问题导向**开始（起点）
- **分析与综合**：认识事物部分与整体的辩证关系
- **归纳与演绎**：个别↔一般的推理
- **从抽象到具体**：两次飞跃贯穿整个研究过程
- **历史与逻辑的统一**：构建理论体系的规定性
- 在创新中体现**收敛与发散、逻辑与非逻辑**的张力

### 6.3 如何把握创造性思维特性？

- 五大特性：求异性、灵活性、飞跃性、整体性、新颖性
- 两大辩证统一：逻辑思维与非逻辑思维、抽象思维与形象思维
- 关键：在**对立方向之间保持张力**
- 创造性思维 + 批判性思维 = 互补
- 非逻辑开拓思路 + 逻辑整理思路

### 6.4 多学科交叉与融贯的方法论意义？

- 当代科学研究"向极综合交叉发力"
- 克服单一学科局限，获得创新成果
- 体现了**广泛联系和发展**的辩证法
- 移植方法实现方法的跨域运用
- 跨学科/多维融贯体现整体性思维

### 6.5 战略性思维对科学研究的意义？

- 决定科学研究能**登多高、走多远、抵达何处**
- 取决于：思考高度、理论深度、知识广度、时间跨度
- 战略与战术**辩证统一**——战略的坚定性+策略的灵活性
- 顶层设计提供最高层次的系统谋划
- 使科学家在科学研究的总体布局中找到自己的定位

| 战略与战术 | 战略坚定性+策略灵活性；辩证统一 |

### 7.3 易混淆概念辨析

| 易混淆 | 区分 |
|--------|------|
| 科学观察 vs 科学实验 | 观察不干预自然状态；实验人为控制/变革条件 |

| 技术构思 vs 技术发明 | 构思结构/功能/工艺 vs 创造人工自然物 |
| 抽象 vs 感性具体 vs 理性具体 | 舍弃非本质抽出本质 vs 感性表象 vs 本质规定+实践 |
