## 二、第一节：毛泽东思想中的科学技术观

### （一）科学技术创新观

#### 1. 科学的本质与特征

| 维度       | 核心内容                       |
| :------- | :------------------------- |
| **本质定位** | **知识论**角度：科学是**知识的结晶**     |
| **两大分类** | 自然科学（生产斗争知识）+ 社会科学（阶级斗争知识） |
| **双重属性** | 自然属性（无阶级性）+ 阶级属性（利用时有阶级性）  |

**四大特征**（记忆口诀：**真实发统**——真理性、实践性、发展性、系统性）：

| 特征 | 核心论点 | 经典引文 |
|:---|:---|:---|
| **客观真理性** | 正确反映客观世界本质与规律，经得起检验 | “许多自然科学理论之所以被称为真理…在于为尔后的科学实践所证实的时候” |
| **系统性** | 系统化的知识体系，按内在联系组成有机体 | — |
| **发展性** | 理论随实践不断发展 | “实践是发展的，理论也应是发展的” |
| **实践性** | 产生于社会实践，又指导社会实践 | “人的正确思想，只能从社会实践中来” |

> **三大实践来源**：生产斗争、阶级斗争、**科学实验**

#### 2. 技术的本质与特征

| 维度       | 核心内容                             |
| :------- | :------------------------------- |
| **本质定位** | **实践论**角度：技术是认识和改造客观世界的**手段和方法** |
| **三大特征** | 客观实在性、工具性、**群众性**（技术革命是全民运动）     |

#### 3. 科学研究观（四大要点）

| 要点       | 核心内涵                        |
| :------- | :-------------------------- |
| **勇于创新** | “破除迷信、解放思想、敢于革新传统、敢于攀登高峰”   |
| **科学态度** | “严肃的态度、严格的要求、严密的方法”（三严）     |
| **调查研究** | “没有调查，没有发言权”；“详细地占有材料，抓住要点” |
| **哲学指导** | 唯物辩证法是唯一确实的、有客观正确性的方法论      |

> **两种错误倾向**：
> - **“代替论”**：夸大哲学，认为靠哲学原理就能推演出科学结论
> - **“实证论”**：否认哲学指导作用

#### 4. 科学技术的四大社会功能

| 功能         | 核心论点                                    |
| :--------- | :-------------------------------------- |
| **生产力功能**  | “科学技术这一仗，一定要打…不搞科学技术，生产力无法提高”           |
| **军事政治功能** | 搞尖端技术，避免“挨打”                            |
| **认知功能**   | “自然科学是人们争取自由的一种武装”；<br>必然王国→自由王国；扫除愚昧迷信 |
| **革命功能**   | **技术革命与社会革命相结合**；通过提高生产力变革生产关系          |

> ⭐ **核心论断**：“中国只有在社会经济制度方面彻底地完成社会主义改造，又在技术方面…统统使用机器操作，才能使社会经济面貌全部改观。”

### （二）科学技术人才观

| 要点        | 核心内容                               |
| :-------- | :--------------------------------- |
| **内涵（质）** | **“红”与“专”**：政治（红，第一位）+ 业务（专，内行）    |
| **外延（量）** | “数量足够的、优秀的科学技术专家”                  |
| **重视作用**  | “无产阶级没有自己的庞大的技术队伍和理论队伍，社会主义是不能建成的” |
| **培养教育**  | 党领导 + 又红又专 + **与工农结合**             |
| **使用管理**  | **团结信任 → 尊重优待 → 关心爱护**（三位一体）       |

> ⭐ 知识分子与工农结合的三重意义：
> ①了解工农才能服务；
> ②把书本马克思主义变成自己的；
> ③站稳立场、掌握科学方法。

### （三）科学技术发展观

| 要点               | 核心内容                                   |
| :--------------- | :------------------------------------- |
| **“百家争鸣”方针**     | 科学上不同学派自由争论，是科学发展的必由之路                 |
| **独立自主、自力更生**    | 根本立足点；但也要**批判性地学习**国外成果                |
| **技术革新 vs 技术革命** | 革新=具体技术改革；<br>革命=历史上重大技术改革（蒸汽机、电力、原子能） |

> ⭐ **经典论述**：“我们不能走世界各国技术发展的老路，跟在别人后面一步一步地爬行。我们必须打破常规，尽量采用先进技术。”

## 七、核心概念辨析

### 1. 三次“第一”的递进
- 邓小平：**科学技术是第一生产力**（经济层面）
- 江泽民：科技是**先进生产力的集中体现和主要标志**
- 习近平：**创新是引领发展的第一动力**（发展层面）+ **人才是第一资源** + 发展是第一要务 = **“三个第一”**

### 2. 从“跟跑”到“领跑”
- 毛泽东时代：跟跑（“赶上世界先进水平”）
- 邓小平时代：跟跑+并跑（“在世界高科技领域占有一席之地”）
- 习近平时代：跟跑→并行→**领跑**（“进入创新型国家前列”）

### 3. 技术革新 vs 技术革命（毛泽东）
- **技术革新**：每一具体技术改革
- **技术革命**：历史上重大技术改革（蒸汽机→电力→原子能）

### 4. “代替论” vs “实证论”（毛泽东）
- **代替论**：哲学可以直接推演出科学结论（夸大哲学）
- **实证论**：否认哲学对科学的指导作用（否定哲学）

## 九、思考题答题框架

### 1. 不同历史时期科技观的继承与创新关系

**答题逻辑**：分述三阶段 → 对比继承点与创新点

- **继承**：
	- ①都坚持马克思主义基本原理与中国科技实践结合；
	- ②都坚持党对科技事业的领导；
	- ③都重视科技的生产力功能和人才作用；
	- ④都坚持独立自主与开放学习结合
- **创新**：①从“向科学进军”→“科教兴国”→“创新驱动发展”（战略升级）；②从“又红又专”→“尊重知识”→“人才是第一资源”（人才理念演进）；③从无伦理意识到系统化科技伦理治理（反思性增强）

### 2. 如何理解理论精髓？

从**六大特征**展开：时代性（与时俱进）、实践性（立足国情）、科学性（规律把握）、创新性（继承创新）、人本性（人民立场）、反思性（伦理自觉）

### 3. 习近平科技观的时代意义？

①适应“强起来”的时代要求；②应对新一轮科技革命与产业变革；③引领高质量发展和中国式现代化；④推动构建人类命运共同体
